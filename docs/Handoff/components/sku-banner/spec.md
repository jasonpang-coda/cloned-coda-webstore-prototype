# Sku Banner

> Read-only L1 pane summarizing one SKU (art + amount + bonus breakdown), with an optional corner tag — grounded in OrderCompletePage's Order Summary banner. NOT a reuse of SkuCard/SkuImageCard, which are both full interactive product cards (click-to-checkout, hover/press states); this is purely presentational. amountText/bonusText arrive pre-formatted from the caller, same contract as TransactionCard's date/total.

**Generated Component Spec from Story Harness.** Generated deterministically from the component's story declaration. Regenerate with `node scripts/export-handoff.mjs --story sku-banner`.

## Usage Rules
- amountText is required; image, bonusText and tagLabel are all optional.
- Does no number formatting itself — the caller formats amount/bonus into display strings.
- Border uses the same mask-composite gradient-ring technique as SkuCard/BundleItem, not a plain border-color.
