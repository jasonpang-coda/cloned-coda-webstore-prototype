# CODM SKU Card 3.0 — v0.1.0

**First prototype release** · 2 June 2026

The inaugural cut of the Call of Duty: Mobile store prototype — a responsive,
motion-rich storefront built to validate the SKU Card 3.0 design direction across
phones and the responsive web. This release establishes the foundation: a
container-query layout system, device-frame previews, a full component set, and a
documented motion language.

---

## Highlights

- **Three preview modes** — step through an iPhone 17 Pro Max frame, a Samsung Galaxy S25+ frame, or a frameless responsive view.
- **Container-query responsiveness** — the layout adapts to the *screen*, not the browser window, so framed previews reflow exactly as a real device would.
- **A real motion language** — entrance cascades, an HDR running border, a story slideshow, and a shimmer sweep, all driven by shared design tokens.
- **Two hero patterns** — a single best-seller card and a horizontally scrollable “recommendations” carousel, plus an Instagram-style story slideshow.
- **Engineering handover docs** — every component, token, and gotcha is written down.

---

## What’s included

### Layout & responsiveness

- 12-column `Grid` / `Span` system rebuilt on **CSS container queries** (breakpoints XS → L, down to 360 px).
- `Span size="content"` centers content to a half-width column on tablet and up; `size="fluid"` runs full-bleed (used by the nav bar).

### Device previews

- Registry-driven `DeviceFrame` — add a device by editing one object in `src/devices/index.js`.
- Realistic chrome: titanium edges, Dynamic Island, punch-hole camera, and side hardware buttons.
- Auto-scaling to fit the window, with the scrollbar hidden inside framed views.

### Components

| Component | Purpose |
|---|---|
| `NavBar` | In-app top bar with an animated Sign-in ↔ avatar toggle and scroll-aware hide/show |
| `SkuCard` / `SkuList` | The core product tile and its titled, staggered list |
| `PromoBanner` | Image banner for promotional sections |
| `BestSellerCard` | Full-bleed hero with an animated OKLCH border and breathing bloom |
| `BestSellerCarousel` | Horizontal recommendations row with intelligent chevron navigation |
| `StoryCarousel` | Instagram-style slideshow — tap to navigate, auto-advance, loop |
| `MaterialIcon` | Any Google Material icon, tinted to `currentColor` |

### Motion & effects

- Project motion tokens (`--motion-sku-*`) layered over a base motion library.
- Effects: HDR conic **running border**, breathing **bloom**, image **shimmer** sweep, and a gentle story **crossfade**.
- Auto-advancing story progress bars driven entirely by CSS — no JavaScript timer.
- Full `prefers-reduced-motion` support throughout.

### Typography

- Ships the static **Hitmarker** cuts, horizontally condensed to match the design’s display width.
- Prices and story headings standardized on the “heading/modal” style — 20 px, uppercase.

### Documentation

- `docs/motion-tokens.md` — the complete motion catalog.
- `docs/component-breakdown.md` — front-end handover, with props tables for all 12 components.
- `docs/README.md` — navigation and quick reference.

---

## Known limitations

- Photographic best-seller and banner art still reference **Figma asset URLs**, which expire after 7 days — swap for local or CDN assets before any shared deploy.
- Data is **static demo content** in `App.vue`; there is no API layer yet.
- This is a **prototype** — not production-hardened, untested below 360 px, and not yet audited for screen-reader flow beyond reduced-motion.

---

## Tech stack

Vue 3 (`<script setup>`) · Vite 5 · Tailwind 3 · plain scoped CSS with design tokens.
