# CODM SKU Card 3.0 — v0.1.1

**Polish & production-readiness release** · 2 June 2026

This release addresses four production issues found after v0.1.0 and adds two significant
new features — a navigation drawer and a horizontally scrollable best-seller carousel with
inertial physics. All motion follows the established token system.

---

## What's new

### Nav drawer
A left slide-in navigation drawer opens from the navbar hamburger. The panel covers 7 of 8
grid columns (87.5%), revealing one column of frosted scrim as the dismiss target. Content
follows the Figma `4261:4492` design: a MENU header with close button, an expandable STORE
accordion (Gifts · CP), and a flat Code Redemption item.

The overlay is mounted via a new `#overlay` slot on `DeviceFrame` — it covers the device
screen without scrolling with page content. Framed mode clips to the screen's rounded
corners; responsive mode uses an `absolute`-within-`relative` approach (avoids the
`position:fixed` / CSS transform containing-block bug).

### Horizontally scrollable best-seller carousel
The recommendations carousel now scrolls by swipe (native `touch-action:pan-x`) and by
mouse drag. Mouse drag uses a rAF-batched implementation with an EMA-smoothed velocity
tracker — layout metrics are cached at resize (not re-read every frame), so there is no
read-after-write thrash. On release, the scroll coasts with frame-rate-independent
friction (FRICTION 0.96) before settling. No scroll-snap — movement is free and physical.

## Improvements

- **CTA labels condensed** — SIGN IN and SHOP NOW are now horizontally condensed to
  `scaleX(0.82)` via an inner `<span>`, matching the rest of the UI. The button box and
  border are never scaled.
- **Global letter-spacing +0.5%** — `letter-spacing: 0.005em` added to `body` as a baseline,
  closing the gap between browser rendering and the Figma design across all text.
- **Story slide crossfade** — the heading and CTA button now crossfade with the image on
  each slide transition (previously they snapped while the image dissolved).
- **Carousel card width** — updated to 87.5% (7 of 8 columns) for a better thumb-reach
  proportion; `max-width: 360px` keeps it from growing too wide on larger viewports.

## Bug fixes

### Material icons missing on Vercel
**Root cause:** `import.meta.glob('/node_modules/**/*.svg', {query:'?url'})` resolves
correctly in dev (Vite serves `node_modules` as a virtual path) but produces dead
`/node_modules/…` URLs in a production build — which aren't deployed to Vercel's file
system, causing 404s.

**Fix:** Replaced the glob with explicit `?url` imports for the six used icons
(`account_circle`, `chevron_left`, `chevron_right`, `close`, `expand_more`, `expand_less`).
Bare-specifier `?url` imports are emitted as hashed assets in `dist/assets`. Icons under 4 KB
inline as `data:image/svg` URIs — no external fetch at all. Bundle size dropped from ~1.5 MB
to ~103 KB.

### Drawer exit animation not playing
**Root cause:** Vue `<Transition>` measures leave duration from the root element's own CSS
`transition` property. `.nav-drawer` had no `transition` set, so Vue read 0 ms and unmounted
the element immediately — bypassing the children's CSS transitions.

**Fix:** Added `:duration="{ enter: 350, leave: 200 }"` to the `<Transition>` element so
Vue holds the DOM node for the full leave duration.

### Drawer header hidden in responsive mode
**Root cause:** The overlay used `position: fixed`, but any ancestor with a CSS `transform`
(including `scale(1)`) creates a new containing block for fixed elements. The device frame's
scale transform caused the overlay to be positioned relative to the device rather than the
viewport.

**Fix:** Changed the responsive overlay to `position: absolute` inside a
`position: relative; min-height: 100dvh` wrapper — the same containment model as the framed
overlay, with no reliance on fixed positioning.

### Horizontal swipe blocked on device screen
**Root cause:** `.device__screen` had `touch-action: auto` (the default). A vertical scroll
container with `auto` intercepts ambiguous gestures, preventing the carousel's
`touch-action: pan-x` from receiving horizontal events.

**Fix:** Added `touch-action: pan-y` to `.device__screen`, explicitly declaring it owns
vertical panning. The carousel's `pan-x` now routes unambiguously.

## Token & design updates

- **`--bg-overlay`** corrected to `#0C0E16` (page colour at 60% opacity + `backdrop-filter:
  blur(64px)`), replacing the incorrect placeholder purple. Token is now defined in `style.css`.
- **Deleted `src/fonts/Hitmarker-VF.woff2`** — the variable font was unreferenced across the
  entire codebase (the static `HitmarkerNormal-*` cuts are used exclusively). Removing it
  eliminates 188 KB of dead weight and prevents future confusion.
- **`src/tokens/effects.css`** — added `.fx-skeleton` (shimmer loader placeholder for slow
  media) with companion `--motion-sku-skeleton: 1400ms` token.
