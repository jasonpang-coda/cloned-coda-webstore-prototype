# Release Notes — v0.10.0

**Date:** June 2026  
**Milestone:** FC Mobile whitelabel — full second-store implementation

---

## Highlights

- **FC Mobile store live** — a complete second whitelabel theme (`[data-theme="fcm"]`) ships alongside COD:M. One build, two stores; switch at runtime with no reload.
- **Multi-store architecture formalised** — four composables (`useTheme`, `useStoreConfig`, `useStoreStrings`, `useStoreCatalog`) centralise every per-store divergence so components stay theme-agnostic.
- **Six new FCM-only components** — `CategoryCatalog`, `FeaturedCarousel`, `SkuImageCard`, `BundleGrid`, `EaSignInPage`, `PageSignInSection` covering the filter-mode catalog page, FCM SKU display, and the EA sign-in flow.
- **Haptics system** — `useHaptics` composable + `v-haptic` directive + haptic token file added for mobile WebKit vibration feedback.
- **DeviceToolbar store switcher** — runtime theme toggle now lives in the prototype toolbar; `useTheme` composable writes `<html data-theme>` reactively.

## New store theme — FC Mobile (`fcm`)

### `src/tokens/ds/themes/fcm.css`
Complete token override layer for the EA SPORTS FC™ Mobile brand:

- **7 seeds** — EA green primary, red secondary/sign-in, muted neutrals; off-500 anchors for the green + red ramps
- **6 × 11-step spectrum ramps** — neutral, primary (green), secondary (red), tertiary, positive, caution, negative
- **L1/L2/L3 composited container surfaces** — dark navy/slate fill system; composited at 16% over the base
- **Typography** — Cruyff Sans (four cuts: `Regular`, `Medium`, `SemiBold`, `Bold`); `--sys-font-condense: 1` (no Hitmarker scaleX hack); tracking tokens zeroed
- **Brand overrides** — EA-red sign-in button (`--bg-action-signin`), green loyalty banner, flattened rarity tier (all → neutral gradient), MP loyalty icon integration
- **HDR boost** — green primary + EA-red boosted past L=1.0 in `@media (dynamic-range: high)`

### `src/stores/fcm/`
Full FCM asset directory: wordmark, CP/AP icons, MP Simple + Colour loyalty icons, payment channel SVGs (light + dark variants), SKU content images, story carousel frames, slide portraits/landscapes.

## New components

### `CategoryCatalog.vue`
Filter-mode catalog page for FCM (Figma `cat-catalog`). Replaces the COD:M linear scroll with a category-filtered grid.

- Top subcategory nav with horizontal scroll (all/daily-supplies/limited-offers/star-pass/top-ups/gifts)
- Grid switches between `SkuImageCard` (image-led, 2-col) and `BundleGrid` (bundle layout) depending on active category
- Category transition: `cat-fade-in/out` keyframe pair with per-item stagger; `cat-catalog` CSS transition on the wrapper
- Scroll position resets on category switch
- Driven by `useStoreCatalog` data layer

### `FeaturedCarousel.vue`
Hero image carousel (FCM top-of-page). Swipeable slide strip with portrait/landscape sources, chevron nav, and autoplay.

- Drag-scroll via `useDragScroll`; chevron hover animates (`featured-chevron` transition)
- Auto-advances every 5 s; pauses on hover/touch
- Slide images resolved from `useStoreAssets`

### `SkuImageCard.vue`
Image-led SKU card for the FCM catalog grid (Figma `sku-image-card`). Replaces the COD:M price-led `SkuCard` in filter mode.

- Full-bleed artwork + overlay price strip
- Rarity gradient via `--rarity-gradient-*` (collapses to neutral for FCM)
- Entrance: `sku-enter` token (shared with `SkuCard`); hover: lift + brightness; press: `sku-press` scale
- Background fade on hover (`sku-img-card__bg-overlay` opacity transition)

### `BundleGrid.vue`
Two-column bundle layout for FCM's bundle category (Figma `bundle-grid`).

- Accepts an array of bundle items; renders in a 2-col CSS grid
- Each cell is a `BundleItem` with image, title, price

### `EaSignInPage.vue`
Full-screen EA sign-in page (FCM only). Triggered when an unauthenticated user attempts checkout.

- EA-red action button (`--bg-action-signin`)
- `ea-page` CSS transition (slide-in from right; `ea-page-enter-active/leave-active`)
- Managed by `useAuth.eaSignInOpen` flag

### `PageSignInSection.vue`
In-page sign-in section for FCM (replaces `PlayerAccount` in non-COD:M stores). Shown when `useStoreConfig.showPageSignIn` is true.

- Static layout: wordmark + sign-in CTA + guest link
- Styled with FCM surface tokens; no guest lookup panel

## Multi-store architecture

### `useTheme.js` *(new composable)*
Single source of truth for `[data-theme]`. Holds `current` as a reactive `ref`; writes through to `<html data-theme>` on `setTheme()`. `useStoreAssets` derives its registry from this ref so imagery updates instantly on switch.

### `useStoreConfig.js` *(new composable)*
Structural capability flags per store (layout switches, show/hide flags, loyalty config). Components read flags — never test `theme === 'fcm'` directly.

| Flag | COD:M | FCM |
|---|---|---|
| `skuLayout` | `'stack'` | `'grid'` |
| `showCatalog` | `false` | `true` |
| `showPageSignIn` | `false` | `true` |
| `showLoyaltyBanner` | `false` | `true` |
| `guestFlow` | `true` | `false` |

### `useStoreStrings.js` *(new composable)*
User-visible copy that differs per store: currency name, sign-in CTA, nav section labels, category headings.

### `useStoreCatalog.js` *(new composable)*
FCM catalog data layer. Provides the category list and SKU/bundle data arrays consumed by `CategoryCatalog`. COD:M stores use `App.vue` demo data directly; FCM routes through this composable.

## Haptics system

### `src/tokens/haptics.js`
Haptic pattern constants (impact style + duration) matching iOS `UIImpactFeedbackGenerator` intensities: `light`, `medium`, `heavy`, `rigid`, `soft`.

### `useHaptics.js`
Composable wrapping `navigator.vibrate` + the WebKit `devicemotion`-style fallback. Exposes `haptic(pattern)` — no-ops gracefully when the API is absent or the user's device doesn't support it.

### `v-haptic` directive (`src/directives/vHaptic.js`)
Custom Vue directive. Usage: `v-haptic` (medium) or `v-haptic="'light'"`. Fires on `pointerdown`; safe to add to any interactive element.

- Lives in the prototype chrome only — product UI is unaffected
