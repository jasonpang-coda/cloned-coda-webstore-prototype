# Release Notes — v0.100.0

**Date:** September 2026
**Milestone:** SkuCard child-breakdown prop, Transaction History added to the toolbar Pages dropdown, library variant dropdown

---

## Highlights

- **`SkuCard.vue` gains an `items` prop.** Optional bundled child breakdown row — `[{ image, tileBg, tag, quantity }]`, default `[]` — rendered via the shared `BundleBreakdown` component, same pattern already used by `SkuImageCard`/`BestSellerCard`. Fixed a tag-layering bug in the same pass: `BundleItem`'s tag pill straddles `-8px` above its tile, and the card's own flex gap (4px default / 2px row layout) wasn't enough clearance — the pill's own stacking context painted over the bonus/subtitle text above it. Added `padding-top: var(--x-pad-surface-s)` to give it full clearance in both layouts.
- **`DeviceToolbar.vue`'s "Pages" dropdown gains Transaction History**, and its option list is now built additively instead of as a fixed-shape branch. Order Complete and Transaction History are each independently optional per store (`strings.page?.orderComplete` / `strings.transactionHistory`) — the old `if/else-if` only ever covered "has both" (COD:M) or "has neither," so FCM (Transaction History only, no Order Complete) had **no Pages dropdown at all** until this fix. `setPage` now explicitly closes whichever of the two view-switches isn't being opened, keeping them mutually exclusive now that both share one control.
- **`LibraryViewer.vue`'s Variant control switched from a segmented row to a dropdown** (`lib__select`, mirroring the existing Theme control) — stories now regularly ship 5+ variants, which no longer fit a `.lib__seg` row legibly.

## Changes

### `src/components/SkuCard.vue`

- New `items` prop, `BundleBreakdown` import, and `.sku-card__breakdown` styling (edge-to-edge bleed in column layout, no bleed in row layout, `padding-top: var(--x-pad-surface-s)` clearance for the child tag pill in both).
- Not forwarded to `openCheckout` — the breakdown is card-visual only, matching `SkuImageCard`/`BestSellerCard`.

### `src/library/stories/SkuCard.stories.js`

- Added "With child breakdown" and "With child breakdown (row)" variants, plus a `notes` line documenting the new prop.

### `src/components/DeviceToolbar.vue`

- `pageOptions` rebuilt additively (`storefront` + optional `order-complete` + optional `transaction-history`), replacing the fixed `config.home` / `strings.page?.orderComplete` either/or branch.
- `currentPage` reads `historyOpen` alongside `orderCompleteOpen`.
- `setPage` explicitly closes the other view-switch before opening one, keeping Order Complete and Transaction History mutually exclusive.

### `src/library/LibraryViewer.vue`

- Variant picker: `.lib__seg` segmented buttons → `<select class="lib__select">`, matching the Theme control's existing pattern.

### `docs/component-breakdown.md`

- Documented all of the above; bumped the "Last updated" footer.
