# Release Notes — v0.101.0

**Date:** September 2026
**Milestone:** Page navigation migrated to real vue-router routes — browser back/forward now work

---

## Highlights

- **Browser back/forward now work between pages.** Page switching (storefront ⇄ Order Complete ⇄ Transaction History ⇄ Codashop home/product) previously flipped in-memory composable refs with no URL/history involvement — the browser's back button did nothing or left the tab entirely. New `src/router.js` gives each page a real route (`/`, `/product`, `/order-complete`, `/history`) with real history entries.
- **`useTransactionHistory`/`useOrderComplete`/`useCodashopHome` are unchanged internally** — same refs, same `openX()`/`closeX()` API. `App.vue` gained a single route↔page-state sync watcher that is now the only place calling these composables' open/close functions; every other call site pushes a route instead. This keeps the design-harness's standalone story mounts (no router installed) working untouched.
- **Store-switch capability guard** — a `router.beforeEach` guard redirects to `/` when navigating (including via back/forward across a store switch) to a page the current store doesn't support, alongside the existing reactive `watch(strings)`/`watch(config.home)` safety nets (now route-aware).

## Changes

### `src/router.js` (new)

- `createRouter({ history: createWebHistory(), routes })` — `/` (storefront, also Codashop's home listing), `/product` (Codashop title/product page), `/order-complete`, `/history`. Route components are unused stubs (`{ render: () => null }`) — `App.vue` keeps its existing v-if/else-if chain, driven by `route.path`, rather than mounting via `<router-view>`.
- `beforeEach` guard redirects to `/` when the current store's `strings`/`config` don't support the target route.

### `src/main.js`

- `app.use(router)` wired into the `createApp(...)` chain.

### `src/App.vue`

- Added `useRoute()`/`useRouter()` and a `watch(() => route.path, …)` that syncs the 3 page composables to the current route (including on browser back/forward).
- `watch(strings)`/`watch(config.home)` store-switch safety nets now `router.push('/')` instead of calling `closeHistory()`/`closeOrderComplete()` directly.
- `goHome()` now `router.push('/')`.

### `src/components/DeviceToolbar.vue`

- `setPage()` now pushes the corresponding route instead of calling the page composables' open/close functions directly.

### `src/components/PurchaseSheet.vue`, `src/components/AccountPopover.vue`, `src/components/OrderCompletePage.vue`

- Navigation call sites (`onCheckoutConfirm()`, `goToHistory()`, the page's CTA buttons) now `router.push(...)` instead of calling `openOrderComplete()`/`openHistory()`/`closeOrderComplete()` directly.

### `docs/component-breakdown.md`

- Documented the router migration; bumped the "Last updated" footer.
