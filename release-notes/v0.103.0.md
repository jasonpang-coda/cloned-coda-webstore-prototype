# Release Notes — v0.103.0

**Date:** September 2026
**Milestone:** Device orientation (portrait/landscape) toggle for the iPhone/Android frame preview

---

## Highlights

- **Orientation toggle in the device toolbar.** A new rotate icon button (`screen_rotation_alt`) sits next to the device segment, letting a tester flip the framed preview between portrait and landscape. Scoped correctly to only appear for iPhone/Android — hidden on Responsive (no physical frame to rotate) and on real mobile (device picker itself is hidden there). State lives in a new singleton composable, `useOrientation.js`, mirroring `useDeviceFrame.js`'s pattern.
- **Hardware chrome physically rotates, not just the screen.** Landscape swaps `screenW`/`screenH` as before, but now the notch/punch-hole and side buttons also relocate to their correct rotated edge (90° CCW: top edge → left edge) instead of staying pinned to their portrait position. The status bar (time/battery/signal) hides outright in landscape, since the notch it anchors to has moved off the top edge and `safeTop` collapses to 0.
- **Smooth rotation transition.** Frame/screen dimensions and all repositioned hardware (notch, buttons) animate via this project's existing motion tokens (`--x-motion-sys-duration-slow` + `--x-motion-sys-ease-standard` — the "large on-screen surface move" pairing) instead of snapping instantly.

## Changes

### `src/composables/useOrientation.js` (new)

- Singleton `ref('portrait' | 'landscape')` + `toggle()`, same `globalThis`-pinned pattern as `useDeviceFrame.js`.

### `src/components/DeviceFrame.vue`

- `spec` computed now swaps `screenW`/`screenH` and zeroes `safeTop` in landscape.
- New `islandStyle()`/`punchStyle()` helpers reposition the notch/punch-hole to the left edge (vertically centered, footprint swapped) using a 90° CCW rotation mapping.
- `btnStyleLeft()`/`btnStyleRight()` reposition side buttons to the bottom/top edge respectively in landscape, with corner radii flipped to match.
- Status bar (`v-if`) now also gated on `!isLandscape`.
- CSS transitions added to `.device`, `.device__screen`, `.device__island`, `.device__punch`, and `.device__button` so the rotation animates rather than snaps.

### `src/components/DeviceToolbar.vue`

- New orientation toggle button, gated `v-if="!isMobile && device !== 'none'"`.

### `src/components/MaterialIcon.vue`

- Added `screen_rotation_alt` icon import + registry entry.

## Known limitations

- `useDeviceScale` only fits the frame to the window's *height* — a wide landscape frame can overflow a narrow browser window horizontally. Pre-existing limitation, not addressed here.
