# Release Notes — v0.104.0

**Date:** September 2026
**Milestone:** Shareable per-device preview URLs, a landscape overlay-notch fix, and a new download-banner handoff doc

---

## Highlights

- **Shareable per-device URL.** The device-frame preview now reads `?device=ios|android|responsive` (plus `&orientation=landscape`) off the URL at boot, so a link can point straight at a specific device/orientation instead of whatever the app happens to boot into. Switching device or orientation via `DeviceToolbar`/`CommandConsole` keeps the address bar in sync going forward — the URL is always a live, shareable snapshot of the current preview.
- **Landscape overlay no longer collides with the rotated notch.** In landscape the notch/punch-hole sits on the screen's left edge, vertically centered — square in the path of a tall sheet's own left edge. The device-frame overlay now insets its `left` edge to clear the rotated hardware automatically, with no per-sheet awareness needed, and the inset transitions in step with the rest of the rotation animation instead of snapping.
- **New download-banner handoff doc.** `docs/Handoff/download-banner/` specs the App Store/Google Play/PWA-install banner (COD:M primary) — every state, every resolved token across all 12 stores, and a cross-reference to the existing `pwa-web-push` handoff for the install CTA's own behaviour rather than re-deriving it.

## Changes

### `src/App.vue`

- New `DEVICE_QUERY_TO_INTERNAL`/`DEVICE_INTERNAL_TO_QUERY` maps translate between the URL's `ios`/`android`/`responsive` vocabulary and the internal `iphone`/`samsung`/`none` device keys.
- Reads `window.location.search` directly (not `route.query`, which hasn't resolved yet at this point in `setup()`) to seed `device`/`useOrientation().orientation` on load — query wins over the store-default device pick, but still loses to the `figmaCapture` override and the real-touch-device Responsive force.
- New `watch([device, orientation], ...)` calls `router.replace({ query })` on every change, keeping the URL in sync with the live preview state.

### `src/components/DeviceFrame.vue`

- New `overlayInsetLeft` computed: in landscape, adds the rotated notch/punch-hole's footprint to `.device__overlay`'s `left` inset (mirrors portrait's existing "sheet height leaves a top gap for the notch" convention, applied to the overlay's containing block instead).
- `.device__overlay` gained `transition: left` so the inset animates alongside the rest of the rotation instead of snapping.

### `docs/Handoff/download-banner/` (new)

- `README.md` — full state/behaviour matrix + token contract, generated with resolved values from `scripts/resolve-css.mjs` across all 12 registered stores (never hand-transcribed).
- `AGENTS.md` — agent entry point, cross-referencing `pwa-web-push/spec.md` for the PWA-install CTA's own state machine.
- `_skill/` — frozen snapshot of the generating `web-store-spec-handoff` skill.

## Known limitations

- The download-banner handoff has no `demo_url` / in-app `/handoff` surface — the feature is an inline `App.vue` template block, not a standalone component, so verification relies on visual parity against the running prototype rather than a live oracle.
