# Release Notes — v0.105.1

**Date:** September 2026
**Milestone:** Codashop homepage ink-token contrast fix — dark-on-dark headings and hero titles now render legible

---

## Highlights

- **Codashop's aggregator homepage (Standard/Visual/Blob layouts) had near-invisible headings, hero titles, and stat numbers.** Codashop's dark-card reskin (v0.10x era) flipped its neutral ramp so `--x-text-header-default`/`--x-text-body-default` now resolve light ink and `-inverse` resolves dark ink — the opposite of the theme's old light-card polarity. Several components in `src/components/home/` still carried comments and local overrides written for that old polarity, forcing `-inverse` (now dark) onto text sitting on the dark page/dark frosted cards. Verified in-browser pre- and post-fix on all three homepage layouts: section headings ("Top up in 3 easy steps", "Loved by millions"), hero titles ("RAINBOW SIX MOBILE — SILENT DESCENT", "EA SPORTS FC MOBILE"), and the count-up stat numbers ("1000+", "5★") all now render crisp white instead of near-black.
- Confirmed the fix doesn't need to generalize to other stores: `HomeStandard`/`HomeVisual`/`HomeBlob` are exclusively Codashop's aggregator-homepage layout shells (per `HomeView.vue`), and every other store's neutral ramp already uses the same default/inverse direction.

## Changes

### `src/components/home/HomeStandard.vue`

- `.home-standard__head h2`/`p`: swapped `--x-text-header-inverse`/`--x-text-body-inverse` → `-default`.
- Removed the stale `.home-standard__hero :deep(.story__heading)` override (and its now-incorrect "Codashop is the first LIGHT-card theme" comment) — `StoryCarousel`'s own default styling already resolves correctly now.

### `src/components/home/HomeVisual.vue`

- `--x-home-surface-text`/`--x-home-surface-text-sub` (consumed by `HomeStatBand`, `HomeFaq`, `HomeReviewRail`, `HomePayments`, `HomeCategoryCards`): swapped to `-default`, since the frosted surface (`--x-surface-ghost-4`, a white tint at low alpha over the dark page) reads dark, not light.
- `.home-visual__head h2`/`p`: swapped to `-default`.
- Removed the stale `.home-visual__hero :deep(.story__heading)` override, same reasoning as `HomeStandard`.

### `src/components/home/HomeBlob.vue`

- Removed the identical stale `.home-blob__hero :deep(.story__heading)` override.

### `src/components/home/HomeStatItem.vue`

- `.stat-item__value`: swapped to `-default`, matching the file's own doc comment ("in white with a soft glow").
