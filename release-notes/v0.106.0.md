# Release Notes — v0.106.0

**Date:** September 2026
**Milestone:** Codashop Home Blob layout — dark mode, redesigned trust-stats/steps sections, and a batch of mobile-responsive fixes

---

## Highlights

- **Home Blob goes dark.** Every card surface across the layout (`HomeBlobCard`, the pill nav, the editorial tail — stats/steps/reviews/payments/FAQ/newsletter) switched from a white squircle card to a dark one, with card text and icons repointed to a neutral light colour for contrast.
- **Trust stats and "how it works" are no longer plain reskins of the shared Standard/Visual components.** New `HomeBlobStats.vue`/`HomeBlobStatItem.vue` gives the trust band a slow-drifting purple/teal/gold gradient background and a bare glowing icon per stat; new `HomeBlobSteps.vue` gives each step its own gradient icon circle and splits the shared data's trailing "24/7 support" entry into a plain text line instead of forcing it into a 4th numbered card.
- **Highlighted Titles dropped its bento grid.** The old asymmetric layout (a tall card beside two stacked cards) and its dual-DOM mobile-rail/desktop-grid split are gone — the hero is now always its own full-bleed row, and the remaining titles share one responsive row (a horizontal drag-scroll rail on mobile, a plain 3-up grid at 801px+), matching `HomeBlobSpotlight`/`HomeBlobPicked`'s existing pattern. Row cards also switched from `size="featured"` to `size="panel"`, so their caption matches every other section's card font instead of standing out.
- **Consistent card sizing on mobile.** `HomeBlobCard`'s `panel` size (used by Spotlight/Picked/Highlights' row) now matches `rail`'s radius, padding, and image radius on small screens — every rail-style card across the layout reads as one consistent size, reset back to `panel`'s own larger values at 801px+.
- **A round of real mobile bugs fixed**, caught through live-browser measurement rather than assumption:
  - Several Home Blob sections (pill nav, card rails, the hero) were inset by a stray 36px on mobile — an uncancelled Grid-margin + section-padding stack that the rest of each section's rail already cancelled. Fixed consistently across `HomeBlobHighlights`, `HomeBlobSpotlight`, `HomeBlobPicked`, and `HomeBlobGenreRail` (the last needed a different fix — a deliberate 5/6-width nav wrapper set to full width on mobile only).
  - The navbar hamburger and locale icons were nearly invisible on the Home Blob layout: Blob's own theme scope repoints the shared neutral colour ramp onto its dark palette, so the navbar's "chrome inverse" icon colour resolved to a near-black tone indistinguishable from the navbar background. Fixed with a layout-scoped override restoring blob's actual light neutral.
  - The Spotlight/Picked-for-you blob shapes had a dead-flat bottom edge (a literal straight SVG line, rounded only at the corners) next to a genuinely curved top. Replaced with a shallow bulge and a matching `viewBoxHeight` bump so it renders without clipping.
  - Rail item width increased from ~240px/202px to 144px across every Home Blob rail, so mobile shows roughly 2.5 cards instead of 1.5.
  - The FAQ accordion's expand/collapse and hover/press states are now genuinely bouncy: a layered `scaleY` transform stands in for the reveal bounce grid-template-rows can't produce on its own (a single-row `Nfr` track can't numerically overshoot), tuned to a snappy back-out curve with no anticipation dip after an earlier attempt read as a stutter; hover and press now resolve to a real background fill instead of a no-op transform on transparent background.
  - Solid star icon for testimonial ratings (was an outline star), and the Payments section's heading/sub switched to the white text token.

## Changes

### New components

- `src/components/home/HomeBlobStats.vue`, `HomeBlobStatItem.vue` — bespoke trust-stats band (purple/teal/gold gradient, ambient drift, per-stat icon), replacing the shared `HomeStatBand` CSS-var reskin.
- `src/components/home/HomeBlobSteps.vue` — bespoke "how it works" cards (gradient icon circle, squircle card), replacing the shared `HomeSteps` CSS-var reskin. Renders only the first 3 items as cards; any items beyond that render as a plain text line.

### `src/components/home/HomeBlobCard.vue`

- Background switched to `--x-palette-home-blob-neutral-900` (dark), card name colour switched to `--x-palette-home-blob-neutral-0` (light) — was white card / purple-link-accent name.
- `panel` size's radius/padding/image-radius now match `rail`'s values by default (mobile), resetting to `panel`'s own larger 64px/16px values at `@container (min-width: 801px)`. `featured` (Highlighted Titles' hero only) is unaffected — kept as a deliberately distinct, prominent element.

### `src/components/home/HomeBlobHighlights.vue`

- Removed the bento grid (`__tall-wrap`/`__tall`/`__col`) and the dual-DOM `__rail`/`__desktop` mobile/desktop split.
- Hero is now always rendered in its own row (`__hero-wrap`), full-bleed on mobile via the same ancestor-margin cancel as the row below it.
- Remaining titles (`titles.slice(1, 4)`) render in one `__row` — a horizontal drag-scroll rail below 801px, a plain 3-up grid at 801px+ — using `size="panel"` instead of `"featured"`.
- Fixed a real bug from an earlier attempt at this: `ref` on `<TransitionGroup>` resolves to the component instance, not a DOM node, so `useDragScroll` threw `el.addEventListener is not a function` on every load. Fixed by moving the ref to a plain wrapping `<div>` with `TransitionGroup` nested inside it un-tagged, matching `HomeBlobGenreRail`'s existing correct pattern.

### `src/components/home/HomeBlobSpotlight.vue`, `HomeBlobPicked.vue`

- Row full-bleed on mobile fixed: `width: 100%` on a flex item whose parent uses `align-items: center` silently defeats a negative-margin bleed trick (the item's width locks to the pre-margin available space, and centring just adds equal blank space on both sides). Fixed by dropping `width: 100%` and using `align-self: stretch` instead.
- Row item width increased to 144px on mobile (was 240px).

### `src/components/home/HomeBlobGenreRail.vue`

- `.home-blob-genres__nav-wrap` set to full width on mobile (was a fixed 5/6 width + auto margin at every breakpoint), restored to 5/6 + centred at 801px+.
- Rail item width set to 144px on mobile, restored to its original 202px at 801px+ (this rail has no other mobile/desktop split).

### `src/components/home/HomeBlob.vue`

- `.home-blob` root's dark-mode surface tokens (`--x-home-surface-bg/-text/-text-sub`) repointed for the editorial tail (stats/steps/reviews/payments/FAQ/newsletter — though stats/steps are now bespoke components, not reskins).
- Newsletter card background switched to the same purple every other blob section uses; its Subscribe button switched to the app's actual secondary-button token pair.
- Payments section heading/sub switched to the white text token.
- FAQ accordion bounce and hover/press states, scoped via `:deep()` so `ItemSummaryAccordion`/`PromoCode` and FAQ on Standard/Visual are untouched:
  - Panel reveal and chevron rotation use a custom snappy back-out curve (no anticipation dip) instead of the shared elastic curve, which read as a pause/stutter.
  - A layered `scaleY` transform on the panel content produces the actual bounce, since `grid-template-rows` on a single-row track can't visibly overshoot.
  - Hover and press now set a real `background` fill (`AccordionHeader.vue` has no press-state background hook at all — only a barely-visible transform).

### `src/components/NavBar.vue`

- Hamburger/locale icon colour on the Home Blob layout repointed to `--x-palette-home-blob-neutral-0`, gated by `html[data-theme="codashop"][data-home-layout="blob"]` — was resolving near-invisible against the navbar background because Blob's theme scope remaps the shared neutral ramp onto its own dark palette.

### `src/components/MaterialIcon.vue`

- Registered `star_fill`, `sports_esports`, and `public` icons.

### `src/components/home/HomeReviewRail.vue`

- Rating stars switched from the outline `star` icon to `star_fill` (affects every store/layout, not just Home Blob — a general correctness fix for a ratings display).

## Verification

Every change verified live in the browser pane at both mobile (390px) and desktop (1440px) viewport widths via direct DOM measurement (not just visual inspection) — full-bleed insets confirmed at exactly `0–390px`, blob shape bulge confirmed unclipped via `getBBox()`, accordion bounce confirmed via sampled `transform` values showing genuine overshoot with no anticipation dip. `vite build` and the project's `preflight` token/pattern linter run clean after every change (aside from the pre-existing, explicitly-allowed `var(--token, #hex-fallback)` pattern). No console errors introduced.
