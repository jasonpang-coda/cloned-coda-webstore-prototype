# Release Notes — v0.107.0

**Date:** September 2026
**Milestone:** PWA gift-claim reset control + dynamic Web Push CTA on the download banner (COD:M)

---

## Highlights

- **A findable way to reset the PWA gift claim.** Previously the only way to retest the install→push→claim flow was to clear localStorage by hand, or open a claimed gift card / the task sheet with the `allowGiftUnclaim` flag on. The device toolbar's **Variants** section now has a plain "Reset claim" button, always visible on COD:M — disabled until the task-gated gift is actually claimed, enabled (and reactively re-disabling itself) once it is.
- **The download banner now reacts to Web Push state.** Its PWA row used to only ever offer "Install the COD:M Store," even after install, with nothing acknowledging Web Push at all. It now has three states: not installed → install CTA (unchanged); installed but not subscribed → a new "Turn on notifications" CTA wired to the existing Web Push toggle; already subscribed → the whole banner section hides itself, since there's nothing left to invite.

## Changes

### `src/components/DeviceToolbar.vue`

- Added a "PWA gift claim" field to the **Variants** segment: a full-width `Reset claim` button bound to `useTaskGiftClaim().unclaim()`, `:disabled` on `!taskGiftClaimed`. Shown whenever the active store defines `strings.page.giftTask` (COD:M today).
- Removed the earlier icon-button version of this control from the Tools row — consolidated into the single Variants field above.
- New `.toolbar__btn--full` style: full-width flex button matching `.toolbar__select--full`'s footprint, with its own disabled treatment (`opacity: 0.5`, `cursor: not-allowed`).

### `src/App.vue`

- `#download-banner`'s outer `v-if` now also requires `!webPushSubscribed` — the section hides entirely once the user has opted into Web Push.
- The PWA row gained a second branch: `pwaInstalled && strings.page.webPush` now renders a Web Push opt-in CTA (bell icon, `toggleWebPush()`) in place of the install CTA, only reachable while `webPushSubscribed` is still false (since the outer `v-if` removes the whole section once it flips true).

### `src/stores/codm/store.js`

- Added `webPush.downloadBannerCta: 'Turn on notifications'` — copy for the new download-banner Web Push CTA.

## Verification

Verified live in the browser pane: toggled `pwaInstalledState`/`simulateWebPushGranted` dev flags to walk all three download-banner states (install CTA → push CTA → banner hidden), and toggled `webstore:taskGiftClaimed` in localStorage to confirm the toolbar's Reset claim button flips from disabled to enabled and back, and that clicking it actually clears the persisted claim.
