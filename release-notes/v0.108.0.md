# Release Notes — v0.108.0

**Date:** September 2026
**Milestone:** Hover-measurement inspector reused in the handoff tab + a dedicated SEO Value-Prop Block handoff, collapsible handoff sidebar

---

## Highlights

- **The in-app handoff tab is now hover-interactive, not just a static token table.** The Components tab of `/handoff/<slug>` can retarget the existing `@coda/inspect-kit` element inspector at its own live component stage — an "Inspect" toggle turns on hover-to-highlight and click-to-select, opening the full resolved-token/measurement panel against whatever's staged, instead of only reading a pre-rendered table.
- **Figma-style spacing redlines**, new to `@coda/inspect-kit` itself (so the live storefront's own inspect mode gets this for free too): hovering any flex/grid element now shows its `gap` as a labeled magenta strip, and holding Alt while hovering a sibling of the current selection draws a distance line between them — both labeled with the matched design token *and* its raw resolved value (e.g. `var(--x-gap-content-default) · 8px`).
- **A new SEO Value-Prop Block handoff** (`/handoff/seo-block`) documenting the config-driven heading/body + benefit grid + FAQ accordion section (ZZZ and Diablo Immortal today) — token contract, presence-gated state diagram, and build order, with `HomeFaq` live-staged for the new hover inspection.
- **The handoff sidebar is now collapsible**, matching the component library viewer's existing collapse pattern — a chevron shrinks it to a slim icon rail (flows still switchable by their first letter) to reclaim width for the content panels.

## Changes

### `packages/inspect-kit`

- `src/vue/config.js` — config is now one stable object mutated in place (`Object.assign`) rather than reassigned, so a later partial `setConfig()` call (e.g. retargeting just `screenRoot`) no longer clobbers a host's earlier full configuration (`resolveSource`, `tokenRules`, etc.).
- `src/core/inspect.js` — new pure geometry helpers `computeGapStrips(el, tokens)` (flex/grid `gap` between DOM-adjacent in-flow children) and `computeDistanceTo(fromEl, toEl, tokens)` (axis-aligned edge-to-edge distance between two non-overlapping elements), both token-matched via the existing reverse token map.
- `src/vue/InspectorOverlay.vue` — renders the new gap/distance redlines in a colour distinct from the existing margin/padding box-model strips; tracks Alt/Option key state so the distance line only appears on demand, not on every hover.
- `src/vue/index.js` — exports `setConfig`/`getConfig` so a host surface (the handoff tab) can retarget the inspector at runtime.

### `src/handoff/components/TokenContract.vue`

- Retargets the global inspector's `screenRoot` to `.cstage__screen` (the Components tab's live stage) on mount, restoring the prior value on unmount.
- Adds an "Inspect" toggle, shown only when the active flow has at least one live-staged component.

### `src/main.js`

- Extended `chromeSelectors` with the handoff surface's own sidebar/topbar/tabs classes, so toggling inspect mode inside the handoff tab doesn't swallow clicks on its own navigation.

### `src/handoff/flows/seo-block.flow.js` (new)

- Documents the shared, config-driven SEO section (`strings.page.seo` + `storeAssets.content.seoTile`) spanning `src/App.vue`'s value-prop and FAQ sections: token contract per sub-block, a 12-state presence/breakpoint diagram, and build order — traced against ZZZ and Diablo Immortal, the only two stores populating it today.

### `src/handoff/HandoffApp.vue`

- Sidebar gains a collapse toggle (session-only, mirroring `LibraryViewer.vue`'s identical pattern) — collapsed state shows an icon-only rail so a flow stays switchable without expanding back out.

## Verification

Confirmed the handoff sidebar collapses to an icon rail and back with no console errors.
