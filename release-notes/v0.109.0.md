# Release Notes — v0.109.0

**Date:** September 2026
**Milestone:** Merged install/notify sheet — one variant-aware TaskGiftSheet replaces the standalone IosInstallSheet across every install/push touchpoint, plus a persistent drawer notification toggle

---

## Highlights

- **The drawer's notification row is now persistent** — no more two-step "install CTA, then (on reopen) a push toggle appears." One row, always visible; switching it on opens the merged sheet, which handles whatever the device actually needs.
- **TaskGiftSheet is now THE merged install/notify sheet.** Every install/enable-notifications touchpoint (drawer, download banner, gifts banner, story-slide CTA, the Gifts-category gift card, Order Complete banner) opens this one component. The standalone `IosInstallSheet.vue` is retired.
- **Content branches on a new `variant`** (`usePwaInstall.js`): `'ios'`, `'webview'`, or `'android'` — because eligibility genuinely differs by platform, confirmed via research rather than assumed:
  - **Android/Chromium** doesn't need install for Web Push at all (`subscribe()` works from a plain tab), so its step machine skips "install" entirely and states the single remaining requirement as prose instead of a checklist.
  - **iOS** needs install first (`PushManager` only exists for an installed PWA) — its checklist's step 1 opens inline media + numbered Add-to-Home-Screen steps, shown directly under the checklist (no tap required to reveal them — this is the actual "merge": the original standalone sheet's content, folded in, not hidden behind an extra interaction).
  - **In-app WebViews** (Instagram/TikTok/etc., detected via the new `useWebviewDetect.js`) can do neither from inside themselves — same 2-item checklist shape as iOS, generic "open in your browser" steps instead.
- **A divider + a small uppercase heading** ("How to Install COD:M Store" / "How to Open in Your Browser") now separate the checklist from the instructions section, so the two read as distinct parts of the sheet.
- **The signed-in PlayerAccount install link is removed** — one touchpoint fewer, not migrated.

## Changes

### `src/composables/useWebviewDetect.js` (new)

- UA-pattern detection for in-app browsers (Instagram, TikTok, Facebook, Line, WeChat, Twitter/X, Snapchat), OR'd with a new `forceWebviewInstallSheet` dev flag for previewing from any real browser.

### `src/composables/usePwaInstall.js`

- Adds `variant` (`'ios' | 'webview' | 'android'`) — the single source every touchpoint now reads instead of duplicating `shouldOfferIos` branching per call site.
- Removes the now-dead `showIosSheet` singleton ref (no consumer left once `IosInstallSheet.vue` was retired).

### `src/composables/useTaskGiftClaim.js`

- Step machine (`install → push → claim → claimed`) now skips `'install'` entirely when `variant === 'android'`.

### `src/components/TaskGiftSheet.vue`

- SKU reward banner always shown (MVP assumption: there's always a reward).
- Checklist shows 2 items for iOS/webview (with split labels — "Install the COD:M Store" vs. "Open in your browser"), or a single line of prose for Android.
- Install instructions (media + numbered steps, variant-specific copy) render inline under the checklist while `step === 'install'` — no tap-to-reveal detour.
- Footer CTA adapts per step/variant: "Got it" while instructions are showing, "Turn on notifications" for the push step, "Claim" once eligible.

### `src/components/NavDrawer.vue`

- Collapsed the old two-row model (install CTA row + separate push-toggle row) into one persistent row. Switching it on opens `TaskGiftSheet`; switching off calls `useWebPush().disable()` directly.

### `src/composables/useFeatureFlags.js`

- New `forceWebviewInstallSheet` dev flag (mirrors `forceIosInstallSheet`).

### `src/App.vue`

- Download-banner, gifts-banner, and story-slide "install" CTAs now all call `openTaskGiftSheet()` instead of branching on `shouldOfferIos`/`promptInstall` individually.
- Removed the `<IosInstallSheet>` mount and import.

### `src/components/PlayerAccount.vue`

- Removed the found-state PlayerCard's PWA install link and the now-unused `showPwaLink` prop entirely.

### `src/composables/useUrlState.js`, `src/composables/useCloseAllOverlays.js`

- The `?overlay=pwaInstall` deep link now opens `TaskGiftSheet` (kept under its original query name); the dead `showIosSheet` reset removed from `closeAllOverlays()`.

### `src/tourguide/flows/pwa-install.tour.js`

- Repointed at `useTaskGiftClaim`/`TaskGiftSheet`; the player-card step removed; the final step now opens the sheet and clicks its footer CTA to reach the install-instructions section for the walkthrough.

### Retired

- `src/components/IosInstallSheet.vue` and `src/library/stories/IosInstallSheet.stories.js` — deleted.
