# Release Notes — v0.11.0

**Date:** June 2026  
**Milestone:** Interactive handoff kit + Story Carousel live demo site

---

## Highlights

- **COD:M Story Carousel interactive handoff** — a deployable VitePress site that mounts the real `StoryCarousel.vue` component live with a token sandbox, choreography timeline, easing-curve viewer, and portrait/landscape frame toggle. Fully vendor-isolated (token cascade, fonts, slide images committed) so Vercel can build it from the subdirectory root.
- **Handoff Kit** (`docs/Handoff/_handoff-kit/`) — a copy-on-scaffold template that eliminates copy-pasting when creating future interactive handoff sites. One command scaffolds a complete new site; `--update` propagates kit fixes to existing sites without touching per-site authored content.
- **Two new generic demo primitives** — `TokenSandbox.vue` (live token editing harness: sliders, easing selects, chip readouts, reset) and `BeatTimeline.vue` (RAF scrub/play choreography harness with beat markers and speed control).
- **`web-store-interactive-handoff` skill** — a new AI skill that reads existing spec docs as a PRD and builds the interactive site via the kit, encoding all hard-won gotchas.

## Interactive handoff: Story Carousel

### `docs/Handoff/carousel-story-interaction/`

A self-contained VitePress site for the `StoryCarousel` interaction + motion spec.

**Pages:**
- Overview (home)
- Flow Spec, Motion Tokens, Typography, Component Breakdown (spec docs, unchanged)
- Playground — live interactive demo

**Playground widgets:**

| Widget | What it does |
|---|---|
| **Live token sandbox** (`CarouselPlayground.vue`) | Mounts the real `StoryCarousel.vue`. Three duration sliders (`--motion-sku-story`, `--motion-sku-story-fade`, `--motion-duration-slow`) + five easing selects + autoplay toggle + reduced-motion shim toggle + portrait/landscape frame toggle (crosses the `@container (min-width:801px)` breakpoint). Chip readouts of current token values. |
| **Slide-cycle timeline** (`SlideCycleTimeline.vue`) | Scrubs one full slide cycle (fill phase → animationend → crossfade) at 0.25×–2× speed. Three beat markers: segment fill start, advance trigger, crossfade complete. |
| **Easing curves** | SVG cubic-bezier visualisers for `--motion-ease-standard`, `--motion-ease-decelerate`, `--motion-ease-accelerate`, `--motion-ease-spring`. Respond live to easing selects in the sandbox. |

**Vendor model:**
- 11 token CSS files in cascade order (theme → system → semantics → space → text-styles → extensions → motion-sku → keyframes → effects → reduced-motion) via `scripts/sync-tokens.mjs` → `vendor/tokens/index.css`
- 10 Hitmarker font files (`vendor/fonts/`)
- 4 slide images (`vendor/img/`)
- `@font-face` URL rewrite in `handoff.config.mjs` so vendored `codm.css` points at `../fonts/`

**Documented shims:**
- `forceReduceMotion` prop — HANDOFF-ONLY addition to the vendored `StoryCarousel.vue`; the real component reads the OS `matchMedia` setting which can't be faked from UI
- `container-type: inline-size` on the demo stage element — required for the `@container` landscape rule to fire off the stage width, not the viewport

## Handoff Kit

### `docs/Handoff/_handoff-kit/`

A copy-on-scaffold template that future interactive handoff sites are built from.

```
_handoff-kit/
├── create-handoff.mjs        # scaffold + update script
├── README.md                 # usage, component APIs, update model, gotchas
└── template/                 # 17 files (package.json, vercel.json, VitePress config,
                              # theme, utils, generic components, placeholder pages)
```

**`create-handoff.mjs` modes:**

| Command | What it does |
|---|---|
| `node .../create-handoff.mjs <slug> "<Title>"` | Copies template into `docs/Handoff/<slug>/`, replaces `{{SLUG}}`/`{{TITLE}}` placeholders, prints next-steps. Refuses to overwrite. |
| `node .../create-handoff.mjs --update <slug>` | Re-copies only the 12 generic files into an existing site (propagates kit fixes). Never touches `handoff.config.mjs`, feature components, or markdown content. |

**`handoff.config.mjs`** — the one file that varies per site:
- `title` / `description` → VitePress config
- `pages[]` → nav + sidebar
- `vendor.tokens[]` + `vendor.urlRewrites[]` + `vendor.fonts[]` + `vendor.images[]` → `sync-tokens.mjs` manifest
- `tokenCatalog.durations[]` + `tokenCatalog.easings[]` → `TokenSandbox` defaults

The generic `sync-tokens.mjs` reads this config and generates `vendor/tokens/index.css` (ordered `@import` list) so the theme always imports a single entry point regardless of cascade depth.

**Generic kit files (re-copyable via `--update`):**

```
scripts/sync-tokens.mjs
.vitepress/config.mjs
.vitepress/theme/index.js       # auto-registers every *.vue in components/ by filename
.vitepress/theme/custom.css     # COD:M dark skin + VP font restore
.vitepress/theme/utils/tokens.js
.vitepress/theme/utils/bezier.js
.vitepress/theme/components/EasingCurve.vue
.vitepress/theme/components/TokenChip.vue
.vitepress/theme/components/TokenSandbox.vue   ★ new
.vitepress/theme/components/BeatTimeline.vue   ★ new
vercel.json
.gitignore
```

**Per-site files (never touched by `--update`):**
`handoff.config.mjs`, feature components (e.g. `CarouselPlayground.vue`), markdown content, `package.json`, `DEPLOY.md`, `vendor/`

### `TokenSandbox.vue` *(new generic primitive)*

The live token-editing harness. Reads `tokenCatalog` from `handoff.config.mjs` by default (overridable via props). Manages token overrides as CSS custom properties on its root element; provides `tokenRoot` for child `EasingCurve` components; renders duration sliders, easing selects, `TokenChip` readouts, and a Reset button.

Slot API:
- `default` → receives `{ values }` (`{ [tokenName]: Number|String }`) — the live demo stage
- `controls` → feature-specific toggles
- `hint` → footer note

### `BeatTimeline.vue` *(new generic primitive)*

RAF scrub/play harness. Decouples playback chrome (play/pause, speed select 0.25×–2×, scrub slider, clickable beat markers) from stage visuals. Stage renders as a **pure function of `{ ms, progress }`** passed via the default slot — no `requestAnimationFrame` in feature components.

Props: `beats` (`[{ ms, label }]`), `range` (total ms), `step` (scrub resolution).

## New skill: `web-store-interactive-handoff`

### `.claude/skills/web-store-interactive-handoff/SKILL.md`

5-phase playbook for building an interactive handoff site from existing spec docs:

| Phase | What it does |
|---|---|
| 0 — Prereq | Check spec docs exist; if not, invoke `web-store-spec-handoff` first |
| 1 — Read spec as PRD | Extract surfaces, beats (→ `BeatTimeline`), tokens (→ `tokenCatalog`), assets; apply component-purity decision tree (vendor real component vs bespoke stubs) |
| 2 — Scaffold | Run `create-handoff.mjs`; or copy kit generics + create config for an existing spec folder |
| 3 — Configure & author | Fill `handoff.config.mjs`; write 1–2 thin feature components composing kit primitives; fill placeholder pages |
| 4 — Verify | `npm run docs:build`; curl all pages + font + image for 200; grep playground HTML for demo markers (preview MCP/Chrome EPERM workaround documented) |
| 5 — Deploy | Separate Vercel project; Root Directory = site folder |

All hard-won gotchas encoded: full cascade requirement, `@font-face` URL rewrite, VP font restore, `container-type: inline-size`, `forceReduceMotion` shim, SSR guards, Tailwind warning.

### `.claude/skills/web-store-interactive-handoff/kit-reference.md`

Full API reference for `TokenSandbox`, `BeatTimeline`, `EasingCurve`, `TokenChip`; `handoff.config.mjs` schema; vendor model; update model; gotchas quick-reference.

### `web-store-spec-handoff/SKILL.md` — sibling pointer added

A one-line callout at the top of the spec-handoff skill now points to `web-store-interactive-handoff` so the two skills are easily discovered as a pair.
