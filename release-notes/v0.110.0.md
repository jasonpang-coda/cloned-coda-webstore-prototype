# Release Notes — v0.110.0

**Date:** September 2026
**Milestone:** Landscape full-screen Payment/Checkout sheet for COD:M (Figma node 6060:3935), plus a first-channel default selection and a promo code field

---

## Highlights

- **Payment/Checkout sheet goes full-screen in landscape.** `BaseSheet.vue` gained a `landscapeFull` prop — when the framed device preview is in landscape orientation, the bottom sheet becomes an edge-to-edge page instead: flat `--x-bg-page` fill (no `--x-bg-sheet` gradient/blur), square corners (`DeviceFrame.vue`'s overlay now squares off in landscape on all four corners, not just the bottom), and a 2-column grid layout (payment-channel list : order summary, 5:3 split).
- **First payment channel selected by default.** `useCheckout().selectedChannel` now defaults to `0` instead of `null`, everywhere — matching Figma's "returning user" pre-selected state.
- **Promo code field added to the landscape payment-channel column**, wired to a new shared `promoDiscountAmount` singleton so the discount reaches the Subtotal in the opposite column without a prop bridge.

## Changes

### `src/components/base/BaseSheet.vue`

- New `landscapeFull` prop; combined with `isMobile` + `useOrientation()` into `isLandscapeFull`.
- `.sheet--landscape-full .sheet__panel`: fills the screen, flat `--x-bg-page` background, `grid-template-columns: 5fr 3fr`, 12px padding/gap.
- `.sheet__header`: no override — uses the same default chrome as every other sheet (an earlier override that zeroed its padding put the close button right at the box edge, where it went missing at some scales).
- `.sheet__body` (left column) / `.sheet__footer` (right column): each becomes its own L1 container — `--x-bg-sku-card-default` fill, `--x-radius-container-s` radius, `12px 8px` padding, `8px` gap, no border (only the inner PC-card tiles get one).

### `src/components/DeviceFrame.vue`

- `.device__overlay`'s rounded corners now square off on **all four** corners in landscape (previously only the bottom did, for `CategoryNav`'s full-bleed bottom bar). Nothing else renders flush against the top corners outside this new landscape-full sheet, so this is a no-op everywhere else.

### `src/components/steps/CheckoutStepBody.vue`

- New `isMobile` prop; `isLandscapeFull` computed drives the landscape branch.
- Account row, chosen-item banner, and the T&Cs bar are hidden in landscape full-screen (moved to/covered by the right column instead).
- Payment-channel grid goes 3-up (`sheet__pc-list--landscape`, `flex-grow: 0` so the trailing lone card doesn't stretch); each card now also shows its price (mirrors `PcCard.vue`/`StepPayment.vue`).
- New `<PromoCode>` field rendered after the grid in landscape full-screen, wired to `useCheckout().promoDiscountAmount`.

### `src/components/steps/CheckoutStepFooter.vue`

- New `isMobile` prop; landscape branch (`checkout-footer-landscape`) renders the item (thumb + title/subtitle, `text-style-heading-card` instead of the oversized `text-style-heading-sku-title`), a selected-channel row, Subtotal (net of the promo discount), and the Buy Now CTA — all right-aligned.
- `subtotalDisplay` computed applies `useCheckout().promoDiscountAmount` to the item price.

### `src/composables/useCheckout.js`

- `selectedChannel` now defaults to `0` (was `null`); `dismissBuyNow()` resets it to `0` instead of `null`.
- New `promoDiscountAmount` singleton (numeric or `null`), reset on `closeCheckout()`.

### `src/components/PurchaseSheet.vue`

- Passes `:landscape-full="currentStep === 'checkout'"` to `BaseSheet`, and `:is-mobile="isMobile"` through to `CheckoutStepBody`/`CheckoutStepFooter`.

## Verification

Checked in-browser via the device-frame landscape toggle (`?device=ios&orientation=landscape`): full-screen 3-col payment grid + right-hand order summary, first channel pre-selected, promo code (`SAVE10`) applies and updates Subtotal live across the shared singleton, channel switching and Buy Now CTA work, portrait bottom-sheet unaffected. `vite build` and scoped `preflight` runs pass on every touched file; no console errors.
