# Release Notes — v0.111.0

**Date:** September 2026
**Milestone:** Boleto BR payment-channel + KYC form flow for COD:M's Payment/Checkout sheet, plus a batch of checkout-sheet polish fixes

---

## Highlights

- **Boleto BR added as a 5th payment channel**, with a real logo asset and a Brazil-specific KYC form that swaps in (both orientations) when selected and Buy Now is tapped.
- **Buy Now → "Checkout"** — this step's CTA label changed, scoped to just this step (Info/FCM payment steps keep "Buy Now").
- **A batch of visual bugs fixed** across the landscape full-screen layout introduced in v0.110.0: uneven payment-card widths, a missing header gap, an intermittently-missing close button, and two invisible/miscoloured icons.

## Changes

### `src/content/sheetContent.js`

- `checkoutDescriptor()`'s `channels` array: every entry gained a `key` field; new 5th entry `{ key: 'boleto', logo: assets.pc.boleto, label: 'Boleto' }`.
- `primaryAction.label` is now the literal `'Checkout'` instead of `strings.checkout.actionLabel` — scoped to this step only; `InfoStepFooter`/`PaymentStepFooter` still read the shared string and keep "Buy Now".

### `src/shared/pc/light/boleto.svg` + `src/composables/useStoreAssets.js`

- New Boleto logo asset, wired into `assets.pc.boleto` following the same polarity-keyed pattern as the other 4 payment-channel logos.

### `src/components/checkout/BoletoKycForm.vue` (new)

- Portuguese-copy KYC form: first/last name, phone with a "+55" chip, email, date of birth with a calendar icon, CPF. Built from this repo's existing `<input>` markup/CSS convention (`StepZipCode.vue`/`StepDetails.vue`) — no shared Input component exists. Includes a "Voltar" back link. Purely visual — no submit action wired (prototype scope, same as `PromoCode.vue`).

### `src/components/steps/CheckoutStepBody.vue`

- Payment-tile `<img>` guarded with `v-if="c.logo"` (avoids a broken-image icon for a channel with no logo).
- `.sheet__pc-card`'s `flex-grow` changed from `1` to `0` (both the 2-up portrait rule and the 3-up landscape rule) — a lone last-row card (now common with 5 channels) no longer stretches to fill the row; all cards stay equal width.
- Renders `<BoletoKycForm>` in place of the account row/banner/grid/promo/terms when `useCheckout().showBoletoKyc` is set, wrapped in a `<Transition mode="out-in">` — the same calm asymmetric fast-out/base-in opacity cross-fade as `PromoCode.vue`'s own form↔success swap (`--x-motion-sys-duration-fast/base` + `--x-motion-sys-ease-accelerate/decelerate`).

### `src/components/steps/CheckoutStepFooter.vue`

- Buy Now click now checks `data.channels[selectedChannel]?.key === 'boleto'`; if selected, sets `useCheckout().showBoletoKyc = true` instead of emitting `confirm`.

### `src/composables/useCheckout.js`

- New `showBoletoKyc` singleton (boolean), reset on `closeCheckout()` — same shared-state, no-prop-bridge pattern as `selectedChannel`/`promoDiscountAmount`.

### `src/components/base/BaseSheet.vue`

- `.sheet--landscape-full .sheet__header`: removed an earlier `padding: 0` override (it put the close button flush against the box edge, where it intermittently went missing) — now uses the default header chrome; added `padding-bottom: var(--x-pad-surface-s)` for separation from the grid row below.

### `src/components/MaterialIcon.vue`

- Added `calendar_today` to the icon allowlist — it was never registered, so the DOB field's calendar icon silently rendered nothing.

## Fixes carried in this release

- DOB icon colour: `--x-text-body-soft` read too faint at the glyph's thin stroke weight; bumped to `--x-text-body-default`.

## Verification

Checked in-browser in both portrait and landscape: Boleto tile renders with its real logo, equal-width payment cards in both layouts, "Checkout" CTA label, the KYC form swap-in/out with a visible cross-fade and working "Voltar" back link, calendar and back-arrow icons both rendering at correct contrast, header spacing in landscape. `vite build` and scoped `preflight` runs pass on every touched file; no console errors.
