# Release Notes — v0.111.1

**Date:** September 2026
**Milestone:** Landscape payment-channel sheet handoff docs + a small copy fix; no app behavior changes beyond the label

## Highlights

- **New in-app handoff** for the landscape payment-channel sheet — live-rendering `CheckoutStepBody`/`CheckoutStepFooter`/`BoletoKycForm` per store theme, with Tokens/Components/States/Choreography/Spec tabs at `/handoff/payment-channel-sheet`.
- **"Select Payment" → "Selected Payment"** on the landscape summary row (it displays the already-chosen channel, not a picker heading).
- **Sprint-retro pass**: 4 lessons compounded to the permanent ledger, including a near-miss content-loss catch in the handoff export tooling itself.

## Changes

### `src/components/steps/CheckoutStepFooter.vue`

- The `cfl__row-label` in the landscape summary column no longer reuses `data.selectPaymentHeading` (the picker's own "Select Payment" grid heading) — it's now a local literal, "Selected Payment", so the two don't misleadingly share text.

### `src/handoff/flows/payment-channel-sheet.flow.js` (new)

- Flow manifest for the landscape payment-channel sheet feature (Figma node 6060:3935): components (`CheckoutStepBody`, `CheckoutStepFooter`, `BoletoKycForm`, plus source-only citations for `BaseSheet`'s `landscapeFull` mechanics and `DeviceFrame`'s corner-squaring), 17 states, 6 transitions, the boleto-form cross-fade choreography, and a full token contract per component.
- Generated `docs/Handoff/payment-channel-sheet/{spec.md,spec.json}` via `npm run handoff:export -- payment-channel-sheet`.

### `public/llms.txt`

- Re-added the "Payment Channel Sheet — Landscape" entry alongside the existing handoff index. **Caught and fixed a near-miss**: running the export script regenerates this file from scratch listing only `.flow.js`-registered flows, which silently drops the hand-authored entries for features with no manifest (Trust Bar, SKU Card Entrance Stagger, Download Banner, Bestseller Card Effects) — those were manually restored before committing.

### `audits/retro-ledger.json` + `src/library/stories/BaseSheet.stories.js`

- 4 lessons compounded from this session's landscape-sheet + Boleto work: diagnosing a stale dev-server-on-a-different-worktree before assuming a code regression; checking for a competing ancestor clip before stripping "redundant" padding on shared chrome (also bridged into `BaseSheet`'s own story rules); the Browser-pane tool's screenshot-cache requirement after navigation; and the `public/llms.txt` regeneration gap above.

## Verification

`vite build` and scoped `preflight` pass; the new handoff route verified live in-browser (all 5 tabs, live component renders across store themes, interactive choreography timeline) with no console errors. `public/llms.txt` diffed by hand to confirm the restore was correct (no accidental content loss survived into the commit).
