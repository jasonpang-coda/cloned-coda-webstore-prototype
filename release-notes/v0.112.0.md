# Release Notes — v0.112.0

**Date:** September 2026
**Milestone:** Drag-resizable sidebar panel, standardized across all three internal tool pages

---

## Highlights

- **New `useResizablePanel` composable** — drag-to-resize + collapse-to-rail behavior for a tool-page sidebar, with keyboard support (arrow-key nudge, Home/End, Enter/Space to toggle), per-page width persistence via `localStorage`, and eased width transitions matching this repo's motion system (ease-in on collapse, ease-out on expand).
- **Rolled out to all three internal tool pages** — Component Library, Token Usage Audit, and Handoff — replacing each page's own bespoke (or, for Token Audit, nonexistent) collapse mechanism with one shared implementation.
- **Token Audit sidebar** gains a collapse-to-rail state for the first time, with 2 new rail icons (`filter_alt` for the bucket toggle, `store` for the store filter).

## Changes

### `src/composables/useResizablePanel.js` (new)

- Zero repo-specific imports (Vue only), so it can be lifted into `packages/harness-kit/src/vue/` later without a rewrite.
- Pointer-driven resize modeled on `useDragScroll.js`'s pointermove/pointerup-on-`document` pattern (no `setPointerCapture`, so clicks on nearby sidebar buttons aren't swallowed).
- Collapse/expand is a discrete state crossing (no valid width between rail width and `minWidth`), handled by an eased `settle()` transition that can resume live drag-tracking once it completes.

### `src/library/LibraryViewer.vue`, `src/token-audit/TokenAuditApp.vue`, `src/handoff/HandoffApp.vue`

- Sidebar now drag-resizable (previously a fixed width) and collapses to a 48px icon rail, wired to `useResizablePanel` with a per-page `storageKey` and `minWidth`/`maxWidth` matching that page's former fixed width as the ceiling.
- Token Audit's rail (new) shows 2 icon buttons (bucket filter, store filter) instead of Library/Handoff's per-item list rail, since its sidebar holds filters rather than a list.

### `src/components/MaterialIcon.vue`

- Added `filter_alt` and `store` icons, used by Token Audit's new collapsed rail.

## Verification

`npm test`, `npm run harness -- test all`, and `npm run harness:render` all pass (same 2 pre-existing unrelated failures as prior release, nothing new). Not yet manually verified in-browser for this specific feature — recommend a manual pass across all three tool pages (drag-resize, collapse/expand, keyboard nav, persistence across reload) before relying on it.
