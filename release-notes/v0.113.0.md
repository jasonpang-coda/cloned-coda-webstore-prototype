# Release Notes — v0.113.0

**Date:** September 2026
**Milestone:** Handoff consolidation — 4 more features migrated to flow-backed, drift-protected specs; 7 stale interactive VitePress sites archived; shared handoff UI extracted into `packages/harness-kit`

---

## Highlights

- **4 features migrated to flow-backed handoff**: `sku-card-entrance-stagger`, `download-banner`, `trust-bar` (new `.flow.js` manifests), and `fcm-checkout-shimmer.md` deleted outright — confirmed dead (its `.checkout-btn` class no longer exists anywhere in source, superseded by the tokenized `fx-shimmer`/`fx-shimmer--metal-gloss` system already covered by `Button.vue`/`BuyNowBar.vue`'s own component story spec).
- **Real drift caught during migration**: `download-banner`'s `v-if` now also gates on `!webPushSubscribed`, undocumented in the old hand-written doc — captured as a new `banner_absent_subscribed` state.
- **7 interactive VitePress handoff sites retired** to `docs/Handoff/.archive/` (`carousel-story-interaction`, `codm-sku-cards`, `bestseller-card-effects`, `sku-cards`, `codm-signin-motion`, `gamer-id-instruction`, plus the interactive-site half of `locale-selector-sheets`), along with the `_handoff-kit` scaffold tool that built them. These had drifted (undetected stale token names) with no mechanism to warn before an update overwrote local edits. The channel for external handoff is now the in-app `/handoff` app — write a `*.flow.js` manifest per feature instead of scaffolding a new site. `docs/Handoff/.archive/README.md` has the full per-item breakdown.
- **Shared handoff Vue components extracted** into `packages/harness-kit/src/vue/` (`EasingCurve`, `FlowDiagram`, `StateDiagram`, `TokenChip`, plus `bezier.js`/`mermaid.js` utils) — previously duplicated per VitePress site, now consumed by `src/handoff/` and `src/token-audit/` alike via `@coda/harness-kit/vue`.
- **2 new CI gates** wired into `.github/workflows/design-harness.yml`: component spec-drift (`export-handoff.mjs --story --verify`, all 86 component story specs) and feature-flow spec-drift (`handoff:verify`, all 7 flow-backed feature specs) — both must stay green going forward.
- **Choreography tab gains an optional live visual stage**: a flow can declare `choreographyStage` (a component + props) so `BeatTimeline`'s scrub/play shows the feature's actual rendered state at that timestamp, not just a raw `ms` readout. Used by `payment-channel-sheet` (Boleto cross-fade) and `seo-block`.
- **`stage-handoff.mjs`** now skips dot-directories (`.archive/`) when building the public manifest, and only re-stages on an unlocked (`--mode all-stores`) build — never a store-locked build, since the manifest spans every client's tokens and specs.

## Changes

### `src/handoff/flows/` (new)

- `sku-card-entrance-stagger.flow.js`, `download-banner.flow.js`, `trust-bar.flow.js` — each verified against current source with zero unexpected `_(resolve live)_` placeholders before the old docs were deleted.
- `PaymentChannelSheetChoreographyStage.vue`, `PaymentChannelSheetComposed.vue`, `SeoValuePropComposed.vue` — new composed-preview stage components feeding the flows above and the existing `payment-channel-sheet`/`seo-block` flows.

### `src/handoff/flow.js`, `resolve.js`, `components/*`

- `flow.js`: documented the new optional `choreographyStage` field on the flow schema.
- `resolve.js` and `Choreography.vue`/`StateLaydown.vue`/`TokenContract.vue`/`TokenLibrary.vue`: import shared primitives from `@coda/harness-kit/vue` instead of local `./utils/tokens.js` / `./components/*.vue` (now deleted, moved to the package).
- `ComponentStage.vue`: new optional `height` prop for a composed preview whose content sizes via `position: absolute; inset: 0` (e.g. a `BaseSheet` mounted for a composed preview) rather than in normal flow.
- `TokenContract.vue`: `width`/`height` now pass through to `ComponentStage`; the token table only renders when the component actually declares tokens (fixes an empty table for components like `Full sheet (landscape, composed)`).

### `packages/harness-kit/src/vue/` (new components/utils)

- `EasingCurve.vue`, `FlowDiagram.vue`, `StateDiagram.vue`, `bezier.js`, `mermaid.js` moved in verbatim from the now-deleted `src/handoff/components/` and `src/handoff/utils/`, alongside the already-present `TokenChip`/`getToken`. `src/token-audit/components/Coverage.vue` updated to the same import.

### `docs/Handoff/`

- 7 sites moved under `.archive/` (see above); `_handoff-kit` deleted.
- `download-banner/`, `sku-card-entrance-stagger/`, `trust-bar/` gain generated `spec.md`/`spec.json` (never hand-edit — regenerate via `scripts/export-handoff.mjs`).
- `docs/README.md` and `public/llms.txt` updated to reflect the new flow-backed entries and the archive, replacing per-site descriptions with pointers to the in-app `/handoff` app.

### `.github/workflows/design-harness.yml`

- Added the "Component spec drift" and "Feature flow spec drift" gates after the existing render/crash gate.
