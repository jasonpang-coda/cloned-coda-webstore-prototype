# Release Notes — v0.113.2

**Date:** September 2026
**Milestone:** Best Seller carousel now snaps to card boundaries on release; new local demo-sandbox dev-server entry

---

## Highlights

- **`BestSellerCarousel.vue` now scroll-snaps** — a drag, swipe, or chevron-press release now always comes to rest on a card boundary (`scroll-snap-type: x mandatory` + `scroll-snap-align: start`), instead of the previous free-scroll-with-JS-inertia behavior that could leave a card sitting half-cut at the visible edge. `mandatory` (not `proximity`) because a drag can release at an arbitrary offset, and only `mandatory` guarantees a snap regardless of how close to a boundary it lands.
- **New `demo-sandbox` entry in `.claude/launch.json`** — a dev-server config pointing at a local Vite project outside this repo (`/private/tmp/demo-sandbox`), for previewing an ad-hoc sandbox from this session's launch config.

## Changes

### `src/components/BestSellerCarousel.vue`

- Row container: `scroll-snap-type: x mandatory` (was no snap).
- Card wrapper: `scroll-snap-align: start`.
- Cards remain ~62.5%/33% width by design — a peek of the next card while actively scrolling is the intended affordance that the row scrolls; only the at-rest position is now constrained.

### `.claude/launch.json`

- Added a `demo-sandbox` configuration (port 5199, autoPort) pointing at `/private/tmp/demo-sandbox` — a local, out-of-repo sandbox project, not part of this repo's own source.

## Verification

Scoped to a CSS-only carousel change and a dev-tooling config addition — no build-affecting code paths touched. `npm test` unaffected (same 2 pre-existing unrelated failures as prior releases).
