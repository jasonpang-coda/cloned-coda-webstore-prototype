# Release Notes — v0.114.0

**Date:** September 2026
**Milestone:** Design harness upgraded from a system-correctness harness to a design-quality one — real contrast/locale/state-coverage gates, a working component library viewer (theme grid, zoom, background swap — plus two silently-broken state-simulation bugs found and fixed), a Figma token-tracing skill/CLI, and a visual capture rig, all driven by a product-design assessment of the harness recorded in `plans/`.

---

## Highlights

- **Contrast gate is now real** (`tools/harness-cli.mjs`) — `harness test` claimed "contrast sanity" in its own header doc with no code behind it. Now runs real WCAG contrast checks (reusing `@coda/inspect-kit`'s existing math) across all 86 stories × 12 themes, calibrated down from 1,292 false positives to 0 through three rounds of tightening (name-based pairing heuristics, excluding decorative `--x-bg-indicator-*` fills, and correctly skipping translucent backgrounds it can't safely score).
- **Locale stress dimension** — `harness-render.mjs` gained an opt-in `--locales stress` flag that re-renders every story with real Arabic/Japanese translated content (not synthetic filler) to catch crashes on non-Latin text. Default behavior is unchanged (zero cost regression).
- **State coverage is honest now, and two real bugs are fixed** — added a `focus` pseudo-state and a non-blocking warning for components left at `states: ['default']`. While wiring this up, found that the Component Library viewer's entire hover/pressed/disabled state simulation had been **silently cosmetic**: a missing `defineExpose` in `src/library/StoryStage.vue`'s adapter threw on every state-apply call, and separately `buildHoverOverride` was marking the wrong DOM element for any component whose interactive child isn't its own root (the norm in this codebase). Both fixed.
- **Component Library viewer is now a design tool** — deep-linkable stage state (story/variant/width in the URL), a 12-store theme grid (small multiples, not a one-at-a-time `<select>`), zoom (1×–3×), background swap (checker/light/dark), and stage centering.
- **Visual capture rig** — a new isolated `?capture=1` render mode plus `tools/harness-capture.mjs`, producing deterministic capture manifests and real embedded screenshots in handoff specs. Proved end-to-end with a real 9-shot capture set for SKU Card.
- **Figma integration, both directions** — a `figma-token-trace` skill + `tools/figma-token-crosswalk.mjs` CLI that traces a Figma variable's full alias chain and ranks matching repo tokens automatically (turns a ~6-call manual trace into one invocation), plus a working Code Connect mapping for the Grid component.
- **Two cross-cutting URL bugs found and fixed**, both the same root cause: `useUrlState.js`'s merged query/hash writer trusted `route.query`/`route.hash` to already contain state the app itself doesn't track, when the file's own comments already documented that both are unreliable at boot. First hit the `#library=` hash (silently wiped on load), then the `?capture=1` query param (same failure, different field). Both fixed by reading off `window.location` directly and re-injecting on every write.

## Changes

### Design-quality gates (`tools/harness-cli.mjs`, `tools/harness-render.mjs`)

- Real contrast checking: `shouldPair`/`alphaOf`/`hexToRgbString` added, reusing `@coda/inspect-kit`'s `contrastInfo` and `tools/lib/color.mjs`'s OKLCH conversion — no new color math written.
- `--locales <csv|stress>` on `harness-render.mjs`; `stringsFor` exported from `useStoreStrings.js` for reuse.
- `presentational: true` story flag (mirrors `tokenFree`) suppresses a new non-blocking `SINGLE_STATE_COVERAGE` warning; applied to `MaterialIcon`, `Media`, `Grid`, `Span`.
- `focus` added to the real state taxonomy (`src/library/story.js`); `loading`/`empty`/`error`/`long-copy` deliberately left out of `states` (documented as content-shape conditions belonging in `variants` instead, not a generic pseudo-state).

### Component Library viewer (`src/library/LibraryViewer.vue`, `useLibrary.js`, `StoryStage.vue`)

- `useLibrary.js`: hash is now `#library=<id>&v=<n>&w=<width>`, parsed with `URLSearchParams`; first open uses `location.hash=`, subsequent changes use `history.replaceState`.
- Theme grid: `assetsFor`/`configFor` exported from `useStoreAssets.js`/`useStoreConfig.js` (mirroring `stringsFor`) so a `themeOverride` prop on `StoryStage.vue` can render an arbitrary store's real content without touching the global active theme.
- Zoom (CSS `zoom`, not `transform`, so it reflows), background swap (`:deep()` + `!important` overriding `@coda/harness-kit`'s own painted device screen), and unconditional stage centering.
- **Bug fix:** `StoryStage.vue` now forwards `componentEl` via `defineExpose` — previously undefined, throwing on every hover/focus/pressed/disabled state application.
- **Bug fix:** `buildHoverOverride` (`packages/inspect-kit/src/core/inspect.js`) now marks whichever element a selector's own base part actually matches (self or a descendant), not always the component's root — the previous behavior silently no-op'd for any component whose interactive CSS targets a nested child.

### Visual capture rig (`tools/harness-capture.mjs`, `LibraryViewer.vue`, `scripts/export-handoff.mjs`)

- `harness-capture.mjs manifest [storyId | --curated]` — deterministic (story, variant, theme, width) → URL/output-path planning; `--curated` targets a defined 7-story/63-shot representative set (not all 86, which would reproduce the 774-shot count the plan explicitly avoids).
- `?capture=1` mode on `LibraryViewer.vue` hides all chrome and sets a `data-capture-ready` signal (reusing `figmaCapture.js`'s `waitForCaptureReady`, exported for this).
- `export-handoff.mjs` embeds any real `docs/Handoff/components/<id>/captures/*.png` found on disk into `spec.md`'s new "Reference Captures" section; `--verify` correctly detects drift when a capture arrives without regeneration.
- `captureVariant` story field (index or name) picks the "worst case" variant for a capture; defaults to the last authored variant.

### Figma integration (`.claude/skills/figma-token-trace/`, `tools/figma-token-crosswalk.mjs`)

- New skill + CLI: traces a Figma node's bound variables to their terminal value via a reusable `use_figma` script, then ranks matching repo tokens by name-segment overlap against `tools/token-cli.mjs`'s `getAllTokens()`.
- Grid component Code Connect–mapped (all 4 breakpoint variants → the one `Grid.vue`); its 6 Figma variables traced and confirmed already correctly aliased in the repo at both the sys and semantic tier — no new tokens needed, only 4 existing tokens found to bypass the sys alias chain with raw literals (tracked, not yet fixed).

### Cross-cutting bug fixes (`src/composables/useUrlState.js`)

- `router.replace({ query, hash: window.location.hash })` — hash is now always explicit, since vue-router doesn't auto-preserve the URL fragment for an object-form location missing it.
- `initialCapture` read off `window.location.search` at boot and re-injected into every subsequent query write, so `?capture=1` survives the same way the hash fix already made `#library=`/`#inspect=` survive.

### Housekeeping

- `tools/harness-cli.mjs`'s `loadAllStories()` exported for reuse (with a new `isMainModule` guard so importing it doesn't also run its own CLI dispatch).
- `MaterialIcon.vue` gained a `grid_view` icon for the new theme-grid toggle.
