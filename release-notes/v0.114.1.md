# Release Notes — v0.114.1

**Date:** September 2026
**Milestone:** Cleanup pass closing out three small plans from v0.114.0's harness assessment — whitelabel de-branching, Figma token re-aliasing, and handoff-spec noise reduction — plus a documented scope decision on which components get harness stories.

---

## Highlights

- **Handoff spec token tables now separate signal from noise.** Every `docs/Handoff/**/spec.md` (both flow-mode and story-mode) now splits its token table into "Same value at every store" (a flat list) and "Diverges per store" (the full N-column table, kept only for tokens that actually differ). Regenerated across all specs in the repo — most tokens in most components are store-uniform, so this is a real signal-to-noise win, not cosmetic.
- **Two whitelabel de-branching fixes landed** (`SignInSheet.vue`, `PageSignInSection.vue`) — both `flow === 'efootball'` sign-in-logomark branches removed; the `??` fallback already does the right thing unconditionally. Re-verified the fix's safety premise against current source first, since 7 more stores now define `signinLogomark` than when this was originally scoped — all alias to the same asset as `logomark`, so the fix is still zero-visual-change.
- **4 existing design tokens re-aliased to their sys primitives** (`--x-gap-grid-gutter-m/-l`, `--x-gap-grid-margin-l`, and Codashop's own `--x-gap-grid-gutter-l` override) — were numerically correct raw literals bypassing the sys tier every sibling token in the same file already uses. Verified zero resolved-value change for both COD:M and Codashop before and after.
- **Dead `motionBeats` schema field removed** — declared in every story's defaults, authored in 0 of 86 stories, consumed by 0 tools, never even had a JSDoc entry. Deleted rather than half-authoring real motion timelines, which would have been a much bigger content task than "remove a dead field."
- **Scope decision, documented, not silently applied or dropped**: `EaSignInPage`/`KonamiSignInPage` will **not** get harness stories. They're flow-completion placeholders for account-linking methods the prototype doesn't otherwise model, not real production UI — scaffolding stories for them would have been busywork. Closed as "won't do" in `plans/harness-false-confidence.md`, with the consequence noted for `plans/ds-remediation.md` Phase 5's gate (which now needs its own before/after verification method, not a story-driven one).
- **A newly-discovered whitelabel violation found, not silently fixed**: re-running Phase 4's own gate command turned up `SignInSheet.vue:60`'s `flow === 'codm'` label-casing branch — outside what this phase was scoped to fix, so it's tracked in `plans/ds-remediation.md` rather than folded in unreviewed.

## Changes

### `scripts/export-handoff.mjs`

- `tokenTable()` now computes per-token whether every store resolves to the same value; uniform tokens render as a flat `| Token | Value |` list, divergent ones keep the original full store-by-store table. Shared by both flow-mode and story-mode generation, so the fix applies everywhere token tables appear, not just one doc type.
- All `docs/Handoff/**/spec.md` files regenerated to the new format (component specs and flow specs alike) — no manual edits, purely generator output.

### `src/components/SignInSheet.vue`, `src/components/PageSignInSection.vue`

- Removed the `flow === 'efootball'` conditional around `assets.brand.signinLogomark` — the existing `??` fallback already yields `logomark` for every store without a `signinLogomark` override, making the branch redundant. Verified across all 8 stores that currently define `signinLogomark` (all alias to `logomark`) that this is a no-op change visually.

### `src/tokens/ds/space.css`, `src/tokens/ds/themes/codashop.css`

- `--x-gap-grid-gutter-m`, `--x-gap-grid-gutter-l`, `--x-gap-grid-margin-l` (base) and Codashop's `--x-gap-grid-gutter-l` override: raw px literals → `var(--x-sys-space-main)`/`var(--x-sys-space-l)`. Resolved values unchanged (verified via `resolveTokensForStore` before/after for both COD:M and Codashop).

### `src/library/story.js`

- Removed the dead `motionBeats: null` default.

### `tests/export-handoff.test.mjs`

- New locking test for the token-table split, grounded in two real tokens (`--x-pad-surface-m` uniform, `--x-radius-container-s` divergent) with known cross-store behavior rather than synthetic mock values.
