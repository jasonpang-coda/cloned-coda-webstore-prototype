# Release Notes — v0.12.0

**Date:** June 2026  
**Milestone:** Checkout sheet fixes — loyalty banner overlap, BestSellerCard label passthrough, subtitle colour

---

## Highlights

- **Checkout loyalty banner now actually overlaps the footer** — the overlap was silently 0px since it shipped (v0.10.0); the root cause was a CSS specificity bug where `--checkout-loyalty-overlap` and `--shadow-checkout-footer` were declared in a plain `[data-theme="fcm"]` block that lost to the later `extensions.css` `:root` declarations by source order. Moved to `html[data-theme="fcm"]` (0,1,1 beats 0,1,0).
- **BestSellerCard now passes its `label` + `subtitle` to the checkout sheet** — "Daily Booster D" was rendering as "499" in the Order Summary banner because `onSelect()` only forwarded the numeric `amount` prop, not the human-readable `label`.
- **Checkout banner subtitle uses `--text-body-default`** — was `--text-body-soft`; the lighter colour was hard to read against the dark banner surface.

---

## Bug fixes

### CheckoutSheet.vue — loyalty banner overlap (FCM)

The `--checkout-loyalty-overlap` token (introduced in v0.10.0 for the FCM loyalty ribbon) was silently a no-op. Both it and `--shadow-checkout-footer` are defined as `0px` / the sheet shadow in `extensions.css (:root)`, which is imported **after** the theme file. Because `[data-theme="fcm"]` and `:root` have equal specificity (0,1,0), and the cascade tiebreaker at equal specificity is source order, the later `extensions.css` declarations were winning every time — regardless of the token value set in the theme.

**Fix:** moved both overrides into the existing `html[data-theme="fcm"]` block (specificity 0,1,1), which beats `:root` regardless of import order. The footer's `margin-top: calc(-1 * var(--checkout-loyalty-overlap))` now resolves to `−16px`, visibly tucking the footer's rounded top corners over the green ribbon.

Companion changes:
- **Footer corner radius:** bumped from `--radius-container-s` (8px) to `--radius-container-m` (12px) so the rounded shoulders read clearly against the ribbon.
- **Footer shadow:** switched from `--shadow-sheet` to a new `--shadow-checkout-footer` token (default: `--shadow-sheet`; FCM override: tight dark two-layer cast) — the existing 30%-alpha warm shadow was invisible against the dark-green ribbon fill.
- **Loyalty banner bottom padding:** decoupled from `--checkout-loyalty-overlap`. Previously `calc(var(--pad-surface-l) + var(--checkout-loyalty-overlap))`, which meant the padding and the negative margin cancelled each other out (the second half of the no-op bug). Now a fixed `var(--pad-surface-xl)` (24px), always larger than the 16px overlap, so the ribbon text stays clear.

This is the same class of specificity regression documented in `multi-store-whitelabel.md §2` — and now serves as the second cautionary example in that doc.

### BestSellerCard.vue — label not forwarded to checkout

`onSelect()` was calling `openCheckout({ amount: props.amount, … })` without passing `label` or `subtitle`. The checkout sheet renders `selectedItem.label` as the banner title when present, falling back to `selectedItem.amount`. For cards like "Daily Booster D" where `label` is the product name and `amount` is a numeric FC Points value (499), the sheet was showing "499".

**Fix:** `onSelect()` now forwards `label` and `subtitle` alongside `amount`. The checkout sheet template was also updated: the banner title line now renders `selectedItem.label || [selectedItem.amount, selectedItem.currencyLabel].join(' ')`, so regular SKU cards (no `label`) are unaffected.

### CheckoutSheet.vue — banner subtitle colour

`.sheet__banner-subtitle` was coloured `--text-body-soft` (dim). Changed to `--text-body-default`.

## Token changes

### New in `extensions.css`

| Token | Default | Notes |
|---|---|---|
| `--shadow-checkout-footer` | `var(--shadow-sheet)` | Footer's own upward shadow; FCM overrides with a tighter darker cast visible against the ribbon green |

### Changed in `themes/fcm.css`

| Token | Block | Was | Now |
|---|---|---|---|
| `--checkout-loyalty-overlap` | `html[data-theme="fcm"]` | `[data-theme]` (no-op) | `html[data-theme]` — 16px (now resolves correctly) |
| `--shadow-checkout-footer` | `html[data-theme="fcm"]` | (new) | `0 -1px 3px oklch(0 0 0 / 0.45), 0 -6px 12px oklch(0 0 0 / 0.50)` |

## Component changes

### `BestSellerCard.vue`

- `onSelect()` now passes `label` and `subtitle` to `openCheckout()`.

### `CheckoutSheet.vue`

- Banner title: renders `selectedItem.label` when present; falls back to `amount + currencyLabel` join.
- Banner subtitle colour: `--text-body-soft` → `--text-body-default`.
- Loyalty ribbon bottom padding: decoupled from overlap token; fixed `--pad-surface-xl`.
- Footer corner radius: `--radius-container-s` → `--radius-container-m`.
- Footer shadow: `--shadow-sheet` → `--shadow-checkout-footer`.
