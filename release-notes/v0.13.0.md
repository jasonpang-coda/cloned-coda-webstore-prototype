# Release Notes — v0.13.0

**Date:** June 2026  
**Milestone:** Gifts category, event countdowns, gift claimed-state, multi-flow sign-in (KONAMI), StoryCarousel single-slide + press-to-pause, NavBar loyalty pill generalisation, DeviceToolbar body-font evaluation

---

## Highlights

- **Gifts category (COD:M)** — new `GiftSkuCard` + `GiftGrid` components; third tab in the category nav (`cat-gifts`); three gift cards with rarity-glow art, FREE GIFT tag, CLAIM GIFT CTA, and per-card live countdowns
- **Gift claimed-state interaction** — clicking a gift card toggles a claimed/unclaimed state (30% image opacity, CLAIMED label, soft colour); daily gift switches countdown prefix "Ends:" → "Refreshes:" when claimed; localisable via `endsLabel` / `refreshesLabel` props
- **Event countdowns on Bundle + BestSeller cards** — `endsAt` prop drives a live `schedule`-icon + "Ends: Xd XXh XXm" row with three-tier urgency colouring (default / warning / error at ≥72h / 24–72h / <24h)
- **`--text-bonus-amount` design token** — bright warm yellow (`--palette-primary-400`) applied to bonus breakdown amounts across `SkuCard`, `BestSellerCard`, `SkuImageCard` — visually subordinate to the CTA yellow (primary-500)
- **CP icon moved left** in `SkuCard` title row (icon precedes denomination)
- **`StoryCarousel` upgraded** — single-slide mode (no progress bar / autoplay), press-to-pause gesture, `aspectRatio` prop override
- **Multi-flow sign-in (eFootball)** — `SignInSheet` + `PageSignInSection` now render one CTA per active flow (device-split arrays); KONAMI ID flow wired in `useAuth`
- **NavBar loyalty generalisation** — `assets.brand.loyaltyIconColour` replaces the FCM-specific `mpColourIcon`; backdrop-filter on the bar uses the shared `--blur-container` token

---

## New components

### `GiftSkuCard.vue`

Free-gift display card. Static (no checkout wiring). Key behaviour:

- **Rarity-graded image tile** — `rarity` → `--rarity-gradient-*` background glow; same mask-composite `::before` border ring as `BundleItem`
- **FREE GIFT tag** — `SkuTag variant="value"` top-left (`--bg-tag-success` / `--text-success-default`)
- **Bold uppercase CTA** — `text-style-heading-modal` + `text-style-utility-action-bold`; centred (`text-align: center`); yellow (`--text-hyperlink-default`)
- **Live countdown** — `schedule` MaterialIcon + urgency colours; drops `0d` segment; ticks every second
- **CTA + countdown bottom-aligned** — `.gift__info { flex: 1 }` + `.gift__action { margin-top: auto }`
- **12px gap** between image area and info block (`--gap-content-loose`)
- **Claimed state** — `claimed` ref toggled on click; image → 30% opacity; CTA → "CLAIMED" (`--text-body-soft`); prefix → `refreshesLabel` when `refreshesOnClaim: true`

New props vs v0.12 baseline: `refreshesOnClaim` (Boolean), `endsLabel` (String, default `'Ends:'`), `refreshesLabel` (String, default `'Refreshes:'`).

### `GiftGrid.vue`

2-up grid wrapper (`grid-template-columns: 1fr 1fr`) at every breakpoint including 360px mobile. Slot-only.

## Component changes

### `BundleSkuCard.vue`

- New `endsAt: Number` prop (ms epoch)
- Live countdown below subtitle: `MaterialIcon name="schedule"` + `"Ends: Xd XXh XXm"` (days drop when 0)
- Urgency colours via `data-urgency` attribute: `default` → `--text-body-default`; `warning` → `--text-warning-default`; `error` → `--text-error-default`
- Interval cleared in `onBeforeUnmount`

### `BestSellerCard.vue`

- New `endsAt: Number` prop; same countdown pattern as `BundleSkuCard` (uses `bsNow`/`bsTimer` names to avoid future naming conflicts)
- **CP icon removed** from the title row — only the formatted amount span is rendered
- **SKU coin overlay** (`skuImage` → `.bestseller__sku-overlay`): 160×160 product art composited centered over the banner via `position: absolute; transform: translate(-50%,-50%)`
- `.bestseller__bonus-amount { color: var(--text-bonus-amount) }`
- `loyaltyIconUrl` now sourced from `useStoreAssets` (`assets.brand.loyaltyIcon` with Material `stars` fallback), matching the `SkuImageCard` pattern

### `SkuCard.vue`

- **CP icon position:** icon renders **left** of the denomination number (template order: `<img>` then `<span>`)
- **`subtitle` prop** — optional body text below the amount/bonus row (`--text-body-default`)
- `.sku-card__bonus-amount { color: var(--text-bonus-amount) }`

### `SkuImageCard.vue`

- Gap between the panel image and the info row: `--gap-content-default` (8px) → **`--gap-content-loose` (12px)**

### `StoryCarousel.vue`

- **`aspectRatio` prop** (`String`, default `null`) — CSS `aspect-ratio` override applied inline on `.story__frame`; takes precedence over the responsive default (1:1 / 2.6:1) at all breakpoints
- **Single-slide mode** (`isSingle = slides.length <= 1`): progress bar, scrim, tap zones, and auto-advance are all disabled; `.story--single .story__frame::before { display: none }`
- **Press-to-pause**: `pointerdown` on the frame sets `isPressed`; the active segment's `animationPlayState` pauses; document-level `pointerup` / `pointercancel` listeners resume it; listeners cleaned up in `onBeforeUnmount`

### `NavBar.vue`

- Loyalty icon binding generalised: `assets.brand.loyaltyIconColour` (was `assets.brand.mpColourIcon`)
- `config.navbar.hideSignIn` — when truthy, wraps the sign-in / avatar control in `v-if`, hiding both (used by eFootball)
- Loyalty points formatted via `formatNumber`
- Background token: `var(--bg-navbar)` + `backdrop-filter: blur(var(--blur-container, 8px))`

### `SignInSheet.vue`

- `activeFlows` computed replaces the single-flow `config.signIn.flow` check. For stores with `config.signIn.desktop` / `.mobile` arrays (eFootball), the active list is device-split (`isMobile` prop); legacy stores derive a single-item array from `.flow`
- One `<button>` per flow rendered dynamically (keyed by flow name)
- Dispatch: `ea-redirect` → `startEaSignIn()`, `mykonami` → `startKonamiSignIn()`, others → `startSignIn()`
- CTA label: `strings.signIn[flow].cta` (keyed) or `strings.signIn.cta` (legacy)
- Logomark hidden for `mykonami`; eFootball flows use `assets.brand.signinLogomark`

### `PageSignInSection.vue`

- Same `activeFlows` + `handleFlow()` pattern as `SignInSheet`; receives `isMobile` prop
- Renders one CTA button per active flow inline (no sheet) — used by multi-flow stores where auth is surfaced on the page rather than behind a sheet

### `DeviceToolbar.vue`

- **Body-font evaluation dropdown** (COD:M only, `v-if="theme === 'codm'"`) — cycles `Hitmarker / Barlow / Inter` via `useBodyFont` composable which writes `<html data-body-font>`; theme overrides swap body family, un-condense body text, and zero body tracking. Remove this control + `index.html` font links once a pairing is chosen
- **Android device option** added (`Samsung`)

### `useAuth.js`

- New KONAMI ID flow: `konamiSignInOpen` ref + `startKonamiSignIn()`, `completeKonamiSignIn(name)`, `cancelKonamiSignIn()` — mirrors the EA flow pattern but opens `KonamiSignInPage`
