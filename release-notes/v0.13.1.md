# Release Notes — v0.13.1

**Date:** June 2026  
**Milestone:** SKU info-column consistency pass — row order, gap, condense, discount alignment, NavBar loyalty gate

---

## Highlights

- **Consistent info-column row order** across all SKU card types: title → bonus → subtitle → loyalty → countdown. Bonus is now treated as a structural subtitle type — it renders immediately after the title, before any explicit subtitle text.
- **Discount info right-aligns with the price CTA** in all card types — `transform-origin: right center` applied to both the original-price and discount-pct spans so condensed Hitmarker text visually aligns with the price below.
- **SkuCard amount now uses standard scaleX condense** (18%) instead of the approximate manual `letter-spacing` approach (~8%) — the title looks noticeably tighter.
- **Info-column gap bumped** from `--gap-content-tight` (2px) to `--gap-content-narrow` (4px) across all three SKU card types.
- **NavBar loyalty gate hardened** — the standalone loyalty icon and rewards pill now additionally gate on `config.checkout.loyalty` (not just the asset), preventing pre-wired assets from leaking into the UI before a programme is live.

---

## Component changes

### `BestSellerCard.vue`

- **Info-column row order** corrected: title → bonus → subtitle → loyalty → countdown. Previously the countdown appeared between the subtitle and bonus.
- **`.bestseller__title-col` gap:** `--gap-content-tight` → `--gap-content-narrow`
- **Discount alignment fixed:** added `align-self: flex-end` to `.bestseller__discount`; added `transform-origin: right center` to `.bestseller__original` and `.bestseller__pct` — all condensed text now visually right-aligns with `.bestseller__current` below.

### `SkuCard.vue`

- **Amount condense:** removed manual `letter-spacing: -0.038em` and `transform: none` override from `.sku-card__amount`. The standard `scaleX(var(--sys-font-condense))` from `.text-style-heading-card` now applies (18% condense, `transform-origin: left center`) — icon gap remains accurate since the left visual edge stays flush with the layout edge.
- **Discount alignment fixed:** `.sku-card__discount-pct` changed from `transform-origin: left center` → `right center`.
- **`.sku-card__info` gap:** `--gap-content-tight` → `--gap-content-narrow`

### `SkuImageCard.vue`

- **Info-column row order** corrected: bonus now renders before subtitle (was reversed).
- **Discount alignment fixed:** `.sku-image-card__discount-pct` changed from `transform-origin: left center` → `right center`.
- **`.sku-image-card__info` gap:** `--gap-content-tight` → `--gap-content-narrow`

### `NavBar.vue`

- **Loyalty gate hardened:** standalone loyalty icon guard changed from `!signedIn && assets.brand.loyaltyIconColour` → `!signedIn && config.checkout.loyalty && assets.brand.loyaltyIconColour`.
- Rewards pill guard changed from `signedIn && config.profile.showLoyaltyPill && assets.brand.loyaltyIconColour` → `signedIn && config.checkout.loyalty && config.profile.showLoyaltyPill && assets.brand.loyaltyIconColour`.
- No visible change for active stores (FCM has loyalty enabled; COD:M has it null). Prevents pre-wired COD:M loyalty assets from appearing if the programme is toggled on in config before a formal launch.
