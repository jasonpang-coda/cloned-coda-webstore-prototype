# Release Notes — v0.13.2

**Date:** June 2026  
**Milestone:** BestSellerCard in-flow coin layout, GiftGrid single-row layout for sparse grids, GiftSkuCard media container fix, metallic-shine shimmer token, eFootball store-locked build

---

## Highlights

- **BestSellerCard coin is now in-flow** — `.bestseller__sku-overlay` changed from `position:absolute` (centered at 160×160px) to `position:relative; display:block; margin:0 auto` at 128×128px. The `.bestseller__image` container switches to `height:auto` + `padding: var(--pad-surface-s) 0`, so the coin image drives the card height rather than a fixed px value.
- **BestSellerCard shimmer refreshed** — shimmer gradient swapped from `--gradient-bestseller-gloss` to the new `--gradient-bestseller-metallic-shine` (cleaner white, 61% opacity core), reduced to `opacity: 0.25`, duration changed from 4500ms → 2954ms, easing changed from `var(--motion-ease-standard)` → `linear` for a more mechanical sweep feel.
- **GiftGrid `count` prop** — accepts `gifts.length` from `App.vue`. At M/L (`@container min-width: 641px`), fewer-than-4 items collapse to a single equal-width row (`repeat(var(--gift-count), 1fr)`) instead of the default 2-column grid.
- **GiftSkuCard media container fixed** — removed `aspect-ratio: 1/1` from `.gift__media`; padding changed from all-sides `var(--pad-surface-s)` to top/bottom only. Height is now driven by the image content, preventing forced-square cropping on taller assets.
- **New `--gradient-bestseller-metallic-shine` token** — `linear-gradient(100deg, oklch(1 0 0 / 0) 15%, oklch(1 0 0 / 0.61) 50%, oklch(1 0 0 / 0) 85%)`. Replaces `--gradient-bestseller-gloss` in `BestSellerCard` shimmer. The old gloss token is retained in `extensions.css`.
- **eFootball store-locked build manifest** — new `src/stores/active.efootball.js` for `--mode efootball` builds. Follows the same active-stores pattern as the CODM/FCM manifests.
- **Dev config path corrected** — `.claude/launch.json` `runtimeExecutable` and `cwd` were pointing to a stale `SKU Card 3.0` directory; both corrected to this repo's path.

---

## Component changes

### `BestSellerCard.vue`

- **`.bestseller__sku-overlay`:** changed from `position:absolute; top:50%; left:50%; transform:translate(-50%,-50%); width:160px; height:160px` → `position:relative; display:block; margin:0 auto; width:128px; height:128px`. Coin is now in-flow, not a float over the banner.
- **`.bestseller__image` (hero):** `height:128px` → `height:auto; padding:var(--pad-surface-s) 0`.
- **`.bestseller__card--compact .bestseller__image`:** `height:104px` → `height:auto; padding:var(--pad-surface-s) 0`.
- **Shimmer (`::after`):** gradient → `var(--gradient-bestseller-metallic-shine)`; added `opacity:0.25`; duration `4500ms` → `2954ms`; timing-function `var(--motion-ease-standard)` → `linear`.

### `GiftGrid.vue`

- **New `count` prop** (`Number`, default `0`): injected from `App.vue` as `:count="gifts.length"`.
- **`gift-grid--few` class:** applied when `count < 4`; sets inline `--gift-count` CSS custom property.
- **New container-query rule:** at `@container (min-width: 641px)`, `.gift-grid--few` uses `grid-template-columns: repeat(var(--gift-count), 1fr)` for a single equal-width row.

### `GiftSkuCard.vue`

- **`.gift__media`:** removed `aspect-ratio:1/1`; padding changed from `var(--pad-surface-s)` (all sides) → `var(--pad-surface-s) 0` (top/bottom only). Height is now content-driven.
