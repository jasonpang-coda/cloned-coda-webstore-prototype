# Release Notes — v0.13.3

**Date:** June 2026
**Milestone:** CTA and timer spacing polish across SkuCard, GiftSkuCard, BundleSkuCard, and BestSellerCard

---

## Highlights

- **CTA breathing room** — all three card types that stack content above a CTA or timer now have a guaranteed minimum gap via `padding-top: var(--pad-surface-s)` (8px), preventing the action area from sitting flush against the content above on short cards.
- **GiftSkuCard CTA/countdown gap widened** — internal gap between the "CLAIM GIFT" label and the countdown ticks up from 2px → 4px for better legibility.
- **BestSellerCard subtitle/countdown nudge** — a lighter touch (2px `padding-bottom` on the subtitle) gives a total 6px clearance before the timer without over-spacing the compact card.

---

## Component changes

### `SkuCard.vue`

- **`.sku-card__price`:** added `padding-top: var(--pad-surface-s)` (8px). Creates a minimum floor above the price CTA block; `margin-top: auto` continues to consume all remaining space above that floor.

### `GiftSkuCard.vue`

- **`.gift__action`:** added `padding-top: var(--pad-surface-s)` (8px) — minimum clearance above the CTA.
- **`.gift__action` gap:** `--gap-content-tight` (2px) → `--gap-content-narrow` (4px) — wider separation between "CLAIM GIFT" label and the countdown timer below it.

### `BundleSkuCard.vue`

- **`.bundle__countdown`:** added `padding-top: var(--pad-surface-s)` (8px) — visually separates the timer from the title/subtitle content above it within `.bundle__title-group`.

### `BestSellerCard.vue`

- **`.bestseller__subtitle`:** added `padding-bottom: var(--pad-surface-xxs)` (2px). Combined with the existing `--gap-content-narrow` (4px) column gap on `.bestseller__title-col`, total clearance between subtitle and countdown is 6px.
