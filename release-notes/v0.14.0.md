# Release Notes — v0.14.0

**Date:** June 2026
**Milestone:** Per-store dynamic favicon and eFootball asset cleanup

---

## Highlights

- **Dynamic per-store favicon** — browser tab icon now switches automatically when the active store changes in the runtime multi-store build. Each store provides its own logomark SVG as `assets.brand.favicon`; store-locked builds bundle only that store's asset.
- **New `useFavicon` composable** — reactive `watchEffect` that upserts `<link rel="icon" type="image/svg+xml">` in `<head>`, driven by `useStoreAssets`.
- **FCM uses its own logomark** — `FCM Logomark.svg` (not the EA logomark) is now wired as the FCM favicon.
- **eFootball asset cleanup** — removed placeholder `efc-icon.svg` and `qr-placeholder.svg` from `src/stores/efootball/img/brand/`; real eFootball logomark SVG replaces the text placeholder.

---

## New files

### `src/composables/useFavicon.js`

- Calls `useStoreAssets()` and `watchEffect`s on `assets.value.brand.favicon`.
- Upserts a `<link rel="icon" type="image/svg+xml">` element in `<head>` — creates it if absent, updates `href` on every store change.
- Called once from `App.vue` `<script setup>`.

### `src/stores/fcm/img/brand/FCM Logomark.svg`

- Official FCM logomark SVG. Used as `assets.brand.favicon` for the FCM store.

---

## Store module changes

### `src/stores/codm/store.js`

- **`assets.brand.favicon`:** added, points to `codm-logomark.svg` (the existing `logomark` import).

### `src/stores/fcm/store.js`

- **New import `fcmLogomark`:** `./img/brand/FCM Logomark.svg`.
- **`assets.brand.favicon`:** added, points to `fcmLogomark`. EA logomark (`logomark`) unchanged for sign-in button.

### `src/stores/efootball/store.js`

- **Removed imports:** `efcIcon` (`efc-icon.svg`) and `qrPlaceholder` (`qr-placeholder.svg`) — placeholder files deleted.
- **`assets.brand.favicon`:** added, points to `logomark` (`logomark.svg` — real art now in place).
- **`assets.brand`:** `efcIcon` and `qrPlaceholder` entries removed.
