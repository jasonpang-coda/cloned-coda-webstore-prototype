# Release Notes — v0.14.1

**Date:** June 2026
**Milestone:** Best-seller section description blurb, category heading renames, qualitative-tweak clarifier in FE skill

---

## Highlights

- **Best-seller section descriptions** — both `BestSellerCard` (hero) and `BestSellerCarousel` now accept a `description` prop; a `<p>` in `text-style-paragraph-regular` / `--text-body-default` renders below the section heading. Default blurb: "Community favourites — top-rated bundles and operator gear."
- **Category heading renames** — `cpDealsHeading` renamed from `'NEW USER CP DEALS'` → `'New Users (Image)'`; `cpImageSection` renamed from `'BUY CP'` → `'CP (Image)'`.
- **Qualitative-tweak clarifier** — folded the standalone `design-tweak-clarifier` skill into `codm-web-store-fe/SKILL.md` §1 as a permanent gate with a regression example and pre-ship checklist item.

---

## Component changes

### `BestSellerCard.vue`

- **New prop `description`** (`String`, default `null`): section-level blurb rendered as `.bestseller__section-desc` between the heading and the card. Only renders when both `showHeading` and `description` are truthy — compact carousel tiles (which have `showHeading: false`) are unaffected.
- **New CSS rule** `.bestseller__section-desc`: `color: var(--text-body-default); margin: 0; text-style-paragraph-regular`.

### `BestSellerCarousel.vue`

- **New prop `description`** (`String`, default `null`): section-level blurb rendered as `.bs-carousel__desc` below the title/chevron row.
- **Header restructure**: `.bs-carousel__header` is now `flex-direction: column; gap: var(--gap-content-narrow)`. A new `.bs-carousel__header-row` child holds the existing title + chevron nav as a `space-between` flex row. The `padding-inline` inset rule (XS/S only) stays on `.bs-carousel__header` so both the row and the description inherit it.
- **New CSS rules** `.bs-carousel__header-row` (flex row) and `.bs-carousel__desc` (`color: var(--text-body-default); margin: 0`).
