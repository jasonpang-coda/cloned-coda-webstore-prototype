# Release Notes — v0.15.0

**Date:** June 2026
**Milestone:** Gift-claim flow — ClaimGiftSheet, useGiftClaim composable, inline PlayerAccount, confirm→success animation, bidirectional player-info sync, snackbar generalisation, selected-state token fixes across all SKU cards

---

## Highlights

- **Gift-claim flow** — tapping a gift card now opens a full confirmation sheet (confirm view + animated success view) driven by the new `useGiftClaim` singleton composable. Signing out or being a guest shows the gamer-ID form inline so users can identify their account without leaving the sheet.
- **ClaimGiftSheet** — new bottom-sheet component (sibling of `CheckoutSheet`): confirm view with SKU banner + optional `PlayerAccount`; success view with completion message + upsell SKU banner; `mode="out-in"` animated body/title/CTA transitions; success border-flash keyframe.
- **PlayerAccount bidirectional sync** — player info verified on the main page is pre-filled in the sheet, and vice versa; state is preserved across sheet open/close cycles.
- **Generalised snackbar** — `useAuth.showSnackbar()` now accepts a `{ title, text }` arg so any flow can reuse the same success toast. `Snackbar.vue` renders dynamic copy. Z-index raised from 3→5 so it appears above all sheets.
- **Selected-state token fix** — `--bg-card-selected` and `--border-sku-card-selected` are now used consistently across all card types (previously some used stale `--bg-sku-card-success` / `--bg-card-success` aliases).
- **Button label centering (CheckoutSheet)** — `transform-origin: center center` added to `.sheet__checkout-label`, matching the fix already in `ClaimGiftSheet`. Hitmarker condense now scales symmetrically from the button centre.

## New files

### `src/composables/useGiftClaim.js`

Singleton composable; mirrors `useCheckout.js` pattern.

- `claimSheetOpen`, `selectedGift`, `claimSuccess` (confirm/success toggle), `requiresAccount` (frozen at open time), `claimedIds` (reactive Set).
- `openGiftClaim(gift)` — always opens (ungated); captures `requiresAccount = !signedIn` at open time.
- `confirmClaim()` — adds to `claimedIds`, flips `claimSuccess = true`, fires gift-claimed snackbar.
- `isClaimed(id)` — drives card CLAIMED state.

### `src/components/ClaimGiftSheet.vue`

- Props: `isMobile` (Boolean), `upsellItem` (Object — best-seller or featured SKU for success upsell).
- Confirm view: label + SKU banner + optional `<PlayerAccount v-if="requiresAccount">`. CTA disabled (`opacity: 0.4`) until `signedIn || guestVerified`.
- Success view: completion label + upsell intro + upsell SKU banner. CTA shows `upsellItem.currentPrice`; tap → `openCheckout(upsellItem)` + `closeGiftClaim()`.
- `claim-body` transition: confirm exits up, success rises from below (`overflow: hidden` on panel clips travel).
- `claim-title` + `claim-footer`: crossfade (`mode="out-in"`).
- `.sheet__panel--success`: `success-border-flash` keyframe pulses `--text-success-default` on the top border.
- Z-index 4. Escape-to-close. Slide-up mobile / scale-in desktop modal.

## Component changes

### `src/components/GiftSkuCard.vue`

- **New prop `id`** (`String`, required): stable claim identity.
- **`claimed`** is now `computed(() => isClaimed(props.id))` — driven by shared confirmed-claim set, not a local ref toggle.
- **`onClaim()`** calls `openGiftClaim({ id, title, subtitle, image })`; `haptic('select')` fires only on a real open.
- **Selected state** (`.gift--selected`): `--bg-card-selected` fill + `--border-sku-card-selected` ring while the sheet is open for this gift.

### `src/components/PlayerAccount.vue`

- **State initialises from shared state:** `playerId = guestPlayerName.value`; `status = 'found'` if already verified.
- **Bidirectional sync:** `watch([guestVerified, guestPlayerName])` mirrors updates from the other instance (main page ↔ sheet). Guard prevents spurious self-triggering.
- **`onBeforeUnmount` no longer resets `guestVerified`** — verified state survives sheet close/reopen. Only `onEdit()` resets intentionally.

### `src/components/CheckoutSheet.vue`

- **`.sheet__bonus`**: colour corrected to `--text-bonus-amount` (was `--text-body-default`).
- **`.sheet__pc-card.is-selected`**: `--bg-card-selected` (was `--bg-card-success`).
- **`.sheet__checkout-label`**: `transform-origin: center center` added — Hitmarker condense now centres symmetrically on the "Buy Now" button.

### `src/components/Snackbar.vue`

- Renders `snackbarContent.title` / `snackbarContent.text` (previously hardcoded sign-in copy).
- **Z-index: 3 → 5** — now renders above all sheets (z:4).

### `src/components/BestSellerCard.vue`

- Selected state: `.bestseller__card--selected` with `--bg-card-selected` + `--border-sku-card-selected`.
- `openCheckout()` now receives `itemKey` (`${amount}|${currentPrice}`) as second arg; `sheetOpen`/`selectedKey` imported to compute `isSelected`.

### `src/components/SkuCard.vue`

- Same selected-state treatment as `BestSellerCard` — `.sku-card--selected` applies `--bg-card-selected` to `.sku-card__bg` + ring on `::before`.

### `src/components/BundleSkuCard.vue`

- `.bundle--selected`: `--bg-card-selected` (was `--bg-sku-card-success`); `--border-sku-card-selected` ring on `::before`.

### `src/components/SkuImageCard.vue`

- `.sku-image-card--selected .sku-image-card__bg`: `--bg-card-selected` (was `--bg-sku-card-success`).
- `::before` ring token corrected to `--border-sku-card-selected`.
