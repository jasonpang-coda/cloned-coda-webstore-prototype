# Release Notes — v0.16.0

**Date:** June 2026
**Milestone:** ResellerBanner — FCM compliance notice, full-bleed L3 surface, accordion expand

---

## Highlights

- **ResellerBanner** — new full-bleed L3 surface banner placed between the NavBar and StoryCarousel in the FCM store. Displays a short compliance line ("THIS WEBSTORE IS OPERATED BY CODA.") with a chevron toggle that expands a longer authorised-reseller statement. Accordion works at all screen sizes.

---

## New components

### `src/components/ResellerBanner.vue`

- Full-bleed strip — no `<Grid>` wrapper; grid-matching left/right padding via `@container` (12px default, 16px at ≥1280px).
- **Surface:** `--bg-sheet` (L3 fill), no border.
- **Bar row:** 4px top/bottom padding (`--pad-surface-xs`); short text (`text-style-utility-label-uppercase`, `--text-body-default`) + chevron toggle button, 4px gap.
- **Accordion:** `isExpanded` ref; `.is-open` CSS class reveals long message panel; chevron rotates 180° via `--motion-duration-exit / --motion-ease-standard`.
- Rendered in `App.vue` via `<ResellerBanner v-if="isFilter" />` — FCM only.
