# Release Notes — v0.16.1

**Date:** June 2026
**Milestone:** Gift-claim success bg glow replaces snackbar, --motion-duration-slowest token, FE skill token-tier rule

---

## Highlights

- **Success bg glow** — the gift-claim success state now radiates a green background glow across the sheet panel (opacity 0 → 0.25 → 0, 1800ms) instead of firing a snackbar. The glow is delayed 550ms so it fires after the body out-in transition fully settles.
- **`--motion-duration-slowest`** — new base motion token (`1800ms`) for extended delight animations; the duration scale no longer has a hard cap at `--motion-duration-slower`.
- **Token-tier rule in FE skill** — new "Match the token tier to the CSS property" rule: `--bg-*` for `background`, `--text-*` for `color`, `--border-*` for `border-color`. Crossing tiers (e.g. using a `--text-*` token for a background) is now explicitly called out as wrong.

---

## Component changes

### `src/components/ClaimGiftSheet.vue`

- **Removed** `.sheet__panel--success` class binding and `success-border-flash` keyframe (top border colour pulse).
- **Added** `.sheet__success-overlay` div (last child of `.sheet__panel`, `aria-hidden="true"`). Resting state: `opacity: 0`. Active state (`.--active` class when `claimSuccess` is true): `success-bg-glow` keyframe — `0% opacity:0 → 15% opacity:0.25 → 100% opacity:0`.
- `animation-duration: var(--motion-duration-slowest)` (1800ms).
- `animation-delay: calc(var(--motion-duration-exit) + var(--motion-duration-slow))` (550ms — waits for body out-in transition to complete).
- `background: var(--bg-indicator-success-default)` — correct `--bg-*` tier token for a background fill (previously used `--text-success-default`, a cross-tier error).

### `src/composables/useGiftClaim.js`

- **Removed** `useStoreStrings` import and usage.
- **Removed** `showSnackbar` from the `useAuth` destructure.
- **`confirmClaim()`** now only adds to `claimedIds` and flips `claimSuccess = true` — no snackbar side-effect.
