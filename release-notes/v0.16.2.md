# Release Notes — v0.16.2

**Date:** June 2026
**Milestone:** Sheet resize transitions — organic height animation within ClaimGiftSheet and handoff fade+resize from ClaimGiftSheet to CheckoutSheet

---

## Highlights

- **Within-sheet resize (confirm → success):** `ClaimGiftSheet`'s body transition now animates the panel height from the confirm-view size to the success-view size while content crossfades, replacing the previous `translateY` slide that looked like separate layers appearing.
- **Cross-sheet handoff (gift success → order summary):** Tapping the upsell CTA no longer shows ClaimGiftSheet sliding down while CheckoutSheet slides up. ClaimGiftSheet fades in place; CheckoutSheet enters starting at the gift-sheet's captured panel height and resizes to its natural checkout height.
- **`useSheetTransition` composable:** New singleton that carries the handoff panel height between sheets. Establishes a reusable pattern for any future sheet-to-sheet transition.

---

## Component changes

### `src/components/ClaimGiftSheet.vue`

- **Body transition redesigned:** `claim-body` transition changed from `translateY + opacity` to fade-only (`opacity` only). JS hooks (`@before-leave`, `@enter`, `@after-enter`) on the inner `<Transition>` lock the panel height, measure the new content height, and animate via `.sheet__panel--resizing`. Confirm exits with a fade; the panel reshapes; success fades in.
- **Sheet handoff exit:** `onUpsellCta()` now captures `panelRef.value.offsetHeight` into `useSheetTransition.handoffHeight` and sets `isHandoffExit = true` before calling `openCheckout` + `closeGiftClaim`. `@before-leave` / `@leave` hooks on the outer `<Transition>` intercept the leave: `@before-leave` pins `transform: none; transition: none` on the panel via `el.querySelector('.sheet__panel')` (bypasses the slide-down CSS); `@leave` sets `transition: opacity` + `opacity: 0` for a fade-only exit. Uses `el.querySelector` instead of `panelRef` because Vue may clear template refs before leave hooks fire.
- `isHandoffExit` ref added; cleared in `@after-leave`.

### `src/components/CheckoutSheet.vue`

- **Handoff enter:** `useSheetTransition` imported. `panelRef` ref added to `<section class="sheet__panel">`. JS hooks on the outer `<Transition>`: `@before-enter` reads `handoffHeight`, saves to `_handoffH`, clears the shared ref, adds `.sheet--handoff-enter` class (suppresses `translateY(100%)` slide, uses opacity fade instead), and locks the panel at the handoff height. `@enter` measures the natural checkout height and starts the height animation via `.sheet__panel--resizing`. `@after-enter` clears inline styles. Normal opens (SKU card taps) are unaffected — all hooks are no-ops when `handoffHeight` is null.
- **CSS added:** `.sheet__panel--resizing { overflow: hidden; transition: height ... }`. `.sheet--handoff-enter` enter overrides (mobile + responsive).

## New composables

### `src/composables/useSheetTransition.js`

Module-level singleton with a single `handoffHeight` ref. The closing sheet writes the panel height before triggering the swap; the entering sheet reads and clears it in `@before-enter`. Establishes a shared contract for sheet-to-sheet height handoffs without coupling the two components directly.
