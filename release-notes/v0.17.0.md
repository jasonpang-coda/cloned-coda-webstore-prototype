# Release Notes — v0.17.0

**Date:** June 2026
**Milestone:** FCM gift claim flow — EA sign-in sheet variant, BundleSkuCard claimed state, toolbar version label

---

## Highlights

- **FCM gift claim flow:** Gifts tab wired to `ClaimGiftSheet` via `BundleSkuCard` click interception. `fcmGiftItems` computed enriches catalog items with `endsAt`, `refreshesOnClaim` (Daily Gift), and `limitLabel` (First Login Reward).
- **EA sign-in in sheet:** Signed-out FCM users see an EA Account button in the sheet footer instead of a disabled CTA. Tapping stores the pending gift, closes the sheet, and redirects to EA sign-in; `useGiftClaim` auto-confirms the claim and reopens the sheet in success state once sign-in completes.
- **BundleSkuCard claimed state:** New `claimed`, `limitLabel`, and `refreshesOnClaim` props. Claimed cards dim their banner to 30% opacity, show `cursor: default`, and switch the countdown prefix from `"Ends:"` to `"Refreshes:"`. Tapping a claimed card is a no-op.
- **Sign-out resets claimed set:** `useGiftClaim`'s `watch(signedIn)` clears `claimedIds` and `pendingEaGift` when the user signs out.
- **`fcmBestSeller` asset fix:** Standalone Daily Booster D `BestSellerCard` now derives `image` (banner background) and `skuImage` (product art overlay) from `featuredItems[0]`, matching the FeaturedCarousel card and Daily Supplies SKU card.
- **Toolbar version label:** `DeviceToolbar` displays a subtle `vX.Y.Z` label pinned to the right edge, read from `package.json` at build time.

---

## Component changes

### `src/components/ClaimGiftSheet.vue`

- **EA flow footer (new):** `isEaFlow` computed (`config.signIn?.flow === 'ea-redirect'`). `showEaSignIn` computed drives a third footer state (`key="confirm-ea"`) rendering an EA button (`.sheet__cta--ea`) with the EA logomark. `onEaSignIn()` stores `pendingEaGift`, calls `closeGiftClaim()` then `startEaSignIn()`.
- **`PlayerAccount` conditional:** now only rendered when `requiresAccount && !isEaFlow` — EA-flow stores use the footer button instead.
- **Upsell item:** `:upsell-item` is now `isFilter ? fcmBestSeller : bestSeller` from App.vue — FCM success view upsells Daily Booster D.

### `src/components/BundleSkuCard.vue`

- **New props:** `claimed` (Boolean), `limitLabel` (String), `refreshesOnClaim` (Boolean).
- **`countdownPrefix` computed:** `props.claimed && props.refreshesOnClaim ? 'Refreshes:' : 'Ends:'`.
- **Template:** `bundle--claimed` class added to root; `limitLabel` renders below subtitle; countdown label uses `countdownPrefix`.
- **CSS:** `.bundle--claimed { cursor: default }` · `.bundle--claimed .bundle__banner { opacity: 0.3; transition: opacity ... }` · `.bundle__limit` styles added.

### `src/components/DeviceToolbar.vue`

- **Version label:** imports `version` from `../../package.json`. Renders `<span class="toolbar__version">v{{ version }}</span>` as an absolutely positioned element (`right: 14px`, `top: 50%`), `font-size: 11px`, `opacity: 0.55`, `pointer-events: none`.

## Composable changes

### `src/composables/useGiftClaim.js`

- **`pendingEaGift` ref (new):** stores the gift before EA sign-in redirect; exported.
- **`watch(signedIn)` expanded:** sign-out branch clears `claimedIds` + `pendingEaGift`; sign-in branch auto-confirms pending EA gift after 200ms.
