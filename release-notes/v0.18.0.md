# Release Notes — v0.18.0

**Date:** June 2026
**Milestone:** TDR store (The Division Resurgence) — full whitelabel from scratch, guest-only checkout, single-section page model, per-store SKU overrides

---

## Highlights

- **New store — TDR (Tom Clancy's The Division Resurgence):** Complete whitelabel: hazard-amber OKLCH palette, Sportize heading font + Borda body font (6 + 12 cuts), guest-only checkout (`navbar.hideSignIn: true`), single Premium Credits section (`page.sections: ['cp-img']`), 6 real SKU denominations with product art and background image, custom wordmark/logomark/carousel.
- **`useStoreSkus()` composable:** Registry-pattern composable (mirrors `useStoreCatalog`/`useFeaturedItems`) that returns a store's per-store SKU overrides. `App.vue`'s `cpImageRegular` computed checks this first, falling back to the hardcoded COD:M items.
- **`showSection()` helper + `page.sections` config:** Section-level allowlist (`config.page?.sections`). Null means show all; an array of IDs gates each `<section v-if="showSection(...)">`. Enables per-store page models without component branching.
- **`catalog.hideNav` capability flag:** Suppresses the sticky bottom `CategoryNav` for single-category stores (TDR). Wired as `v-if="!config.catalog.hideNav"` on the `CategoryNav` mount in App.vue.
- **`profile.showAccountInstructions` capability flag:** Default-true (`!== false`) flag. Setting it to `false` in `config.profile` hides the instruction chips in `PlayerAccount` — TDR presents a clean ID field with no find-UID guidance.

## Composable changes

### `src/composables/useStoreCatalog.js`

- **`useStoreSkus()`:** new export. `SKUS_REGISTRY` built from `ACTIVE_STORES.map(s => [s.key, s.skus ?? null])`; returns a computed resolving to the active store's `skus` object or `null`. Consumed by App.vue's `cpImageRegular` computed to allow per-store SKU sets without hardcoding per-store branches.

---

## Component changes

### `src/App.vue`

- **`showSection(id)` helper:** reads `config.value.page?.sections`; returns `true` if null (all sections show) or the id is in the allowlist array. Applied to: `best-seller`, `bundle`, `gifts`, `new-users`, `cp`, `cp-img-newuser` sections.
- **`storeSkus` + `cpImageRegular` override:** imports `useStoreSkus()`; `cpImageRegular` computed checks `storeSkus.value?.cpImageRegular` first and maps it with `bonusLabel` before falling back to COD:M hardcoded items.
- **`catalog.hideNav`:** `<CategoryNav v-if="!config.catalog.hideNav" …>` — suppresses the sticky bottom nav when set.
- **`currency-label` prop:** `:currency-label="strings.currency.name"` passed to the `cat-cp-img` `SkuImageList`, so SKU titles read "125 Premium Credits" rather than bare "125".

### `src/components/PlayerAccount.vue`

- **`showAccountInstructions` flag:** instruction chips div now gated `v-if="status !== 'found' && config.profile?.showAccountInstructions !== false"`. Imports `useStoreConfig`; uses the `!== false` default-true pattern so all existing stores are unaffected.
