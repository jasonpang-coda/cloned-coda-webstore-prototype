# Release Notes — v0.18.1

**Date:** June 2026
**Milestone:** TDR section description, SKU strikethrough prices + -20% discount labels; SkuImageList description prop

---

## Highlights

- **TDR section description:** "Get 20% discount on your first purchase" renders below the "Premium Credits" section heading, wired via `strings.page.cpImageSectionDesc`.
- **TDR SKU discount display:** all 6 Premium Credits SKUs now show a strikethrough original price (20% above current price) and a `-20%` badge, using the existing `originalPrice`/`discountPercent` props on `SkuImageCard`.
- **`SkuImageList` description prop:** new optional `description` prop renders a subtitle line (`text-style-paragraph-regular`, `--text-body-soft`) below the section title. Null by default — all other stores are unaffected.

---

## Component changes

### `SkuImageList.vue`

- **`description` prop (new):** optional `String`, default `null`. When set, title + description are wrapped in a `.sku-image-list__header` flex column (`gap-content-narrow`); the description renders as `<p class="text-style-paragraph-regular">` in `--text-body-soft` colour.
- Title-only path unchanged — no visual regression for stores that don't pass a description.
