# Release Notes — v0.19.0

**Date:** June 2026
**Milestone:** Yu-Gi-Oh! DUEL LINKS store (KONAMI ID sign-in, page model, L1/L2/L3 frosted surfaces, per-store SKU sections)

---

## Highlights

- **New store — Yu-Gi-Oh! DUEL LINKS (YGODL):** full whitelabel build — theme, store module, SKU data, and assets. Electric blue primary, KONAMI red secondary, gold tertiary, fixed circuit-board page background. KONAMI ID (`myKONAMI`) sign-in with no navbar sign-in button. Three-section page model: Regular, Limited, Free Rewards.
- **KONAMI gift claim flow:** gift sheet shows a KONAMI ID Sign In button instead of the gamer-ID lookup. Shares the `pendingEaGift` watcher pattern with the EA flow — gift auto-confirms after sign-in completes.
- **L1/L2/L3 frosted surfaces:** `BundleSkuCard` and `GiftSkuCard` now use the `--bg-sku-card-default` (L1) surface + `backdrop-filter` blur. Sheet footers use the new `--bg-sheet-footer` semantic token (L3). Sheets switch to `--bg-sheet` (L2) and footers to L3 via per-store token overrides.
- **Horizontal drag-scroll breakdown row:** `BundleSkuCard` gains a `breakdownScrollable` prop — scrolls and mouse-drags horizontally for wide item sets (e.g. Monthly Pack A, 8 items). Powered by `useDragScroll`.
- **Unified `SkuTag` bonus/value colour:** both the `bonus` and `value` tag variants now resolve their text colour through `--text-tag-bonus`, ensuring BONUS chips and card badge labels (WEB STORE EXCLUSIVE, BEST VALUE, FREE GIFT) all share one per-store token.
- **`tagLabel` prop on `SkuCard` and `SkuImageCard`:** any card can now carry an arbitrary tag badge without needing a hardcoded flag.
- **`showRank` flag on `PlayerCard`:** `config.profile.showPlayerRank: false` hides the MP Rank stat row — wired for TDR and YGODL which have no rank concept.
- **Gradient border ring on `PageSignInSection` card:** replaced the solid `--border-card-default` with the mask-composite `::before` technique matching `SkuCard`.

## New store

### `src/stores/ygodl/` + `src/tokens/ds/themes/ygodl.css`

- **Theme seeds:** `--ref-primary: oklch(0.550 0.215 264)` (electric blue `#2563EB`), `--ref-secondary: oklch(0.460 0.195 27)` (KONAMI red `#B60014`), `--ref-tertiary: oklch(0.860 0.175 95)` (gold `#FFCC00`).
- **`--bg-page: transparent` (in `html[data-theme="ygodl"]`):** sheet `background-color` is transparent so the fixed-image page background shows through the frosted `backdrop-filter`. Required for L2/L3 surfaces to render correctly.
- **Surface fills (L1/L2/L3):** white-tinted overlays (`oklch(1 0 0 / 0.10→0.16)` / `0.13→0.21` / `0.15→0.23`), all `to bottom`, 8px blur. `--blur-container: 8px`.
- **`--bg-sheet: var(--surface-l2-fill)`** (override from default L3 → L2 so the sheet sits one level below the L3 footer).
- **`--rarity-gradient-*` all → `var(--surface-l3-fill)`:** bundle item tiles use the L3 frosted surface regardless of rarity, without any component edit.
- **Token direction (primary ↔ secondary swapped vs codm):** primary = electric blue, secondary = KONAMI red. `--text-hyperlink-*` and `--text-final-price` → primary; `--text-error-default` / KONAMI action background → secondary.
- **`--text-tag-bonus: var(--text-bonus-amount)`, `--text-bonus-amount: var(--palette-tertiary-400)` (gold):** all tag and bonus amount text resolves to gold in the YGODL theme.
- **`config.catalog.mode: 'page'`** — three named sections (`regular`, `limited`, `free-rewards`) + `config.page.sections` array driving `App.vue`'s `categories` computed and section rendering.
- **`config.signIn: { desktop: ['mykonami'], mobile: ['mykonami'] }`**, `config.navbar.hideSignIn: true`, `config.checkout.allowGuest: false`.
- **`config.profile: { avatarStyle: 'image', playerCard: 'nickname-only', showLoyaltyPill: false, showPlayerRank: false }`.**

## Component changes

### `BundleSkuCard.vue`

- **L1 surface treatment (v0.19.0):** background changed from `var(--rarity-gradient-neutral)` to `var(--bg-sku-card-default)` + `backdrop-filter: blur(var(--blur-container, 32px))`. YGODL's L1 surface `--surface-l1-fill` shows through automatically.
- **`breakdownScrollable` prop (new):** Boolean, default `false`. When true, `.bundle__breakdown` gains `overflow-x: auto; scrollbar-width: none; -webkit-overflow-scrolling: touch`. `useDragScroll(breakdownRef)` enables pointer-drag on desktop; `isDragging` adds `.is-dragging` (`user-select: none`) while dragging.
- **Price text style:** `.bundle__current` changed from `text-style-heading-page-title` → `text-style-heading-card`.

### `GiftSkuCard.vue`

- **L1 surface treatment (v0.19.0):** `.gift` gains `background: var(--bg-sku-card-default)` + `backdrop-filter: blur(var(--blur-container, 32px))`. Previously had no explicit background (transparent).

### `ClaimGiftSheet.vue`

- **KONAMI sign-in flow (v0.19.0):** `isKonamiFlow` computed (`config.signIn.mobile/desktop.includes('mykonami')`). When true and signed out, `PlayerAccount` is hidden and a KONAMI ID Sign In button renders in the footer (`.sheet__cta--mykonami`: `--bg-action-mykonami` background, no icon, `text-style-utility-action-bold`, natural casing). `onKonamiSignIn()` saves `pendingEaGift`, closes the sheet, and calls `startKonamiSignIn()` — the existing `watch(signedIn)` watcher in `useGiftClaim` fires on completion.
- **Footer background:** changed from `var(--bg-sheet)` → `var(--bg-sheet-footer)`.
- **`startKonamiSignIn`** imported from `useAuth`.

### `CheckoutSheet.vue`

- **Footer background (v0.19.0):** changed from `var(--bg-sheet)` → `var(--bg-sheet-footer)`.

### `PageSignInSection.vue`

- **Gradient border ring (v0.19.0):** `.page-signin__card` border changed from `var(--border-weight-default) solid var(--border-card-default)` to `border: 0` + `::before` mask-composite ring (`background: var(--border-sku-card-default)`, same technique as `SkuCard`). `position: relative` added to the card.

### `PlayerCard.vue`

- **`showRank` prop (new):** Boolean, default `true`. When `false`, the `MP Rank: …` stat span is hidden (`v-if="showRank"`). Consumed via `config.profile.showPlayerRank` in `AccountPopover` and `PlayerAccount`.

### `SkuCard.vue`

- **`tagLabel` prop (new):** String, default `null`. When set, overrides the hardcoded `'BEST VALUE'` label — any card can carry an arbitrary tag badge. `v-if` now triggers on `tagLabel || isBestValue`.

### `SkuImageCard.vue`

- **`tagLabel` prop (new):** String, default `null`. When set, renders a `SkuTag` (variant `value`) absolutely positioned top-left over the card (`.sku-image-card__badge`, `top/left: --pad-surface-xs`, `z-index: 3`). `SkuTag` imported.

### `SkuTag.vue`

- **Unified `bonus` + `value` colour (v0.19.0):** both variants now use `color: var(--text-tag-bonus)`. Previously `bonus` used `var(--text-bonus-amount)` and `value` used `var(--text-hyperlink-default)` — causing the gift card tag and SKU badge to be a different colour from the bundle BONUS chip. One token (`--text-tag-bonus`) now controls all three; per-store override is trivial.

## Store / data changes

### `src/stores/tdr/store.js`

- **`config.profile.showPlayerRank: false`** — hides the MP Rank row in TDR's PlayerCard (no rank concept in TDR).

### `src/App.vue`

- **`categories` computed:** now reads `config.value.page?.sections` when present — maps section IDs to tab labels by position, so the CategoryNav only lists sections that actually render. Falls back to the hardcoded COD:M section map.
- **`regularImageItems`, `limitedBundles`, `rewardGifts` computeds:** read `storeSkus.value?.regular/.limited/.gift` respectively; return `null` when absent (unaffected stores). Relative `endsInMs` offsets are resolved to absolute epoch values at boot via `PAGE_NOW = Date.now()`.
- **Three new conditional section templates:** `cat-regular` (SkuImageList), `cat-limited` (BundleGrid/BundleSkuCard), `cat-free-rewards` (GiftGrid/GiftSkuCard) — each gated on `v-if="<computed> && showSection('<id>')"`.
- **`cat-cp-img` section:** wrapped with `v-if="showSection('cp-img')"` so it hides on stores using the new section model.
