# CODM SKU Card 3.0 — v0.2.1

**Polish & HDR colour release** · June 2026

This release completes the v0.2.0 sign-in + checkout flow with a round of visual polish:
the SKU card border is upgraded to OKLCH with an HDR glint, the action yellow follows
suit, the checkout bottom sheet ships with its full responsive behaviour and corrected
font condensing, and several UX timing improvements land.

---

## What's new

### OKLCH gradient border on SKU cards
The SKU card border moves from a flat `rgba` 3-sided rule to a **OKLCH gradient ring**
via the mask-composite pseudo-element technique (the same family as the best-seller
conic border). The gradient runs at 160° from near-transparent at the top-left to bright
near-white at the bottom-right, giving the card a natural specular highlight.

On HDR-capable displays (`@media (dynamic-range: high)`) the border pushes above the
sRGB white ceiling (`oklch(1.2–1.3 … 247)`) for a genuine glint — consistent with the
action-yellow and best-seller glow HDR treatment. Hover brightens the gradient in-place.

### OKLCH action / primary yellow
`--text-hyperlink-inverse` and `--bg-action-primary` are now defined in OKLCH
(`oklch(0.91 0.191 97)` at SDR; `oklch(1.03 0.25 97)` on HDR) — the same perceptual
hue as `#ffe700` but with a tiny L lift and HDR headroom. All components that reference
the token automatically benefit.

### Checkout bottom sheet — full responsive behaviour
The "SELECT PAYMENT" sheet adapts to device context:
- **Mobile / framed** — bottom sheet, slide-up from the screen edge
- **Responsive ≥ 801px** — centered modal (`max-width: 420px`, `max-height: 85vh`),
  fade + scale entrance, `position: fixed` to the viewport

The sheet also picks up Coda branding (logo replaces the text "CODA"), an OKLCH
superluminant shimmer on the CHECK OUT button (`oklch(1 0 0 / 0.7)` → `oklch(1.3 …)` on
HDR), and full Hitmarker horizontal condensing on all text (account name, bonus text,
payment channel labels, tax copy).

### Snackbar — viewport-pinned on desktop + entrance delay
In responsive mode the snackbar switches to `position: fixed` so it sits at the
**viewport bottom** rather than the bottom of the tall scrolling page. A 500 ms delay
is also added between the sign-in transition completing and the snackbar bouncing in —
the navbar swap and loader fade-out finish before the toast arrives, giving a more
choreographed sequence.

### Sign-in loader — viewport-fixed on desktop
The desktop QR sign-in overlay is now `position: fixed`, pinning it to the 100vh
viewport instead of the full-height scrolling page. The Cancel Sign In link is vertically
centred with the content (no longer bottom-pinned + divider), matching the updated Figma.

## Visual refinements

- **SKU card title 28 → 24px** (H2) and **price 20 → 18px** (H5) — matched to updated Figma
- **Best Value tag** condensed via `letter-spacing` (not `scaleX`) — the tag box now
  hugs the label text; the previous `scaleX` left invisible padding inside the chip
- **Section headers 22 → 16px** across Best Seller, Best Seller Carousel, SKU List
- **Best-seller carousel** compact variant: single continuous card radial gradient;
  no info-bar seam (previous design had a separate dark gradient on the info row)
- **Story carousel CTA** is now conditional (`v-if ctaLabel`) — portal-configurable
  per slide; The Boys slide ships without a CTA
- **Carousel full-bleed** on XS/S via `size="carousel"` Span variant (negative margins
  cancel the Grid's 12px padding); centred ½ on M/L

## Sign-in & checkout flow (v0.2.0 base, shipped here with polish)

- `useAuth.js` singleton: 5s loader → signed-in → 500ms → snackbar 5s auto-dismiss
- `useCheckout.js` singleton: no-op when signed out; opens the SELECT PAYMENT sheet
- Drawer updated to Figma 5031:14225 — Sign In footer / Sign Out footer toggle
- QR overlay for desktop sign-in (Figma 5031:15622); Cancel in content flow
- `vercel.json` — SPA rewrite + SVG `Content-Type` for CSS mask reliability

---

## Infrastructure

- `DeviceFrame.vue` overlay has **no `container-type`** — removing it lets
  `position: fixed` descendants reach the viewport in responsive mode (a `container-type`
  establishes a containing block for fixed elements, same as `transform`)
- All overlay components receive `:is-mobile="device !== 'none'"` from App.vue for
  context-aware layout switching

## Motion token additions

| Token / Pattern | Value | Purpose |
|---|---|---|
| `--motion-snackbar-enter` | 350ms spring | Snackbar bounce entrance |
| `--motion-snackbar-exit` | 250ms accelerate | Snackbar drop exit |
| `loading-indeterminate` keyframe | 1.4s linear ∞ | Sign-in loader bar |
| `snackbar-drop` keyframe | 250ms | Anticipation-hop + drop |
| `sheet` Vue Transition | 350ms decelerate / 200ms accelerate | Bottom sheet / modal |
