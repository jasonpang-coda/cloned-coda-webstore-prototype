# Release Notes — v0.20.0

**Date:** June 2026
**Milestone:** Global SKU press-scale token, hyperlink/bonus sys role ramps, YGODL surface + heading + player-card polish

---

## Highlights

- **Global SKU press-scale token:** `--motion-sku-press-scale: 0.99` added to `motion-sku.css`. All four card types (`SkuCard`, `BundleSkuCard`, `SkuImageCard`, `GiftSkuCard`) now share a single token — previously each had its own hardcoded value (SkuCard was `0.97`, BundleSkuCard was hardcoded `0.99`, SkuImageCard had no scale at all, GiftSkuCard had no press state). Changing the token adjusts every card simultaneously.
- **`GiftSkuCard` press state (new):** the card had no press feedback. Added `isPressed` ref, mousedown/mouseup/mouseleave/touchstart/touchend handlers, `gift--pressed` class binding, and the CSS rule — consistent with all other SKU cards.
- **Hyperlink sys role ramp:** `--sys-colour-hyperlink-{main,strong,heavy,inverse}` added to `system.css`. All themes previously overrode the five semantic `--text-hyperlink-*` tokens individually; they now each override only `--sys-colour-hyperlink-inverse` (the one value that differs per store). The semantic aliases in `semantics.css` now point to the sys ramp instead of hard-coding secondary/primary.
- **Bonus sys role ramp:** `--sys-colour-bonus-{subtle,strong,inverse}` added to `system.css`. Per-store bonus tag/chip/amount colours flow through this one role; YGODL overrides `bonus-strong` and `bonus-inverse` to gold. Theme-level `--bg-tag-bonus` / `--text-tag-bonus` / `--text-bonus-amount` overrides removed from all five themes — they inherit the sys role automatically.
- **`--text-text-on-brand` → near-white:** changed from `--sys-colour-neutral-subtle` (near-black) to `--sys-colour-ink-heavy` (`palette-neutral-0`, oklch ≈0.992) — consistent with how white ink is expressed everywhere else in the system.
- **YGODL surface fills corrected:** L1/L2/L3 fills were white-tinted overlays; corrected to dark-frosted overlays (`oklch(0 0 0 / 0.64→1.0)` / `0.56→0.88` / `0.42→0.88`), matching the Figma nodes.
- **YGODL heading weight 800:** all `.text-style-heading-*` on YGODL bumped from 700 to 800 (Meiryo at 700 read too thin).
- **`PlayerCard` L1 surface:** background changed from `--surface-ghost` (raw translucent white from `extensions.css`) to `--bg-sku-card-default` (the semantic L1 fill token), so it inherits the per-store surface correctly.
- **YGODL default player name:** KONAMI sign-in now defaults to `codayw` (was `'Player'`), matching the default used by the COD:M and FCM flows.

## Component changes

### `GiftSkuCard.vue`

- **Press state (new):** `isPressed` ref added; `@mousedown`, `@mouseup`, `@mouseleave`, `@touchstart.passive`, `@touchend.passive` handlers on the root element; `gift--pressed` class binding; `.gift--pressed { transform: scale(var(--motion-sku-press-scale)) !important; transition: transform var(--motion-sku-press), border-color var(--motion-sku-press); }` CSS rule added.

### `SkuCard.vue`

- **Press scale tokenised:** `.sku-card--pressed` scale changed from hardcoded `0.97` to `var(--motion-sku-press-scale)`.

### `BundleSkuCard.vue`

- **Press scale tokenised:** `.bundle--pressed` scale changed from hardcoded `0.99` to `var(--motion-sku-press-scale)`.

### `SkuImageCard.vue`

- **Press scale (new behaviour):** `.sku-image-card--pressed` previously used `translateY(0)` (removing the hover lift with no scale). Now uses `scale(var(--motion-sku-press-scale))` — consistent with all other card types.

### `PlayerCard.vue`

- **L1 surface:** background changed from `var(--surface-ghost)` to `var(--bg-sku-card-default)`. Comment updated from "Ghost surface + hairline border — L1 treatment" to "L1 surface + hairline border".

### `KonamiSignInPage.vue`

- **Default player name:** fallback in `handleSignIn()` changed from `'Player'` to `'codayw'`.

### `PageSignInSection.vue`

- **Hyperlink colour on sign-in card:** link colour changed from `--text-hyperlink-default` to `--text-hyperlink-inverse` (the card sits on a brand-coloured surface where `inverse` is the correct role).

### All themes (`codm`, `efootball`, `fcm`, `tdr`, `ygodl`)

- Per-theme `--text-hyperlink-*` semantic overrides removed. Replaced by a single `--sys-colour-hyperlink-inverse` override in each `html[data-theme]` block where the inverse colour differs from the default (`--sys-colour-secondary-main`).
- Per-theme `--bg-tag-bonus` / `--text-tag-bonus` / `--text-bonus-amount` overrides removed. All themes inherit from the new sys bonus ramp, which defaults to the primary family (reproducing the prior per-store values exactly).
