# Release Notes — v0.21.0

**Date:** June 2026
**Milestone:** CommandConsole — keyboard-driven `/` command palette for switching store, device, auth state, and navigation

---

## Highlights

- **`/` command palette:** Press `/` anywhere outside a text field to open a centred command console. Type to fuzzy-filter, `↑`/`↓` to navigate the list, `Enter` to run, `Esc` or scrim-click to close. Replaces reaching for the DeviceToolbar dropdowns during walkthroughs.
- **Blurred backdrop:** Full-bleed scrim (`--scrim` + `backdrop-filter: blur(64px)`) dims and blurs the store behind the palette, mirroring the NavDrawer pattern. Fades in/out with the panel via `--motion-modal-enter/exit`.
- **Data-driven command registry:** Built reactively from existing composables — no per-store branching. Store commands respect the active-stores manifest (absent in store-locked builds), auth commands toggle on `signedIn`, navigation commands derive from the live `categories` computed, and body-font commands appear only where `bodyFonts.length > 1` (COD:M).
- **System font isolation:** `--sys-font-family-body` and `--sys-font-family-heading` are overridden on `.cmd__panel` so `.text-style-*` descendants resolve to the OS system stack instead of the active store's typeface (Hitmarker, etc.).
- **Field-safe trigger:** `/` opens the palette only when `document.activeElement` is not an INPUT / TEXTAREA / SELECT / contenteditable — matches GitHub/Slack behaviour.

---

## New components

### `CommandConsole.vue`

- Centred overlay, `z-index: 6` (above Snackbar at z:5), mounted in DeviceFrame's `#overlay` slot.
- Command groups: **Store** (switch theme) · **Device** (iPhone/Android/Responsive) · **Auth** (sign in/out, store-correct flow dispatch) · **Navigation** (section jump, drawer, scroll-to-top) · **Appearance** (body-font, COD:M only).
- Fuzzy subsequence filter (dependency-free). Highlighted row auto-scrolls into view on arrow-key navigation.
- Motion: fade + 8px translateY lift on enter/exit (`--motion-modal-enter` / `--motion-modal-exit`).

---

## New composables

### `useCommandConsole.js`

- Module-level singleton (mirrors `useAuth`). Exports `open` (readonly ref), `openConsole()`, `closeConsole()`, `toggleConsole()`.
- Shared between the global keydown listener (`App.vue`) and the overlay without prop-drilling.

---

## Component changes

### `App.vue`

- Imports and mounts `<CommandConsole>` in the `#overlay` slot with `v-model:device`, `:sections="categories"`, `@navigate="onDrawerNavigate"`, `@open-drawer="menuOpen = true"`.
- Global `/` keydown registered in `onMounted`; removed in `onBeforeUnmount`. Guard: `isTypingTarget(el)` skips INPUT/TEXTAREA/SELECT/contenteditable targets.
