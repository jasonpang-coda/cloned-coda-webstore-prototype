# Release Notes — v0.21.2

**Date:** June 2026
**Milestone:** SkuImageCard `isBestValue` prop; BEST VALUE badge on COD:M image-led SKU cards

---

## Highlights

- **`isBestValue` on `SkuImageCard`** — mirrors the identical boolean prop already on `SkuCard`. When `true`, renders the top-left BEST VALUE `SkuTag` badge without requiring the caller to pass a `tagLabel` string. `tagLabel` takes precedence when both are set.
- **COD:M parity** — the two COD:M SKUs that carry the BEST VALUE badge in the text-only sections now also show it in their image-led counterparts: **5400 CP** (`cpImageNewUser`) and **160 CP** (`cpImageRegular`).

---

## Component changes

### `SkuImageCard.vue`

- **New prop `isBestValue` (Boolean, default `false`):** shorthand for showing the BEST VALUE badge; tag condition updated from `v-if="tagLabel"` to `v-if="tagLabel || isBestValue"`, label resolves `tagLabel ?? 'BEST VALUE'`.

### `App.vue`

- **`cpImageNewUser`:** 5400 CP item gains `isBestValue: true`.
- **`cpImageRegular`:** 160 CP item gains `isBestValue: true`.
