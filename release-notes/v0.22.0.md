# Release Notes — v0.22.0

**Date:** June 2026
**Milestone:** Global button disabled→enabled activation animation; `--text-text-on-brand` alias corrected to dark; new secondary/tertiary action-text semantic tokens

---

## Highlights

- **Button activation animation** — every button in the store (primary CTAs, sign-in buttons, carousel chevrons) now has a smooth 250ms ease-out transition when moving from disabled to enabled: opacity lifts from 40% to full and scale settles from 97% to 100%. Driven by a single new `--motion-btn-activate` token; `prefers-reduced-motion` collapses it to instant via the global `reduced-motion.css`.
- **`--text-text-on-brand` fixed** — the semantic alias was pointing to `--sys-colour-ink-heavy` (near-white), which gave poor contrast on the bright-yellow primary button. Corrected to `--sys-colour-ink-inverse` (dark charcoal `oklch(0.142 0.011 284.9)`). FCM and eFootball already override this token at theme level and are unaffected.
- **New button type tokens** — `--text-on-action-secondary` and `--text-on-action-tertiary` added to `semantics.css`, codifying the text-color role for secondary (frosted) and tertiary (ghost) buttons. NavBar "SIGN IN" label now uses `--text-on-action-tertiary` (same resolved near-white, correct semantic role).

---

## Token changes

| Token | Old | New | Note |
|---|---|---|---|
| `--text-text-on-brand` | `var(--sys-colour-ink-heavy)` (near-white) | `var(--sys-colour-ink-inverse)` (dark charcoal) | Fixes primary button text contrast |
| `--text-on-action-secondary` | — | `var(--sys-colour-ink-main)` (near-white) | New — text on secondary/frosted button |
| `--text-on-action-tertiary` | — | `var(--sys-colour-ink-main)` (near-white) | New — text on tertiary/ghost button |
| `--motion-btn-activate` | — | `250ms var(--motion-ease-decelerate)` | New — button unlock transition timing |

## Component changes

### All button components (global pattern)

Every button with a disabled state gains:
- `transition` extended with `opacity var(--motion-btn-activate), transform var(--motion-btn-activate)`
- Disabled rule: `opacity: 0.4; transform: scale(0.97); pointer-events: none; cursor: not-allowed`

### `ClaimGiftSheet.vue`

- **Activation animation:** `.sheet__cta--disabled` now includes `transform: scale(0.97)`. Transition extended. When `signedIn || guestVerified` is satisfied, the CTA animates from dimmed/compressed to full presence over 250ms ease-out.

### `CheckoutSheet.vue`

- **Activation animation:** `.sheet__checkout` transition extended; `:disabled` rule added.

### `SignInSheet.vue`

- **Activation animation:** `.signin-sheet__codm` transition extended; `:disabled` rule added.

### `PageSignInSection.vue`

- **Activation animation:** `.page-signin__btn` transition extended; `:disabled` rule added.

### `NavBar.vue`

- **Token correction:** `.navbar__signin span` label token changed from `--text-body-default` → `--text-on-action-tertiary` (semantic re-labelling; same resolved near-white).
- **Activation animation:** transition extended; `:disabled` rule added.

### `FeaturedCarousel.vue` / `BestSellerCarousel.vue`

- **Activation animation:** chevron base transition gains `opacity var(--motion-btn-activate)`; `.is-disabled` gains `transform: scale(0.97)` alongside existing `opacity: 0.3`.
