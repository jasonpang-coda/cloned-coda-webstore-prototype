# Release Notes — v0.23.0

**Date:** June 2026
**Milestone:** Item Summary sheet (pre-checkout bundle breakdown); store-agnostic screenshot tool; theme-switch singleton fix

---

## Highlights

- **Item Summary sheet** — a new pre-checkout step for bundles. Tapping a child item tile inside a `BundleSkuCard` now opens an "ITEM SUMMARY" bottom sheet showing the bundle hero, a "You will receive" accordion list (rarity-tinted thumbs, expandable image/video + description per item), price, and a Buy Now / sign-in footer. On Buy Now it morphs into the `CheckoutSheet` on the same surface. Opt-in per store via `config.bundle.itemSummary` (COD:M only); other stores keep the existing direct-to-checkout tap.
- **Screenshot tool** — a camera button in the `DeviceToolbar` and a "Tools › Take screenshot" command in the `/` console export the current preview as a 2× `.webp` (80% quality). Framed mode captures the device frame on a transparent surround; responsive mode captures the visible viewport minus the toolbar. Store-agnostic — the filename derives from the active store key.
- **Theme-switch fix (critical)** — switching stores via the toolbar dropdown flipped the colour theme but left all content stuck on COD:M. Cause: mixed import specifiers (`@/composables/useTheme` vs `./useTheme`) made Vite instantiate `useTheme` twice, so the dropdown updated one `current` ref while the content composables read another. `useTheme` now pins its state to a global symbol so every module instance shares one ref, and the toolbar's imports were normalised to relative paths.

## New components

### `ItemSummarySheet.vue`

- "ITEM SUMMARY" bottom sheet (signed-in / signed-out variants). Reads the open bundle from the `useItemSummary` singleton; swaps its footer (Buy Now ↔ sign-in CTA) on auth state. Cross-fades to/from `CheckoutSheet` via the shared `useSheetTransition` handoff.

### `ItemSummaryAccordion.vue`

- One "You will receive" row: rarity-tinted thumb, rarity-coloured name, ×quantity, expand chevron. Expands a `<Media>` container (image or video) + description via the sanctioned `grid-template-rows 0fr→1fr` accordion transition.

### `useItemSummary.js`

- Module-level singleton (same pattern as `useCheckout` / `useGiftClaim`) holding the open state + selected bundle, with a pending-return slot so the sheet can re-open after the sign-in flow.

### `useCountdown.js`

- Extracted live "Nd HHh MMm" countdown + urgency band (default/warning/error) from `BundleSkuCard`, so the Item Summary sheet renders the same timer. Accepts a number or ref; ticks reactively.

## Component changes

### `BundleSkuCard.vue`

- Child item tiles emit `select`; when `config.bundle.itemSummary` is set, the tap opens the Item Summary sheet (`stopPropagation` so the card-level checkout doesn't also fire). Passes a full `bundleInfo` payload so `CheckoutSheet` can surface the "Item Info" link.

### `BundleItem.vue`

- Replaced the `rarity` enum prop with a flexible `tileBg` prop accepting any CSS background **or** an image URL (auto-wrapped `center / cover`). Emits `select` on tap (no `stopPropagation` — non-opted-in stores still bubble to the card's default action).

### `CheckoutSheet.vue`

- New "Item Info" action re-opens the Item Summary sheet (`handoffToInfo`, checkout stays open beneath). Transition hooks now resolve the panel via `el.querySelector('.sheet__panel')` rather than a template ref (refs may be unpopulated when `@before-enter` fires on the same tick).

### `ClaimGiftSheet.vue`

- Handoff exit now fades only the content containers (`.sheet__header/.sheet__body/.sheet__footer`) over `--motion-duration-slow`, leaving the frosted panel visible so the incoming sheet reads as "same surface changing". Leave duration matched to 350ms.

### `useSheetTransition.js`

- Added `handoffToInfo` flag for the CheckoutSheet → ItemSummarySheet cross-fade.

### `useTheme.js` / `DeviceToolbar.vue`

- State pinned to `Symbol.for('webstore.useTheme.state')` on `globalThis`; toolbar imports normalised from `@/composables/*` to relative paths.

### `App.vue`

- Bundle demo data carries `name`/`media`/`description` (Item Summary accordion) + `tileBg`; CP-coin icon tier thresholds remapped for the smaller denominations.

### `MaterialIcon.vue` / `CommandConsole.vue`

- Registered the `photo_camera` (round) glyph; added the async "Take screenshot" console command (closes the palette before capturing).
