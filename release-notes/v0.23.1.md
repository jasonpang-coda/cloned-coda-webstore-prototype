# Release Notes — v0.23.1

**Date:** June 2026
**Milestone:** Screenshot tool hidden in store-locked builds via compile-time flag

---

## Highlights

- **Store-locked builds hide the screenshot tool** — the camera button in `DeviceToolbar` and the "Take screenshot" entry in `CommandConsole` are now invisible in isolated builds (`build:codm`, `build:fcm`, etc.). The tool remains available in the multi-store dev/build. Implemented via a `__STORE_LOCKED__` boolean injected by Vite at build time — no runtime cost, the dead branch is eliminated by the bundler.

## Component changes

### `DeviceToolbar.vue`

- Camera button segment wrapped in `v-if="!isStoreLocked"` where `isStoreLocked = __STORE_LOCKED__` (compile-time constant).

### `CommandConsole.vue`

- Screenshot command push wrapped in `if (!__STORE_LOCKED__)` guard; the `tools:screenshot` entry and the "Tools" group header are absent from locked bundles.

## Build changes

### `vite.config.js`

- Added `define: { __STORE_LOCKED__: store !== null }` to the Vite config. `true` when `mode` is a store name (`codm`, `fcm`, `efootball`, `tdr`, `ygodl`); `false` in the default dev and multi-store build.
