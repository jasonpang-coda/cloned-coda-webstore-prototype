# Release Notes — v0.24.0

**Date:** June 2026
**Milestone:** Motion token namespace rename (--motion-sys-*); CommandConsole hidden in store-locked builds; SignInSheet focus fix

---

## Highlights

- **Motion token namespace rename** — all primitive and stagger/distance tokens have moved from `--motion-<tier>-*` to `--motion-sys-<tier>-*` (e.g. `--motion-duration-base` → `--motion-sys-duration-base`, `--motion-ease-decelerate` → `--motion-sys-ease-decelerate`). The `sys` prefix makes the tier explicit and avoids collision with component-scoped `--motion-sku-*` tokens. Semantic/composite tokens (`--motion-modal-enter`, `--motion-sku-hover`, etc.) are unchanged — they now reference the renamed primitives. All 17 components, both token files, and Tailwind config updated.
- **CommandConsole hidden in store-locked builds** — the `/` command palette no longer mounts and the global keydown listener is not registered when `__STORE_LOCKED__` is `true` (any `build:*` mode). Previously only the screenshot *command* was gated; now the entire overlay is absent from published store builds.
- **SignInSheet — focus input after guest checkout** — "Continue as guest" now focuses the Player ID input after scrolling to the `#player-account` section, with a 500ms delay to let the sheet exit animation and scroll settle.

## Component changes

### `App.vue`

- `CommandConsole` tag wrapped in `v-if="!isStoreLocked"` (`const isStoreLocked = __STORE_LOCKED__`).
- `window.addEventListener/removeEventListener('keydown', onGlobalKey)` guarded by `if (!__STORE_LOCKED__)`.

### `SignInSheet.vue`

- `checkoutAsGuest()` now focuses `section.querySelector('input')` after a 500ms delay, so the Player ID field is ready immediately after the scroll+sheet-exit settle.

### All animated components (17)

Token references updated from `--motion-duration-*` / `--motion-ease-*` / `--motion-stagger-*` / `--motion-distance-*` to `--motion-sys-duration-*` / `--motion-sys-ease-*` / `--motion-sys-stagger-*` / `--motion-sys-distance-*`:

`BestSellerCard`, `BundleSkuCard`, `CategoryBanner`, `CategoryCatalog`, `CategoryNav`, `CheckoutSheet`, `ClaimGiftSheet`, `GiftSkuCard`, `ItemSummarySheet`, `NavBar`, `NavDrawer`, `PlayerAccount`, `ResellerBanner`, `SignInLoader`, `SkuCard`, `SkuImageCard`, `StoryCarousel`.
