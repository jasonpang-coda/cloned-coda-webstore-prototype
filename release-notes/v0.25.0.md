# Release Notes — v0.25.0

**Date:** June 2026
**Milestone:** Handoff inspector — Figma-dev-mode-style element picker with live design-token reverse-mapping, CSS/motion panel, and copy-as-spec export

---

## Highlights

- **Handoff inspector** — a new prototype-only dev tool (hidden in store-locked builds) that lets anyone click an element in the running prototype to read its design tokens, computed CSS, owning Vue component, and animations. Accessible from the toolbar (`highlight_alt` button) or the `/` command console ("Inspect elements"). Pressing Esc exits.
- **Token reverse-mapping engine** — `useTokenMap` enumerates every `--*` CSS custom property on `:root` at runtime and reverse-matches computed values (colours, lengths, durations, easing curves, composite motion pairs) back to their **semantic** token name (`--bg-card-default` over `--sys-colour-*`). Rebuilt automatically on theme switch so COD:M↔FCM token differences resolve correctly.
- **Motion as first-class** — the panel's Motion section lists every keyframe animation and transition on the selected element, each matched to its duration/easing/composite motion token (`--motion-sku-badge`, `--motion-sys-ease-spring`, etc.), plus a **Replay** button that restarts keyframes on the live element.
- **Copy-as-spec export** — click-to-copy on every individual token/value; "Copy all as spec" dumps a formatted markdown spec (component name, file path, grouped fields, motion) for pasting into a ticket or handoff doc.
- **Component identity from Vue internals** — `resolveComponent()` walks Vue 3's dev-only `__vueParentComponent` on DOM nodes to surface the owning `.vue` filename and component name without any component edits. Falls back to BEM root-class → PascalCase.
- **Interaction blocked, animations preserved** — capture-phase document listeners swallow clicks/mousedown on demo elements (no `pointer-events:none` on the demo itself), so CSS entrance/loop animations (bestseller bloom, border-spin, shimmer, skeleton) keep running while the demo is non-interactive.
- **Panel backdrop blur** — the inspector side panel uses `backdrop-filter: blur(64px)` matching the CommandConsole scrim so text is legible over any prototype content.

## New files

### `src/composables/useInspector.js`

Singleton (module-level refs, mirroring `useCommandConsole`). Holds `active` (inspection mode on/off) and `selected` (picked DOM element). Exports `open`, `close`, `toggle`, `select`. Gated at call sites — not imported in store-locked builds.

### `src/composables/useTokenMap.js`

Runtime reverse-map of the 4-tier design-token system. Enumerates `getComputedStyle(document.documentElement)` for all `--*` props; classifies each as `color / length / duration / easing / motion`; resolves colour tokens to `rgb()` via a probe element (reuses the `useScreenshot` probe idiom). Exports `matchToken(value, kind)`, `matchMotionPair(durationCss, easingCss)`, `rebuild`, `all`. Watches `useTheme().theme` and invalidates cache on switch.

### `src/utils/inspect.js`

Pure DOM/CSS helpers (no Vue). Key exports:
- `resolveComponent(el)` — walks `__vueParentComponent`, returns `{ name, file, instance }`; falls back to BEM→PascalCase.
- `componentBreadcrumb(el)` — component ancestry chain (App → … → owner).
- `elementPath(el, stop)` — DOM path from the device screen to the picked node.
- `collectStyles(el, tokens)` — grouped CSS fields (Layout, Colour, Typography, Effects), each reverse-matched to a token.
- `collectAnimations(el, tokens)` — keyframe animations + transitions with `durationToken`, `easingToken`, `motionToken`.
- `replayAnimation(el)` — restart CSS animation via reflow-restart idiom (`animation = 'none'` → `offsetWidth` → restore).
- `formatSpecMarkdown(spec, anims)` — "copy all" markdown export.
- `describeNode(node)` — `tag.bem-root` string for breadcrumb display.

### `src/components/InspectorOverlay.vue`

Full-window capture layer (`position:fixed; z-index:9000; pointer-events:none`). Intercepts interaction via document capture-phase listeners (`click`, `mousedown`, `pointerdown`, `pointermove`). Draws hover-highlight (dashed blue outline + 12% tint) and selection-highlight (solid outline + 8% tint) positioned in viewport coordinates via `translate()`. Contains `InspectorPanel`. Mounted at the App root (not the `#overlay` slot) so the panel's `position:absolute` isn't trapped by the device-frame transform or clipped by `overflow:hidden`.

### `src/components/InspectorPanel.vue`

Side panel (`position:absolute; right:0; width:min(92vw,340px)`). Sections: Component header (name, `.vue` file path, component-ancestry tree, DOM breadcrumb), Layout, Colour, Typography, Effects, Motion. Each field row: label · raw value (click-to-copy) · token chip (click-to-copy `var(--token)`). Motion rows: animation-kind badge, name, duration/easing, matched tokens, Replay button. Footer: "Copy all as spec" button. Monospace font; `backdrop-filter: blur(64px)`; slides in from the right on selection.
