# Release Notes — v0.26.0

**Date:** June 2026
**Milestone:** Inspector P1 — state simulation, box model overlay, token warnings, responsive context; Figma-blue store-agnostic UI; GiftSkuCard claimed-countdown fix

---

## Highlights

- **State picker** — the inspector panel now has a Default / Hover / Pressed / Disabled row between the breadcrumb and the scroll area. Selecting a state applies it to the live element (`buildHoverOverride` clones `:hover` CSS rules into a unique class; `applyPressedState` adds BEM `--pressed`; `applyDisabledState` sets the `disabled` attribute + class) and re-reads all computed styles via a `styleVersion` reactive counter. Switching elements or states cleans up the previous override automatically.
- **Box-model overlay** — a "box model" toggle in the Layout section header renders Figma-style margin (orange) and padding (teal) `position:fixed` strips over the selected element in the viewport. Strips track on scroll and resize via the existing `tick` ref.
- **"Not a token" warnings** — `collect Styles` now flags tokenisable fields (colour, length, duration, easing) that have no reverse-token match with `warning: true`. The panel renders a `⚠ no token` amber badge on those fields and a total count in the footer — a passive design-system lint surface.
- **Responsive section** — a new panel section shows the nearest CSS container-query ancestor (class, `container-type`, current inline-size) alongside the active device-frame label. `containerContext(el)` walks up the DOM reading `getComputedStyle().containerType` and returns the first explicit container; falls back to `.device__screen`.
- **Figma-blue store-agnostic UI** — all inspector accent colours (bounding-box outline, panel token chips, file link, state picker active, crumb active, copy-all button) are now hardcoded `#1c6feb` / `#6aa3f8` / `rgba(28,111,235,…)` instead of `var(--text-hyperlink-default)`. This makes the inspector visually consistent across COD:M, FCM, and any future store whose hyperlink token differs. The chosen blue sits at ~50% OKLCH lightness — sufficient contrast on both dark and light backgrounds.
- **Element name label chip** — a small `#1c6feb` chip showing `describeNode(el)` (e.g. `div.sku-card`) is anchored to the top-left corner of the selection bounding box. Flips inside the box when the element is within 24px of the viewport top.
- **GiftSkuCard claimed-countdown fix** — when a gift is claimed, `data-urgency` is no longer passed through (preventing the urgency colour from applying to already-claimed cards). A `gift__countdown--claimed` class applies `--text-body-subtle` instead. The countdown clock icon is repositioned absolutely to the left of the text so only the text's own width drives centring under the CTA.

## Component changes

### `src/components/InspectorOverlay.vue`

- **Box-model strips:** `boxStrips` computed returns up to 8 `position:fixed` divs (4 margin, 4 padding) sized and positioned from `getBoundingClientRect()` + `getComputedStyle()`. Toggled by `showBoxModel` from `useInspector`.
- **Figma-blue highlight:** `.inspector__box--hover` and `.inspector__box--sel` colours replaced from `var(--text-hyperlink-default)` to hardcoded `#1c6feb` / `rgba(28,111,235,…)`.
- **Element label chip:** `.inspector__label` — `position:fixed; background:#1c6feb; color:#fff` chip positioned `rect.top - 22px` (or `rect.top + 4` if near the viewport top). Text = `describeNode(selected)`.
- **`device` prop** forwarded from `App.vue` and passed to `InspectorPanel`.

### `src/components/InspectorPanel.vue`

- **State picker:** `STATES = ['default','hover','pressed','disabled']` row rendered between DOM breadcrumb and scroll area. `watch(activeState)` applies the relevant `inspect.js` state helper on the live element and calls `bumpStyleVersion()`. `watch(selected)` clears state and resets to `'default'` on element change. `onBeforeUnmount` cleans up on panel destroy.
- **`styleVersion` dep:** `spec` and `anims` computeds call `void styleVersion.value` so they re-run after state changes.
- **"Not a token" badges:** `⚠ no token` amber span shown in place of the token chip when `f.warning === true`. Footer shows total warning count.
- **Responsive section:** new section rendered when `spec.container` or `device !== 'none'`. Shows device name, container class, type, and inline-size (click to copy).
- **Box-model toggle:** small "box model" button in the Layout section `h3`, calls `toggleBoxModel()`. Active state uses teal accent matching the strip colour.
- **All accent colours migrated to hardcoded blue:** file link `#6aa3f8`, token chips `rgba(28,111,235,0.15)` bg + `#6aa3f8` text, state picker active and crumb active same blue family, copy-all button `#1c6feb`.
- **`formatSpecMarkdown`** now receives `{ state, device }` and includes state + responsive context in the markdown output.

### `src/composables/useInspector.js`

- Added refs: `showBoxModel` (box-model overlay toggle), `activeState` (`'default'|'hover'|'pressed'|'disabled'`), `styleVersion` (monotonic counter).
- Added functions: `toggleBoxModel()`, `setState(s)`, `bumpStyleVersion()`.
- `close()` and `select(el)` both reset `activeState` to `'default'`.

### `src/utils/inspect.js`

- **`field()`** — added `warning` flag: `true` when `kind` is set, no token matched, and value is non-zero.
- **`containerContext(el)`** — new export. Walks up the DOM for `containerType !== 'normal'`, returns `{ element, type, name, inlineSize, blockSize, cls }`. Fallback to `.device__screen`.
- **`buildHoverOverride(el)`** — new export. Iterates `document.styleSheets`, clones `:hover` rules replacing `:hover` with a unique generated class, injects a `<style>` element, adds the class to `el`. Returns cleanup fn. Cross-origin sheets skipped gracefully.
- **`applyPressedState(el)`** — new export. Adds BEM `${bemRoot}--pressed` + generic `pressed` class. Returns cleanup fn.
- **`applyDisabledState(el)`** — new export. Sets `disabled` attribute + `disabled` class. Returns cleanup fn.
- **`formatSpecMarkdown()`** — signature extended to `(spec, anims, { state, device } = {})`. Includes state label and Responsive section in output.
- `collectStyles` — passes `container: containerContext(el)` in returned object.

### `src/App.vue`

- `<InspectorOverlay>` now receives `:device="device"`.

### `src/components/GiftSkuCard.vue`

- **Countdown urgency on claimed cards:** `data-urgency` binding changed to `:data-urgency="claimed ? null : countdownUrgency"`. Added `.gift__countdown--claimed { color: var(--text-body-subtle) }` which wins over urgency colours via rule order.
- **Countdown icon layout:** `.gift__countdown-icon` repositioned to `position: absolute; right: calc(100% + var(--gap-content-tight))` so only the countdown text width is used for centring, keeping the text aligned under the CTA above. `.gift__countdown` gains `position: relative` to establish the containing block.
