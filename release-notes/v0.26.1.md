# Release Notes — v0.26.1

**Date:** June 2026
**Milestone:** SKU card CTA type unified to `heading-sku-title` (20px); SkuImageCard price centered; `heading-sku-title` token bumped H7→H4

---

## Highlights

- **Unified SKU CTA type scale** — all SKU card CTA / price labels (`SkuCard`, `BundleSkuCard`, `BestSellerCard`, `GiftSkuCard`, `SkuImageCard`) now share `.text-style-heading-sku-title`. `BestSellerCard` and `GiftSkuCard` were previously on `heading-modal`; both migrated.
- **`heading-sku-title` bumped to 20px** — the token's `font-size` moves from `--sys-size-h7` (18px) to `--sys-size-h4` (20px), lifting all card CTAs and aligning the price scale with the existing modal/sheet heading tier.
- **SkuImageCard price centered** — the price / CTA block in `SkuImageCard` is now horizontally centred across the card (was right-aligned). `transform-origin` on all price spans updated from `right center` → `center center` so Hitmarker condense anchors correctly.

---

## Component changes

### `src/tokens/ds/text-styles.css`

- **`heading-sku-title` size:** `var(--sys-size-h7)` (18px) → `var(--sys-size-h4)` (20px). All consumers of this class receive the bump automatically.

### `src/components/BestSellerCard.vue`

- **CTA class:** `.bestseller__current` changed from `text-style-heading-modal` → `text-style-heading-sku-title`.

### `src/components/GiftSkuCard.vue`

- **CTA class:** `.gift__cta` changed from `text-style-heading-modal` → `text-style-heading-sku-title`.

### `src/components/SkuImageCard.vue`

- **Price alignment:** `.sku-image-card__price` `align-items: flex-end` → `center`; `.sku-image-card__discount` `align-self: flex-end` → `center`.
- **Condense anchor:** `transform-origin` on `original-price`, `discount-pct`, and `current-price` updated from `right center` → `center center`.
