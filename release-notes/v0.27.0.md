# Release Notes — v0.27.0

**Date:** June 2026
**Milestone:** Inspector P2 (JSON export, shareable deep-link) + P3 (props inspector, WCAG contrast badge, asset extraction, component export)

---

## Highlights

- **Deep-link sharing** — the inspector now writes `#inspect=<CSS selector>` to the URL on every selection. Share the URL and the inspector restores the same element on open.
- **JSON export** — "Copy as JSON" in the footer serialises the full spec (layout, colour, typography, motion, props, a11y, assets) as a structured object for programmatic use.
- **Props inspector** — the panel's new Props section lists the owning component's declared prop schema (type, required flag) alongside live resolved values; click to copy any value.
- **WCAG contrast badge** — Accessibility section shows the text/background contrast ratio with AA / AA-large / AAA pass indicators, computed from the element's actual rendered colours.
- **Asset extraction** — Assets section scans `<img>` sources and CSS `background-image` URLs in the selected subtree; thumbnail + filename + per-asset Download button.
- **Component export** — Usage section renders a paste-ready `<ComponentTag :prop="…" />` snippet built from live props (required always; non-default values included; defaults omitted). Footer adds "Copy source" + "Download .vue" to fetch the real component source via Vite's `/@fs…?raw` endpoint.

## Component changes

### `src/components/InspectorOverlay.vue`

- **Deep-link hash sync (P2):** `writeHash(el)` encodes the current selection as `#inspect=<elementSelector>` on every selection change via `history.replaceState`. `restoreFromHash()` — called when the inspector activates — decodes the hash and selects the matching element one frame after render. Hash is cleared on inspector exit.
- Imports `elementSelector` from `inspect.js`.

### `src/components/InspectorPanel.vue`

- **JSON export (P2):** `copyJson()` serialises the spec via `formatSpecJson` + `JSON.stringify`; "Copy as JSON" footer button with check-state feedback.
- **Copy link (P2):** `copyLink()` copies `window.location.href` (which already contains the `#inspect=` fragment written by the overlay); "Copy link" footer button.
- **Props section (P3):** `ip__group` listing each declared prop — name, required `*` indicator, live value (click to copy), type badge (`ip__prop-type`). Default-valued props dimmed (`ip__row--dim`).
- **Accessibility section (P3):** contrast ratio + AA/AAA badge (`ip__badge--pass/warn/fail`); role + aria-label rows when present.
- **Assets section (P3):** thumbnail + filename + download button per detected image/background asset.
- **Usage snippet section (P3):** `<pre class="ip__snippet">` with inline copy button; built from `componentUsageSnippet(instance)`.
- **Footer (P3):** "Copy source" + "Download .vue" row (only when the selected element resolves to a component with a known `__file`). Fetches real `.vue` source via `fetchComponentSource`.
- `ip__toggle-btn` gains `display: inline-flex; align-items: center; gap: 3px` for correct icon+text layout in the Usage group header.
- New CSS: `.ip__row--dim`, `.ip__req`, `.ip__prop-type`, `.ip__badge`, `.ip__badge--pass/warn/fail`, `.ip__asset`, `.ip__asset-thumb`, `.ip__asset-name`, `.ip__asset-dl`, `.ip__snippet`, `.ip__foot-row`, `.ip__sec-btn`.

### `src/components/MaterialIcon.vue`

- Added `link`, `download`, `code` round-variant imports + `ICONS` entries for P2/P3 actions.

### `src/utils/inspect.js`

- **`elementSelector(el)`** — builds a `tag.bemRoot > …` CSS path from `.device__screen` to `el`; used by the overlay for hash sync and by `formatSpecJson`.
- **`formatSpecJson(spec, anims, opts)`** — structured JSON-serializable spec object; includes layout/colour/typography/effects fields, animations, transitions, props, a11y, assets, container, component metadata.
- **`collectA11y(el, cs)`** (internal) — gathers contrast, role, aria-label, tag.
- **`effectiveBackground(el)`** (internal) — walks ancestor chain to the first opaque `backgroundColor`.
- **`contrastInfo(textColor, bgColor)`** (exported) — WCAG 2.1 ratio + `{ aa, aaLarge, aaa }` flags.
- **`collectProps(instance)`** (exported) — normalizes `instance.type.props` schema + reads live `instance.props`; returns sorted `[{ name, type, required, default, value, isDefault }]`.
- **`componentUsageSnippet(instance)`** (exported) — generates a paste-ready `<Tag … />` invocation from live props.
- **`fetchComponentSource(file)`** (exported) — dev-only; `import(/* @vite-ignore */ \`/@fs${file}?raw\`)` → raw `.vue` string or `null`.
- **`collectAssets(el)`** (exported) — scans `<img>` + CSS `backgroundImage`; returns `[{ url, kind }]`, deduped and absolutized.
- **`assetName(url)`** (exported) — extracts the filename component from a URL for the download attribute.
- **`collectStyles`** now returns `a11y`, `props`, `assets` alongside existing fields.
- **`formatSpecMarkdown`** extended with Props, Accessibility, Assets sections.
