# Release Notes — v0.28.0

**Date:** June 2026
**Milestone:** PlayerAccount disclosure toggle (gated instruction chips) + Inter as default body font

---

## Highlights

- **Instruction chip disclosure** — the three "Find UID / Find Player ID / Find Nickname" chips in `PlayerAccount` are now hidden by default behind a tappable **"How to find your COD:M account"** label with a rotating chevron. Opening auto-selects the first chip so steps show immediately; chip selection is preserved across collapse/expand.
- **Animated reveal** — the chip+panel block transitions in with a 200ms ease-out fade + 4px slide from the disclosure button; exits in 150ms ease-in. Only `opacity` + `transform` animate.
- **Inter default** — Inter is now the default body font on first paint (`data-body-font="inter"` in `index.html`, `useBodyFont` default updated). No condense applied to body text.

---

## Component changes

### `PlayerAccount.vue`

- **Disclosure toggle:** new `instructionsOpen` ref + `toggleInstructions()` replace the always-visible chip row. The outer `v-if` guard (`status !== 'found' && showAccountInstructions !== false`) moves to a wrapper `<div>`; a `<button class="player-account__disclosure">` inside it renders the label + chevron (`MaterialIcon expand_more`).
- **Auto-select first chip:** `toggleInstructions()` sets `activeChip` to `chips[0].id` on open when no chip has been previously selected; re-opening preserves prior selection.
- **`<Transition name="instructions">`** wraps the `player-account__instructions` div. Enter: 200ms `--motion-sys-ease-decelerate`. Leave: 150ms `--motion-sys-duration-fast` `--motion-sys-ease-accelerate`. From/to: `opacity: 0; translateY(-4px)` (`--motion-sys-distance-sm`).
- **New CSS:** `.player-account__disclosure` (inline-flex, underlined, `--text-body-default`, `gap: --gap-content-narrow`), `.player-account__disclosure-chevron` (rotates 180° via `--motion-accordion`), `.instructions-*` Transition classes. `.player-account__instructions` gains `margin-top: --gap-content-default`.
- **`MaterialIcon` imported** into `PlayerAccount.vue` for the chevron.
