# Release Notes — v0.29.0

**Date:** June 2026
**Milestone:** Component library viewer (hash page, 8 stories, inspector deep-link); EA/KONAMI token scoping; DS token adoption across 11 components

---

## Highlights

- **Component library viewer** — full-page dev tool (`#library` hash, `view_module` toolbar toggle) for browsing, inspecting, and theming components. The store is unmounted while the library is active; the inspector floats on top for spec work. Tree-shaken from all store-locked builds.
- **Inspector "View in library" deep-link** — `InspectorPanel` shows a chip when the selected component has a story; clicking navigates directly to that story.
- **EA + KONAMI token scoping** — `--ea-*` and `--konami-*` were global in `extensions.css`; now correctly scoped to `[data-theme="fcm"]` and `[data-theme="efootball"]` respectively.
- **Design-system token adoption** — 11 components now reference `--size-icon-*`, `--size-control-*`, `--size-img-*`, `--size-input-*`, `--pad-surface-*`, `--gap-grid-*` tokens instead of hardcoded pixel values.
- **Grid token wiring** — `Grid.vue` XS/S gap and pad-X reference `--gap-grid-gutter`/`--gap-grid-margin`.

## New: Component Library (`src/library/`)

### Architecture

- **Hash-based page swap** (`App.vue`): `<template v-if="!libraryActive">` unmounts the store; `<component :is="LibraryViewer">` renders in its place. `InspectorOverlay` stays mounted for Specs tab. No router, no overlay stacking.
- **`useLibrary.js`** — module-level singleton. `open(id?)`, `close()`, `toggle()`, `select(id)`, `setVariant(i)`. Syncs `active` to `#library` URL hash with a `hashchange` listener; ignores `#inspect=` fragments. Direct load at `/#library` restores page on mount.
- **Isolation**: `defineAsyncComponent(() => import('./library/LibraryViewer.vue'))` only when `!isStoreLocked` → zero library/registry/stories chunks in `build:codm`.

### `LibraryViewer.vue`

- Full-page chrome (`z-index: 8000`): sidebar (248px, grouped + searchable story list), topbar, control bar (variant / state / theme / width), scrollable stage, docs tabs (Notes + Specs).
- Backdrop hardcoded `#0c0e16` (never `var(--bg-page)` — YGODL sets that to `transparent`).
- Closes the inspector on activate so a "View in library" jump doesn't leave a stale selection on the now-unmounted store element.

### `StoryStage.vue`

- `container-type: inline-size` host at device width (390 / 384 / 100%) — resolves `@container` queries identically to the real `.device__screen`; also traps `position:fixed` overlay descendants (CheckoutSheet stays in the stage).
- Opaque layered backdrop: `background-color: #0c0e16` + `background-image: var(--page-bg-image, none), linear-gradient(var(--bg-page), var(--bg-page))` — faithful for image-backed stores (YGODL, efootball), opaque fallback when `--bg-page` is `transparent`.
- `setup()/teardown()` hooks per variant for singleton priming; `renderKey` forces remount on story/variant/theme change.

### `registry.js` + `story.js`

- `import.meta.glob('./stories/*.stories.js', { eager: true })` auto-discovers stories; new files appear with zero viewer changes.
- `findStory({ component, name })` used by InspectorPanel deep-link; `getStory(id)` for direct lookup.

### Stories shipped (Phase 1, 8 files)

`SkuCard`, `BundleSkuCard`, `GiftSkuCard`, `SkuImageCard`, `BestSellerCard`, `SkuTag`, `NavBar`, `CheckoutSheet`

## Component changes

### `MaterialIcon.vue`

- **New icons registered:** `view_module` (`round/view_module`) and `search` (`round/search`) imported with `?url` and added to the allow-list. Previous uses of `widgets` (unregistered — rendered as empty square) replaced with `view_module`.

### `DeviceToolbar.vue`

- **Library toggle:** `view_module` icon button added to the dev-tools segment; calls `useLibrary().toggle()`; active state shown via `toolbar__btn--active`; hidden in store-locked builds.

### `CommandConsole.vue`

- **"Open component library"** entry added to the Tools group (inside `!__STORE_LOCKED__` guard); keywords include `library components storybook catalog viewer stage variants states themes`.

### `InspectorPanel.vue`

- **"View in library" button:** appears below the DOM breadcrumb when `findStory()` returns a match for the selected component. Styled in Figma blue (consistent with panel accent family). `registry.js` imported lazily via dynamic `import()`.

### `InspectorOverlay.vue`

- **Library chrome exemption:** `isChrome()` now excludes `.lib__sidebar`, `.lib__topbar`, `.lib__controls`, `.lib__docs` so their controls remain interactive while inspecting. The stage (`.lib__stage`) is NOT excluded — the staged component stays fully inspectable.

### `App.vue`

- `libraryActive` from `useLibrary()` gates the store shell, `bgImageStyle` (no store page art painted behind the library), and the global `/` key handler.
- `LibraryViewer` lazily imported via `defineAsyncComponent`; rendered as `<component :is="LibraryViewer">` at App root alongside `InspectorOverlay`.
