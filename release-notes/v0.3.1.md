# CODM SKU Card 3.0 — v0.3.1

**Design-token sweep, Bundle SKU card, Category Navigation & interaction polish** · June 2026

This release is the largest single change to the prototype since v0.2.0. It covers
three major areas: a complete design-token sweep that eliminates every hardcoded
value from the codebase, two new SKU components (Bundle SKU card + child item tiles),
and a sticky Category Navigation bar with scroll-spy, auto-scroll, and drag support.
A round of interaction polish follows — fixing non-interactive carousel cards and
navigation tabs caused by the pointer-capture drag implementation, and making the
story hero flush to the navbar.

---

## What's new

### Full design-token sweep
Every hardcoded colour, gradient, shadow, radius, and border thickness has been
replaced with a CSS custom-property token. Zero raw literals remain in component
CSS (only `var(--token, #fallback)` defensive fallbacks are permitted). The token
surface in `src/style.css` grew by ~50 new entries:

- **Gradient-border tokens** — `--gradient-border-sku` / `--gradient-border-sku-hover`
  (OKLCH, HDR-boosted in `@media (dynamic-range: high)`) shared by SkuCard,
  BundleSkuCard, BundleItem, and the checkout PC cards. One token source; all
  consumers get the HDR upgrade automatically.
- **Rarity gradient tokens** — `--rarity-gradient-{mythic|legendary|epic|rare|neutral}`
  for the bundle child item backgrounds. Named with `gradient` to leave room for future
  `--rarity-color-*` solid variants without clashing.
- **Scrim, border, shadow, radius tokens** — `--scrim*`, `--border-soft*`,
  `--shadow-card/drawer/sheet/story-card/logo`, `--radius-xxs/pill/circle`, etc.
- **Indicator tokens** — `--bg-indicator-prominent-subtle`, `--text-error-inverse`
  (OKLCH: `oklch(0.96 0.02 32)`), `--bg-indicator-neutral-default`.
- **Border-weight tokens** — `--border-weight-default` (1px), `--border-weight-selected`
  / `-action` / `-press` (2px). Every `border` thickness and gradient-ring `padding`
  across all components now uses these; the selected PC card in checkout gets a proper
  2px ring via `--border-weight-selected`.
- **Nav tokens** — `--gradient-scroll-fade-left/right`, `--shadow-nav`,
  `--shadow-nav-inset`; `--motion-nav-enter` in `motion.css`.
- **`--text-error-inverse` converted to OKLCH** — was `#ffede9`; now
  `oklch(0.96 0.02 32)` for perceptual accuracy and HDR headroom.

### Bundle SKU card (`BundleSkuCard.vue` + `BundleItem.vue`)
New components implementing Figma node `4843:10166` — a bundled SKU with a wide
banner image, a breakdown row of child item tiles, and a title + price.

**`BundleSkuCard.vue`** — the parent card. Props: `bannerImage`, `title`,
`currentPrice`, `originalPrice`, `discountPercent`, `items[]`, `skuImage`,
`baseDelay`. Tapping opens `useCheckout`. Entrance: `bundle-enter` keyframe (fade +
12px rise). All display text condensed via `scaleX(var(--hm-scale))`.

**`BundleItem.vue`** — one child tile. Rarity-graded background (`rarity` →
`--rarity-gradient-{mythic|legendary|epic|rare|neutral}`), tokenised gradient border,
optional tag pill (BONUS / Loyalty — `--bg-indicator-prominent-subtle`,
`--text-error-inverse`), quantity badge. Tag/qty text condensed via an inner
`.bundle-item__condense` span — the pill box itself is not scaled.

The bundle is rendered in `App.vue` between the Best Seller Carousel and the New
Users Promo, with its own entrance delay (`DELAY_BUNDLE = 550ms`).

### Category Navigation (`CategoryNav.vue`)
Sticky-bottom L3 navigation bar (Figma `5100:19182`). Frosted glass surface
(`--gradient-sheet-panel` + `backdrop-filter: blur(32px)`), top hairline, custom
shadow (`--shadow-nav`). Slides up from the bottom on load with a 700ms delay
(`--motion-nav-enter`) so it lands after the content cascade.

**Tabs** map to the 4 real storefront categories: Best Sellers · Bundle · New Users · CP.

**Scroll-spy** — `IntersectionObserver` tracks the most-visible category section;
root is `.device__screen` (framed) or `null`/viewport (responsive). Rebuilds when
the device context switches.

**Auto-scroll follow** — when scroll-spy (or a tap) promotes a new active tab,
the nav horizontally smooth-scrolls to centre that tab (`centerActiveTab`,
`watch(activeId)`).

**Tap → scroll-to** — `scrollIntoView` with reduced-motion aware behaviour.

**Mouse drag** — delegated to `useDragScroll` composable (see below). Edge fades
(`--gradient-scroll-fade-left/right`) appear independently on each side when content
is hidden.

**Active tab** — 2px yellow top border (`--border-weight-action`) +
`--text-hyperlink-inverse`; labels condense via `.cat-nav__label`.

Mounted in the DeviceFrame `#overlay` slot at `z-index: 0` (below all transient
overlays). Absolute (framed) / fixed (responsive) via the `isMobile` pattern.

### `useDragScroll` composable (`src/composables/useDragScroll.js`)
Shared, reusable pointer-events drag-scroll for horizontal scroll containers.
Used by `BestSellerCarousel` and `CategoryNav`.

Key improvements over the former inline `mousedown` implementation:
- Document-level `pointermove`/`pointerup` listeners (no `setPointerCapture`) —
  fast swipes that leave the element still track; child `click` events are never
  broken.
- `dragstart` suppression kills native OS image/link drag (the original "difficult
  to drag" bug).
- rAF-batched `scrollLeft`, EMA velocity, FRICTION 0.96 momentum coast.
- `>threshold` movement suppresses the trailing click via capture-phase interception.
- Ignores `pointerType: 'touch'` (native pan-x handles it).

### Checkout improvements
- **SKU image in checkout banner** — `skuImage` prop added to `SkuCard`,
  `BestSellerCard`, `BundleSkuCard`, `SkuList`, and `BestSellerCarousel`; passed
  through `openCheckout(item)`. The 64×64 thumbnail in the sheet banner now shows
  the selected product's image (falls back to the gloss placeholder when absent).
- **Footer bottom padding** — `.sheet__footer` bottom padding increased from 12px
  to 24px (`var(--pad-xl)`).

## Bug fixes

### Carousel cards and nav tabs were non-interactive
Introduced by the `useDragScroll` composable's initial `setPointerCapture` approach.
When called immediately on `pointerdown`, pointer capture rerouted `pointerup` to
the scroll container — browser saw `pointerdown` on a child button but `pointerup`
on the list, so no `click` ever fired. Fixed by switching to document-level
`pointermove`/`pointerup` listeners (no capture needed).

### Story carousel flush to navbar
Removed the 16px `padding-top` from the story section (`section--flush-top` class)
so the carousel image meets the navbar bottom edge with no gap.

### Bundle fonts too wide
`BundleSkuCard` title, price, and discount text, and `BundleItem` tag/qty badges,
all missing `scaleX(var(--hm-scale, 0.82))`. Fixed; inner spans used for badge
text to preserve pill box dimensions.

## Visual refinements

- **BestSeller carousel header padded, list full-bleed** — the title/chevron header
  now gets `padding-inline: var(--pad-m)` (inset to the content gutter) while only
  the card list bleeds edge-to-edge on XS/S. Reset at `@container (min-width: 801px)`.
- **Category nav font corrected** — tab labels now condense via `.cat-nav__label`
  (inner span), letter-spacing increased to `0.08em`.
