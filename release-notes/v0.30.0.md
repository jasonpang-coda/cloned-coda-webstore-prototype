# Release Notes — v0.30.0

**Date:** June 2026
**Milestone:** Warhammer 40,000: Rogue Trader store import — grimdark-gothic whitelabel with TT Supermolot Neue heading font, OKLCH void/gold palette, and Profit Factor currency

---

## Highlights

- **New store: Warhammer 40K: Rogue Trader** — full whitelabel import with zero component edits. Guest-only checkout, page model (like COD:M), "Profit Factor" currency, ornate gilded-gold-on-void theme.
- **TT Supermolot Neue** — licensed condensed grotesque, 3 local woff2 cuts (Regular 400 / Medium 500 / Demibold 600). Replaces the Google Fonts Oswald proxy; Cinzel proxy also removed. Only Open Sans (body) remains on Google Fonts.
- **OKLCH palette** — void-black `#0c0a0a`, military-green `#72a846` (primary CTA), imperial-gold `#d1a974` (ornament/hairlines), warp-green `#a1e967` (VFX accent), blood-red `#a51c20` (negative status). Full 50–950 ramps generated for all 6 chromatic roles + warm void→parchment neutral.
- **Gilded container surfaces** — L1/L2/L3 surfaces use dark void fills with gold-tinted gradient borders (gold hue ≈ oklch h80). Reskins SKU cards, generic cards, sheet, and category nav at once via the surface token layer.
- **HDR boost** — `@media (dynamic-range: high)` block pushes warp-green and L1 gold border past the sRGB ceiling on wide-gamut panels.

## Changes

### New: `src/tokens/ds/themes/roguetrader.css`

- 3 `@font-face` declarations for TT Supermolot Neue (Regular / Medium / Demibold).
- `--sys-font-family-heading: 'TT Supermolot Neue', sans-serif`; body stays Open Sans.
- Weight tokens capped at 600 (Demibold) — no synthesis artifacts from missing 700+ cut.
- `--sys-font-condense: 1` (natively condensed face; no scaleX squeeze unlike COD:M).
- 7 ref seeds + 6 chromatic spectrum ramps (50–950) + warm neutral ramp (0–1000).
- L1/L2/L3 surface tokens with gold-gradient borders.
- `html[data-theme="roguetrader"]` block: `--border-card-default` gold hairline + `--sys-colour-hyperlink-inverse` → gold (not cyan).
- HDR `@media` block for warp-green and L1 gold border.

### New: `src/stores/roguetrader/store.js`

- `config`: page model, `navbar.hideSignIn: true`, `checkout.allowGuest: true`, `checkout.actionLabel: 'Acquire'`, `showPoweredByCoda: true`, `showRating: false`, `loyalty: null`.
- `strings`: Profit Factor (`name: 'Profit Factor', abbr: 'PF'`), "Warrant Bonus", "Most Favoured", "Best Value" SKU labels; full imperial-voiced checkout + nav copy.
- `assets`: RT wordmark + logomark (real site images), imperial sunburst Profit Factor icon, key-art hero, warp-orb, aquila avatar, authored SVG card background. Null-guarded for unused slots.
- `skus.cpImageRegular`: 6 PF tiers ($1.99–$79.99).

### New: `src/stores/roguetrader/fonts/`

- `TTSupermolotNeueRegular.woff2`, `TTSupermolotNeueMedium.woff2`, `TTSupermolotNeueDemibold.woff2` — licensed files, bundled into store-locked builds only.

### New: `src/stores/roguetrader/img/`

- `brand/`: `wordmark.png`, `logomark.png`, `cp-icon.svg` (gold sunburst coin).
- `content/`: `story-hero.jpg` (companions key art), `profit-factor.svg` (imperial seal), `sku-bg.svg` (void gradient + filigree), `avatar.svg` (aquila silhouette), `placeholder.svg`, `warp-orb.png`, `relics.png`.

### `index.html`

- Google Fonts link reduced to Open Sans only — Oswald and Cinzel removed (TT Supermolot Neue is now local).
