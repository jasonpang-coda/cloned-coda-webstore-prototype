# Release Notes — v0.31.0

**Date:** June 2026
**Milestone:** Rogue Trader editions + DLC catalog; HeroSkuCard component; single-scroll page model; StoryCarousel wordmark overlay

---

## Highlights

- **HeroSkuCard** — new shared component for flagship named products (game editions, collector's packs). Full-bleed key art, bottom-up scrim, text + includes-chips left / price right, whole card tappable. Zero store-name branching — any store can use it via `cardType: 'hero'` in their catalog.
- **Rogue Trader catalog** — store pivots from Profit Factor currency to selling **game editions + DLC digital keys** (scraped from Steam). Two categories ("Games & Editions", "DLC") rendered as a COD:M-style single-scroll page. Voidfarer Edition uses the HeroSkuCard; all other editions and DLC use BundleSkuCard with empty `items[]`.
- **Page-mode catalog** — `catalog.mode: 'page'` stores can now supply a `catalog` tree. App.vue renders all categories as scroll sections (`cat-{id}`) with CategoryNav tabs as anchors — COD:M behavior, not FCM filter tabs.
- **StoryCarousel logo** — slides now accept a `logo` field. For the single-hero slide (any store with `content.storyHero`), `brand.wordmark` is rendered centered above the heading with a drop-shadow.
- **New capability flags** — `config.profile.showPlayerAccount` (hides the guest ID form for non-account-linked stores), `config.catalog.featuredHero` (gates the filter-mode standalone best-seller hero), `config.page.sections: []` (suppresses legacy page sections for catalog-only stores).

## Changes

### New: `src/components/HeroSkuCard.vue`

- Full-bleed `image` (absolute, `object-fit: cover`) + `--gradient-hero-scrim` bottom-up scrim.
- Row layout: `.hero-sku__text` (flex 1, eyebrow + title + includes-chips + description) + `.hero-sku__price` (flex-shrink 0, right-aligned, `transform-origin: right center`).
- Gilded `::before` mask-composite border ring — same pattern as BundleSkuCard, picks up `--border-sku-card-*` tokens.
- Props: `eyebrow`, `title` (required), `description`, `includes[]`, `image` (required), `skuImage`, `currentPrice` (required), `originalPrice`, `discountPercent`, `loyaltyPoints`, `baseDelay`.
- Checkout: `amount: title` convention (same as BundleSkuCard), `itemKey = title|currentPrice`.
- `sku-enter` entrance animation with `baseDelay` cascade.

### New: `src/library/stories/HeroSkuCard.stories.js`

- 3 variants: "Edition (full)" (Voidfarer), "No discount" (Deluxe), "Minimal" (Base Game).
- Auto-registers via `import.meta.glob` — no registry edit needed.

### New: `src/stores/roguetrader/img/content/edition-banner.svg` + `dlc-banner.svg`

- On-brand banner SVGs (void gradient + imperial gold filigree) for edition and DLC BundleSkuCards.

### `src/stores/roguetrader/store.js`

- `config.catalog.mode`: `'page'` (COD:M single-scroll, not FCM filter tabs).
- `config.page.sections: []`: suppresses all legacy COD:M page sections.
- `config.catalog.featuredHero: false`: hides the FCM Daily Booster D demo hero.
- `config.profile.showPlayerAccount: false`: hides the guest Player ID form (no game account to link for Steam key purchases).
- `strings.nav.groups` anchors updated from raw category ids to `cat-games` / `cat-dlc` (page-mode scroll targets).
- `catalog`: two-category array — Games & Editions (HeroSkuCard flagship + 2 bundle editions) and DLC (5 story expansions + 5 packs/extras), all with USD Steam sale pricing.
- Dropped `cpImageRegular` SKU list (currency tier retired for this store).

### `src/components/CategoryCatalog.vue`

- Added `cardType: 'hero'` branch (renders `HeroSkuCard` per item) before the `'bundle'` branch.
- Imports `HeroSkuCard`.

### `src/components/BundleSkuCard.vue`

- `v-if="items.length"` guard on the breakdown `<div>` — prevents the `-20px` negative-margin gap when a bundle has no child tiles (edition / digital key cards pass `items: []`).

### `src/App.vue`

- **Catalog-in-page-mode**: when `catalog.value` exists and mode is `'page'`, renders all categories as `<section id="cat-{id}">` sections in the page template. CategoryCatalog handles its own Grid/Span internally — no outer wrapper.
- **`categories` computed**: now derives nav tabs from `catalog.value` in both filter and page modes (filter: raw `c.id` for activeCat matching; page: `cat-${c.id}` for scroll anchors).
- **PlayerAccount gate**: `config.profile?.showPlayerAccount !== false` condition added so key-sale stores skip the guest ID form.
- **`featuredHero` gate**: `v-if="config.catalog.featuredHero"` on the filter-mode standalone best-seller section.
- **StoryCarousel**: passes `logo: brand.wordmark` on the single-hero slide.

### `src/stores/fcm/store.js`

- `catalog.featuredHero: true` added (explicit opt-in for FCM's Daily Booster D best-seller hero).

### `src/tokens/ds/extensions.css`

- `--gradient-hero-scrim`: stronger bottom-up gradient — `scrim-banner-strong` holds solid 0–25%, steps through `scrim-banner` at 50%, `scrim` at 70%, transparent at 95%.

### `src/components/StoryCarousel.vue`

- Slide shape gains optional `logo` field — renders `<img class="story__logo">` in the content block, centered above heading/CTA.
- `.story__logo`: `max-height: 64px`, `max-width: 220px`, `object-fit: contain`, `filter: var(--shadow-logo)`.
