# Release Notes — v0.32.1

**Date:** June 2026
**Milestone:** Dual-comet border extracted to reusable `.fx-glow-border--dual` class; `--border-hero-card-*` tokens renamed to `--fx-border-*`; `prefers-reduced-motion` gap closed

---

## Highlights

- **Reusable `.fx-glow-border--dual` class** — the animated dual-comet conic border (shipped in v0.32.0 as a one-off scoped rule on `HeroSkuCard`) is now a global opt-in class in `src/tokens/effects.css`, sitting alongside `.fx-glow-border` and `.fx-glow-border--hdr`. Any component adds the effect with one class on its root element. Carries HeroSkuCard's proven mask recipe (the `#fff` luminance mask + `destination-out`, `inset: 0` + `--border-weight-default` padding, inline conic).
- **`--fx-border-*` token family** — `--border-hero-card-glow/hot/glow-2/hot-2` renamed to `--fx-border-glow/hot/glow-2/hot-2`. The `-1` pair is shared with the existing single `.fx-glow-border`; stores that already define `--fx-border-glow/hot` (ygodl, tdr) feed their brand colour into the dual border automatically.
- **`prefers-reduced-motion` gap closed** — the scoped `HeroSkuCard::before` was not covered by the reduced-motion block; the global class is, so the border now halts correctly for motion-sensitive users.

---

## Changes

### `src/tokens/effects.css`

- **`.fx-glow-border--dual` class added** — mirrors the `.fx-glow-border--hdr` pattern. Root rule: `position: relative` only (no `border`, no `border-radius` — consumer's own radius is inherited by `::before`). `::before` carries the full dual-comet conic inline, proven mask recipe, `z-index: 3`, `animation: border-spin var(--motion-border-spin) var(--motion-sys-ease-linear) infinite`.
- **Reduced-motion guard** — `.fx-glow-border--dual::before { animation: none }` added to the existing `@media (prefers-reduced-motion: reduce)` block alongside the two sibling classes.
- **File header** — updated to list all three `fx-glow-border` variants.

### `src/tokens/ds/extensions.css`

- **`--border-hero-card-*` → `--fx-border-*`** — four tokens renamed. Values unchanged (default to `--hdr-glow / --hdr-hot`). Comet 1 (`--fx-border-glow/hot`) is now shared with the plain `.fx-glow-border` class; comet 2 (`--fx-border-glow-2/hot-2`) is new.

### `src/tokens/ds/themes/roguetrader.css`

- **Override block renamed** — `--border-hero-card-*` overrides renamed to `--fx-border-*`. Values unchanged: secondary ramp (imperial gold) for comet 1, tertiary ramp (warp-green) for comet 2.

### `src/components/HeroSkuCard.vue`

- **Class applied** — root element: `class="hero-sku fx-bloom fx-glow-border--dual"`.
- **Scoped `::before` removed** — the ~36-line conic `::before` rule deleted; a short comment points to the source class.
- **`--selected::before` kept** — overrides `inset`, `padding`, `background` for the static selection ring. Added `animation: none` (the scoped selector's specificity 0,2,1 beats the global class's 0,1,1 so this was already winning, but the `animation: none` is now explicit).

### `docs/component-breakdown.md`

- HeroSkuCard paragraph updated to reference `.fx-glow-border--dual` class + `--fx-border-*` tokens; notes that `--border-hero-card-*` names from v0.32.0 are superseded.
- Footer bumped to v0.32.1.

## Using `.fx-glow-border--dual` on a new component

```html
<div class="my-card fx-glow-border--dual">…</div>
```

Requirements:
- Root must **not** have `overflow: hidden` (clips the ring). Move it to an inner wrapper.
- To customise comet colours, override in the component's scoped CSS:

```css
.my-card {
  --fx-border-glow:   var(--palette-primary-500);
  --fx-border-hot:    var(--palette-primary-200);
  --fx-border-glow-2: var(--palette-secondary-500);
  --fx-border-hot-2:  var(--palette-secondary-200);
}
```

> **Note:** The `--border-hero-card-*` token names from v0.32.0 are superseded. Update any theme override that references them to the new `--fx-border-*` names.
