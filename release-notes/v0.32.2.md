# Release Notes — v0.32.2

**Date:** June 2026
**Milestone:** Trail-comet token rename — `--fx-border-*-2` → `--fx-border-trail-glow/hot`

---

## Highlights

- **`--fx-border-trail-glow` / `--fx-border-trail-hot`** — the second-comet color tokens for `.fx-glow-border--dual` are renamed from the non-descriptive `-2` suffix to the orbital-role name `trail`. The trail comet orbits 180° behind the lead comet (`--fx-border-glow/hot`). No functional change — values and defaults are identical.

---

## Changes

### `src/tokens/effects.css`

- Conic gradient stops renamed: `var(--fx-border-glow-2)` × 2 + `var(--fx-border-hot-2)` × 1 → `var(--fx-border-trail-glow)` / `var(--fx-border-trail-hot)`.
- Block comment updated to use new names.

### `src/tokens/ds/extensions.css`

- `--fx-border-glow-2` / `--fx-border-hot-2` defaults renamed to `--fx-border-trail-glow` / `--fx-border-trail-hot`.

### `src/tokens/ds/themes/roguetrader.css`

- RT overrides renamed (warp-green comet): `--fx-border-glow-2` / `--fx-border-hot-2` → `--fx-border-trail-glow` / `--fx-border-trail-hot`.

### `src/components/HeroSkuCard.vue` + `docs/component-breakdown.md`

- Comment and paragraph updated to reference new names.

---

> **Migration note:** Any theme that overrides `--fx-border-glow-2` / `--fx-border-hot-2` must rename to `--fx-border-trail-glow` / `--fx-border-trail-hot`. The lead-comet pair (`--fx-border-glow` / `--fx-border-hot`) is unchanged.
