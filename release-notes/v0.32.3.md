# Release Notes — v0.32.3

**Date:** June 2026
**Milestone:** FX border library expansion — rotate, pulse, HUD, trace effects; YGODL dark-page fix

---

## Highlights

- **Four new `.fx-glow-border--*` effect classes** — `--rotate` (gapless tri-tone ring), `--pulse` (breathing opacity ring), `--hud` (L-shaped corner brackets), `--trace` (border draws itself 0→360°). All inherit `--fx-border-glow/hot` tokens automatically, so they theme-switch with each store brand.
- **YGODL background fix** — `--bg-page` was `transparent`, letting the browser's white `html` background bleed through on short pages. Now set to `var(--palette-neutral-1000)` (`#0B111B`, the cold navy already defined in the theme).

---

## Changes

### `src/tokens/effects.css`

- Added `.fx-glow-border--rotate`: conic gradient (`--angle`-driven) that runs a full-spectrum tri-tone ring (glow → hot → trail-glow → trail-hot) via `border-spin` animation.
- Added `.fx-glow-border--pulse`: static conic ring with `filter: drop-shadow` that breathes via `pulse` keyframe.
- Added `.fx-glow-border--hud`: four L-shaped corner brackets drawn with eight `background` gradient layers; no `::after`, no animation. Arm length = `--fx-hud-corner-length`, stroke = `--fx-hud-weight`.
- Added `.fx-glow-border--trace`: `@property --arc` conic sweep that grows from 270° outward; defaults to single `forwards` play (mount reveal). Infinite + linear = loading indicator.
- Expanded `prefers-reduced-motion` block: `--rotate`, `--pulse` animations disabled; `--trace` frozen at `--arc: 360deg` (ring fully visible, no draw-on motion).
- Updated class-index comment block at the top of the file.

### `src/tokens/keyframes.css`

- Added `@property --arc` (`syntax: '<angle>'`, `initial-value: 0deg`, `inherits: false`) — enables CSS interpolation of the trace arc.
- Added `@keyframes border-trace` (`to { --arc: 360deg }`).

### `src/tokens/motion.css`

- Added `--motion-border-pulse: 2400ms` — breathing period for `--pulse`.
- Added `--motion-border-trace: 1600ms` — draw-on sweep period for `--trace`.

### `src/tokens/ds/extensions.css`

- Added `--fx-hud-corner-length: 18px` and `--fx-hud-weight: var(--border-weight-default)` — sizing tokens for the HUD corner brackets; override in scoped CSS to scale for different card sizes.
- Updated FX border token block comment to describe all six effect classes.

### `src/tokens/ds/themes/ygodl.css`

- `--bg-page: transparent` → `--bg-page: var(--palette-neutral-1000)` — eliminates the white body fallback. The fixed background image continues to render on top via `.device__screen`; the L1/L2/L3 frosted dark overlays are unaffected.
