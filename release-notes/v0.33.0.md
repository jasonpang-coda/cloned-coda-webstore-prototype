# Release Notes — v0.33.0

**Date:** June 2026
**Milestone:** Transaction History page — signed-in account history for COD:M and FCM

---

## Highlights

- **Transaction History page** — full-page view reached from the signed-in account popover. Shows a filterable list of purchase history with three card states: Fulfilled, In Progress, Failed. Ships for both COD:M and FCM with no theme branching — all differences (copy, demo data, currency) live in the store modules.
- **FilterDropdown component** — animated generic select: trigger + frosted options panel 12 px below, ease-out reveal, chevron rotation, option-row stagger. Reuses the existing `--motion-dropdown` token; no new motion tokens.
- **StatusTag component** — bordered status pill (Fulfilled / In Progress / Failed). Indicator surface tokens, Inter label (not Hitmarker), theme-agnostic.
- **TransactionCard component** — three-state card with a conditional Total Payment row (fulfilled + total only) and a dashed divider. Staggered entrance animation using `--motion-sys-stagger-md`.
- **AccountPopover Transaction History link** — `swap_horiz` icon + label row with hyperlink hover/pressed states. Strings-gated (never theme-tested); hidden on stores without the feature.

---

## Changes

### `src/components/AccountPopover.vue`

- Added "Transaction History" link row (Figma 5695:5013) between `PlayerCard` and the sign-out action.
- Link visible only when `strings.transactionHistory` exists — strings-gated, no `theme.value` test.
- Hover: `--text-hyperlink-hover`; pressed: `--text-hyperlink-pressed`. Icon inherits via `currentColor`.
- Tapping calls `openHistory()` + `closeAccountMenu()`.

### `src/components/MaterialIcon.vue`

- Added `swap_horiz` and `arrow_back` (round variant) to the bundled icon map.

### `src/App.vue`

- Imports `TransactionHistoryPage` + `useTransactionHistory`.
- Wraps all storefront content below `NavBar` in `v-if="!historyOpen"`; renders `TransactionHistoryPage` in the else branch.
- Hides `CategoryNav` while `historyOpen`.
- Safety `watch(strings)`: calls `closeHistory()` if the new store doesn't ship `transactionHistory` copy.

### `src/stores/codm/store.js` + `src/stores/fcm/store.js`

- Added `strings.transactionHistory` (title, popoverLink, filterLabel `'Filter Transactions'`, ranges d7/d30/d90, row labels, status labels, empty copy).
- Added `transactions` array — 6 demo items per store (CP flavour for COD:M, FC Points for FCM). Items carry `daysAgo` integers so the range filter is clock-robust.
