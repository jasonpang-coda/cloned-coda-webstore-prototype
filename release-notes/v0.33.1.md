# Release Notes — v0.33.1

**Date:** July 2026
**Milestone:** TransactionHistoryPage — responsive card grid (up to 3 columns on M–L screens)

---

## Highlights

- **Responsive transaction card grid** — cards now lay out in a CSS grid that steps from 1 column (mobile) to 2 columns at 641 px and 3 columns at 801 px, matching the container-query breakpoints used by `SkuList` and `GiftGrid`.

---

## Changes

### `src/components/TransactionHistoryPage.vue`

- **`.txn-page__list`:** `display: flex; flex-direction: column` → `display: grid; grid-template-columns: 1fr`.
- Added `@container (min-width: 641px)` rule: `grid-template-columns: repeat(2, 1fr)`.
- Added `@container (min-width: 801px)` rule: `grid-template-columns: repeat(3, 1fr)`.
- Container queries resolve against `.device__screen` (`container-type: inline-size`) — consistent with all other grid components.
