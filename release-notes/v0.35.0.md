# Release Notes — v0.35.0

**Date:** July 2026
**Milestone:** Collapsible, mobile-aware DeviceToolbar; checkout sheet moved to the L2 surface

---

## Highlights

- **DeviceToolbar collapses.** A sticky, icon-only tab handle at the bottom of the bar expands/collapses the device/theme/dev-tools segments, animated with the accordion (`grid-template-rows`) and toggle (chevron rotate + fade) motion tokens.
- **Touch devices default to Responsive, collapsed.** A new `useDeviceDetect` composable (`matchMedia('(pointer: coarse) and (hover: none)')`) forces the device frame to `'none'` and the toolbar to start collapsed on real phones/tablets — the device-frame segment is hidden there too, since previewing a phone frame inside a phone is meaningless.
- **Toolbar toggle reachable from the `/` command console.** Collapse state moved into a shared singleton (`useToolbarCollapse`) so "Collapse/Expand preview toolbar" appears alongside the existing Tools commands.
- **Checkout sheet surface fill moved L3 → L2**, matching the category nav's surface level; `--rarity-gradient-common` now aliases `--bg-card-default` instead of `--bg-sheet`.

---

## Changes

### `src/composables/useDeviceDetect.js` (new)

- Singleton (globalThis-pinned via `Symbol.for(...)`, mirrors `useTheme`) exposing a reactive `isMobile` derived from `matchMedia('(pointer: coarse) and (hover: none)')`, with a `change` listener so it stays live across rotation or devtools device emulation.

### `src/composables/useToolbarCollapse.js` (new)

- Singleton `collapsed` ref + `collapse()` / `expand()` / `toggle()` / `set()`, mirroring the `useInspector` / `useLibrary` shape. Shared between `DeviceToolbar` and `CommandConsole` so both read/write the same state.

### `src/components/DeviceToolbar.vue`

- Restructured into a collapsible `.toolbar__body` (all existing segments) plus an always-visible `.toolbar__handle` tab, positioned at the **bottom** of the bar so content expands upward above it.
- Collapse/expand animates `grid-template-rows` (`--motion-accordion`) on the body and `opacity` (`--motion-toggle`) on its contents; the chevron rotates on `--motion-toggle`, pointing toward wherever the content will appear.
- The device-frame segment is hidden (`v-if="!isMobile"`) on touch devices; `collapsed` defaults to `isMobile` and re-syncs on device-class changes.
- Now owns `--toolbar-h`: a `ResizeObserver` on the root writes the live height to `:root`, so overlays that dock beneath the bar (`CategoryNav`, `AccountPopover`, the responsive `DeviceFrame` overlay) track the bar continuously through the collapse animation instead of a one-shot measurement.

### `src/components/CommandConsole.vue`

- New Tools command: `Collapse preview toolbar` / `Expand preview toolbar` (label flips with state), wired to `useToolbarCollapse().toggle()`.

### `src/App.vue`

- `device` now defaults to `'none'` when `useDeviceDetect().isMobile` is true (both on load and on store switch), with a `watch(isMobile, …)` forcing it back to Responsive if the device class changes mid-session.
- Removed the one-shot `onMounted` `--toolbar-h` measurement and the `toolbarRef` template ref — superseded by `DeviceToolbar`'s own `ResizeObserver`.

### `src/tokens/ds/semantics.css`, `src/tokens/ds/extensions.css`

- `--bg-sheet` / `--bg-sheet-footer` now alias `--surface-l2-fill` (was `--surface-l3-fill`) — the checkout sheet moves to the same surface level as the category nav.
- `--rarity-gradient-common` now aliases `--bg-card-default` (was `--bg-sheet`), keeping the common-rarity tile fill independent of the sheet's surface level.
