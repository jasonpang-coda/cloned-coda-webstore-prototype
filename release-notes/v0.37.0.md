# Release Notes — v0.37.0

**Date:** July 2026
**Milestone:** Region & language switcher — drawer footer + navbar M+ pill, region/language selector sheets, and a shared locale data layer wired into all six stores

---

## Highlights

- **New region & language switcher, live in every store.** A footer control at the bottom of the left drawer, plus a matching pill in the navbar from M-size screens up (`@container (min-width: 801px)`), opens two new selector sheets: "Select Region" (search + continent-grouped list) and "Select Language" (endonym list with a check-marked active row).
- **A real locale data layer, not per-store hardcoding.** `src/locale/` holds a 30-language and 68-market canonical registry, four per-store sets (COD:M 22/55, FCM 28/66, TDR 29/65, and a Codashop-standard 27/64 fallback for eFootball/Rogue Trader/YGO:DL), and the switcher's own UI copy translated into all 30 languages.
- **RTL suppressed until it's actually active.** Arabic-script market names and the Arabic language row are hidden from both selectors while the active language is LTR (a lone RTL string in an otherwise LTR sheet read as a layout glitch); once the active language is Arabic, everything shows natively.

---

## Changes

### `src/locale/` (new)

- `languages.js` — 30-language union registry (endonym, English name, RTL flag).
- `markets.js` — 68-market registry: native name (English fallback in parens for non-Latin scripts), continent group, and the market's own languages (English is implicit everywhere, never duplicated). The 8 Arabic-script markets (EG, MA, IQ, SA, BH, KW, QA, AE) carry `rtl: true` + an explicit `englishName` fallback.
- `sets.js` — per-store language/market sets (`LOCALE_SETS.{codm,fcm,tdr,codashop}`), each with a `defaultMarket`.
- `uiStrings.js` — "Select Region" / "Select Language" / "Search" localised across all 30 languages.
- `flags.js` — manifest over `src/shared/flags/*.svg` (63 provided assets) with filename remaps for three irregular names (KN→KE, UAE→AE, GB-UKM→GB); `flagEmoji()` covers the 6 markets without SVG art (IE, GT, FI, GR, SK, TW).

### `src/composables/useLocale.js` (new)

- `globalThis`-pinned singleton (same pattern as `useTheme`) holding `region`/`language` state, persisted per store (`locale:<theme>` in `localStorage`) and re-validated on store switch.
- `isRtlActive` + a `marketLabel()` resolver drive the RTL-suppression rule described above; `availableLanguages` filters RTL languages the same way.
- Changing region resets the language to `en` if the new region doesn't offer the current one.

### `src/components/FlagTile.vue`, `RegionSelectorSheet.vue`, `LanguageSelectorSheet.vue` (new)

- `FlagTile` — 4:3 flag art with the Figma hairline-border + gloss treatment (new `--flag-tile-border`/`--flag-tile-gloss` tokens in `extensions.css`), emoji fallback when no SVG exists.
- `RegionSelectorSheet` / `LanguageSelectorSheet` — mirror `CheckoutSheet`'s chrome (scrim + `--bg-sheet` panel, z-4, bottom sheet on framed devices → centered modal at `@media (min-width: 801px)`). The region sheet adds a typeahead suggestion card anchored under the search input (matched substring bolded, diacritic-insensitive) while the full continent list stays visible underneath.

### `src/components/NavDrawer.vue`

- New `.nav-drawer__locale` footer pinned below the scrolling nav: flag + region name | divider | globe icon + language endonym, each opening its selector. Added 24px bottom clearance below the footer.
- Hover/press states added: `--surface-ghost-2` on hover, `--surface-ghost-3` + `scale(0.97)` on press (padding + matching negative margin so the hit area grows without shifting layout at rest).

### `src/components/NavBar.vue`

- New `.navbar__locale` pill leading the right cluster (flag opens region, uppercased language code opens language), hidden by default and shown only via `@container (min-width: 801px)`. Same hover/press treatment as the drawer footer.

### `src/components/MaterialIcon.vue`

- Registered the `round/language` icon (was missing — resolved to an unmasked solid-square fallback wherever `name="language"` was used).

### `src/tokens/ds/extensions.css`

- Added `--flag-tile-border` / `--flag-tile-gloss` for `FlagTile`'s hairline border + top-light gloss overlay.

### `src/stores/{codm,fcm,tdr,efootball,roguetrader,ygodl}/store.js`

- Each store now sets `config.locale = LOCALE_SETS.<set>` (codm/fcm/tdr get their dedicated set; the other three fall back to `codashop`).

### `src/App.vue`

- Mounted `RegionSelectorSheet` and `LanguageSelectorSheet` in the `#overlay` slot alongside the other sheets.
