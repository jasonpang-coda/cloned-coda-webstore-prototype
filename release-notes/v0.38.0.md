# Release Notes — v0.38.0

**Date:** July 2026
**Milestone:** Content localisation Phase 1 (per-store translation layer, shared chrome copy, full ISO flag library) plus region/language switcher polish and bug fixes

---

## Highlights

- **Store content can now actually be translated.** Each store's `strings` object is the English source of truth; a store may ship a `translations` map (`{ ja: {…}, es: {…}, … }`, each a *partial* override) that `useStoreStrings` deep-merges over English for whichever language `useLocale` has selected. Any untranslated key falls through to English automatically — no missing-string crashes, no all-or-nothing translation files.
- **Shared chrome copy, translated once for every store.** `commonStrings.js` + `useLocale().common` hold store-agnostic UI text (checkout, sign-in, account, nav, carousel labels) that doesn't belong to any one store's content — components read `common.*` instead of duplicating the same English strings six times.
- **Full ISO flag coverage.** `src/shared/flags/` was renamed from irregular `XX_-_Name.svg` filenames to plain uppercase ISO codes (`SG.svg`) and expanded to ~265 flags — every market the switcher can select now has real artwork instead of an emoji fallback.
- **The region/language switcher's rough edges from v0.37.0 are fixed.** NavBar's scroll-hide state no longer gets stuck hidden after a store switch; FCM's subcategory nav no longer collides with the sticky NavBar; every sheet/modal shows a bottom scroll scrim when its content overflows; tapping the navbar avatar now closes the account popover instead of being a no-op re-open.

---

## Changes

### Content localisation (new)

- **`src/utils/deepMerge.js`** — recursive merge helper: plain objects merge key-by-key, arrays replace wholesale (a translated `page.tabs` must supply the full array, not a sparse patch), any other value in the override replaces the base, inputs aren't mutated.
- **`src/composables/useStoreStrings.js`** — now language-aware: reads `useLocale().language`, deep-merges `store.translations[lang]` over `store.strings` when a translation exists (`lang !== 'en'`), and memoises the merged result per `${storeKey}:${lang}` since it's static.
- **`src/composables/useLocale.js`** — new `common` computed: `deepMerge(COMMON_STRINGS.en, COMMON_STRINGS[language] ?? {})`.
- **`src/locale/commonStrings.js`** (new) — shared chrome copy across checkout, sign-in, account, nav, carousel sections, per language.
- **`src/stores/<store>/strings/<lang>.js`** (new, per store) — partial translation-override files. Phase 1 ships `ja`/`es`/`pt`/`ar` for COD:M, plus `id`/`ko`/`th`/`zh-Hant` for FCM/TDR/eFootball/Rogue Trader/YGO:DL where those languages are in the store's locale set.
- **`docs/localisation.md`** (new) — the full model, the merge-order diagram, and the authoring rules for translation files (no proper nouns/brand names/currency; arrays replace wholesale).
- Content updates riding along: COD:M's account-instructions chip copy (`strings.account.chips`, `disclosureLabel`, `viewImageInstructions`) moved from hardcoded template markup into per-store strings so it translates; several components (`BestSellerCard`, `BundleSkuCard`, `SkuCard`, `SkuImageCard`, `PlayerAccount`, `SignInLoader`) swapped hardcoded English copy for `strings.*` / `common.*` lookups.

### Flag library

- `src/shared/flags/*.svg` renamed from `XX_-_Name.svg` to plain `XX.svg`; `src/locale/flags.js` simplified accordingly (no more irregular-prefix remap table). Expanded from 68 to ~265 flags — full ISO 3166 coverage plus a few regional/organisation flags (`EU`, `UN`, `CEFTA`, GB nation flags).

### `src/components/NavBar.vue`

- **Theme-switch fix:** switching stores via the DeviceToolbar/console reuses this component instance — `.device__screen`'s scroll position carries over, which could leave the bar stuck scroll-hidden on the new store. Added `watch(theme, …)` to reset `hidden` and resync the scroll baseline on every switch.
- **`--navbar-h` now tracks visible height, not layout height:** reports `0` while the bar is scroll-hidden (`transform` doesn't change `offsetHeight`, so the old version reserved dead space at the top for a bar that wasn't there) — consumed by `CategoryNav`'s top-docking offset.
- **Avatar toggle:** `@click` now calls `toggleAccountMenu()` instead of `openAccountMenu()`; tagged `data-account-toggle` so `AccountPopover`'s outside-click handler can exclude it (see below).

### `src/components/CategoryNav.vue`

- **Top-variant docking fix:** `.cat-nav--top` (FCM's subcategory nav) now docks at `top: var(--navbar-h, 0px)` instead of `var(--safe-top, 0px) + var(--navbar-h, 0px)` — the double-counted `--safe-top` pushed it well past where NavBar actually ends, since NavBar's own height already bakes that clearance into its top padding.

### `src/components/AccountPopover.vue`

- `onPointerDown` (the outside-tap-to-close listener) now skips closing when the tap target is `[data-account-toggle]` — without this, the listener (which fires on `pointerdown`, before the avatar's `click`) would close the popover first, and the toggle handler would then see it already closed and immediately reopen it.

### Bottom scroll scrim + 80vh modal cap (`CheckoutSheet`, `ItemSummarySheet`, `ClaimGiftSheet`, `SignInSheet`, `RegionSelectorSheet`, `LanguageSelectorSheet`)

- Every sheet's responsive-modal `max-height` capped at `80vh` (was `85vh`).
- Each sheet's scrolling body is now wrapped in a non-scrolling `__body-wrap` (`position: relative`); a `__scroll-fade` sits inside it as `position: absolute; bottom: 0`, pinned to the scroll viewport's bottom edge regardless of scroll offset. (Earlier attempts using `position: sticky`, then a negative-margin flex sibling, both proved unreliable — especially over `RegionSelectorSheet`'s CSS-multi-column list.) Height bumped to `--size-img-xl` (64px, from 48px) for visibility. Fill is the new `--gradient-scroll-fade-bottom` token (extensions.css, built from the neutral scrim ramp so it reads over any themed sheet fill). Visibility driven by the new `useBottomFade(bodyRef)` composable (`src/composables/useBottomFade.js`) — tracks real overflow via `ResizeObserver` + scroll listener, shows only while there's more content below the fold.
- `RegionSelectorSheet` additionally gets a permanent, always-visible scrim under its search box (`.selector__search-fade`) plus an 8px gap between the search box and the list — reuses the same gradient token flipped via `scaleY(-1)` so it darkens at the search box's edge instead of the list's edge.
- `SignInSheet`'s body previously had no scroll mechanism at all (missing `overflow-y: auto`) — added so it can genuinely scroll instead of clipping.
