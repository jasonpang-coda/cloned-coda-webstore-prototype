# Release Notes — v0.38.1

**Date:** July 2026
**Milestone:** Close out the localisation gaps left by v0.38.0 — YGO:DL catalog data, the checkout action button, and two gift-card copy bugs

---

## Highlights

- **YGO:DL's catalog data no longer bakes English text into `store.js`.** `skus.regular/limited/gift` used to hardcode tag/limit/CTA/countdown labels as literals, which never translated when the language switcher changed — they now carry data markers (`tagKey`, `labelKey`) that `App.vue` resolves against `strings`/`common` at render time.
- **"Buy Now" (and "Checkout" / "Acquire") is finally translatable.** The button's label lived in `config.checkout.actionLabel` — a *structural* field, never read through the translation layer — across all six stores. Moved to `strings.checkout.actionLabel` and translated into every language each store already ships.
- **Two gift-card copy bugs fixed.** `GiftSkuCard`'s "CLAIMED" state text was hardcoded directly in the template (only the resting-state CTA was ever wired to strings); and two of COD:M's three demo gift items were missing a `ctaLabel` override entirely, silently falling back to the component's hardcoded English default.

---

## Changes

### `src/stores/ygodl/store.js`

- `strings.sku` gains `bonusTag` (`'BONUS'`, matches COD:M's existing convention for nested item-breakdown badges) and `webExclusiveTag` (`'WEB STORE EXCLUSIVE'`); `strings.page` gains `giftTagLabel`/`giftTitle`/`giftSubtitle`/`giftCta`/`giftEndsLabel`/`giftRefreshesLabel` for the weekly gift card, replacing the now-removed `giftLimit` (superseded by the shared `common.sku.limitLabel`).
- `skus.regular` items no longer carry `bonusLabel`/`tagLabel`/`subtitle` literals — a `tagKey` (naming a `strings.sku` key) and a `limited: true` flag replace them.
- `skus.limited` items drop their `limitLabel: 'Limit: 1'` literals (blanket-defaulted downstream); nested breakdown badges use `tag: { labelKey: 'bonusTag', … }` instead of `tag: { label: 'BONUS', … }`.
- `skus.gift`'s single weekly-gift item is now pure data (`id`, `image`, `endsInMs`, `refreshesOnClaim`) — every visible label comes from `strings`/`common`.

### `src/App.vue`

- `regularImageItems` / `limitedBundles` / `rewardGifts` (the three YGO:DL-only page-mode computeds) now resolve `tagKey`/`labelKey` markers against `strings.value.sku[...]` (falling back to the raw key text if unresolvable, so a bad marker is visible rather than silently dropping the tag) and pull the shared "Limit: 1" from `common.value.sku.limitLabel`.
- COD:M's demo `gifts` computed: `gift-emote` and `gift-gun` now set `ctaLabel: strings.value.page.giftClaimCta` (previously unset — silently fell back to `GiftSkuCard`'s hardcoded `'CLAIM GIFT'` default).
- Both `GiftSkuCard` call sites now pass `:claimed-label="common.sku.claimedLabel"`.

### `src/components/GiftSkuCard.vue`

- New `claimedLabel` prop (default `'CLAIMED'`, preserving existing behaviour when unset) replaces the hardcoded `'CLAIMED'` literal in the template.

### `src/locale/commonStrings.js`

- New `sku.claimedLabel` key, translated across all 9 languages (`en` + the 8 Phase-1 languages).

### `config.checkout.actionLabel` → `strings.checkout.actionLabel` (all six stores)

- Moved the purchase-button label out of each store's structural `config` block into its `strings` block — `config` is for capability flags, not user-visible copy, and the old location bypassed translation entirely regardless of language.
- `src/components/CheckoutSheet.vue` and `src/components/ItemSummarySheet.vue` updated to read `strings.checkout.actionLabel` instead of `config.checkout.actionLabel`.
- Translated into every language each store already ships: "Buy Now" (COD:M, TDR, YGO:DL), "Checkout" (FCM, eFootball), "Acquire" (Rogue Trader — keeps its mercantile Warhammer 40K voice).

### `docs/localisation.md`

- New "Catalog/SKU data — no baked-in chrome" section documenting the `tagKey`/`labelKey` marker pattern established by this release, so the next store with static catalog data follows the same approach instead of re-introducing hardcoded literals.
