# Release Notes — v0.39.0

**Date:** July 2026
**Milestone:** Seventh store — METAL GEAR SOLID Δ: SNAKE EATER — plus a new reusable "calm/stealthy" fx effect and a capability-flag refactor of the hero-card ring

---

## Highlights

- **MGS Delta joins the storefront.** Built from a style-guide-designer extraction of konami.com/mg/mgs3r: guest-only Steam-key store, page-model catalogue (Games & Editions / DLC), no virtual currency, a fully sharp-cornered OKLCH field-green + pale-lime palette on a true achromatic void-black page, and the licensed **URW DIN Semi-Condensed** heading font (Regular + Bold, converted from the user-supplied OTF family to local woff2). Second store after Rogue Trader to default to the responsive/no-device-frame layout (`config.device.default: 'none'`).
- **`HeroSkuCard` and `BestSellerCard`'s ring effect is now a capability flag, not a hardcoded class.** Both components previously baked in a fixed `fx-glow-border--*` class (`--dual` and `--hdr` respectively). They now read a shared `config.sku.heroRingEffect` flag from `useStoreConfig()`, defaulting to each component's original class so every existing store is pixel-identical to before. This is what let MGS Delta's actual flagship card (which renders via `HeroSkuCard`, not `BestSellerCard`) opt into a different effect without a store-name check anywhere.
- **New fx-effects library variant: `fx-glow-border--camo-breathe`.** A static ring (no rotation) whose opacity breathes from a near-invisible rest state to a clearly-lit peak over a slow, tunable period — designed for MGS Delta's "calm and stealthy" brand, but added as a genuine sibling to `--hdr`/`--dual`/`--rotate`/`--pulse` so any future store can opt in. Paired with a brightened `--fx-bloom-image` on MGS Delta's theme for a slight ambient halo.

## Changes

### `src/stores/mgsdelta/` (new)

- `store.js` — `key: 'mgsdelta'`, guest checkout (`navbar.hideSignIn: true`, `checkout.allowGuest: true`), `catalog.mode: 'page'` with two categories (`games`: Digital Deluxe Edition as the hero card, Standard Edition as a bundle; `dlc`: Sneaking DLC Pack), `page.sections: []` (disables the currency/gift/promo sections this store has no use for), `device: { default: 'none' }`, `sku: { heroRingEffect: 'camo-breathe' }`.
- `img/{brand,content}/` — logo and key art/character-portrait reference assets copied in from the style guide's `refs/`, downsized for web delivery.
- `font/` — the full URW DIN family (all widths/weights) as supplied by the user, kept as source archive.
- `fonts/URWDINSemiCond-{Regular,Bold}.woff2` — the two cuts actually wired, converted from the source OTFs via `fontTools` (~50KB each, down from ~97KB as OTF).

### `src/tokens/ds/themes/mgsdelta.css` (new)

- OKLCH seeds/ramps converted from the style guide's hex values (`#009600` primary, `#C4E39C` secondary, `#007E00` tertiary, `#080808` neutral — the neutral ramp is true achromatic grey, unlike Rogue Trader's warm-tinted one).
- All `--radius-*` tokens forced to `--sys-radius-0`, including badges (no pill exception).
- `@font-face` for URW DIN Semi-Condensed Regular/Bold; `--sys-font-family-heading` leads with the real font, Oswald (Google Fonts) demoted to a fallback.
- Retints the shared `--fx-border-*`/`--fx-bloom-image` tokens to field-green/pale-lime and overrides `--motion-border-camo`/`--motion-sku-bloom` to run slower than the effect's own defaults.

### `src/components/HeroSkuCard.vue` / `src/components/BestSellerCard.vue`

- Both now import `useStoreConfig` and compute their ring class from `config.sku.heroRingEffect` (`'dual'`/`'hdr'` fallback respectively) instead of hardcoding it — a genuine capability flag per the whitelabel golden rule, not a `theme.value` check.

### `src/tokens/effects.css` / `src/tokens/keyframes.css` / `src/tokens/ds/extensions.css`

- New `.fx-glow-border--camo-breathe` class, `@keyframes breathe-dim` (opacity 0.1→0.95), and two new tokens: `--motion-border-camo` (5500ms default) and `--fx-camo-border-width` (3px, thicker than the shared `--border-weight-default` so the slow breathe stays legible without a spin to catch the eye).
- Reduced-motion guard extended to cover the new class.

### `src/stores/active.all.js`, `src/stores/active.mgsdelta.js` (new), `vite.config.js`, `package.json`, `.claude/launch.json`

- MGS Delta registered as the seventh store: runtime switcher, store-locked build mode (`dev:mgsdelta`/`build:mgsdelta`), and a dev-server launch config.

### `docs/component-breakdown.md`, `docs/multi-store-whitelabel.md`, `docs/Handoff/sku-cards/component-breakdown.md`

- Documented the `heroRingEffect` capability flag and the `camo-breathe` variant; the whitelabel doc's "last updated" milestone now points at MGS Delta's addition (previous Rogue Trader entry kept as history).

### `src/components/LanguageSelectorSheet.vue`

- `.selector__row.is-selected` colour corrected from `--text-hyperlink-inverse` to `--text-hyperlink-default` (unrelated one-line fix carried in this diff).
