# Release Notes — v0.39.1

**Date:** July 2026
**Milestone:** MGS Delta store renamed to MGSSE; real logomark/favicon asset wired in

---

## Highlights

- **Store identifier renamed `mgsdelta` → `mgsse`.** Every file, path, selector, and build-mode name that referenced the old identifier is updated: the store directory, theme CSS file and its `[data-theme]`/`html[data-theme]` selectors, local font paths, the active-stores manifest entry, `vite.config.js`'s `STORES` list, `package.json`'s `dev`/`build` scripts, and the dev-server launch config. The customer-facing `label` ("METAL GEAR SOLID Δ: SNAKE EATER") is untouched — only the internal code identifier changed.
- **Real logomark/favicon SVG wired in.** A solid field-green (`#009600`) standalone Δ mark replaces the full-wordmark PNG that was previously reused as a placeholder for every icon-only brand slot (`logomark`, `signinLogomark`, `navSignInIcon`, `favicon`). The browser tab now shows the actual Δ glyph instead of the full lockup.

---

## Changes

### `src/stores/mgsdelta/` → `src/stores/mgsse/`

- Directory renamed (`git mv`, history preserved): `store.js`, `font/` (source OTF archive), `fonts/` (the two wired woff2 cuts), `img/brand/`, `img/content/`.
- `store.js`: `key: 'mgsdelta'` → `'mgsse'`; theme import path updated to `@/tokens/ds/themes/mgsse.css`.

### `src/tokens/ds/themes/mgsdelta.css` → `src/tokens/ds/themes/mgsse.css`

- `[data-theme="mgsdelta"]` / `html[data-theme="mgsdelta"]` → `mgsse`; `@font-face` `url()` paths updated to `../../../stores/mgsse/fonts/...`; comments updated.

### `src/stores/mgsse/img/brand/logomark.svg` (new)

- Moved from `img/content/favicon.svg` (as supplied) into the `img/brand/` convention every other store follows — `favicon`/`logomark`-type assets live there, matching `useFavicon.js`'s `assets.brand.favicon` read.
- `store.js` imports it and assigns it to `logomark`, `signinLogomark`, `navSignInIcon`, and `favicon` (previously all pointed at the full `wordmark` PNG as a stand-in).

### `src/stores/active.all.js`, `src/stores/active.mgsse.js` (renamed from `active.mgsdelta.js`), `vite.config.js`, `package.json`, `.claude/launch.json`

- Import paths, variable names, the `STORES` list, `dev:mgsse`/`build:mgsse` scripts, and the launch config entry all updated to the new identifier.

### `src/components/HeroSkuCard.vue`, `src/components/BestSellerCard.vue`, `src/tokens/ds/extensions.css`

- Cosmetic "MGS Delta" → "MGSSE" doc-comment updates only — no functional change.

### `docs/component-breakdown.md`, `docs/multi-store-whitelabel.md`, `docs/Handoff/sku-cards/component-breakdown.md`

- "MGS Delta"/`mgsdelta` mentions renamed to "MGSSE"/`mgsse`. While in the Handoff copy, also corrected a stale description of `fx-glow-border--camo-breathe` left over from before the v0.39.0 visibility tuning (it still described the original `0.3→0.6` opacity range and "no drop-shadow bleed" — now reflects the shipped `0.1→0.95` range, the glow bleed, and the thicker ring).

## Not renamed (by design)

- `docs/style-guides/mgs-delta/` — the original style-guide-designer research artifact, kept as an immutable historical reference (same treatment as `docs/style-guides/roguetrader/`).
- `release-notes/v0.39.0.md` — historical record of what shipped under the old name at the time; not retroactively edited.
