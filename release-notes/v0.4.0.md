# CODM SKU Card 3.0 — v0.4.0

**Bundle category overhaul — countdown banner, second bundle, SKU-on-banner composition & rich media** · June 2026

This release reshapes the Bundle category to match Figma node `4843:10166`. The
single bundle card becomes a full category: a countdown info banner on top, **two**
bundle cards beneath it, and a new banner-composition model where a 1:1 SKU hero is
layered over a separate 2.6:1 background banner. The banner/SKU media layer is also
generalised to tolerate video (mp4/webm) and animated webp, not just stills.

---

## What's new

### `Media.vue` — image-or-video surface
A tiny presentational wrapper that picks its element by file extension: `<video>`
(autoplay · loop · muted · playsinline · `disablepictureinpicture`) for
`.mp4/.webm/.mov`, and `<img loading="lazy">` for everything else — animated
webp/gif/apng simply play through the `<img>` branch.

`inheritAttrs` is on and the rendered node is the component **root**, so the
consumer's `class` lands on it *and* the parent's scoped-CSS data attribute applies
— a parent rule like `.bundle__banner-img` styles the img/video with no extra
plumbing. Props: `src` (req), `alt`, `poster`. Consumed by `BundleSkuCard` (banner
+ SKU overlay) and the optional `App.vue` category backdrop.

### SKU image on the banner (`BundleSkuCard.vue`)
The banner now treats the **2.6:1 background** and the **1:1 SKU hero** as two
separate entities:

- `bannerImage` renders through `Media` (image or video).
- New `skuOnBanner` prop (default `false`): when true, the 1:1 `skuImage` is
  composited as a right-anchored, full-height `object-fit:contain` hero
  (`.bundle__banner-sku`) above the legibility scrim.

Bundle 1 (Midnight Sun) keeps its baked-in banner (`skuOnBanner` off). **Bundle 2**
(new) uses the plain *The Boys* backdrop + the `4000 CP + 50 BONUS STRONGBOXES` hero
on top, exercising the new path.

### Second bundle
`App.vue` gains a `bundle2` (4000 CP + 50 BONUS STRONGBOXES · **$24.99**; items
Crate/BONUS ×50, COD Point ×4000, Armory Point/Loyalty ×2499). The `#cat-bundle`
section is reworked into the banner-over-content pattern (like New Users Promo):
countdown banner, then both cards, staggered (`DELAY_BUNDLE` / `+120ms`).

### Countdown banner (`PromoBanner.vue`)
`PromoBanner` is extended rather than replaced:

- New `endsAt` (ms epoch) + `countdownLabel` props. When `endsAt` is set, a frosted
  chip renders above the description — a `schedule` clock glyph + a live
  `{label} {Dd HHh MMm}` readout that ticks each second (informational, so it runs
  regardless of `prefers-reduced-motion`; the interval is cleared on unmount). Chip
  text condenses via an inner `.promo-banner__countdown-text` span so the box keeps
  its padding.
- `icon` and `title` are now both optional — the icon block renders only when an
  icon is supplied (no placeholder circle), and the title only when set — so the
  component doubles as the description-only Bundle banner. The New Users Promo
  banner is unaffected (it still passes an icon + title).

### Optional category backdrop
The `#cat-bundle` section supports a full-bleed backdrop (`Media` + 88% scrim,
`--scrim-banner-strong`) gated on `CATEGORY_BG` / `BUNDLE_BANNER_BG` constants —
currently `null` (dark surface) until the background assets are dropped into `src`.

## Supporting changes

- **`MaterialIcon.vue`** — registered the `round/schedule` clock glyph for the
  countdown chip.
- **`App.vue`** — imports `The Boys Banner.webp` + the
  `4,000_CP_+_50_BONUS_STRONGBOXES.webp` hero (Vite sanitises the comma/plus
  filename on build); `bundle2` data; `BUNDLE_ENDS_AT` (~20d 02h 34m out);
  `.section--bundle` / `.section__bg*` styles for the optional backdrop.
