# Release Notes — v0.40.0

**Date:** July 2026
**Milestone:** Eighth store — Yu-Gi-Oh! MASTER DUEL — plus a new story-carousel capability flag; PvZ3 scaffold registered

---

## Highlights

- **YGOMD joins the storefront.** Built from a style-guide-designer extraction of konami.com/yugioh/masterduel plus the real SKU catalogue scraped from yugioh-masterduel.codashop.com: KONAMI-ID-required (no guest checkout, same as YGO:DL), page-model store selling Gems as a single flat `skus.regular` list (not a category-tree catalogue) — all 10 real Gem Packs, with the two limited/exclusive packs leading the list and their real purchase limits (Limit: 3 / Limit: 1) spelled out directly rather than the shared generic label. OKLCH near-black + Millennium-gold + Yu-Gi-Oh!-ribbon-red + arcane-violet palette with a genuinely *mixed* radius profile — pill controls and badges, near-zero-radius cards and thumbnails, tiny-radius inputs — not one radius value applied store-wide like MGSSE's all-sharp profile.
- **Licensed Yu Gothic font, overriding the style guide's own recommendation.** The style guide (`docs/style-guides/yugioh-masterduel/spec.json`) recommended Rajdhani + Noto Sans as Google-Fonts proxies for a system-fallback situation. The store owner explicitly chose Yu Gothic instead — a real JP system font actually observed once in the live site's own CSS — and supplied the three licensed weights (Light/Medium/Bold) as local woff2 files. Light maps to `--sys-weight-regular` (Yu Gothic's true Regular reads heavier than most Latin regular weights), Medium gets its own accurate `--sys-weight-semibold` cut (unlike MGSSE's reuse-Bold 2-cut compromise).
- **New capability flag: `config.page.storyHeroLogo`.** `App.vue`'s single-hero-KV story-carousel branch always stamped `assets.brand.wordmark` on top of the slide as a small overlay logo. YGOMD's carousel key art already reads as fully branded on its own, so this flag (default `true`, only YGOMD sets it `false`) suppresses just that overlay — the second page-level capability flag after `heroRingEffect`, and every other store is unaffected.
- **KONAMI ID sign-in section, reskinned per-brand via tokens only.** YGOMD reuses `PageSignInSection.vue` exactly as YGO:DL does (`allowGuest: false`, `signIn: { desktop: ['mykonami'], mobile: ['mykonami'] }`, navbar sign-in hidden), but the `--bg-action-mykonami` button colour is the *actual* KONAMI corporate red (`#B60014`, the same seed YGO:DL's own theme uses) rather than YGOMD's own Yu-Gi-Oh!-ribbon-red secondary — the myKONAMI CTA is a KONAMI-brand element and reads identically across every KONAMI store regardless of each game's own palette.
- **PvZ3 (Plants vs. Zombies 3: Evolved) registered as an eighth build mode.** Folder structure, capability wiring, and a filter-model catalogue skeleton exist, but every asset is a placeholder SVG and every copy string is marked `PLACEHOLDER` — see `src/stores/pvz3/store.js`'s own header for the remaining setup phases. Not a real store addition yet; carried in this release because it was sitting uncommitted alongside the YGOMD work.

## Changes

### `src/stores/ygomd/` (new)

- `store.js` — `key: 'ygomd'`, KONAMI ID sign-in required (`checkout.allowGuest: false`, `navbar.hideSignIn: true`, `signIn: { desktop: ['mykonami'], mobile: ['mykonami'] }`), `catalog: { mode: 'page', hideNav: true }`, `page: { sections: ['regular'], storyHeroLogo: false }`, `sku: { heroRingEffect: 'dual' }`. Real 10-item `skus.regular` catalogue (pricing/copy from yugioh-masterduel.codashop.com, accessed 2026-07-07). Strings seeded from the style guide's extracted brand voice (`generic.voice.copyExamples`/`lexicon`) — always "Duelist," never "player."
- `img/brand/logomark.png` — real user-supplied card-back/portal icon; used for the navbar logo, sign-in icon, and favicon (`assets.brand.wordmark`/`logomark`/`signinLogomark`/`navSignInIcon`/`favicon`).
- `img/content/story-hero.png` — real user-supplied 4th Anniversary key art (Dark Magician Girl), used for the hero carousel. Flagged in code: unlike the gem/chest icons below, this is Konami's own copyrighted character art — the same category `docs/style-guides/yugioh-masterduel/spec.json`'s `assetManifest` marks "not for redistribution" when pulled from its own `refs/` folder. Supplied directly and explicitly by the store owner for this specific use, not pulled from the reference-only folder.
- `img/content/{gem-small,gem-medium,gem-large,chest-blue,chest-gold}.png` — 5 real user-supplied generic gem-crystal/treasure-chest icons (not Konami character art, no copyright concern), scaled by SKU tier.
- `fonts/yu-gothic-{light,medium,bold}.woff2` — the 3 real licensed Yu Gothic cuts, user-supplied.

### `src/tokens/ds/themes/ygomd.css` (new)

- OKLCH seeds/ramps converted from the style guide's hex values (`#E8C878` primary gold, `#E8001E` secondary red, `#5B4FC7` tertiary violet, `#0B0C1C` neutral — a genuinely violet-tinted near-black, not true achromatic grey, preserved through the whole neutral ramp). 3 derived status colours (brand has no native green; a distinct alert-red separate from the brand's own secondary).
- `@font-face` for Yu Gothic Light/Medium/Bold; mixed `--radius-*` profile (pill controls/badges, zero-radius containers/thumbnails, tiny-radius inputs) instead of one value store-wide.
- Gold+violet `--fx-border-*`/`--fx-bloom-image` retint for the `heroRingEffect: 'dual'` ring; hardcoded radial-gradient page backdrop on `.device__screen` (no image asset — the copyrighted key-art crops in the style guide's `refs/` aren't reused for this).
- `--bg-action-mykonami`/`--bg-action-signin` set to the real KONAMI corporate red (`#B60014`, matching YGO:DL's own seed), not YGOMD's own secondary — the myKONAMI CTA is a shared KONAMI-brand element, not a per-game one.

### `src/App.vue`

- `stories` computed: new `config.page.storyHeroLogo` flag (default `true`) gates the brand-mark overlay on the single-hero-KV carousel slide. Only YGOMD sets it `false`; every other store's carousel is pixel-identical to before.

### `src/stores/active.all.js`, `src/stores/active.ygomd.js` (new), `src/stores/active.pvz3.js` (new), `vite.config.js`, `package.json`, `.claude/launch.json`
