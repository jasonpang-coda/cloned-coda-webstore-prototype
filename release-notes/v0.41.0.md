# Release Notes — v0.41.0

**Date:** July 2026
**Milestone:** New runtime feature-flag system, first flag gates the language/region switcher

---

## Highlights

- **`useFeatureFlags` — a new runtime-mutable layer, distinct from static per-store config.** `useStoreConfig`'s capability flags only ever change when the active store/theme changes; there was no way to flip a behaviour on/off live without editing code. The new composable is a `globalThis`-pinned singleton (same rationale as `useTheme`/`useLocale`) holding a small `FLAG_DEFS` registry — one entry per flag — persisted to `localStorage` under a single shared `webstore:flags` key (deliberately prototype-wide, not per-store like `locale:<theme>`). Adding a future flag is one registry entry; no plumbing anywhere else.
- **First flag: `localeSwitcher`, default off.** Gates the region/language switcher on both surfaces it appears — the `NavDrawer` footer and the `NavBar` right cluster — behind one `v-if="isEnabled('localeSwitcher')"` each. On `NavBar` this composes with the existing `@container (min-width: 801px)` CSS gate; both must pass for the switcher to render.
- **Toggled from the existing `/` command console**, not a new UI surface. A "Feature flags" command group renders one entry per registered flag (`Enable: …` / `Disable: …`, relabelling reactively); present in every build, since flags are a product capability rather than build-only dev tooling.

---

## Changes

### `src/composables/useFeatureFlags.js` (new)

- `FLAG_DEFS` registry: `{ key, label, description, default }`. Ships one flag, `localeSwitcher` (`default: false`).
- Singleton state on `Symbol.for('webstore.useFeatureFlags.state')`; `flags` (reactive), `isEnabled(key)`, `setFlag(key, value)`, `toggleFlag(key)`, `resetFlags()`.
- Persists to `localStorage` (`webstore:flags`) on every mutation; persisted keys are pruned against the current `FLAG_DEFS` on read, so a flag removed from the registry can't leave an orphaned value from an older build.

### `src/components/NavDrawer.vue`, `src/components/NavBar.vue`

- Both switcher containers (`.nav-drawer__locale`, `.navbar__locale`) gained `v-if="isEnabled('localeSwitcher')"`, sourced from the new composable.

### `src/components/CommandConsole.vue`

- New **Feature flags** command group in the registry, built from `useFeatureFlags().FLAG_DEFS` — one toggle command per flag, label driven off its current value.

### `docs/component-breakdown.md`

- New `useFeatureFlags.js` writeup under §6 (State composables); cross-references added to the `NavBar`/`NavDrawer` switcher sections and the `CommandConsole` command-registry breakdown.
