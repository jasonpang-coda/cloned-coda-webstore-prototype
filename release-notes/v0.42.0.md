# Release Notes — v0.42.0

**Date:** July 2026
**Milestone:** New global Footer component, wired into all 9 stores

---

## Highlights

- **New `Footer.vue` — global bottom chrome, the counterpart to `NavBar`'s top chrome.** Two full-bleed bars: an Actions bar (Need Help support link, region/language switcher, cookie preference, social icon links — row layout at `@container (min-width: 801px)`, column below) and a publisher TM/legal bar (logo, disclaimer, Powered-By-Coda, copyright, legal links). Mounted in `App.vue` right before `</DeviceFrame>`, visible on both the storefront and the Transaction History page.
- **Store-agnostic by construction.** Every per-store bit — support URL, social profile links, disclaimer copy, legal links — comes from new `config.footer` / `strings.footer` fields added to all 9 store modules; the component itself never branches on theme identity, mirroring `NavBar`'s composable wiring (`useStoreConfig`/`useStoreAssets`/`useStoreStrings`/`useLocale`).
- **Region/Language switcher gets a third, always-visible home.** Unlike the `NavBar`/`NavDrawer` switchers (behind `isEnabled('localeSwitcher')`), the footer's Region action is not gated by that flag — it renders on every store regardless of the flag's state.
- **Social icons and payment-channel logos now share one polarity flag.** `config.pc.variant` was renamed to `config.chrome.iconVariant` — a single "does this store's chrome need light-on-dark or dark-on-light brand marks" signal now drives both the existing `assets.pc.*` merge and a new `assets.social.*` merge (shared/market-level, same light/dark structure as the PC logos). X's mark is monochrome and swaps polarity; the other five (Facebook/Instagram/YouTube/TikTok/Discord) are full-colour and reuse one file for both.
- **`CategoryNav` overlap fix.** `CategoryNav` is `position: fixed` to the viewport bottom, and Footer is now the last thing on the page — its TM bar reserves extra bottom padding (`+64px`, matching `App.vue`'s existing `.app__nav-gap` clearance) while `CategoryNav` is actually mounted, so the footer's logo/disclaimer/legal links are never scrolled-to-rest behind the fixed nav.

## Changes

### `src/components/Footer.vue` (new)

- Actions bar (`--bg-navbar`) + TM bar (`--bg-nav`), both `<Grid><Span size="fluid">` like `NavBar`'s row.
- Need Help pill → `config.footer.supportUrl`, `target="_blank"`; hidden when falsy.
- Region pill → `useLocale()`'s `openRegionSelector()` + `FlagTile`, always visible (no feature-flag gate).
- Cookie Preference pill → inert (no consent-management system exists yet).
- Social icon row → art from `assets.social.*`, link `href`/visibility from `config.footer.social.<network>`.
- TM bar → publisher logo, per-store disclaimer, Powered-By-Coda (`config.checkout.showPoweredByCoda` gate, same as `CheckoutSheet`), runtime copyright line, legal links row.
- `.footer__tm--nav-clearance` — conditional `+64px` bottom padding while `CategoryNav` is mounted (`!config.catalog.hideNav && !historyOpen`).

### `src/composables/useStoreAssets.js`

- `config.pc.variant` reader renamed to `config.chrome.iconVariant`.
- New `SOCIAL` map (`src/shared/social/{light,dark}/x.svg` + 5 shared full-colour marks), merged into the returned object as `assets.social.*`, sibling to `assets.pc.*`.

### `src/stores/<store>/store.js` (all 9)

- `pc: { variant: 'light' }` → `chrome: { iconVariant: 'light' }`.
- New `config.footer`: `supportUrl` (real Activision URL for COD:M; `'#'` placeholder for the other 8, pending real destinations) + `social: { x, facebook, instagram, youtube, tiktok, discord }` (all `null` — profile URLs to be filled in per store).
- New `strings.footer`: `supportCta`, `cookieLabel`, `cookieCta`, `socialHeading`, `disclaimer` (`null` except COD:M), `legalLinks` (`[]` except COD:M).

### `src/locale/commonStrings.js`

- New shared `footer` key (`en` only, falls through elsewhere): `needHelpLabel`, `regionLabel`, `copyrightSuffix`.

### `src/components/MaterialIcon.vue`

- Added the `question_answer` icon (Footer's Need Help pill).

### `src/App.vue`

- Mounted `<Footer />` after both the storefront and Transaction History `<template>` branches.
