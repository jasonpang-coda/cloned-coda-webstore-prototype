# Release Notes — v0.42.1

**Date:** July 2026
**Milestone:** Footer social icons now render on every store

---

## Highlights

- **Fixed: Footer's social icon links weren't showing.** `config.footer.social.<network>` was `null` on all 9 stores — `v-show` treats that as hidden, so every icon was invisible even though the shared `assets.social.*` art (added in v0.42.0) always resolves. All 9 stores now set every network to a `'#'` placeholder, the same pattern already used for `config.footer.supportUrl`, so the icons render immediately; swap in real profile links per store whenever they're ready.

## Changes

### `src/stores/<store>/store.js` (all 9)

- `config.footer.social`: `{ x: null, facebook: null, instagram: null, youtube: null, tiktok: null, discord: null }` → `{ x: '#', facebook: '#', instagram: '#', youtube: '#', tiktok: '#', discord: '#' }`.
