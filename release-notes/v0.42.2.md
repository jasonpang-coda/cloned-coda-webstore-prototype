# Release Notes — v0.42.2

**Date:** July 2026
**Milestone:** Footer gains a Language field for multi-language markets

---

## Highlights

- **New Language field in the footer, below Region.** Reuses `useLocale()`'s existing `availableLanguages`/`currentLanguage`/`openLanguageSelector()` — only markets that actually offer more than one language get the field (`v-if="availableLanguages.length > 1"`). Uses the `translate` Material icon on the left of the pill (Region's `language` icon sits on the right, so the two pills read distinctly at a glance), with the current language's endonym as the label.

## Changes

### `src/components/Footer.vue`

- `useLocale()` destructure gained `currentLanguage`, `availableLanguages`, `openLanguageSelector`.
- New pill button stacked below the Region pill inside the same `.footer__action` column.

### `src/components/MaterialIcon.vue`

- Added the `translate` icon (`round/translate`).
