# Release Notes — v0.43.0

**Date:** July 2026
**Milestone:** Collaborator comment mode — Figma/Vercel-style feedback pins, backed by Supabase

---

## Highlights

- **New comment mode.** Press **C**, click the 💬 button in the DeviceToolbar (works even on locked per-store builds where the `/` console is compiled out), or use the `/` console. Click any element — including inside sheets, popovers, the nav drawer, and sign-in pages — to drop a pin and leave feedback. First post asks for a name/initials, persisted locally.
- **Shared, live, per-store isolated.** Comments persist to a single Supabase project shared by every store deployment, but each build reads only its own store's rows (FCM never sees COD:M), enforced by a `store` column + RLS. A localStorage fallback keeps the feature usable without a Supabase project configured (session-local, no cross-browser sharing).
- **Native, zero-lag scroll tracking.** Pins are real DOM children of whatever they're anchored to (`.device__screen`, or an overlay's own scrolling body) via `<Teleport>`, positioned `absolute` in that container's local coordinate space — so they scroll with the browser's own compositor instead of visibly lagging a frame behind a JS-driven recompute.
- **Semantic element tagging + flow-state context.** Every comment records the component name, a structural label, and a short text snippet, plus which overlay ("surface") was open when it was placed — e.g. a comment on the checkout sheet re-shows only when checkout is reopened, and is listed with a "Checkout" tag while closed. Both the list and the open thread panel show this element reference.
- **Custom placement cursor.** A Material `add_location` pin glyph (matching the placed-pin colour/shape) replaces the default cursor across every anchorable surface while in comment mode.

## New files

- `src/composables/useComments.js` — singleton state: identity, CRUD, store-scoped fetch + realtime subscription, `enabled` gate (Vercel/PROD + local opt-in, independent of `__STORE_LOCKED__`), localStorage fallback cache.
- `src/lib/supabase.js` — singleton Supabase client; `null` when env vars are absent (feature no-ops rather than crashing).
- `src/utils/commentAnchor.js` — hybrid anchor capture/resolve: container detection (base screen or an overlay's scroll region), selector + normalized coordinates, and the semantic tag (component/label/text/breadcrumb via `inspect.js`).
- `src/utils/timeAgo.js` — compact relative timestamps for the comment UI.
- `src/components/CommentOverlay.vue`, `CommentThreadPanel.vue`, `CommentListPanel.vue`, `CommentIdentityGate.vue` — the pins/panel, thread (reply/edit/delete/resolve), filterable list (all/open/resolved/mine), and first-run name gate.
- `docs/comment-mode.md`, `docs/comments-backend.md`, `docs/comments-schema.md` — feature docs, Supabase setup + RLS SQL, and the full column/jsonb schema reference.
- `.env.example` — documents the two `VITE_SUPABASE_*` vars.

## Changes

### `src/App.vue`

- `C` key toggles comment mode (guarded against typing targets and `/` console focus); registered independently of `__STORE_LOCKED__` so it works on locked review builds.
- Mounts `<CommentOverlay>` at the app root, beside `InspectorOverlay`, escaping the device-frame transform trap.
- New flow-state aggregation: derives the topmost open overlay ("surface") by static z-index priority across `useCheckout`, `useItemSummary`, `useGiftClaim`, `useAuth`, `useLocale`, and the local `menuOpen` (nav drawer), publishing it into comment context.

### `src/components/DeviceToolbar.vue`, `CommandConsole.vue`

- Comment-mode toggle button (toolbar) and "Comment mode" / "Show comments list" commands (console), both gated on the comment-mode `enabled` flag rather than store-lock.

### `src/components/MaterialIcon.vue`

- Added `mode_comment` and `add_location` icons.

### Nine overlay components — `CheckoutSheet.vue`, `ItemSummarySheet.vue`, `ClaimGiftSheet.vue`, `SignInSheet.vue`, `RegionSelectorSheet.vue`, `LanguageSelectorSheet.vue`, `NavDrawer.vue`, `EaSignInPage.vue`, `KonamiSignInPage.vue`

- Added `position: relative` (visually a no-op) to each component's actual inner scrolling element, mirroring `.device__screen`'s existing pattern — required so a comment pin Teleported into that scroll region has the correct containing block and tracks its inner scroll natively, instead of freezing relative to the outer (non-scrolling) dialog panel.

### `package.json`

- Added `@supabase/supabase-js` — the prototype's first network dependency.

## Database

New `public.comments` table (Supabase): `store`/`context`/`anchor` jsonb payloads, a generated `surface` column (derived from `context->>'surface'`) for indexed filtering, and permissive prototype-grade RLS policies. Full schema in `docs/comments-schema.md`; setup steps in `docs/comments-backend.md`.
