# Release Notes — v0.44.0

**Date:** July 2026
**Milestone:** Comment mode extracted into `@coda/comment-kit` — an installable package other teams can use in their own Vue 3 + Vite prototypes

---

## Highlights

- **New package: `@coda/comment-kit`** (`packages/comment-kit`). The full collaborator-comments feature — pins, threads, list, identity, Supabase realtime backend with a localStorage-only fallback — is now a standalone Vue 3 plugin any prototype in the org can install and wire up in ~10 lines, with zero dependency on this repo's internals.
- **Every host coupling became a config option.** `useTheme()` → `scope` (string, ref, or function); `__STORE_LOCKED__` → `deploymentScope`; the hardcoded 12-selector DOM list → `containers`; `VITE_SUPABASE_*` env reads → `supabaseUrl`/`supabaseAnonKey` (or a pre-built client); the enablement gate → `enabled`; localStorage key prefix → `storagePrefix`. The cursor CSS, previously a second hardcoded copy of a selector subset, is now generated at runtime from the same `containers` array — one source of truth instead of two lists to keep in sync.
- **Built-in zero-wiring entry points.** The package ships an optional floating 💬 launcher and a bare-key hotkey (both typing-target-guarded) so a consumer with no toolbar of their own still gets full functionality out of the box. The webstore disables both (`hotkey: false, launcher: false`) since it keeps its existing `C`-key handler, DeviceToolbar button, and `/` console commands.
- **Git-branch distribution.** `npm run kit:publish` snapshots `packages/comment-kit` onto a dedicated `comment-kit` branch (npm can install a branch, not a repo subfolder), so teammates run `npm install github:yiweicoda/coda-webstore-prototype#comment-kit` — no private registry, no token setup.
- **Webstore dogfoods it.** The 8 original feature files are deleted from `src/`; `main.js` now configures the kit with the webstore's exact prior values (same Supabase table, same `store`/`deployment_scope` semantics, same `storagePrefix: 'webstore:comments'` so existing reviewer identities and cached data are untouched).

## New additions

- `packages/comment-kit/` — the package: `src/index.js` (plugin), `src/config.js` (resolved options singleton), `src/useComments.js`, `src/core/{supabase,anchor,timeAgo}.js`, `src/components/{CommentLayer,CommentThreadPanel,CommentListPanel,CommentIdentityGate}.vue`, `sql/comments.sql`, `README.md`.
- `scripts/publish-comment-kit.sh` + `npm run kit:publish`.
- Root `package.json` gains an npm workspace (`packages/*`) and a linked `@coda/comment-kit` dependency.

## Changes

### `src/main.js`

- New `.use(createComments({...}))` call configuring `scope`, `deploymentScope`, `containers`, `ignoreSelectors`, `enabled`, `storagePrefix`, and disabling the kit's built-in hotkey/launcher.

### `src/App.vue`, `src/components/DeviceToolbar.vue`, `src/components/CommandConsole.vue`

- Imports switched from the deleted local files to `@coda/comment-kit`; `<CommentOverlay>` → `<CommentLayer>` in `App.vue`. No behavioral change — the entry points (C key, toolbar button, console commands) and surface-aggregation logic are unchanged.

### Deleted

- `src/composables/useComments.js`, `src/lib/supabase.js`, `src/utils/commentAnchor.js`, `src/utils/timeAgo.js`, `src/components/Comment{Overlay,ThreadPanel,ListPanel,IdentityGate}.vue` — all migrated into `packages/comment-kit`.

### Docs

- `docs/comment-mode.md` — now documents the webstore's kit *configuration* and links to the package README as the canonical feature reference.
- `docs/README.md` — doc-index entry updated to point at the package.
