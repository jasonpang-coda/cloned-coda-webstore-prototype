# Release Notes — v0.45.0

**Date:** July 2026
**Milestone:** Export comments as Markdown — all threads or a hand-picked selection, ready to paste into an AI coding session

---

## Highlights

- **Export to Markdown, right from the list panel.** A new ⬇ "Export all" button and a ☑ "Select" mode (with a bulk action bar) let reviewers pull comments out of the tool as a single Markdown file — author, timestamp, resolved status, the anchor's element reference (component/label/text snippet), the surface/page it was left on, the body, and every reply. This is the exact context an AI coding agent needs to find and fix the right thing.
- **Selection works like a file manager.** Checkboxes per row, Shift-click for a contiguous range, Cmd/Ctrl-click to toggle an individual row — no new interaction model to learn.
- **"Include resolved threads" is a per-export choice**, not a permanent setting — a small confirmation step appears before the file downloads, for both "export all" and "export selected."
- **`@coda/comment-kit` bumped to v0.3.0.** The export logic lives in a new framework-free `core/export.js` (pure Markdown builder + browser download trigger, zero dependencies) and one new `exportMarkdown()` store action, exposed through `useComments()` in the Vue adapter for hosts who want a custom export button outside the built-in list panel.

## Changes

### `packages/comment-kit/src/core/export.js` (new)

- `buildExportMarkdown(threads, { repliesOf, scope, includeResolved })` — the Markdown document builder; sorts chronologically, one section per thread with `[OPEN]`/`[RESOLVED]` status, element/surface reference, body, and a `### Replies` list.
- `exportFilename(scope)`, `downloadMarkdown(filename, content)` — filesystem-safe naming + Blob-based browser download.

### `packages/comment-kit/src/core/store.js`

- New `exportMarkdown(threadIds, { includeResolved = true })` action — `threadIds: null` exports every thread for the current scope regardless of the active Open/Resolved/Mine filter.

### `packages/comment-kit/src/vue.js`

- `useComments()` now also exposes `exportMarkdown`.

### `packages/comment-kit/src/elements/comment-layer.js`

- List header: **Select** toggle + **Export all** button.
- Select mode: per-row checkboxes, click/Shift-click/Cmd-Ctrl-click selection, a bulk bar ("N selected" · Select all · Export · Cancel).
- New export-options modal (reuses the identity-gate's shell) with an "Include resolved threads" checkbox before the download fires.
- Selection state resets whenever the list closes.
