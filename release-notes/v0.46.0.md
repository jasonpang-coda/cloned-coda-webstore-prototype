# Release Notes — v0.46.0

**Date:** July 2026
**Milestone:** COD:M settles its body-font pairing on Inter, adds an MCOC theme + style guide, and fixes the `C`/`/` hotkeys misfiring inside comment mode's shadow DOM

---

## Highlights

- **Comment-mode hotkey fix.** The global `C` (toggle comment mode) and `/` (open the dev console) hotkeys in `App.vue` guarded against typing targets by reading `e.target` — but the compose box lives inside `<comment-kit-layer>`'s shadow DOM, so `e.target` gets retargeted to the shadow host at the `window` level and the guard couldn't detect typing. Typing a `c` while composing a comment would close comment mode and lose the draft. Fixed by reading `e.composedPath()[0]` instead, the same pattern `@coda/comment-kit` already uses internally for its own (disabled) hotkey handler.
- **COD:M body-font pairing decided: Inter.** Removed the `useBodyFont` demo evaluation toggle (Hitmarker / Barlow / Inter, wired through DeviceToolbar + CommandConsole) now that the pairing is settled — Inter is baked directly into the theme as the body font, with Hitmarker staying on headings/display.
- **New MCOC style guide + theme scaffold** — `docs/style-guides/mcoc/` (guide, Figma token/config JSON, refs) and `src/tokens/ds/themes/mcoc.css`.
- **Handoff token snapshots synced** — `docs/Handoff/sku-cards/vendor/tokens/*.css` updated to match the live DS token set (elevation surfaces L1/L2/L3, status surface gradients, and related semantic aliases).

## Changes

### `src/App.vue`

- `onGlobalKey`: computes a shadow-DOM-safe `origin` via `e.composedPath?.()[0] ?? e.target` and uses it for both the `/` and `c`/`C` typing-target guards.

### Body-font pairing cleanup

- Deleted `src/composables/useBodyFont.js`.
- `src/tokens/ds/themes/codm.css`: collapsed the `[data-body-font="barlow"/"inter"]` override blocks into a single `[data-theme="codm"]` block hardcoding the Inter pairing.
- `src/components/CommandConsole.vue`, `src/components/DeviceToolbar.vue`: removed the body-font dropdown/commands and the `useBodyFont` import.
- `index.html`: dropped the Barlow font-face link and the `data-body-font` attribute; kept Inter.
- `docs/design-tokens-codm.md`: typography table now documents `--sys-font-family-body` as Inter and notes the condense/tracking overrides that go with it.

### New additions

- `src/tokens/ds/themes/mcoc.css` — new theme.
- `docs/style-guides/mcoc/` — style guide, Figma token/config JSON, reference assets.

### Docs sync

- `docs/Handoff/sku-cards/vendor/tokens/{codm,effects,extensions,keyframes,semantics,system}.css` — brought in line with the current live token set.
