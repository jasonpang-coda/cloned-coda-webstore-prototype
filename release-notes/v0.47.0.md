# Release Notes — v0.47.0

**Date:** July 2026
**Milestone:** New scoped interactive handoff site for the COD:M SKU-card family — component reference + playground only

---

## Highlights

- **New `docs/Handoff/codm-sku-cards/` handoff site.** A trimmed-down sibling of the existing `docs/Handoff/sku-cards/` deep-dive: just two pages instead of six — a component reference (`components.md`) and the live playground — so a FE picking up the SKU cards isn't wading through app-wide docs (NavBar, sheets, inspector, composables, haptics/typography catalogues) to find what they need.
- **Playground reused verbatim.** `SkuCardsPlayground.vue` (live 6-card gallery with token sliders) and `SkuCardsTimeline.vue` (entrance-cascade scrubber) were copied from the original site unchanged — the FE's own feedback was that the playground is the most useful part.
- **`components.md` written fresh at "props + behaviour" depth** (~350 lines): the 6-card family table, shared anatomy (gradient-ring `::before` idiom, entrance choreography, `itemKey` selection contract, countdown pattern), per-card prop tables and non-obvious behaviours, the containers table, and the 8 gotchas that most often get broken (no `overflow:hidden` on Hero/BestSeller, `bundle-enter`/`gift-enter` omitting `transform` in `to`, the 90ms vs 50ms stagger mismatch, etc.). Also captured two deltas the original site's doc missed: `BundleBreakdown.vue` was extracted as a shared child-item row (now used by `BundleSkuCard`, `BestSellerCard` **and** `SkuImageCard` via an `items` prop), and Hero/BestSeller's ring effect became a `config.sku.heroRingEffect` capability flag (e.g. MGSSE's `'camo-breathe'`).
- **Fixed a two-layer broken-link bug** in cross-repo source links (`src/components/*.vue`): VitePress's markdown-to-HTML transform appends `.html` to any relative link regardless of extension at *build time*, and its client-side SPA router independently intercepts same-origin clicks to any extension outside its "known non-HTML" list and does the same at *click time* — so even a raw `<a>` tag pointing at a `.vue` file got mangled into `/src/components/SkuCard.vue.html`. Fixed by pointing these links at the real GitHub blob URLs (`github.com/yiweicoda/coda-webstore-prototype/blob/main/...`) instead of local relative paths — a different-origin link the router never touches, and one that resolves correctly regardless of the site's own build depth. (The original `sku-cards/README.md` has the same latent bug, unpatched.)

## New additions

- `docs/Handoff/codm-sku-cards/` — full VitePress site: `index.md`, `components.md`, `playground.md`, `handoff.config.mjs` (scoped to the 2-page nav, same 11-file token cascade + Hitmarker fonts as the full site), `.vitepress/` (kit generics + the two vendored playground components), `vendor/` (committed token/font snapshot), `DEPLOY.md`, `vercel.json`.
