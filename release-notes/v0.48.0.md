# Release Notes — v0.48.0

**Date:** July 2026
**Milestone:** Codashop store added — first light theme, first two-column split layout, first inline page-step checkout — plus unique per-SKU CP images for COD:M and a Vercel build fix for the SKU Cards handoff site

---

## Highlights

- **Codashop store added** (placeholder Mobile Legends: Bang Bang Diamond catalog — no real MLBB assets shipped, see `src/stores/codashop/img/README.md`). Three firsts for the whitelabel system:
  - **First LIGHT theme.** Every other store assumes a dark container; Codashop inverts the ink ramp and L1/L2/L3 elevation surfaces from `html[data-theme="codashop"]` — white cards on a deep-purple page.
  - **First two-column split layout** (`config.page.layout: 'split'`, 4-of-12 left rail / 8-of-12 right rail at M/L). `App.vue` wraps the storefront in `.storefront__col--lead`/`--main`, both `display: contents` unless `--split` is active — a complete no-op for every other store. New `GRID_BARE_KEY` provide/inject (`src/composables/gridBare.js`) stops each section's own `<Grid><Span>` from nesting a second 12-col grid inside the already-gridded split column. New M/L grid-gutter tokens (`--gap-grid-gutter-m/-l`, `--gap-grid-margin-l`) replace three values `Grid.vue` previously hardcoded inline as "Phase 3" TODOs — a pure refactor for every existing store.
  - **First inline page-step checkout** (`config.checkout.mode: 'inline'`) instead of the overlay `CheckoutSheet`. `useCheckout.js` skips the signed-in/guest-verified gate in this mode (Gamer ID entry is itself step 1) and adds `isItemSelected(key)` so `SkuCard` shows selected state with no sheet involved. New `src/components/checkout/` step cards: `StepGamerId`, `StepPayment`, `StepZipCode`, `StepDetails` (+ shared `StepCard`).
  - Also new: `GameIdentity.vue` (left-rail card, gated on `config.identity`), `SkuList`'s `columns` prop (`config.skuList.columns`, Codashop's 5-up grid), and a `storeSkus.value?.promo`/`.cp` override so a store can supply its own CP denominations directly.
  - Full write-up in `docs/multi-store-whitelabel.md` §6 and `docs/grid-layout-system.md` (including the anonymous-container-query limitation this introduces, and why Codashop drives its SKU grid density with an explicit prop instead).
- **Unique per-SKU CP images (COD:M).** The 8 bucketed coin images (`1.webp`…`8.webp`, shared across a price-range scheme where one file could represent up to four different denominations) are now 12 files named by exact CP amount (`88.webp`…`58000.webp`). `cpCoins` in `store.js` is now an amount-keyed object instead of an array; `cpCoinFor(amount)` does a direct lookup instead of bucketing amounts into ranges.
- **Vercel build fix for `docs/Handoff/codm-sku-cards`.** PostCSS's config loader was walking up past the site's own directory and picking up the repo-root `postcss.config.js` (which requires `tailwindcss`, a main-app-only dependency) — worked locally, failed on Vercel where the Root Directory install never populates the repo root's `node_modules`. Fixed with a local, empty `postcss.config.js` in the site directory.

## Changes

### `src/stores/codashop/`, `src/tokens/ds/themes/codashop.css`, `docs/design-tokens-codashop.md`

- New store module, theme (OKLCH, light-theme inversion), and colour token reference. Registered in `active.all.js`, `vite.config.js`'s `STORES` list, `.claude/launch.json`, and `package.json`'s `dev:codashop`/`build:codashop` scripts.

### `src/App.vue`

- `isSplit`, `showHero`, `skuColumns`, `isInlineCheckout` computeds; `provide(GRID_BARE_KEY, isSplit)`; storefront section stack now wrapped in the split shell; inline checkout step sections; `CheckoutSheet` gated on `config.checkout.mode !== 'inline'`; `cpCoinFor`/`CP_COIN_1` updated for the amount-keyed `cpCoins` map.

### `src/components/Grid.vue`, `src/components/Span.vue`, `src/composables/gridBare.js` (new)

- `bare` (injected) mode; new `col-lead`/`col-main` Span sizes; M/L gutter/margin now read from tokens instead of hardcoded values.

### `src/composables/useCheckout.js`, `src/components/SkuCard.vue`, `src/components/SkuList.vue`

- `isInlineMode()`/`isItemSelected()` branch the checkout gate and selected-state check on `config.checkout.mode`; `SkuList` gained the nullable `columns` prop.

### `src/stores/codm/store.js`, `src/App.vue`, `src/library/stories/*.stories.js`

- CP coin imports/`cpCoins` map rewritten from an 8-bucket array to a 12-entry amount-keyed object; Storybook stories that indexed `cpCoins` by bucket number now use amount keys.

### `docs/Handoff/codm-sku-cards/postcss.config.js` (new)

- Empty PostCSS config, scoped to stop the parent-directory config search reaching the repo root.

## New additions

- `src/stores/codashop/` (store, theme, placeholder assets), `src/components/checkout/` (`StepCard`, `StepGamerId`, `StepPayment`, `StepZipCode`, `StepDetails`), `src/components/GameIdentity.vue`, `src/composables/gridBare.js`, `docs/design-tokens-codashop.md`, `docs/color-tokens-codm.md`.
