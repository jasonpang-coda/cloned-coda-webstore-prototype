# Release Notes — v0.49.0

**Date:** July 2026
**Milestone:** Codashop TrustBar section (publisher partnerships, count-up stats, payment icons) + CompactHero Figma-fidelity rebuild + catalog-card SKU container, plus a new FE spec-handoff doc set for the TrustBar component

---

## Highlights

- **New `TrustBar.vue` section (Codashop only).** A four-card trust-signal row — publisher-partnership logo rotator, gamer-count and delivery-rate count-up stats, and a static payment-icons row — mounted directly under `CompactHero` in the sticky left rail at every breakpoint. Ships with:
  - A swipeable single-card carousel (pointer-drag + dot pagination + auto-advance) below 801px of its own rendered width, and a 2×2/4-up grid from 801px/1280px.
  - A **self-scoped container** (`container-type: inline-size; container-name: trust-bar`) rather than this repo's usual anonymous binding to `.device__screen` — required because the component now lives in a ~4/12-column rail that's reliably narrower than the screen; an ambient container query would have measured screen width instead of the rail's own ~400px box.
  - New `src/composables/useCountUp.js` (rAF/`easeOutCubic` tween, gated on `prefers-reduced-motion`) and `src/tokens/motion-trust.css` (rotator/carousel interval + fade tokens).
  - `InfoTag.vue` gained a `success` variant (bg/border/text triplet) for the delivery badge, alongside its existing `neutral` variant.
- **CompactHero Figma-fidelity rebuild.** `GameIdentity.vue` is renamed `CompactHero.vue` and split into two new reusable pieces — `Thumbnail.vue` (sized image tile) and `InfoTag.vue` (icon+label pill, replacing the ad-hoc chip markup). Fixes four token/asset mismatches found against the real Figma spec (thumbnail size, heading style, tag colour, icon) and one latent bug: `MaterialIcon.vue` never actually imported the `verified_user`/`shield` glyph it referenced, so the delivery-chip icon silently rendered blank.
- **Catalog "card" container (`config.page.catalogBoxed`).** The New Users Promo banner + CP SKU grid now render inside a single bordered/rounded panel (`--bg-card-default`/`--border-card-default`/`--radius-container-l`) matching the Figma "Select Recharge" container, instead of two separate dividered sections. Codashop-only; every other store keeps the original unboxed rendering.
- **12px side inset for TrustBar at S and smaller.** Added from the *host* (`App.vue`'s `.trust-bar-section` wrapper), not from inside the component — the split shell's own grid margin already covers this at M/L, so the inset is added only below 801px and removed above it.
- **New FE spec-handoff doc set** (`docs/Handoff/trust-bar/`) documenting TrustBar's full state machine (18 states), resolved token contract, and the two placement decisions above (self-scoped container, host-owned side inset), per the `web-store-spec-handoff` skill. Flags the `--border-navbar` token/comment discrepancy in `codashop.css` as an open question rather than silently fixing it.
- **Spec-handoff skill updated** — `web-store-spec-handoff` and `web-store-interactive-handoff` SKILL.md and `handoff-template.md` extended (state-count reconciliation, `agents-template.md` scaffold) based on lessons from authoring this handoff.

## Changes

### `src/components/TrustBar.vue` (new)

- Publisher-logo crossfade rotator (`mode="out-in"`, pairs chunked from `assets.content.publisherLogos`), two `useCountUp` stat cards, static payment-icons row, XS/S pointer-drag carousel with dot pagination and auto-advance, M/L 2×2/4-up grid with column dividers. Self-scoped `@container trust-bar` query (`container-name: trust-bar`) so its layout states resolve against its own box, not the screen.

### `src/App.vue`

- New `showTrustBar`/`catalogBoxed` computeds. `TrustBar` mounted inside `storefront__col--lead` directly after `CompactHero` (previously it was the first item in the wider main column, beside the hero rather than under it). New `.trust-bar-section` wrapper supplies the 12px side inset below 801px only. New boxed variant of the New Users Promo + CP sections (`.catalog-card`) gated on `config.page.catalogBoxed`, alongside the original unboxed rendering for every other store. `CompactHero` import/usage updated from `GameIdentity`.

### `src/components/CompactHero.vue` (renamed from `GameIdentity.vue`), `src/components/Thumbnail.vue` (new), `src/components/InfoTag.vue`

- `CompactHero` composes the new `Thumbnail` + `InfoTag`, drops its own padding (picked up from the `.section` wrapper in `App.vue` instead), and fixes the thumbnail size/heading class/tag tokens against the real Figma node. `InfoTag` gains a `variant` prop (`'neutral' | 'success'`).

### `src/components/MaterialIcon.vue`

- Adds the `verified_user`, `groups`, `bolt`, and `credit_card` icon imports (the first fixes a pre-existing silent-blank-icon bug; the other three are new, used by TrustBar's four card icons).

### `src/components/NavBar.vue`

- `.navbar__signin--filled .navbar__signin-label` now sets `color: var(--text-text-on-brand)` — a pre-existing generic `.navbar__signin span` rule was winning on specificity and rendering the Sign In label in the wrong (dark) colour on Codashop's filled button.

### `src/composables/useCountUp.js`, `src/tokens/motion-trust.css` (new)

- rAF-driven count-up tween composable and its two motion tokens (`--motion-trust-rotate-interval`, `--motion-trust-rotate-fade`) plus the carousel's interval/slide tokens; imported in `main.js`.

### `src/stores/codashop/store.js`, `src/tokens/ds/themes/codashop.css`

- `config.trustBar` (stats), `strings.trustBar` (all copy), `assets.content.publisherLogos` (4 real publisher logo imports); `config.page.catalogBoxed: true`. Theme gains `--bg-tag-neutral`/`--border-tag-neutral` overrides (fixes `InfoTag`'s neutral variant rendering as a near-invisible black smudge on the dark page).

### `.claude/skills/web-store-spec-handoff/`, `.claude/skills/web-store-interactive-handoff/SKILL.md`

- `handoff-template.md` extended with state-count reconciliation guidance; new `agents-template.md` scaffold for the `AGENTS.md` companion file both skills produce.
