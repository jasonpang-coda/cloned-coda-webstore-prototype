# Release Notes — v0.49.2

**Date:** July 2026
**Milestone:** Fix an unscoped HDR colour override that broke Codashop's Sign In button, plus a Sign In copy fix and a responsive step-spacing rhythm

---

## Highlights

- **Fixed `--bg-action-primary`/`--text-hyperlink-inverse` silently resolving to COD:M's hardcoded gold on every store, on any HDR-capable display.** Reported as "update the Sign In button" — investigated against the real Figma spec ([node 2189:2735](https://www.figma.com/design/LBnhQZYmtplAs0Rc9s5D3b?node-id=2189-2735)) and found the button rendering as a solid yellow pill with invisible yellow-on-yellow text, instead of the purple pill with bold yellow label the design calls for. Root cause: `src/tokens/motion-sku.css` had an `@media (dynamic-range: high)` block that boosted these two semantic tokens to a fixed superluminant gold at plain `:root` — written for COD:M's own yellow `--ref-primary` (`#FFE700`), but with **no `[data-theme]` scope at all**, so it silently overrode every other store's brand colour for these roles on HDR-capable displays. Fixed by scoping the override to `html[data-theme="codm"]`; verified live that COD:M keeps its intended gold boost while Codashop (purple) and FC Mobile (green) now correctly show their own brand colours. Documented as Cautionary tale #3 in `docs/multi-store-whitelabel.md` — the first documented case of a `:root` leak happening *inside* an at-rule (`@media`), not just a plain declaration.
- **Codashop's Sign In label corrected** from `Sign In` to `Sign in` (sentence case), matching the Figma copy exactly.
- **New responsive step-spacing rhythm for Codashop's inline checkout.** The gap between every adjacent step in the flow — compact hero → trust bar → gamer ID → SKU catalog card → payment → zip code → details — is now a deliberate 12px at S and smaller, 24px at M and up (`--gap-section-default`/`--gap-section-separation`), via new `.section--tight-top`/`.section--tight-bottom` utility classes in `App.vue`, replacing the default `.section` rhythm (~40px between any two sections) for these specific boundaries only. Verified via computed-style checks at 384px and 1280px.

## Changes

### `src/tokens/motion-sku.css`

- The `--bg-action-primary`/`--text-hyperlink-inverse` HDR gold boost moved from unscoped `:root` to `html[data-theme="codm"]`, inside the existing `@media (dynamic-range: high)` block. `--hdr-glow`/`-hot`/`-bloom` in the same block stay unscoped (already a per-theme-overridable system — see `efootball.css`/`tdr.css`/`fcm.css`/`ygodl.css`).

### `src/stores/codashop/store.js`

- `strings.signIn.cta`: `'Sign In'` → `'Sign in'`.

### `src/App.vue`

- New `.section--tight-top`/`.section--tight-bottom` CSS utility classes (12px default, 24px from `@container (min-width: 801px)`), applied across all 6 step-section boundaries in Codashop's inline-checkout flow (CompactHero, TrustBar, StepGamerId, the boxed catalog card, StepPayment, StepZipCode, StepDetails).

### `docs/multi-store-whitelabel.md`, `docs/component-breakdown.md`

- New "Cautionary tale #3" documenting the unscoped-`@media`-override bug pattern; footers bumped.
