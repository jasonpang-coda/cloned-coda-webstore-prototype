# Release Notes — v0.51.0

**Date:** August 2026
**Milestone:** FCM production SKU card design pilot, feature-flagged; multi-level nav gradient/underline polish

---

## Highlights

- **Production SKU card design pilot (`fcmSkuCardModel`)** — a second FCM-only runtime flag swaps the prototype's new (unreleased) SKU card designs for the two templates actually live in production today: a regular SKU card (`SkuImageCard.vue`'s new `variant="prod"`) and a landscape highlighted/hero card (new `ProdHighlightedSkuCard.vue`, replacing `BestSellerCard`). Resting state only.
- **Gifts and TWG/Campaign Packs converted to the regular prod SKU card** — prod has no separate bundle template, so both now render through `SkuImageCard`'s `'prod'` variant instead of `BundleSkuCard`. Gifts use the literal string `"Claim"` as their CTA (already present in the catalogue data, uppercased by the card's own CSS) instead of a price.
- **Real background art for both prod card templates** — a marble/gold background for the regular card and a green-glow background for the highlighted hero, both sourced from Figma and wired via new `--bg-image-sku-card-prod` / `--bg-image-sku-card-prod-highlighted` tokens (replacing the earlier flat-gradient placeholder).
- **Best sellers carousel removed under the prod flag** — prod merchandises only the single highlighted hero; the separate `FeaturedCarousel` "Best sellers" section no longer renders when `fcmSkuCardModel === 'prod'`.
- **Isolated FCM build defaults to prod designs with no toggle** — in `build:fcm`/`dev:fcm` (`__STORE_LOCKED__`), `fcmSkuCardModel` always resolves to `'prod'` and its dev-toolbar/console control is hidden (new `hideWhenLocked` flag-def option). The multi-store prototype build keeps the toggle.
- **Fixed the highlighted card's "RECOMMENDED" tag being clipped** — `v-ripple` forces `overflow: hidden` on its host element to contain the ripple wave, which was clipping the tag's intentional top-left overhang. Moved the ripple/click handling to a dedicated surface layer behind the tag/content instead of the card root.
- **Multi-level nav gradient/underline polish (`fcmNavModel`)** — L1/L2/L3 selected-tab backgrounds and underlines now render as tokenised gradients on FCM (`--bg-nav-selected`, `--gradient-nav-selected-stroke`, `--text-nav-selected`, `--border-nav-selected`), inert everywhere else. Fixed `NavBar`'s intent row not reaching the true edge (`width: 100%` over-constrained the box model against its own negative margins) and moved its divider to below the row.

## Changes

### `src/composables/useFeatureFlags.js`

- New `fcmSkuCardModel` flag: `'new' | 'prod'`, FCM-scoped, `hideWhenLocked: true`.
- New `hideWhenLocked` flag-def option, respected by `DeviceToolbar.vue`'s enum-select segment and `CommandConsole.vue`'s flag command loop.

### `src/stores/fcm/store.js`

- New `config.sku.prodCardDesigns: true` capability gate (FCM only), same two-gate pattern as `config.nav.multiLevel`.

### `src/App.vue`

- `skuCardModel`/`isProdCards` computeds; `__STORE_LOCKED__` short-circuits to `'prod'`.
- `BestSellerCard` mount swapped for `ProdHighlightedSkuCard` under the flag; both `CategoryCatalog` mounts and both Gifts branches (multi-level + legacy filter) get `SkuImageCard` `variant="prod"` instead of `BundleSkuCard`/`BestSellerCard`.
- "Best sellers" `FeaturedCarousel` section gated off under the prod flag.

### `src/components/SkuImageCard.vue`

- New `variant="prod"` layout (separate template branch): square corners, outside hairline, info-above-art order, reward strip + champagne price bar.
- New `title` prop, taking precedence over amount+currencyLabel for bundle/gift items.

### `src/components/ProdHighlightedSkuCard.vue` (new)

- Landscape two-column highlighted/hero card mirroring `BestSellerCard`'s checkout/press/ripple wiring, with its own `prod-hero|...` selection-identity prefix.
- Ripple/click handling isolated to a `.prod-highlighted-sku__surface` layer behind the tag/content, so the RECOMMENDED tag's overhang isn't clipped by `v-ripple`'s forced `overflow: hidden`.

### `src/components/CategoryCatalog.vue`

- New `cardVariant` override prop; `cardType === 'bundle'` branch renders `SkuImageCard` (`'prod'`) instead of `BundleSkuCard` when set to `'prod'`.

### `src/tokens/ds/semantics.css` / `src/tokens/ds/themes/fcm.css` / `src/tokens/ds/extensions.css`

- New inert-by-default tokens for the prod SKU card pilot: `--bg-image-sku-card-prod`, `--border-sku-card-prod`, `--gradient-sku-card-prod-price`, `--bg-sku-card-prod-reward`, `--border-sku-card-prod-highlighted`, `--bg-image-sku-card-prod-highlighted`, `--gradient-sku-card-prod-gold`(+`-angle`), `--text-sku-tag-popular`, `--bg-loyalty-badge-prod`, `--text-shadow-sku-card-prod`. Real values (including the two background-image `url()`s) in `themes/fcm.css`.
- Nav gradient/underline tokens for the multi-level nav pilot: `--bg-nav-selected`, `--gradient-nav-selected-stroke`, `--text-nav-selected`, `--border-nav-selected`, `--border-weight-nav-selected-stroke`.

### `src/components/NavBar.vue` / `src/components/CategoryNav.vue`

- L1/L2/L3 selected-tab styling switched from solid colours to the new gradient/underline tokens.
- `NavBar`'s intent row edge-to-edge fix (`width: auto` instead of `100%`) and divider moved below the row.
- `CategoryNav`'s row-variant tab centering switched to `justify-content: safe center` (plain `center` mis-centred the scroll offset once tabs overflow).

### `src/components/PageSignInSection.vue`

- Card radius token corrected (`--radius-container-m` → `--radius-container-s`).
