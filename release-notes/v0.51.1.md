# Release Notes — v0.51.1

**Date:** August 2026
**Milestone:** FCM multi-level nav — removed the dead L2/L3 nav bar for Loyalty & Rewards and Events

---

## Highlights

- **`CatalogNavStack` (L2/L3 nav) is now Store-only** — Loyalty & Rewards and Events are each a single stub category with a single "coming soon" subcategory, so the category/subcategory nav had nothing real to switch between; it was rendering one dead L2 tab instead. Gated behind the existing `isStoreIntentActive` check, so it applies uniformly across all three nav-model presentations (`stacked`, `dropdown`, `flat`) since they share the one `CatalogNavStack` mount point in `App.vue`. Store's own nav is unaffected.

## Changes

### `src/App.vue`

- `CatalogNavStack`'s `v-if` gains `&& isStoreIntentActive`, matching the same gate already used for the Best Seller hero/carousel above it.

### `docs/fcm-components.md`

- Section 5 (multi-level nav pilot) updated to document the Store-only gating.
