# Release Notes — v0.51.2

**Date:** August 2026
**Milestone:** Fixed a stale `--motion-sku-enter` token, shipped two new spec handoffs for the Best Seller card's motion, and taught the handoff skill to bundle itself

---

## Highlights

- **`--motion-sku-enter` token fixed** — the entrance token named for exactly the "card fades/slides in on mount" role was aliasing `--motion-sys-duration-base` (250ms) while every actual card entrance in the codebase hardcoded `--motion-sys-duration-slow` (350ms) instead. Verified nothing consumes the token via `var()` anywhere in `src/`, so realigning it to the value every component already uses is a zero-risk, non-behavioural fix.
- **Two new spec handoffs** under `docs/Handoff/` — `bestseller-card-effects` (the running-border ring, breathing bloom, metallic shimmer, and mount entrance on `BestSellerCard`) and `sku-card-entrance-stagger` (the two-axis staggered mount cascade shared by six SKU-family card types). Both are agent-executable, token-cited, source-linked, and cross-link each other.
- **The `web-store-spec-handoff` skill now bundles itself** — every handoff it produces ships a frozen `_skill/` snapshot (`SKILL.md`, `handoff-template.md`, `agents-template.md`) so a reader of `docs/Handoff/<feature>/` has the full generating context without needing repo access. Retrofitted onto both new handoffs.

## Changes

### `src/tokens/motion-sku.css`

- `--motion-sku-enter` now aliases `var(--motion-sys-duration-slow)` (350ms) instead of `var(--motion-sys-duration-base)` (250ms), matching the hardcoded duration every card entrance (`SkuCard`, `SkuImageCard`, `BestSellerCard`, `HeroSkuCard`, `BundleSkuCard`, `GiftSkuCard`, `ProdHighlightedSkuCard`, `StoryCarousel`) already uses.

### `docs/motion-tokens.md`

- Fixed the `--motion-sku-enter` entry, which previously stated "250ms" directly above a 350ms code sample — now internally consistent at 350ms.

### `.claude/skills/web-store-spec-handoff/SKILL.md`

- Added Phase 4 step 5: bundle the skill's own `SKILL.md`/`handoff-template.md`/`agents-template.md` into a `_skill/` subfolder inside every handoff it produces, plus a footer link and a matching "Quality bar" checklist item.

## New additions

- `docs/Handoff/bestseller-card-effects/` — running-border, shimmer, bloom, and mount-entrance handoff for `BestSellerCard` (`README.md`, `AGENTS.md`, `_skill/`).
- `docs/Handoff/sku-card-entrance-stagger/` — cross-family staggered mount-entrance handoff (`README.md`, `AGENTS.md`, `_skill/`).
