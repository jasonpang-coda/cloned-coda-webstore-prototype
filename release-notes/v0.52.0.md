# Release Notes — v0.52.0

**Date:** August 2026
**Milestone:** Shipped an interactive handoff site for the Best Seller card effects, plus a Rogue Trader dual-comet worked example and a kit-level fix for bundled skill snapshots

---

## Highlights

- **New interactive handoff site** — `docs/Handoff/bestseller-card-effects/` now has a full VitePress companion: a live single-card playground (toggle Compact/Selected to reach all four §2.1 states, replay the mount entrance, swap the ring variant), a scrubbable entrance-choreography timeline, easing-curve viewers, and a token sandbox for the ring/bloom/entrance durations. This is the behaviour oracle an implementer verifies a rebuild against.
- **Rogue Trader dual-comet worked example** — the spec doc's §2.1.c now documents Warhammer 40,000: Rogue Trader's fully-resolved `--fx-border-*` colours (imperial gold + warp-green, with an HDR boost) as a concrete reference for the `--dual` ring variant, live in the new playground's ring-variant selector. Clarified that Rogue Trader's own `BestSellerCard` still defaults to `hdr` today — the dual comet is currently live on `HeroSkuCard`, not `BestSellerCard`.
- **Handoff kit fix** — the `_handoff-kit` template's VitePress config now excludes `_skill/**` from page scanning. Every handoff now bundles a frozen skill snapshot (since the last release); without this, VitePress's Vue compiler would choke on those templates' unfilled `<placeholder>` syntax the first time an interactive site was built for one.
