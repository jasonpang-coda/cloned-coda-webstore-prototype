# Release Notes — v0.52.1

**Date:** August 2026
**Milestone:** Fixed a Vercel deploy failure affecting every interactive handoff site (`Cannot find module 'tailwindcss'`)

---

## Highlights

- **PostCSS/Tailwind Vercel deploy failure fixed** — every interactive VitePress handoff site was missing a local `postcss.config.js`, so PostCSS's config loader walked up to the repo-root config (which requires `tailwindcss`, a devDependency of the main prototype app). That resolves locally (the whole repo's `node_modules` is on disk) but fails on Vercel, where the Root Directory install only populates `node_modules` inside that site's own folder. `docs/Handoff/codm-sku-cards/` had already solved this with an empty override — backfilled the same fix into every other site, plus the kit template so no future site regresses.
- **Stale vendored tokens refreshed** — rebuilding each site to verify the fix also re-ran `sync-tokens`, which caught several sites' vendored token snapshots up to the current prototype (most notably `carousel-story-interaction`'s `codm.css`, which predated the surface-namespace refactor).

## Changes

### `docs/Handoff/_handoff-kit/template/postcss.config.js` (new)

- Empty PostCSS config, sourced from `codm-sku-cards`'s existing fix, so every future scaffolded site gets this by default.

### `docs/Handoff/{bestseller-card-effects,sku-cards,carousel-story-interaction,codm-signin-motion,gamer-id-instruction}/postcss.config.js` (new)

- Same empty override, backfilled into every existing interactive site that was missing it.

### Vendored token refresh

- `docs/Handoff/{carousel-story-interaction,codm-signin-motion,gamer-id-instruction,sku-cards}/vendor/tokens/*.css` — re-synced from `src/tokens/` via each site's own `npm run sync-tokens`, picking up token changes made since these sites were last built (including the `--motion-sku-enter` fix from v0.51.2 and the surface-namespace token refactor).
