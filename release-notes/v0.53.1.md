# Release Notes — v0.53.1

**Date:** August 2026
**Milestone:** New spec handoff + interactive VitePress demo site for the region/language selector sheets

---

## Highlights

- **`docs/Handoff/locale-selector-sheets/` spec handoff** — agent-executable spec for `RegionSelectorSheet.vue` and `LanguageSelectorSheet.vue` (both driven by `useLocale`). Documents all 19 §2 states across the two sheets, the full token contract (colour/typography/spacing/radius/size/effects/motion with resolved values), the region→language reset rule, and the RTL-visibility gate.
- **New interactive playground** — a single-frame live demo of both sheets against a small fixture dataset (8 markets / 8 languages, not the real 55/22 registry), wired to the real vendored token cascade. Includes a token sandbox (entrance/exit/hover duration + easing sliders), an enter/exit choreography timeline, and easing-curve viewers.
- **Discovered gap recorded, not silently fixed** — while building the demo, found that `LanguageSelectorSheet`'s own RTL-visibility gate makes an RTL active language unreachable through the real UI (it depends on the language already being RTL to show RTL rows at all). Recorded as assumption A3 in the spec rather than worked around; the playground previews the gated state behind a clearly-labelled demo-only toggle.
