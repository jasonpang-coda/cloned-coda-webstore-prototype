# Release Notes — v0.53.3

**Date:** August 2026
**Milestone:** Tokenized the Best Seller card's shimmer effect (duration, easing, opacity) instead of leaving it hardcoded

---

## Highlights

- **Shimmer sweep now reads the existing shimmer token.** `BestSellerCard`'s compact-variant gloss sweep hardcoded `animation-duration: 2954ms` and `animation-timing-function: linear` directly, instead of consuming `--motion-sku-shimmer` (aliases `--motion-shimmer-sweep`, `3000ms`) — the semantic token that already existed for exactly this role. Switched to `var(--motion-sku-shimmer)` / `var(--motion-sys-ease-linear)`. **Deliberate visual change:** the sweep is now 3000ms instead of 2954ms (+1.5%).
- **Shimmer opacity is now a real token.** `opacity: 0.25` was a bare literal on the pseudo-element; added `--fx-bestseller-shimmer-opacity` (`src/tokens/ds/extensions.css`) so it's no longer a magic number, with no change to the rendered value.
- **Corrected a stale doc entry that predates both the old and new values.** `docs/motion-tokens.md` separately claimed the shimmer was `4500ms` with a champagne colour override — matching neither the previous `2954ms`/white-metallic implementation nor the new `3000ms` one. Fixed to reflect the real values.

## Changes

### `src/components/BestSellerCard.vue`

- Compact shimmer's `animation-duration`/`animation-timing-function`/`opacity` now read `var(--motion-sku-shimmer)`, `var(--motion-sys-ease-linear)`, and `var(--fx-bestseller-shimmer-opacity)` respectively, replacing the hardcoded `2954ms`, `linear`, and `0.25`.

### `src/tokens/ds/extensions.css`

- Added `--fx-bestseller-shimmer-opacity: 0.25`, colocated with the shimmer's existing `--gradient-bestseller-metallic-shine` token.

### `docs/motion-tokens.md`

- Fixed the `--motion-sku-shimmer` entry and its `.fx-shimmer` usage note, both of which described a stale `4500ms`/champagne-colour variant that never matched the actual implementation.

### `docs/Handoff/bestseller-card-effects/README.md`

- §1.1/§3.7/§3.8/§4.3: updated to the new tokenized values; retired open question Q1 (was: is the `2954ms` hardcode deliberate or drift?) into the Resolved table.
- §9/`AGENTS.md`: removed the now-obsolete "don't fix the shimmer duration" caution.
