# Release Notes — v0.54.0

**Date:** August 2026
**Milestone:** FCM nav polish — bigger L3 tabs with a resting→selected transition, cleaner dropdown popover with interactive trigger states, and a compact mobile toolbar

---

## Highlights

- **L3 tab prominence** — internal-testing feedback called the flattened L3 nav (`fcmNavModel` = `flat`/`flat-bottom-s`) too small/subtle. Tabs are now wider (72px min-width, up from an effectively-broken 64px — see bug fix below) with larger labels, applied uniformly to both the top-docked row and the bottom-docked bar.
- **Resting→selected transition** — the gradient fill now fades in instead of snapping on, and the accent-stroke indicator visibly **grows** from the edge the user scrolled in from (left when scrolling down, right when scrolling up), via a new small scroll-direction detector. The bottom-docked bar gets the same growing stroke on its top edge.
- **Bug fix**: `--size-control-xl` was referenced by the original L2/L3 tab min-width rule but never aliased in `space.css` — the rule has silently been a no-op (`auto`) since it was written. Fixed, plus a new `--size-control-xxl` one step up for the L3 bump.
- **Cleaner dropdown popover** — removed the visible parent-category label above each group of subcategories in the `'dropdown'` nav variant (read as clutter); a divider is now the only separation between groups, with `group.label` still reaching assistive tech via `aria-label`.
- **Dropdown trigger interaction states** — added hover, keyboard-focus, and pressed/active states to the dropdown trigger button (previously had none). Hover and focus-visible both reuse the same `--surface-frost-hover` wash the panel's own option rows already use; pressed adds a subtle scale via a new generic `--motion-control-press-scale` token.
- **Compact mobile toolbar** — on a real touch device, the dev toolbar now hides its library/inspector/screenshot icons and collapses the store + feature-flag selects into a single horizontally-scrollable row instead of wrapping into several stacked rows, so switching `fcmNavModel`'s variant takes one swipe + one tap. Desktop is unaffected.

## Changes

### `src/tokens/ds/space.css`

- Added missing `--size-control-xl` alias (`--sys-size-control-xl`, 64px) and new `--size-control-xxl` (`--sys-size-control-xxl`, 72px).

### `src/tokens/motion.css`

- New `--motion-control-press-scale: 0.98` — the non-SKU-scoped equivalent of `--motion-sku-press-scale`, for plain controls like the dropdown trigger.

### `src/components/CategoryNav.vue`

- `level` class no longer requires `variant === 'row'`; new `cat-nav--bottom` class.
- New `.cat-nav--l3` rules (min-width, padding, font-size) apply to both the row and bottom-docked variants.
- Gradient fill moved to an always-present `::before` layer with an opacity transition; label promoted to `z-index: 1` to stay above it.
- Accent-stroke `::after` rewritten to always render and grow via `transform: scaleX()` from a `--tab-grow-origin` custom property; new local scroll-direction listener (mirrors `NavBar.vue`'s private pattern) sets it per activation.
- Bottom-docked L3's plain `border-top-color` re-sourced through `--border-nav-selected` so it doesn't double up with the new gradient stroke.

### `src/App.vue`

- `flat-bottom-s`'s bottom-docked `CategoryNav` mount gains `level="l3"`.

### `src/components/FilterDropdown.vue`

- Removed the `.filter-dropdown__group-label` element and its CSS (grouped popover no longer shows a visible parent-category label; `aria-label` on the group `<div>` is unchanged).
- Trigger button gained `:hover`/`:focus-visible` (`--surface-frost-hover`) and `:active` (same background + `--motion-control-press-scale`) states.

### `src/components/DeviceToolbar.vue`

- Dev-icon segment (library/inspector/screenshot) hidden on mobile (`!isMobile`).
- New `.toolbar__body-inner--compact` class (bound when `isMobile`) switches the control row to horizontal-scroll with hidden scrollbar and truncated (ellipsized) select labels.
- `.toolbar__version` moved out of the scrolling row so it stays visible regardless of scroll position.

### `docs/fcm-components.md`

- New section 7 documenting all of the above.
