# Release Notes — v0.55.0

**Date:** August 2026
**Milestone:** Background glow on selected SKU/Hero/Best Seller cards

---

## Highlights

- **Selected-state glow** — SKU cards, the Hero card, and the Best Seller card now emit a soft, brand-coloured glow when selected, reinforcing the existing border/background swap with a clearer "this is active" signal instead of relying on the border and fill change alone.
- **Fully token-driven, no new colour decision** — the glow reuses each store's existing `--hdr-glow` (already resolved per-theme and HDR-boosted), so it re-tints automatically across codm/fcm/efootball/etc. with zero per-store overrides needed.
- **Static, not animated** — the glow fades in on the existing `--motion-sku-select` transition token (no new duration introduced), consistent with selection reading as an instant, confident swap rather than a decorative cross-fade.

## Changes

### `src/tokens/ds/extensions.css`

- New `--fx-glow-selected: var(--hdr-glow)` — a dedicated alias so the selection glow can be retuned per store independently of the running-border effect (`--fx-border-glow`).
- New `--shadow-card-selected` and `--shadow-bestseller-selected` — each layers the card's existing resting shadow (`--shadow-card` / `--shadow-bestseller`) under a `0 0 24px 4px var(--fx-glow-selected)` bleed.

### `src/components/SkuCard.vue`

- `.sku-card--selected` now sets `box-shadow: var(--shadow-card-selected)`, transitioning `border-color`/`box-shadow` on `--motion-sku-select`.

### `src/components/HeroSkuCard.vue`

- `.hero-sku--selected` now sets `box-shadow: var(--shadow-card-selected)`, transitioning on `--motion-sku-select`.

### `src/components/BestSellerCard.vue`

- `.bestseller__card--selected` now sets `box-shadow: var(--shadow-bestseller-selected)`, transitioning on `--motion-sku-select`.
