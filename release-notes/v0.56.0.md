# Release Notes — v0.56.0

**Date:** August 2026
**Milestone:** FCM Buy Now pilot — sticky Buy Now bar → Order Summary / Select Payment sheet

---

## Highlights

- **New two-step FCM checkout flow, behind a flag** — tapping a non-gift SKU now docks a sticky, scrim-less **Buy Now bar** at the bottom of the screen instead of opening the shared payment sheet directly. Signed-out shows an EA-red **SIGN IN** CTA; signed-in shows a green **BUY NOW** CTA that promotes into a new full **Order Summary** sheet. Gated by the `fcmPaymentSheet` feature flag (FCM only, off by default) — every other store's `CheckoutSheet` is untouched.
- **Collapsible Order Summary + priced payment grid** — the new sheet's Order Summary accordion auto-collapses once the payment list scrolls; each payment card shows its own price (regional e-wallets can carry a proportional surcharge), and the footer CTA stays disabled ("SELECT PAYMENT") until a channel is chosen, then reads "CHECKOUT · <price>".
- **Selected payment channel persists** — closing the sheet and tapping a different SKU keeps the previously chosen channel pre-selected (matches the Figma "returning user" state), since channels are a single store-wide list rather than per-item.
- **Real payment-channel logos** — 10 regional brand logos (Truemoney, PromptPay, K PLUS, DTAC, Bank Transfer, AIS, Card Payment, 7-Eleven, ShopeePay, Rabbit LINE Pay) cropped directly from the Figma design and registered alongside the existing shared PC logo family.
- **Incidental fix** — `SkuImageCard.vue`'s `onSelect()` never passed its `title` prop into `openCheckout()`, so prod-variant bundle/gift cards with no numeric `amount` (e.g. TWG campaign packs) showed a blank product name in the payment sheet's summary. Fixed for `CheckoutSheet` and both new components at once.

## Changes

### `src/composables/useFeatureFlags.js`

- New boolean flag `fcmPaymentSheet` (FCM-scoped, default `false`).

### `src/composables/useCheckout.js`

- New `buyNowVisible` / `selectedChannel` refs and `openPaymentSheet()` / `dismissBuyNow()` functions.
- `openCheckout()` now branches on `usesBuyNowBar()` (flag on + not inline mode): docks the bar instead of opening the sheet, and skips the sign-in/guest-verified gate entirely (the bar's own CTA is the gate).
- `selectedChannel` is intentionally **not** reset when a different SKU is tapped, so a previously chosen channel carries over.
- `isItemSelected()` gates on `buyNowVisible` in the Buy Now presentation, so a SKU card reads selected as soon as the bar docks.

### `src/components/BuyNowBar.vue` *(new)*

- Docked sticky bar (Figma 2867:9216 signed-in / 2542:3187 signed-out). No scrim — the storefront stays visible/scrollable behind it.
- Signed-out: item label + price, red `--bg-action-signin` SIGN IN pill (EA logomark), soft rewards line.
- Signed-in: item label (+ chosen channel once picked) + price, green `fx-shimmer` BUY NOW pill, rewards line with the loyalty icon, "View Buy Now Terms & Conditions" link.
- Hidden while the EA Account / KONAMI ID sign-in overlay is open (`eaSignInOpen` / `konamiSignInOpen`).
- Content crossfades (`buynow-content`, keyed on signed-in state + item + price + channel) instead of snapping on any change.

### `src/components/OrderSummarySheet.vue` *(new)*

- Full "Order Summary / Select Payment Method" sheet (Figma 3376:28471 default / 3376:29877 selected), promoted into via `BuyNowBar`'s BUY NOW. Shell copied from `CheckoutSheet.vue`.
- Order Summary accordion: SKU thumb + name + subtitle + Total, expands to Account / item / Tax / Total rows (mock price split — no real tax data). Auto-collapses once the payment list scrolls past a small threshold.
- Payment grid: `config.checkout.channels`, 2-col wrap, each card shows its own price; selected card gets the green fill + ring.
- Footer CTA disabled until a channel is picked, then reads `<actionLabel> · <price>`.
- Panel height `95%` of the overlay (was the shared sheet's `85%`).

### `src/stores/fcm/store.js`

- New `config.checkout.channels` — 14 payment-channel entries (10 from the Figma design + 4 generic ones, to demonstrate list overflow). `feePercent: 5` on ShopeePay/Rabbit LINE Pay/Cash App applies a proportional surcharge to whatever SKU is selected, instead of a flat literal price.

### `src/shared/pc/light/*.png` *(new)*

- 10 regional payment-channel logos, cropped from the Figma PC-card renders (72×24 @1x).

### `src/composables/useStoreAssets.js`

- Registered the 10 new logos in the `PC.light` map.

### `src/locale/commonStrings.js`

- New `checkout.buyNow`, `checkout.buyNowTerms`, `checkout.selectPaymentCta`, `checkout.accountLabel`, `checkout.tax`, `checkout.total` — added across all 9 locales.

### `src/components/SkuImageCard.vue`

- `onSelect()` now passes `label: props.title || null` into `openCheckout()`, fixing a blank product name for prod-variant bundle/gift cards.

### `src/App.vue`

- `#overlay` slot now mounts `BuyNowBar` + `OrderSummarySheet` instead of `CheckoutSheet` when `fcmPaymentSheet` is enabled (and `config.checkout.mode !== 'inline'`); `CheckoutSheet` renders unchanged otherwise.

### `docs/component-breakdown.md`

- Documented the overlay stack change and both new components; changelog footer updated with the above.
