# Release Notes — v0.56.1

**Date:** August 2026
**Milestone:** FCM Buy Now pilot — polish pass

---

## Highlights

- **Flag on by default** — `fcmPaymentSheet` now defaults to enabled for FCM (was off), so the Buy Now flow is live without a manual toggle.
- **Sheet copy/style cleanup** — the "Select Payment Method" heading reads larger, the checkout CTA no longer repeats the price (each payment card already shows its own), the Order Summary accordion's item row now reads "Item Price" instead of repeating the SKU title, and "Account" was renamed to "Player Nickname" for clarity.

## Changes

### `src/composables/useFeatureFlags.js`

- `fcmPaymentSheet` default changed from `false` → `true`.

### `src/components/OrderSummarySheet.vue`

- `.sheet__pc-heading` ("Select Payment Method") text style bumped from `.text-style-utility-micro-regular` (10px) → `.text-style-utility-label-regular` (12px).
- `checkoutLabel` no longer appends `· <price>` — reads the plain `strings.checkout.actionLabel` once a channel is chosen.
- Accordion item row's label switched from `summaryLabel` (the SKU title) to the new `common.checkout.itemPrice` string.

### `src/locale/commonStrings.js`

- New `checkout.itemPrice` ("Item Price") added across all 9 locales.
- `checkout.accountLabel` renamed from "Account" → "Player Nickname" (and equivalent translations) across all 9 locales.

### `docs/component-breakdown.md`

- Changelog footer updated with the above.
