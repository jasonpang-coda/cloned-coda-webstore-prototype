# Release Notes — v0.56.2

**Date:** August 2026
**Milestone:** FCM Buy Now pilot — two small fixes

---

## Highlights

- **Chevron actually animates now** — `OrderSummarySheet`'s accordion chevron was swapping between two different `expand_more`/`expand_less` icons on toggle, which can't animate (they're separate SVGs). It now rotates a single icon in place on `--motion-toggle` — the same token `ResellerBanner`'s legal-disclaimer chevron and `FilterDropdown`'s category-nav chevron already use for the same interaction.
- **Correct hyperlink colour** — `BuyNowBar`'s "View Buy Now Terms & Conditions" link was using `--text-hyperlink-inverse`; switched to `--text-hyperlink-default`, matching every other hyperlink-styled element in the codebase (`CheckoutSheet`'s "Item Info" link, `ItemSummarySheet`'s sign-in link).

## Changes

### `src/components/OrderSummarySheet.vue`

- Chevron `<MaterialIcon>` now always renders `expand_more`, toggling an `.is-open` class instead of swapping `:name`.
- `.osum__chevron` gained `transition: transform var(--motion-toggle)`; `.osum__chevron.is-open { transform: rotate(180deg) }`.

### `src/components/BuyNowBar.vue`

- `.buynow__terms` colour changed from `var(--text-hyperlink-inverse)` → `var(--text-hyperlink-default)`.

### `docs/component-breakdown.md`

- Changelog footer updated with the above.
