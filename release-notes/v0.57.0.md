# Release Notes — v0.57.0

**Date:** August 2026
**Milestone:** `@coda/track-kit` — session click/scroll tracking for user testing

---

## Highlights

- **New package: `@coda/track-kit`.** A Hotjar-style session recorder for moderated and unmoderated usability testing — clicks, scroll depth, rage-clicks, dead-clicks, and SPA navigation, persisted to Supabase, with an in-app heatmap/replay/scroll-depth viewer. Built framework-agnostic from the start (a Lit Web Component viewer + a framework-free capture core, with Vue and React adapters), in the same mold as the existing `@coda/comment-kit` — sits beside it in `packages/track-kit`, reuses its patterns, and is dogfooded here before extraction to a standalone repo.
- **Reuses the existing Supabase project.** No new env vars or backend setup — `test_sessions`/`test_events` (with cascade-delete + RLS) live in the same project as `comments`, isolated the same way (`store` × `deployment_scope`).
- **The viewer overlay scrolls natively with the page.** The first pass used a `position:fixed` panel repositioned via `getBoundingClientRect()` on a `window` scroll listener — which goes stale the moment the target container scrolls *internally* (like this repo's `.device__screen`). Fixed by adopting comment-kit's pin technique: a real light-DOM child of the container itself, so the browser's own compositor moves it — zero JS, zero lag.
- **Scroll-depth funnel with a true gradient.** A canvas `createLinearGradient` (not discrete colored bands) blends red (most sessions reached here) to blue (fewest) continuously, with opacity scaling by reach so low-traffic sections fade rather than reading as flat color. Dashed checkpoints mark 100/75/50/25/0% depth; a distinct solid marker calls out the *actual* drop-off point — one past the deepest any single session reached.
- **On by default for deployed contexts, off on localhost.** A facilitator running a local test opts in via `?testmode=moderated`/`?testmode=unmoderated`, or the `/` console's "Resume session tracking" command.
- **Retention:** only the latest 30 sessions per store × deployment scope are kept (free-tier Supabase), pruned automatically after each new session starts.

## Changes

### `packages/track-kit/` (new package)

- Framework-free core: `config.js` (options singleton), `core/supabase.js` (lazy client, `null` = localStorage-only fallback), `core/anchor.js` (`captureAnchor`/`capturePoint`, adapted from comment-kit's anchor math), `core/session.js` (device/session identity, heartbeat, retention pruning), `core/recorder.js` (capture engine — clicks, scroll, rage/dead-click detection, `history` API patching for nav events, batched flush).
- `core/store.js` — read side for the viewer: session list, replay steps (click/rage/dead/nav, scroll excluded), rage/dead badge counts per session, heatmap point aggregation, scroll-depth bucketing (fine-grained gradient stops + exact 100/75/50/25/0% checkpoints + the data-derived drop-off marker).
- `elements/overlay.js` — `OverlayManager`, the light-DOM technique that makes the heatmap/replay/scroll-depth visuals scroll natively; injects its own stylesheet (including an explicit high `z-index`, required because a `transform`-based carousel or similar can otherwise paint above a `z-index:auto` sibling regardless of DOM order).
- `elements/heatmap-layer.js` — `<track-kit-heatmap>` (Lit), the four-tab viewer panel (Sessions/Replay/Heatmap/Scroll Depth).
- `src/{index,vue,react}.js` — vanilla entry (`createTracker`, zero-JS-framework auto-init via `data-track-*` script attributes), Vue plugin (`createTracking`/`useTracking`, with a small reactive bridge for `recording`/`viewerOpen`), React hook.
- `sql/tracking.sql`, `README.md`, `examples/plain.html` (no-framework proof).

### `src/main.js`

- `.use(createTracking({...}))` alongside the existing `createComments(...)` — same `ANCHOR_CONTAINERS` list (hoisted out of the comment-kit block so both plugins share it), same Supabase env. `enabled` is on for any deployed context, off on localhost/local dev unless `?testmode=` is present.

### `src/components/CommandConsole.vue`

- Four new `tracking:*` commands (show/hide viewer, jump to Heatmap/Scroll Depth tab, pause/resume recording), mirroring the existing `comments:*` block.

### `src/components/DeviceToolbar.vue`

- New toolbar button (`query_stats` icon) toggling the tracker viewer.

### `src/components/MaterialIcon.vue`

- New `round/query_stats` icon registered.

### `docs/`
