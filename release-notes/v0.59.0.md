# Release Notes — v0.59.0

**Date:** August 2026
**Milestone:** FCM SKU info bottom sheet — a modified `ItemSummarySheet` triggered by a new `(i)` icon, with a seamless handoff into `OrderSummarySheet`

---

## Highlights

- **FCM's own info sheet, zero duplicate components.** COD:M's bundle-breakdown
  `ItemSummarySheet` gained a `config.itemSummary` capability block
  (`titleFromItem`, `showProduct: false`, `footer: 'buyNow'`, `compactAccordion`)
  instead of a second sheet component — every opt-in defaults off, so COD:M's
  sheet is unchanged.
- **New trigger: an `(i)` icon on the card title, not a card tap.** A new
  outline-style `MaterialIcon` (`outlined/info`) renders in hyperlink colour at
  the end of a SKU/bundle card's title, gated on a new `infoItems` prop.
  Tapping the card itself still docks `BuyNowBar` as before.
- **Eligibility is data-driven.** Every FCM catalogue item now carries an
  `infoItems` field except the whole Top Ups category (FC Points, 2x FC
  Points, Silver) — those have nothing to "receive" beyond the currency
  itself. Campaign Packs list their real contents; standalone SKUs (Daily
  Boosters, Daily FP Deals, Star Pass, Special Offers) get a single summary
  row.
- **Seamless Buy Now handoff.** Tapping BUY NOW inside the info sheet now
  reuses the exact height-morph + content-cross-fade choreography already
  proven by the COD:M `ItemSummarySheet → CheckoutSheet` handoff
  (`useSheetTransition`'s `handoffHeight`/`isHandoffExit`) — the panel grows
  and its content cross-fades in place, instead of two independent sheets
  sliding/fading past each other.
- **Two small naming/spacing fixes**, both surfaced from testing: the six
  Daily FP Deals SKUs' info row now reads "\<amount\> FC Points" (was "\<amount\>
  FC Bundle" — the card/header keep the deal's own name); the compact sheet's
  header→body gap is now `--pad-surface-l` (was the implicit
  `--pad-surface-m`).

## Changes

### `src/stores/fcm/store.js`

- New `config.itemSummary` capability block: `{ titleFromItem: true,
  showProduct: false, footer: 'buyNow', compactAccordion: true }`.

### `src/stores/fcm/catalog.js`

- Every eligible catalogue item (everything except Top Ups) now builds an
  `infoItems` array — `bundleInfoItems()` for Campaign Packs (player item +
  draft vouchers, real display names), `singleInfoItem()` for standalone SKUs
  (one row from the SKU's own art + name). Top Ups items get `infoItems:
  null`.
- New `INFO_ITEM_CURRENCY_OVERRIDES` map swaps the six Daily FP Deals stems'
  info-row label from "FC Bundle" to "FC Points" — scoped to the accordion
  row only, not the stem-derived `currencyLabel` used on the card face/header.
- `featured` carousel entries (Daily Booster D, TWG Pack, Star Pass ticket)
  also carry `infoItems`.

### `src/components/MaterialIcon.vue`

- Added `outlined/info` (`@material-design-icons/svg/outlined/info.svg`) —
  the stroke/outline glyph, alongside the existing solid `round/info`.

### `src/components/SkuImageCard.vue` / `BundleSkuCard.vue`

- New `infoItems` prop (`null` default → no icon rendered). When set, an
  `(i)` button (`variant="outlined"`, `--text-hyperlink-default`) appends to
  the card's title; its `onInfo()` handler stops propagation and calls
  `openItemSummary(...)` with the tapped SKU's fields.

### `src/components/CategoryCatalog.vue`

- Wires `:info-items="item.infoItems ?? null"` into `SkuImageCard` (both the
  bundle→prod branch and the plain sku-variant branch). `BundleSkuCard`
  already receives it via its existing `v-bind="item"` spread.

### `src/components/ItemSummarySheet.vue`

- Header, product block, accordion, and footer each gained a `config.itemSummary`-gated
  branch (see Highlights). New `onBuyNowFcm()` hands off to `OrderSummarySheet`
  via `openCheckout()` + `openPaymentSheet()`, and now mirrors `onBuyNow()`'s
  handoff-capture (`handoffHeight`, `isHandoffExit`) so the transition below
  actually fires.
- `.sheet--compact .sheet__body` gets `padding-top: var(--pad-surface-l)` for
  a looser header→body gap on the FCM variant only.

### `src/components/OrderSummarySheet.vue`

- Added `panelRef`, the `onSheetBeforeEnter`/`onSheetEnter`/`onSheetAfterEnter`
  handoff hooks, and the `.sheet--handoff-enter` CSS override — copied
  directly from `CheckoutSheet.vue`'s own handoff-enter implementation. No
  effect on this sheet's default (non-handoff) entrance.

### `src/components/ItemSummaryAccordion.vue`

- New `compact` prop hides the rarity-tinted thumb (text + chevron only) —
  additive, COD:M's default (`compact: false`) is unchanged.

## New additions

- `outlined/info` Material icon.
- `config.itemSummary` capability block (FCM store module).
- `infoItems` data field across the FCM catalogue.
