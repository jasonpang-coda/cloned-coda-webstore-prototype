# Release Notes — v0.59.1

**Date:** August 2026
**Milestone:** FCM Buy Now — sign-in now advances straight to payment selection, plus a compact-sheet height tweak

---

## Highlights

- **Sign in → straight to payment.** Completing EA sign-in from either the
  docked `BuyNowBar`'s SIGN IN button or the `ItemSummarySheet` info sheet's
  SIGN IN button (the FCM `footer: 'buyNow'` variant) now lands the user
  directly in `OrderSummarySheet` (payment/channel selection) — previously
  the bar path left the user back on the bar (had to tap BUY NOW again), and
  the info-sheet path reopened the info sheet itself.
- **One shared mechanism, mirroring an existing pattern.** A new
  `pendingBuyNowSignIn` flag + `watch(signedIn, ...)` in `useCheckout.js`
  follows the same protocol `useGiftClaim`'s `pendingEaGift` already uses
  (including the ~200ms delay to let the EA sign-in overlay's leave
  transition finish) — no new composable, no new pattern.
- **Compact info sheet grows a bit more room on small screens.** The
  `max-height` cap for S and smaller screens (< 801px) is now 95% (was 85%);
  the M+ responsive-modal cap (`80vh`) is unchanged.

## Changes

### `src/composables/useCheckout.js`

- New `pendingBuyNowSignIn` ref, exported from `useCheckout()`.
- New `watch(signedIn, ...)`: when sign-in completes and the flag is set,
  clears it and calls `openPaymentSheet()` after a 200ms delay (same timing
  rationale as `useGiftClaim.js`'s `pendingEaGift` watcher).

### `src/components/BuyNowBar.vue`

- `onSignIn()` now sets `pendingBuyNowSignIn.value = true` before redirecting
  to EA sign-in.

### `src/components/ItemSummarySheet.vue`

- New shared `fcmCheckoutArgs(b)` helper (extracted from `onBuyNowFcm()`) —
  builds the `openCheckout()` payload from the selected bundle.
- `onSignIn()`'s FCM branch (`config.itemSummary.footer === 'buyNow'`) now
  calls `openCheckout(...fcmCheckoutArgs(b))` and sets `pendingBuyNowSignIn`
  *before* handing off to sign-in, instead of `savePendingReturn()` (which
  reopened the info sheet on return). COD:M's own sign-in path (still
  `savePendingReturn()` + reopen) is unchanged.
- `.sheet--compact .sheet__panel`'s `max-height` raised from 85% to 95%.
