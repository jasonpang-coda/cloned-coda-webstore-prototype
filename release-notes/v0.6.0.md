# CODM SKU Card 3.0 — v0.6.0

**Horizontal row SKU cards · global ripple · bonus OKLCH · responsive drawer fix · focus token** · June 2026

Polish and interaction-system release: a new card orientation for the stacked-vs-columns layout demo, a project-wide click ripple directive, OKLCH bonus colours with HDR headroom, and several targeted bug fixes.

---

## What's new

### Horizontal row layout for SKU cards (`SkuCard.vue`, `SkuList.vue`)
Cards in the `columns` layout section now use a **horizontal row** arrangement — product info (tag, amount, bonus, AP) on the left, price stack (strikethrough + discount % + final price) pinned to the right — matching the Figma layout for horizontal card items.

Driven by a new `layout` prop on `SkuCard` (`'default'` column / `'row'` horizontal). `SkuList` passes `layout="row"` to every card when its own `layout === 'columns'`. CSS: a `.sku-card__left` wrapper uses `display: contents` in default mode (transparent passthrough, zero layout impact) and becomes a `flex-direction: column; flex: 1` left column in row mode. The price block drops `margin-top: auto` and right-aligns instead. Empty badge slots (`isBestValue: false`) are hidden in row mode via `.sku-card--row .sku-card__badge-slot:empty { display: none }` — no reserved height gap.

### Global click-point ripple (`src/directives/vRipple.js`, `src/main.js`)
A new `v-ripple` Vue directive adds the `.fx-ripple` class (already in `effects.css`) and attaches a `pointerdown` handler that spawns a `.fx-ripple__wave` span centred on the tap/click point. Wave diameter = `2 × max(offsetWidth, offsetHeight)`, which at `scale(2.5)` guarantees full coverage from any corner. Teardown reads `getComputedStyle(wave).animationDuration` so cleanup timing is always in sync with `--motion-ripple`.

Applied to every interactive surface: **NavBar** (hamburger, sign-in, avatar), **NavDrawer** (close, L1 accordion btns, L2 sub-items, flat L1 items, sign-in, sign-out), **CategoryNav** (tab buttons), **CheckoutSheet** (close, PC channel cards, CHECK OUT CTA), **PlayerAccount** (chip tabs, "View image instructions" link), **SkuCard** and **BundleSkuCard** (the card divs).

Project-wide ripple colour set to `rgba(255, 255, 255, 0.14)` in `style.css :root` (overrides the effects.css fallback of 0.5 which was too bright). The yellow CHECK OUT CTA overrides locally with `--fx-ripple-color: rgba(0, 0, 0, 0.15)` (dark ripple on yellow). SkuCard wave z-index is `1` (above background glow, below content and gradient ring).

**Bug fix:** wave `<span>` receives `position: absolute; pointer-events: none` as inline styles in the directive (not relying solely on the CSS rule) — prevents a one-frame flash where the span participates as a flex item in column-flex containers (repro: PC channel cards in CheckoutSheet grew tall on click).

### Bonus text OKLCH tokens with HDR boost (`src/style.css`)
Both bonus colour tokens are now OKLCH with a **+0.04 L luminance boost** over their sRGB baselines, stored as named design tokens:

| Token | SDR | sRGB baseline |
|---|---|---|
| `--text-web-bonus-codashop` | `oklch(0.78 0.155 297)` | `#b493ff` ≈ `oklch(0.74 …)` |
| `--text-web-bonus-cp` | `oklch(0.78 0.135 260)` | `#77aaff` ≈ `oklch(0.74 …)` |

HDR variants added to the existing `@media (dynamic-range: high)` block: `oklch(0.85 0.17 297)` and `oklch(0.85 0.15 260)` — genuinely luminous purple/blue on P3/wide-gamut panels.

### `--border-input-focus` design token (`src/style.css`)
New border token `--border-input-focus: oklch(0.91 0.191 97)` — the same perceptual yellow as `--text-hyperlink-inverse`. The PlayerAccount input's `:focus` rule now references this token (was `--border-soft-3`, a dim white hairline). The loading/spinner state also uses it for consistency. Establishes a single source of truth for the yellow focus ring, reusable by any future input.

### SkuList grid: 2 → 4 columns (`SkuList.vue`)
`.sku-list__grid` changed from `display: flex; flex-wrap: wrap` to an explicit **CSS grid**: 2 columns on XS (`< 641px` container), 4 columns at S/M/L (`@container (min-width: 641px)`). Caps the maximum cards per row at 4 on wider screens. The `--columns` modifier (1 → 2 col stacked demo) is defined after the base grid rules so cascade order guarantees it always wins.

### NavDrawer viewport fix (`DeviceFrame.vue`, `App.vue`)
In responsive (no-frame) mode the drawer panel previously extended to the full page height rather than the visible viewport. Fix: `App.vue` measures the DeviceToolbar height on mount via a `ref` + `offsetHeight` and writes it to `--toolbar-h` on `:root`. `DeviceFrame.vue` switches `.device__overlay--responsive` from `position: absolute; inset: 0` to `position: fixed; top: var(--toolbar-h, 0px); right: 0; bottom: 0; left: 0`. No ancestor `transform` exists in responsive mode, so `fixed` correctly resolves to the viewport — the drawer scrim and panel are now bounded to the area below the toolbar.

## Bug fixes

- **Empty badge reserved space in row cards** — `.sku-card--row .sku-card__badge-slot:empty { display: none }` collapses the 16px slot; cards without a "Best Value" badge no longer have a gap above the title in horizontal layout.
- **Bottom section divider** — the `section--divided` class (top border hairline) removed from the new final columns section; it's the last section on the page.
- **PC card ripple height jump** — fixed (see ripple section above).
