# Release Notes — v0.60.0

**Date:** August 2026
**Milestone:** Codashop aggregator homepage — a title-listing surface with a standard/cinematic layout toggle

---

## Highlights

- **Codashop's storefront is now a homepage.** Instead of booting straight
  into the scaffold MLBB product page, Codashop's store now boots into a
  title-listing aggregator homepage (`config.home` capability) — hero
  carousel, trending-titles grid with filter tabs, shop-by-category,
  picked-for-you rail, trust stats, how-it-works, reviews, payments, FAQ,
  and newsletter. Reached by tapping the navbar wordmark (now a real button,
  Codashop-only — every other store's logo stays a plain, non-interactive
  `<img>`); left via a "Back to Codashop" control on the product page.
- **Two layouts, one feature flag.** A new `homepageLayout` enum flag
  (`useFeatureFlags.js`, Codashop-only, `stores: ['codashop']` +
  `requiresCapability: config.home`) switches between:
  - **Standard** — full editorial parity with the PM's mock.
  - **Visual** — a cinematic reinterpretation: a scroll-reactive canvas
    particle background, scroll-triggered reveal choreography, a scroll-
    linked "bloom in" effect for the Picked-for-You grid, a rotating 3D
    depth stack for reviews (click/swipe to advance, 10s autoplay), and a
    frosted-glass surface treatment across every card.
  Both layouts render from the **same** data/copy — they differ only in
  presentation and motion.
- **Real reference art, not placeholders.** 76 files under
  `src/stores/codashop/img/ref/` — square title tiles, landscape hero
  banners, how-it-works icons, social icons, and a new Codashop logo — cover
  ~50 titles across four categories (Popular & Direct Top-Up, Entertainment
  & Social, PC & Console, Gift Cards & Vouchers). Only Mobile Legends has a
  full product page in this prototype; every title card routes there as the
  representative "title detail" view.

## Changes

### New — `src/components/home/`

- **`HomeView.vue`** — orchestrator: reads the store's homepage data once,
  shapes it into a shared prop contract, and renders `HomeStandard` or
  `HomeVisual` via `<component :is>` on the flag's value. Owns the one piece
  of shared interactive state (the trending-titles filter tab).
- **`HomeStandard.vue` / `HomeVisual.vue`** — the two layout shells.
- **Leaf components** — `TitleCard`/`TitleGrid`/`TitleRail` (title tiles,
  cursor-tracked 3D parallax on `TitleCard` with per-layer depth — badge/
  title elevate more than the image), `FilterTabs`, `HomePromoTiles`,
  `HomeCategoryCards`, `HomeStatBand`/`HomeStatItem` (giant glowing count-up
  numbers), `HomeSteps`, `HomeReviewStack` (rotating 3D depth stack, click/
  swipe/autoplay) + `HomeReviewRail` (Standard's horizontal drag-rail),
  `HomePayments` (fixed coral→magenta panel + ambient bloom glow),
  `HomeFaq`, `HomeNewsletter`, `HomeParticles` (Visual-only canvas
  background).

### New composables

- **`useStoreHome.js`** — per-store homepage data accessor, mirrors
  `useStoreCatalog.js`'s registry pattern.
- **`useReveal.js`** — IntersectionObserver-driven scroll-reveal for
  section/card entrances (staggered via `--reveal-index`).
- **`useScrollBloom.js`** — scroll-linked (not reveal-once) "bloom in"
  progress per tile; recomputes from `getBoundingClientRect()` on scroll
  rather than `animation-timeline: view()`, since that CSS API doesn't
  reliably span this app's two device-frame scroll contexts (framed vs.
  Responsive). Reverses smoothly on scroll-up.
- **`useScrollParticles.js`** — canvas particle field reacting to scroll
  velocity (drift speed/streak), rAF-driven, DPR-aware, hard-gated on
  `prefers-reduced-motion`.

### `src/components/NavBar.vue`

- Wordmark becomes a real `<button>` emitting a new `home` event, but only
  when `config.home` is truthy — every other store's logo is unchanged.

### `src/App.vue`

- New `homeView` ref + `showHomeView`/`homeLayout` computeds; `<HomeView>`
  renders in place of the storefront when `showHomeView` is true (mirrors
  the existing `historyOpen`/`libraryActive` view-switch pattern). A "Back
  to Codashop" control appears on the product page when `config.home` is
  set. Category-nav overlays are suppressed on the homepage. Footer's
  action band (Need Help/Region/Cookie/social) gets an inverse-text override
  scoped to Codashop, since it sits directly on the dark page there instead
  of the dark chrome every other (dark-theme) store gives it for free.

### `src/composables/useFeatureFlags.js`

- New `homepageLayout` enum flag definition.

### `src/stores/codashop/store.js`

- New `config.home`, `strings.home` (all homepage copy), a top-level `home`
  field (the title catalogue, grouped by category), and `assets.home`
  (social icons) — plus the real reference-art imports and the new logo
  pointed at from `assets.brand`.

### `src/tokens/ds/themes/codashop.css`

- Four new Codashop-only tokens, each composed from palette steps rather
  than a raw literal in a component: `--gradient-home-ribbon`,
  `--gradient-home-tile-scrim`, `--gradient-home-payments`,
  `--glow-home-payments`.

### `src/components/MaterialIcon.vue`

- Added the plain `star` icon (the previously-used `stars` icon is a star
  *inside a circle badge* — wrong for a 5-star rating row).
