# Release Notes — v0.60.1

**Date:** August 2026
**Milestone:** Codashop homepage — bug fixes and polish pass on v0.60.0

---

## Highlights

- **Fixed a broken filter-tab horizontal scroll**, root-caused to two
  separate issues:
  - `App.vue`'s `isSplit` (which puts nested `Grid`/`Span` into "bare" mode,
    stripping their max-width/centring) stayed `true` on Codashop's homepage
    because `config.page.layout === 'split'` is a leftover capability from
    the underlying MLBB product page, not the homepage — now gated with
    `&& !showHomeView.value`.
  - On touch devices specifically, `.filter-tabs` was missing
    `touch-action: pan-x`, so `.device__screen`'s own `touch-action: pan-y`
    claimed horizontal swipes before they ever reached the row's own
    `overflow-x: auto`.
- **Fixed a layout-snap in the review stack's rotation.** An earlier version
  toggled whichever card held the front slot back to `position: relative` so
  it could establish the container's height — but `position` isn't
  animatable, and the swap landed on the same card that was mid-transform.
  Every card is now permanently `position: absolute`; the container's height
  is measured once via `ResizeObserver` into `--stack-height` instead.
- **Homepage-only 3/4-max-width override** added to both `HomeStandard.vue`
  and `HomeVisual.vue` for M+ screens, scoped via `:deep()` so no other
  `Span` consumer in the app is affected.
- **`TitleCard` polish**: dropped the overlaid title name entirely — the art
  plus a hover-revealed "View Items" CTA now carry the tile — and removed
  the CSS `transition` from every cursor-parallax layer so tilt/lift track
  the pointer instantly instead of easing a beat behind it.
- **`HomeSteps` background hue progression.** After two rejected attempts (a
  guessed corner-ribbon accent, then a corner-fold hover accent — the actual
  effect referenced by the codepen this was patterned on, but still the
  wrong shape for this section), the three step cards now get a background
  hue progression instead: acid-green → coral → indigo, via new
  `--home-step-ink-1/2/3` and `--wash-home-step-1/2/3` tokens.

## Changes

### `src/App.vue`

- `isSplit` computed now also requires `!showHomeView.value`, so Codashop's
  homepage never inherits bare-grid mode from the product page's
  `config.page.layout: 'split'` capability.

### `src/components/home/FilterTabs.vue`

- Added `touch-action: pan-x` + `-webkit-overflow-scrolling: touch`.
- Added a hover ring (`box-shadow: inset ... var(--border-card-hover)`) on
  inactive tabs.

### `src/components/home/HomeReviewStack.vue`

- Every card is now permanently `position: absolute` — no card ever toggles
  back to normal flow.
- Container height reserved via a one-time `ResizeObserver` on the first
  card (`reserveHeight()`, watched for `props.reviews` changes too), written
  to `--stack-height`.
- Per-slot transform gained `scale(calc(1 - var(--slot) * 0.08))` alongside
  the existing `translateZ`/`translateY`, so the outgoing front card visibly
  shrinks as it recedes.

### `src/components/home/HomeStandard.vue` / `HomeVisual.vue`

- New `@container (min-width: 801px)` override capping `.ce-span--content`/
  `.ce-span--carousel` to a centred 75% width, scoped per-layout.
- `HomeVisual.vue`: removed `data-reveal` from the Picked-for-You section
  (it already has its own per-tile `scroll-bloom` entrance via `TitleGrid`;
  the section-level fade was competing with it).

### `src/components/home/TitleCard.vue`

- Removed the overlaid `.title-card__name` element entirely — `name` is now
  `alt`-text/click-payload only.
- Added a "View Items" CTA (`.title-card__visit`), hidden at rest, revealed
  on hover as the nearest (highest `translateZ`) parallax layer.
- Removed the `transition: transform` from every parallax layer (thumb,
  image, ribbon/instant badges) — tilt and lift now track the pointer
  instantly; roughly doubled every layer's depth/shift multiplier.
- Every floating layer (ribbon, instant badge, CTA) gained its own
  `box-shadow: var(--shadow-card)`.

### `src/components/home/HomeSteps.vue`

- Removed a guessed corner-ribbon hover effect and its follow-up corner-fold
  hover effect (both reverted as the wrong shape for this section).
- Each of the three step cards now layers a flat-colour wash
  (`--wash-home-step-1/2/3`) over the shared `--home-surface-bg`, and the
  step icon's mask colour matches the same per-step ink.

### `src/tokens/ds/themes/codashop.css`

- New tokens: `--home-step-ink-1/2/3`, `--tint-home-fold-1/2/3`,
  `--wash-home-step-1/2/3` — all composed from palette steps, never a raw
  literal in a component.

## Verification

- `node_modules/.bin/vite build` passes clean.
- Token-discipline grep clean across every touched file in
  `src/components/home/`.
- Manual verification (dev server): filter-tabs scroll on both touch and
  M/L pointer input; review stack rotates without a layout snap; homepage
  Span width cap holds at M+; `HomeSteps` hue progression and no leftover
  hover accent.
