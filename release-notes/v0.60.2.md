# Release Notes — v0.60.2

**Date:** August 2026
**Milestone:** Codashop homepage now defaults to the cinematic (Visual) layout

---

## Highlights

- **Visual is now the default homepage layout.** The `homepageLayout` feature
  flag (`useFeatureFlags.js`, Codashop-only) previously defaulted to
  `'standard'`; it now defaults to `'visual'`, so the cinematic layout —
  scroll-reactive particles, scroll-linked reveal/bloom, the rotating 3D
  review stack, frosted-glass cards — is what stakeholders see out of the
  box. `'standard'` (full editorial parity with the PM's mock) is still
  available as a flag option, unchanged.

## Changes

### `src/composables/useFeatureFlags.js`

- `homepageLayout` flag's `default` changed from `'standard'` to `'visual'`.

## Verification

- `node_modules/.bin/vite build` passes clean.
- No other files touched — a single default-value flip.
