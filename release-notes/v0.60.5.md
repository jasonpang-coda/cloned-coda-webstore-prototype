# Release Notes — v0.60.5

**Date:** August 2026
**Milestone:** Transition for the L2/L3 nav surface mounting/unmounting on L1 intent switch

---

## Highlights

- **CatalogNavStack (L2/L3) now animates in/out instead of popping.** In the
  FCM multi-level navigation pilot, switching L1 intents (Store ↔ Milestone
  Rewards/Events) mounts or unmounts the L2/L3 category nav surface via
  `isStoreIntentActive` — Rewards/Events have no real categories to switch
  between, so the bar disappears entirely there. That mount/unmount is now a
  short fade + rise transition instead of an instant appear/disappear,
  mirroring the fade+slide motion the legacy top subcategory bar already
  uses for its own show/hide.

## Changes

### `src/App.vue`

- Wrapped the `CatalogNavStack` mount point in `<Transition name="nav-stack">`.

### `src/components/CatalogNavStack.vue`

- Added `.nav-stack-enter-active` / `.nav-stack-leave-active` /
  `.nav-stack-enter-from` / `.nav-stack-leave-to` — opacity + `translateY(-8px)`,
  using the existing `--motion-sys-duration-base/exit` and
  `--motion-sys-ease-decelerate/accelerate` tokens.

## Verification

- `vite build --mode fcm` builds clean.
- Manual check via local dev server (FCM theme, `fcmNavModel` enabled):
  switching L1 tabs now fades/rises the L2/L3 bar in and out instead of
  popping instantly.
