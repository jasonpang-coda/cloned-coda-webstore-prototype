# Release Notes — v0.60.8

**Date:** August 2026
**Milestone:** FCM bundle info-sheet rows are now expandable accordions

---

## Highlights

- **FCM's TWG Pack breakdown rows now expand.** The `(i)`-icon info sheet's
  player-item and draft-voucher rows (`ItemSummaryAccordion`) previously had
  no `description`/`media`, so they rendered as disabled, non-expanding
  headers. Each row now carries its own name as a placeholder `description`,
  making it a real accordion — tap to expand and see the SKU item named in
  the description, until real per-SKU copy is written.

## Changes

### `src/stores/fcm/catalog.js`

- `bundleInfoItems()`: added `description` to both rows (player item, draft
  voucher), set to that row's own name. `ItemSummaryAccordion` only shows a
  chevron/expand affordance when `media || description` is truthy — this was
  the missing plumbing, not a component-level change.

## Verification

- `node_modules/.bin/vite build` passes.
- Verified live in the Browser pane preview on the FCM store: opened the
  TWG Pack info sheet, confirmed both rows now show an expand chevron, and
  clicking a row reveals its name as the description text.
