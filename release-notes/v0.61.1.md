# Release Notes — v0.61.1

**Date:** August 2026
**Milestone:** Promo Code details modal + T&C bar polish pass

---

## Highlights

- **The details modal's CLOSE button actually closes it now.** Root cause:
  `.device__overlay` (an ancestor) sets `pointer-events: none` and expects
  each child to opt back in — `.sheet__scrim`/`.sheet__panel` do that
  themselves, but `promo-modal` is a later sibling of `.sheet__panel`,
  outside that opt-in, so a real mouse click silently did nothing. (A
  synthetic `.click()` used during earlier testing bypasses `pointer-events`
  entirely, which is why it looked fine at the time.)
- **The modal's exit transition now actually plays.** Vue's `<Transition>`
  auto-detects CSS transition duration from the *root* element passed to it
  — but the real transition lived on `promo-modal`'s children
  (`__panel`/`__scrim`), so Vue found nothing on the root and unmounted the
  node within a couple of frames. Added an explicit `:duration` matching the
  outer sheet transition.
- **Layout/alignment fixes:** the modal's header is left-aligned (was
  centered); `PromoCode`'s header row (icon + label + chevron) is now
  centered as one compact group instead of the chevron stretching to the
  far edge; the static T&C bar sits closer to the payment-channel list and
  clears the footer's shadow instead of reading as covered by it.
- **Hyperlink styling on the named legal documents** ("User Agreement",
  "Terms & Conditions", "Privacy Notice") inside the T&C body copy.

## Changes

### `src/components/OrderSummarySheet.vue`

- `.promo-modal` gained `pointer-events: auto`.
- The `<Transition name="promo-modal">` wrapping the details modal now
  passes `:duration="{ enter: 350, leave: 200 }"`.
- `.promo-modal__header`/`.promo-modal__title`: `center` → `flex-start`/`left`.
- `.sheet__terms`: removed its own `margin-top` (the parent's flex `gap`
  already separates it from the payment list).
- `.sheet__terms-body`: added `padding-bottom: var(--pad-surface-s)` (8px);
  now rendered via `v-html` instead of text interpolation, and gained a
  `:deep(.sheet__terms-link-inline)` rule (hyperlink token colour +
  underline) for the named legal documents embedded in the copy.

### `src/components/PromoCode.vue`

- `.promo__head` gained `justify-content: center`.
- `.promo__label` no longer sets `flex: 1` — the chevron now sits
  immediately after the label instead of being pushed to the button's far
  edge.

### `src/locale/commonStrings.js`

- `checkout.termsBody` (English): "User Agreement", "Terms & Conditions",
  and "Privacy Notice" wrapped in `<span class="sheet__terms-link-inline">`
  — same convention as `SignInLoader`'s `openingApp`/`qrInstruction` strings,
  which already embed a raw `<sup>` tag.
