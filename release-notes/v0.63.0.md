# Release Notes — v0.63.0

**Date:** August 2026
**Milestone:** In-app `/handoff` dev surface + static export pipeline, `BaseSheet` footer motion simplified and made real, selected-card glow tightened

---

## Highlights

- **New `/handoff` dev tool.** A real child route (`useHandoff.js`, mirrors
  `useLibrary.js`'s pattern but on a genuine path, not a hash) that opens a
  full-screen surface — `HandoffApp.vue` — listing every registered "flow"
  (`src/handoff/flows/*.flow.js`, auto-discovered via `registry.js`) with five
  tabs per flow: Tokens, Components, States, Choreography, Spec. A flow
  manifest (`defineFlow`, `flow.js`) declares WHAT a feature's handoff needs
  to show — token *names*, state ids, transitions, choreography beats,
  component references — and never a transcribed value; resolved values
  (`350ms cubic-bezier(...)`, an actual hex/oklch color) are read live via
  `resolve.js`'s `getComputedStyle` so a manifest can never drift stale.
  Toggled from a new toolbar button (`DeviceToolbar.vue`) and gated behind
  `!isStoreLocked` exactly like the component library, so it tree-shakes out
  of store-locked builds entirely.
- **Static handoff export pipeline** (`scripts/export-handoff.mjs` +
  `scripts/resolve-css.mjs`) — generates `docs/Handoff/<slug>/{spec.md,spec.json}`
  from a live flow manifest, for AI/FE readers who can't run the app.
  `resolve-css.mjs` is a no-browser token resolver: it re-derives the same
  cascade result `resolve.js` gets live (via `getComputedStyle`) by parsing
  the token CSS files in `main.js`'s import order and simulating the
  import-order + specificity rule from the web-store-tokens skill, so a
  regenerated spec's "Resolved" column can never be hand-transcribed or
  silently drift from the CSS on disk. New `npm run handoff:export` script;
  new `mermaid` dependency for the flow/state diagrams rendered by the tool.
- **First registered flow: `locale-selector-sheets`** — a proof-of-concept
  migration of `docs/Handoff/locale-selector-sheets/README.md`'s hand-written
  spec into the in-app framework, covering `RegionSelectorSheet`/
  `LanguageSelectorSheet`'s shared singleton and transition scheme. Its
  generated `spec.md`/`spec.json` are the first output of the export
  pipeline above.
- **`BaseSheet`'s sticky-footer motion simplified — and fixed.** The footer
  now reuses the panel's own `--motion-modal-enter`/`-exit` duration and
  easing directly, with just a `--motion-sys-duration-footer-delay` (100ms)
  offset on both enter and exit — the dedicated `--motion-sheet-footer-enter`/
  `-exit` tokens from v0.60.7 are retired. Along the way, a real bug in the
  exit direction was caught and fixed: an earlier draft of this change had
  the footer's leave transition mistakenly reusing the *enter* duration/
  easing instead of the exit one.
- **New `--motion-sys-duration-modal-panel-delay` (60ms)** staggers panel↔
  scrim on every sheet's own open/close, and is reused by the promo-code
  T&Cs modal in `PaymentStepBody.vue` (its panel now settles 60ms after its
  own scrim on enter, and its scrim trails 60ms behind its panel on exit).
- **Selected-card glow tightened.** `--shadow-card-selected`/
  `-bestseller-selected`'s glow bleed shrunk from `24px 4px` to `20px 1px`,
  and `--fx-glow-selected` now mixes `--hdr-glow` down to 55% opacity
  (`color-mix(in oklch, ...)`) instead of using it at full strength — a
  subtler "lit up" selection cue.

## Changes

### `src/handoff/` (new)

- `useHandoff.js` — singleton open/close + route state for `/handoff`,
  `/handoff/<slug>`, `/handoff/<slug>/<tab>`; mirrors `useLibrary.js` but on a
  real pathname (SPA-rewritten by both Vercel and Vite's dev server).
- `HandoffApp.vue` — the surface shell: sidebar of registered flows + a
  five-tab main panel (Tokens/Components/States/Choreography/Spec).
- `flow.js` (`defineFlow`) — the manifest schema/validation helper.
- `registry.js` — `import.meta.glob('./flows/*.flow.js', { eager: true })`
  auto-discovery, tree-shaken out of store-locked builds.
- `resolve.js` — live token resolution via `getComputedStyle` for the in-app
  tabs.
- `components/` (new) — `TokenLibrary.vue`, `TokenContract.vue`,
  `StateLaydown.vue`, `Choreography.vue`, `ComponentStage.vue`,
  `TokenSandbox.vue`, `TokenChip.vue`, `EasingCurve.vue`, `BeatTimeline.vue`,
  `FlowDiagram.vue`, `StateDiagram.vue` — the per-tab rendering surfaces.
- `utils/bezier.js`, `utils/mermaid.js`, `utils/tokens.js` — easing-curve
  math, Mermaid diagram helpers, token-value formatting.
- `flows/locale-selector-sheets.flow.js` (new) — first registered flow.

### `scripts/export-handoff.mjs`, `scripts/resolve-css.mjs` (new)

- Static spec generation for flows that can't be read by an AI/FE dev
  running the app directly. `npm run handoff:export` (new script in
  `package.json`).

### `src/App.vue`, `src/components/DeviceToolbar.vue`

- Wires `HandoffApp` in behind `!isStoreLocked` alongside the existing
  library viewer, unmounting the store shell while active; new toolbar
  button (handshake icon) toggles it. Global `/` and bare-`c` shortcuts now
  also check `!handoffActive` before firing, matching the existing
  `!libraryActive` guard.

### `src/components/base/BaseSheet.vue`

- Sticky-footer enter/exit CSS reworked to reuse `--motion-modal-enter`/
  `-exit` directly instead of dedicated footer-duration tokens; both
  directions now correctly use their own matching duration/easing (a bug
  in an interim draft — leave sharing the enter timing — was caught before
  release).
- Panel enter now delayed `--motion-sys-duration-modal-panel-delay` (60ms)
  behind the scrim; scrim exit likewise delayed 60ms behind the panel.

### `src/components/steps/PaymentStepBody.vue`

- Promo-code T&Cs modal's panel/scrim now share the same 60ms
  `--motion-sys-duration-modal-panel-delay` stagger as the sheet itself.

### `src/tokens/motion.css`

- Removed `--motion-sys-duration-footer-enter`/`-exit` and
  `--motion-sheet-footer-enter`/`-exit` (retired, no longer referenced).
- Added `--motion-sys-duration-modal-panel-delay: 60ms`.

### `src/tokens/ds/extensions.css`

- `--shadow-card-selected`/`-bestseller-selected` glow bleed: `24px 4px` →
  `20px 1px`. `--fx-glow-selected`: now `color-mix(in oklch, var(--hdr-glow) 55%, transparent)`
  instead of aliasing `--hdr-glow` at full strength.

### `docs/Handoff/locale-selector-sheets/{spec.md,spec.json}` (new)

- Generated output of the export pipeline above, for the first registered
  flow.

## Docs

- `docs/motion-tokens.md` — sheet sticky-footer + scrim/panel layering
  section rewritten to match the reworked tokens/CSS above.
