# Release Notes — v0.64.1

**Date:** August 2026
**Milestone:** Polish pass on the Milestone Rewards tab (continuous step track, nav hover/press feedback, ship icon, glass shimmer + bloom FX) plus a repo-wide frosted-surface audit

---

## Highlights

- **Continuous step track.** `MilestoneRewardsRail.vue`'s progress track now
  renders as a single continuous fill bar instead of per-segment bars, measured
  via `offsetLeft`/`offsetWidth` rather than `getBoundingClientRect()` — this
  app's device-frame preview renders inside a CSS `transform: scale(...)`
  wrapper, so `getBoundingClientRect()` returns post-scale viewport pixels
  while scroll position stays pre-scale, and mixing the two produced a growing
  misalignment (the bar visibly stopping short of the last tier).
- **Nav hover/press feedback.** `NavBar.vue`'s L1 tabs and `CategoryNav.vue`'s
  L2/L3 tabs gained the same hover/press recipe `NavDrawer.vue` already used
  (indicator tint on hover, hyperlink colour + `scale(0.97)` on press) —
  scoped to `.cat-nav--l2`/`--l3` so other stores' plain filter tabs are
  untouched.
- **Ship icon + a pre-existing icon bug caught along the way.**
  `DeviceToolbar.vue`'s handoff button now uses `directions_boat` instead of
  `handshake` — which turned out to have never been registered in
  `MaterialIcon.vue`'s `ICONS` map, so it silently rendered nothing everywhere
  it was used (two more spots remain in `HandoffApp.vue`, flagged separately).
- **Glass shimmer.** The shared `.fx-shimmer` sweep and the Milestone Rewards
  hero banner's local shimmer both moved from a single-point colour stop (which
  reads as a harsh thin line) to a flat, broader plateau at a lower opacity,
  and switched to linear easing — a perpetually-looping sweep is continuous
  motion, which this project's motion-design convention reserves linear for.
- **Bloom effect.** New ambient glow behind the Milestone Rewards hero banner
  and the tier-10 "Champion" card, reusing the existing shared `.fx-bloom`
  recipe (previously only on `HeroSkuCard`/`BestSellerCard`). The hero's glow
  is coloured dynamically from a blurred copy of the actual hero art; the
  Champion card's glow reuses its own muted-blue token, whose opacity was also
  lowered so the glow shows through the card instead of being masked by it.
- **Frosted-surface audit.** Every component using `--x-surface-frost`/`-hover`
  or a `--x-scrim*` token was checked for a paired `backdrop-filter` —
  `TransactionCard.vue` was the one gap, now fixed. `--x-surface-ghost-*`
  (icon-button hover fills on already-opaque chrome) and `CategoryBanner.vue`'s
  legibility scrim were deliberately left alone — neither is a glass panel.

## Changes

### `src/components/MilestoneRewardsRail.vue`

- Track rewritten from two per-segment half-bars to one continuous base/fill
  bar pair, geometry driven by `offsetLeft`/`offsetWidth` off the track nodes
  instead of `getBoundingClientRect()` + scroll offset.

### `src/components/NavBar.vue`, `src/components/CategoryNav.vue`

- Added hover (`--x-bg-indicator-neutral-subtle` + `--x-text-header-strong`)
  and press (`--x-bg-indicator-neutral-default` + `--x-text-hyperlink-default`
  + `scale(0.97)`) states, mirroring `NavDrawer.vue`. `CategoryNav.vue`'s rule
  is scoped to `.cat-nav--l2 .cat-nav__item` / `.cat-nav--l3 .cat-nav__item`.

### `src/components/DeviceToolbar.vue`, `src/components/MaterialIcon.vue`

- Handoff button icon swapped `handshake` → `directions_boat`; the new icon
  registered in `MaterialIcon.vue`'s `ICONS` map (`handshake` never was).

### `src/tokens/effects.css`, `src/components/MilestoneRewards.vue`

- `.fx-shimmer::after`'s gradient widened from a single colour stop to a
  45%–55% plateau with longer fades either side; fallback opacity 0.25 → 0.24;
  easing switched to `--x-motion-sys-ease-linear`. The hero banner's local
  shimmer mirrors the same band shape and easing change.

### `src/components/TransactionCard.vue`

- `.txn-card` gained `backdrop-filter: blur(var(--x-blur-container, 32px))`
  to match every other `--x-surface-frost` consumer.

### `src/components/MilestoneRewards.vue`, `src/components/MilestoneRewardCard.vue`, `src/tokens/ds/extensions.css`

- New `.milestone__hero-bloom` wrapper (hero banner) and
  `.milestone-reward-shell` wrapper (reward card) apply the shared `.fx-bloom`
  effect outside the elements that need their own `overflow: hidden` (image
  clipping; `v-ripple`'s `.fx-ripple` class on the card). The hero's
  `--x-fx-bloom-image` is set inline to a blurred, cover-fit copy of the hero
  art. `--x-fx-gradient-muted-blue` (the Champion card's special background)
  had its alpha lowered from 0.64 to 0.36.

## Known follow-ups

- `HandoffApp.vue` still references the unregistered `handshake` icon in two
  places (flagged as a separate task, not fixed here).
