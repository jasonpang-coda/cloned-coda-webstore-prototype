# Release Notes — v0.64.2

**Date:** August 2026
**Milestone:** Fixed the previously near-invisible bloom effect from v0.64.1, removed the hero shimmer, and reconciled light-angle consistency across FCM's gold/champagne gradients

---

## Highlights

- **Hero shimmer removed.** The Milestone Rewards hero banner's gloss sweep
  is gone — `.milestone__hero-img-wrap::after`, its `shimmer-loop` animation,
  and the now-unused image wrapper div were all removed. The bloom halo
  (below) is now the banner's only ambient effect.
- **Bloom actually visible.** v0.64.1 added a bloom halo behind the hero
  banner and the tier-10 "Champion" card, but it was structurally correct and
  practically invisible: the Champion card's halo colour was already a
  low-alpha token (0.36) and the shared `.fx-bloom` animation itself only
  ranges 0.12–0.22 opacity, so the two multiplied down to almost nothing.
  Both halos now use full-strength (opaque) colours — the same convention
  `HeroSkuCard`/`BestSellerCard` use, where the shared animation is the only
  dimming factor — plus more inset/brightness/saturation for presence.
- **Known limitation, not fixed:** the Champion card's halo still bleeds
  mostly sideways rather than in every direction, because
  `.milestone-rail__list` has `overflow-y: hidden` (needed for the rail's
  horizontal drag-scroll gesture), which clips the halo's top/bottom bleed.
  A full fix would mean restructuring the rail's scroll container.
- **FCM gold/champagne gradient light-angle consistency (unrelated).** Two
  gloss-metal surfaces on FCM's prod SKU screen — the CTA/tag gradient and the
  champagne price-bar gradient — previously carried independent hand-picked
  light angles; the price bar now resolves from the same
  `--x-gradient-sku-card-prod-gold-angle` token the CTA/tag already used.
  Separately, `--x-sys-colour-surface-l1-fill`'s highlight hotspot moved from
  dead-centre to `35% 0%` so its implied light source agrees with the same
  card's own border gradient instead of contradicting it.
- **New `fcm` dev-server launch config** in `.claude/launch.json`, for
  previewing the FCM store directly on its own Vite mode/port (5181) instead
  of via the multi-store dev server + `?theme=fcm`.

## Changes

### `src/components/MilestoneRewards.vue`

- Removed the hero shimmer (`.milestone__hero-img-wrap::after`, the
  `--milestone-hero-shimmer-sweep` var, and the `shimmer-loop` animation) and
  the now-unnecessary `.milestone__hero-img-wrap` div — the `<img>` is now a
  direct child of `.milestone__hero`.
- `.milestone__hero-bloom::after`: `inset` -14% → -18%,
  `filter: blur(56px) brightness(1.05) saturate(1.3)` →
  `blur(44px) brightness(1.25) saturate(1.6)`.

### `src/components/MilestoneRewardCard.vue`

- `.milestone-reward-shell--bloom`'s `--x-fx-bloom-image` switched from the
  card's own translucent `--x-fx-gradient-muted-blue` token to a dedicated
  opaque gradient of the same hue, so the halo's colour isn't double-dimmed
  by both the token's own alpha and the shared bloom-pulse keyframe.
  `::after`: `inset` -12% → -16%,
  `filter: blur(40px) brightness(1.1) saturate(1.2)` →
  `blur(32px) brightness(1.15) saturate(1.3)`.

### `src/tokens/ds/system.css`

- `--x-sys-colour-surface-l1-fill`'s radial-gradient hotspot: `50% 0%` →
  `35% 0%`.

### `src/tokens/ds/themes/fcm.css`

- `--x-gradient-sku-card-prod-price` now reads its angle from
  `--x-gradient-sku-card-prod-gold-angle` instead of a hardcoded
  `92.36716586902443deg`.

### `src/tokens/ds/semantics.css`

- Comment-only: updated to describe the shared gold-angle token's new scope
  (CTA, tag, and price bar) instead of just CTA/tag.

### `.claude/launch.json`

- New `fcm` entry: `vite --mode fcm` on port 5181.

## New additions

- `.claude/skills/material-fx/` — a new skill for deriving material/FX
  choices (glass, metal, bloom, sheen) from real optics rather than copying
  existing patterns; used for this release's light-angle consistency fixes.
