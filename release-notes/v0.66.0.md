# Release Notes — v0.66.0

**Date:** August 2026
**Milestone:** Diablo Immortal onboarded as a new whitelabel store, plus several new generic capability flags it exercises

---

## Highlights

- **New store: Diablo Immortal.** `src/stores/diabloimmortal/store.js` +
  `src/tokens/ds/themes/diabloimmortal.css` — ember-gold/blood-brick/cold-arcane-blue
  palette sourced from a CSS-observed style-guide extraction of the live site
  (`docs/style-guides/diablo-immortal/`), Cinzel proxying the licensed Exocet
  Immortal display face, Alegreya Sans body. Auto-discovered by
  `vite.config.js`'s filesystem scan — no manifest edits needed. Run with
  `npm run dev:diabloimmortal` / `npm run build:diabloimmortal`.
- **No login, region/lang toggle on by default.** New `config.navbar.localeSwitcher`
  flag shows the region/language switcher without the shared, normally-off
  `localeSwitcher` dev feature flag — for stores that want it on by default.
  `config.navbar.hideSignIn` (existing) suppresses sign-in entirely.
- **Navbar wordmark suffix.** New `config.navbar.wordmarkSuffix` appends a text
  label right after the logo (e.g. "Web Store").
- **Single-field Player ID.** New `config.checkout.gamerId.showServer: false`
  hides `StepGamerId`'s Server input for stores with no server selection.
- **Config-driven payment-channel set.** `StepPayment.vue`'s channel list is now
  `config.checkout.paymentChannels` (an ordered key list) with a shared
  `CHANNEL_DEFS` registry — omitting the flag keeps every existing store's
  original 4-channel default. Added PayNow/GrabPay/WeChat Pay/StarHub/M1/Singtel
  as generic icon+label tiles (no logo asset shipped yet) rather than fabricating
  brand marks — same "text-only, no invented logos" precedent as `TrustBar`'s
  publisher chips.
- **Optional Zip Code step.** New `config.checkout.zipCodeStep: false` skips the
  step entirely for stores whose flow doesn't need it.
- **Enter Your Details, extended.** `StepDetails.vue` gained an optional Terms &
  Conditions block (`strings.details.termsHeading`/`termsBody`, null hides it),
  rich-text `consentLabel` (now `v-html`, same trusted-copy precedent as
  `CategoryBanner`'s `description`), and optional leading/trailing CTA icons via
  `config.checkout.detailsCta.{icon,trailingIcon}`.
- **SEO content + FAQ, and a download banner — both new page sections.** Gated
  purely by the presence of `strings.page.seo` / `strings.page.download` (no new
  config flag) — absent for every store before Diablo Immortal. The FAQ reuses
  the existing `HomeFaq` accordion component unmodified.
- **6 new Material Icons registered:** `qr_code_2`, `local_taxi`, `chat`,
  `sim_card`, `radio_button_unchecked`, `add_shopping_cart`.

## Changes

### `src/stores/diabloimmortal/` (new)

- `store.js` — config/strings/assets/skus for the store. SKU art, App/Play
  badge SVGs, and confirmed pricing are PLACEHOLDER pending the user's own
  assets (search "PLACEHOLDER" in the file for swap points).
- `img/brand/` — placeholder wordmark/logomark/currency-icon SVGs (no isolated
  brand lockup exists on the live site — the real wordmark is baked into key art).
- `img/content/` — real hero key art + carved-stone texture harvested for the
  style guide, plus generic placeholder SKU/avatar art.

### `src/tokens/ds/themes/diabloimmortal.css` (new)

- 7 OKLCH seeds + full 50–950 spectrum ramps, Cinzel/Alegreya Sans typography
  tokens. No HDR block or custom L1–L3 surface overrides in this pass — system
  defaults are used, matching the minimal-theme precedent (`pvz3.css`).

### `src/components/NavBar.vue`

- `config.navbar.localeSwitcher` OR'd into the existing `isEnabled('localeSwitcher')`
  gate.
- New optional `.navbar__logo-suffix` span, gated on `config.navbar.wordmarkSuffix`.

### `src/components/checkout/StepGamerId.vue`

- New `config.checkout.gamerId.showServer` (default true) hides the Server input.

### `src/components/checkout/StepPayment.vue`

- Channel list is now `config.checkout.paymentChannels`, resolved against a new
  `CHANNEL_DEFS` map; a channel with no logo asset renders a `MaterialIcon`
  fallback instead of an `<img>`.

### `src/components/checkout/StepDetails.vue`

- New optional Terms & Conditions block; `consentLabel` switched to `v-html`;
  new optional leading/trailing `MaterialIcon`s on the CTA via
  `config.checkout.detailsCta`.

### `src/components/MaterialIcon.vue`

- Registered `qr_code_2`, `local_taxi`, `chat`, `sim_card`,
  `radio_button_unchecked`, `add_shopping_cart`.

### `src/App.vue`

- `StepZipCode`'s section gated on `config.checkout.zipCodeStep !== false`.
- New SEO-content section (`strings.page.seo`, reuses `HomeFaq`) and download-banner
  section (`strings.page.download`), each rendering purely off that string
  object's presence.

### `src/tokens/ds/extensions.css`

- New `--x-gradient-download-banner-scrim` — the download banner's background-image
  scrim, kept out of `App.vue` per the token-discipline rule (gradients with no
  semantic slot live in `extensions.css`).

### `index.html`, `.claude/launch.json`, `package.json`

- Google Fonts `<link>` for Cinzel + Alegreya Sans.
- New `diabloimmortal` dev-server launch config (port 5182) and
  `dev:diabloimmortal`/`build:diabloimmortal` npm scripts.

### `docs/style-guides/diablo-immortal/` (new)

- `guide.html` + `spec.json` + `refs/` — the style guide this release's palette,
  typography, and voice/copy were sourced from (CSS-observed from the live
  site, not guessed).

## Not done in this pass

- Real SKU art per Eternal Orb denomination, App Store / Google Play badge
  SVGs, and confirmed real-world pricing — all still PLACEHOLDER, pending
  assets from the user.
- No isolated Diablo Immortal wordmark/logomark asset — the live site never
  ships one separately from baked-in key art; the navbar/logo currently uses a
  text-rendered placeholder.
- No localised (non-English) strings for this store yet — `translations: {}`.
