# Release Notes — v0.68.0

**Date:** August 2026
**Milestone:** Diablo Immortal — real assets wired in, brick material system, guided-checkout → Buy Now handoff, and a round of layout/UX polish

---

## Highlights

- **Real assets wired in.** Replaced the placeholder wordmark/SKU art with the
  user-supplied real wordmark, icon-only nav mark, App Store / Google Play
  badges, 6 Eternal Orb pack renders (60/300/600/1500/3000/6000), the
  category-banner stone-texture background, the download-banner key art, and
  a tileable leather/mortar texture for the SEO section.
- **Brick material system.** `themes/diabloimmortal.css` now classifies every
  surface as a rough, gritty, sharp-cornered dielectric (per the `material-fx`
  skill's "paper — uncoated" recipe): a static `feTurbulence` grain layered
  under flat brick-red-brown fills across L1/L2/L3 surfaces, sharp-corner
  radius overrides throughout, and a repointed `--x-border-card-default`.
- **Guided checkout → Buy Now handoff.** New `InlineCheckoutCta.vue` — a
  container-less, bottom-docked button whose icon (cart → wallet), label, and
  progress donut advance as the SKU/payment-channel gates clear. Once both
  clear (`useCheckout().checkoutReady`), it transitions into `BuyNowBar` (a new
  `forceReady` prop) — the same Buy Now widget FCM's pilot uses — via a
  slide transition, not a fade, since both are docked to the same edge. The
  button's own anchor scrolls to the SKU grid or the payment grid depending on
  which step it's asking for.
- **`PcCard.vue` extracted.** Shared payment-channel tile component pulled out
  of `PaymentStepBody.vue`'s inline markup; now used by both the overlay sheet
  and the new inline `StepPayment.vue` grid — no more duplicated tile CSS.
- **`SkuImageCard` selected-state bug fixed.** Its selected-state check read
  `sheetOpen`, which is never true in inline-checkout mode — every inline
  store's SKU cards never showed a selected border. Switched to
  `useCheckout().isItemSelected()`, which already resolves all three
  presentation modes correctly.
- **Store-scoped fallback-var overrides**, all defaulting to current behaviour
  for every other store: SKU thumbnail top padding/bottom gap and aspect ratio
  (`--x-sku-image-pad-top`, `--x-sku-image-gap-adjust`, `--x-sku-image-aspect`
  — matches the real 16:9 pack art instead of forcing a square crop), and
  `CategoryBanner`'s padding/bottom-border (`--x-category-banner-pad`,
  `--x-category-banner-border-bottom`).
- **Hero banner respects its own aspect ratio.** New `config.carousel.aspectRatio`
  (`StoryCarousel`'s existing prop, just not previously set) stops the 700×365
  landscape key art from being cropped into a forced 1:1 square on mobile.
- **`HomeFaq` grid layout.** New `layout="grid"` prop lays the accordion out as
  3 equal-height columns at the M breakpoint instead of a single stack;
  default `"stack"` leaves every other usage unchanged.
- **Download banner redesign.** Real containerised banner — background art +
  heading/body/badges all inside one box, same width as every other content
  section (no more bespoke half-width), badges close to the copy at a
  legible 40px height.
- **SEO section, full-bleed backdrop.** The tileable texture now bleeds behind
  the whole section (reusing the same `section__bg` layer other categories use
  for a cover photo, repeating instead of `object-fit: cover`) rather than
  being boxed inside the copy block, with a lighter scrim than the default
  photo-backdrop strength so the grain stays visible.
- **`--x-gradient-download-banner-scrim` fixed.** Was built from
  `--x-bg-card-default`, which becomes an invalid `color-mix()` argument once
  a store's card fill is a multi-layer image (this store's brick material) —
  rebuilt from `--x-bg-page`, always a plain colour.
- **`BuyNowBar` divider is now a literal middle-dot** (`&middot;`) instead of a
  CSS-drawn circle, and gained a `forceReady` prop + `buy-now` emit for the
  guided-checkout handoff above.

## Changes

### `src/components/checkout/InlineCheckoutCta.vue` (new)

- Cart/wallet icon crossfade, half-filled progress donut, no enclosing card —
  same absolute/fixed device-frame positioning as `BuyNowBar`.

### `src/components/checkout/PcCard.vue` (new)

- Extracted from `PaymentStepBody.vue`; props `logo`/`icon`/`label`/`price`/
  `selected`. Used by `StepPayment.vue` and `PaymentStepBody.vue`.

### `src/components/BuyNowBar.vue`

- New `forceReady` prop + `buy-now` emit; divider switched to a literal `·`
  character; `isVisible`/button-visibility conditions OR in `forceReady`.

### `src/components/SkuImageCard.vue`

- `isSelected` now reads `useCheckout().isItemSelected()` instead of a
  sheet-only check (bug fix, all stores).
- New fallback vars: `--x-sku-image-pad-top`, `--x-sku-image-gap-adjust`,
  `--x-sku-image-aspect` (all no-ops for every store but Diablo Immortal).

### `src/components/CategoryBanner.vue`

- New fallback vars: `--x-category-banner-pad`, `--x-category-banner-border-bottom`.

### `src/components/NavBar.vue`

- New `assets.brand.navLogomark` (falls back to `wordmark`) for stores whose
  navbar chrome is an icon-only mark rather than the full wordmark.

### `src/components/home/HomeFaq.vue`

- New `layout` prop (`'stack'` default, `'grid'` for 3-column M+ layout).

### `src/components/checkout/StepPayment.vue`

- Rewritten on top of the new `PcCard`; reads/writes `useCheckout()`'s shared
  `selectedChannel` instead of local state; page-section shape (heading +
  grid) instead of an enclosing `StepCard`.

### `src/components/checkout/StepDetails.vue`

- `config.checkout.stepCta: true` now hides this component's own CTA button
  entirely (`InlineCheckoutCta` replaces it).

### `src/composables/useCheckout.js`

- New `checkoutReady` computed (`selectedItem` AND `selectedChannel` both set).

### `src/components/MaterialIcon.vue`

- Registered `wallet`, `add`.

### `src/tokens/ds/extensions.css`

- `--x-gradient-download-banner-scrim` rebuilt from `--x-bg-page` instead of
  `--x-bg-card-default` (bug fix, all stores).

### `src/tokens/ds/themes/diabloimmortal.css`

- Brick material system (grain data-URI, sharp-corner radius overrides,
  L1/L2/L3 surface fills/borders, `--x-border-card-default`), the SKU-image
  and category-banner fallback-var overrides above, and `--x-sys-size-h4`
  stepped down to 14px (SKU card headers read too large at the default 20px).

### `src/App.vue`

- Guided-checkout ↔ Buy Now `<Transition>` (slide, not fade) in the overlay
  slot; hero banner moved above/below the Player ID step per
  `config.page.heroBeforeGamerId`; `cpImgBanner` `CategoryBanner` wiring; SEO
  section's full-bleed tiled backdrop; download-banner redesign (contained,
  same width as other sections, badges inside the copy block); removed the
  now-unnecessary bottom nav-gap spacer for `config.checkout.stepCta` stores.

### `src/stores/diabloimmortal/store.js`

- Real asset imports throughout (see Highlights); `config.carousel.aspectRatio`;
  `config.checkout.stepCta` + `channels`; inferred base/bonus SKU split from
  the real pack-art filenames; new copy strings (`selectPaymentCta`,
  `purchaseCompleteTitle/Text`).

## Not done in this pass

- No isolated Diablo Immortal *logomark* (distinct from the navbar mark) —
  still the earlier placeholder SVG.
- Pricing remains PLACEHOLDER — industry-standard price points, not confirmed
  against real Diablo Immortal pricing.
- No localised (non-English) strings for this store — `translations: {}`.
