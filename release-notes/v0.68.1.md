# Release Notes — v0.68.1

**Date:** August 2026
**Milestone:** Diablo Immortal — navbar download CTA, category-banner border polish, a header-style SKU section clone

---

## Highlights

- **Navbar download button.** For a store with no sign-in (`config.navbar.hideSignIn`)
  that also has a download banner (`strings.page.download`), the navbar's
  sign-in slot now shows a text-only "Download" button instead of being
  empty — clicking it smooth-scrolls to the download banner section (newly
  `id="download-banner"`). Gated purely on content presence, same precedent
  as the download/SEO sections themselves; every other store's sign-in/avatar
  button is unaffected.
- **Category banner, full border.** New `--x-category-banner-border`
  fallback var (default `none` for every other store) draws a border on all
  four edges instead of just a bottom divider line; `--x-category-banner-border-bottom`
  is restated at the same value so the bottom edge matches instead of being
  left at the component's own divider colour.
- **Cloned SKU section, plain header.** A second "Eternal Orbs" section
  (`#cat-cp-img-header`) renders right after the CategoryBanner one, reusing
  the same items but through `SkuImageList`'s own plain title/description
  header instead of a second banner — no new component needed, just the
  existing `v-else` presentation always taken here.
- **Navbar wordmark suffix copy.** "Web Store" → "Official Store".

## Changes

### `src/components/NavBar.vue`

- New `scrollToDownload()` + a download button in the auth slot
  (`v-else-if="strings.page.download"`, sibling to the existing sign-in/avatar
  `Transition`).

### `src/components/CategoryBanner.vue`

- New `--x-category-banner-border` fallback var on the `.category-banner` rule.

### `src/tokens/ds/themes/diabloimmortal.css`

- `--x-category-banner-border` set to the mortar-line card border colour;
  `--x-category-banner-border-bottom` updated to match (was `none`).

### `src/App.vue`

- New cloned `#cat-cp-img-header` section (plain-header `SkuImageList`,
  `config.page.cpImgBanner` stores only); `id="download-banner"` added to the
  download banner section for the new navbar button to scroll to.

### `src/stores/diabloimmortal/store.js`

- `config.navbar.wordmarkSuffix`: `'Web Store'` → `'Official Store'`.
- New `strings.page.download.navCta: 'Download'` (short label for the navbar
  button; the full heading is too long for that slot).
