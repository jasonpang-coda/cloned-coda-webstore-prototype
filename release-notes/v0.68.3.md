# Release Notes — v0.68.3

**Date:** August 2026
**Milestone:** Diablo Immortal — SEO value-prop benefit grid, header/spacing polish, real favicon

---

## Highlights

- **"Why top up here" benefit grid.** New section in the SEO block, right
  above the FAQ accordion — 6 benefit tiles (Easy and Fast, Instant Delivery,
  Convenient Payment Methods, Speedy & Localized Customer Support, Exciting
  Promotions, More With Every Purchase), each a `MaterialIcon` in a circle
  badge, 2 columns at the M breakpoint. Copy speaks to the Diablo Immortal
  Official Store specifically (Player ID, Eternal Orbs, Warband, web bonus)
  rather than a generic account/loyalty pitch. Renders purely off
  `strings.page.seo.benefits`' presence — same content-gate precedent as the
  rest of the SEO section.
- **Cloned SKU section header, larger.** The plain-header "Eternal Orbs" title
  (the header-only clone added last release) read small at its default 16px —
  new `--x-sku-image-list-title-size` fallback var (no-op for every other
  store) bumps it to 18px, matching `CategoryBanner`'s own title size so both
  "Eternal Orbs" headers on the page read consistently.
- **Extra spacing around the benefit grid.** It now reads as a distinct block
  between the intro copy and the FAQ, not just another paragraph in the
  stack.
- **Real favicon.** Browser tab icon switched from the placeholder standalone
  logomark to the real navbar mark (`navLogomark`) — matches what users
  actually see in the nav.
