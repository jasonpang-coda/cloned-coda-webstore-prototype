# Release Notes — v0.69.0

**Date:** August 2026
**Milestone:** Zenless Zone Zero store added, sticky-nav DeviceFrame fix, material-fx plastic/brick/clay coverage

---

## Highlights

- **Zenless Zone Zero (ZZZ) store.** New guest-only, page-model store
  (`src/stores/zzz/`) — real user-supplied logo/wordmark, 7 Monochrome/
  Inter-Knot pack-crate renders, App Store/Google Play badges (reused from
  Diablo Immortal's generic Apple/Google artwork), and a real collage
  background for the download banner. OKLCH near-black + neon
  yellow-green (`#D8FA00`) palette and licensed "en impact"/"en inpin" fonts
  (proxied by Anton/Noto Sans), sourced from a style-guide pass over the live
  site (`docs/style-guides/zenless-zone-zero/`). A "Best Sellers" section
  (Inter-Knot Membership + the top Monochrome tier, wide 2-up cards) sits
  above the main 5-tier Monochrome grid. Pricing is placeholder — the six
  denominations match the standard HoYoverse premium-currency tier structure
  exactly, but USD price points aren't confirmed against the real store.
- **New `config.page.topNav` capability — a real in-flow, dock/undock
  category nav for the page model.** Mounted in normal document flow right
  after the guest-ID card, wrapping the sections it should dock over
  (Best Sellers + Monochrome) in one parent element. Plain CSS
  `position: sticky` (`CategoryNav` `variant="row"`, mirroring
  `CatalogNavStack.vue`'s own pattern) — no IntersectionObserver
  bookkeeping. Docks once scrolled past the guest-ID card, stays docked
  through Best Sellers and Monochrome, releases the instant the wrapper
  (ending after Monochrome) scrolls past. Used by ZZZ because its sticky
  guided-checkout bar (`config.checkout.stepCta`) already occupies the
  bottom dock a `CategoryNav` would otherwise use.
- **Fixed a real cross-store sticky-positioning bug this surfaced.**
  `DeviceFrame.vue`'s `.device--none .device__screen` carried
  `overflow-y: auto` even though responsive mode already lets it grow
  unbounded (`height: auto`) and never actually scrolls internally — CSS
  still counted it as the nearest scroll container for any
  `position: sticky` descendant, so a sticky element inside it (this new
  top nav, and potentially `CatalogNavStack` on any future
  `device.default: 'none'` store) rode off-screen with the box instead of
  sticking to the real viewport. Fixed by setting that rule's `overflow` to
  `visible`; framed (device-simulator) mode is untouched. Verified no
  regression in FCM's `CatalogNavStack` in both iPhone and Responsive
  mode — Responsive mode was in fact silently affected by the same latent
  bug before this fix.
- **`SkuImageList` gains a `wide` prop.** Fewer, bigger cards (1 col mobile /
  2 col desktop, same ratio as `BundleGrid`), independent of the
  art-rendering `variant` — for a featured row (e.g. Best Sellers) that
  wants more visual weight per card without switching to the oversized
  full-bleed `background` art treatment (which would badly crop/upscale a
  small icon-style SKU render).
- **`SkuImageCard`'s default (`panel`) variant now honours `title`.**
  Previously only the `prod` variant checked the `title` prop before falling
  back to `amount` + `currencyLabel` — a `panel`-variant card with
  `amount: null` and a `title` set (e.g. a membership/subscription SKU)
  silently rendered just the bare currency label instead of its name.
- **`material-fx` skill: three more materials.** Gloss/matte plastic,
  unglazed brick, and unglazed clay/terracotta each get their own
  material→FX validity rows in `fx-catalogue.md`, plus a `physics.md` §4
  clarifying the metal-vs-plastic highlight tell (a hue-shifted highlight is
  a metal claim; a neutral/white highlight over a saturated pigment is
  plastic).

## Changes

### `src/stores/zzz/` (new)

- `store.js` — config (page model, `hideNav: true`, `topNav: true`,
  `stepCta: true` guided checkout), strings (Monochrome currency, ZZZ brand
  voice copy, SEO/FAQ content), assets (logo/wordmark/download banner/App
  Store+Google Play badges), and `skus.bestSeller` / `skus.cpImageRegular`.
- `img/brand/` — `logomark.svg`, `wordmark.svg`, `app-store-badge.svg`,
  `google-play-badge.svg`.
- `img/content/` — `download-banner-bg.jpg`, `SKU/monochrome-{60,330,1090,
  2240,3880,8080}.png`, `SKU/inter-knot-membership.png`.

### `src/tokens/ds/themes/zzz.css` (new)

- 7 ref seeds + palette ramps (neon yellow-green primary, gold secondary,
  cyan tertiary, near-black neutral, derived status colours).
- Anton/Noto Sans typography tokens.
- `--x-radius-control-full` pill override, flat L1/L2/L3 surfaces, category-
  banner and download-banner border tokens, lightened download-banner scrim,
  white-silhouette filter for the flat-black brand marks.

### `src/App.vue`

- New `bestSellerImage` computed + `cat-best-seller-img` section (image-led
  cards, `wide`), gated on `storeSkus.value.bestSeller`.
- Removed a pre-existing duplicate "cat-cp-img-header" section that
  unconditionally re-rendered the Monochrome grid a second time whenever
  `config.page.cpImgBanner` was set — a real bug affecting Diablo Immortal
  too, not intentional behaviour.
- New `.page-nav-stack-wrap` / `.page-nav-stack` markup + CSS for the
  `config.page.topNav` capability (see Highlights).
- SEO section's benefit grid + FAQ accordion moved to a `Span size="fluid"`
  (was `"content"`, capped at 960px) — heading/body keep their own
  independent `max-width` (44ch/90ch) so only the benefit grid and FAQ widen.
- `.download-banner` gained an optional `border: var(--x-download-banner-
  border, none)` escape hatch (no-op for every existing store).

### `src/components/DeviceFrame.vue`

- `.device--none .device__screen` now sets `overflow: visible` (see
  Highlights).

### `src/components/SkuImageList.vue`

- New `wide` prop → `.sku-image-list__grid--wide` (1/2 col grid).

### `src/components/SkuImageCard.vue`

- `panel`-variant title block now checks `title` before falling back to
  `amount`/`currencyLabel`.
