## What's new

### Checkout footer — "Buy Now" + rating badge (`CheckoutSheet.vue`)
The primary CTA label is updated from **"Check Out"** → **"Buy Now"** to align with standard e-commerce copy. A **rating SVG badge** (`src/img/rating.svg`) is placed 4px below the button, right-aligned, via a new `.sheet__checkout-wrap` flex column:

```
.sheet__checkout-wrap
  display: flex; flex-direction: column; align-items: flex-end;
  gap: var(--gap-narrow);   /* 4px */
```

The wrapper inherits `flex-shrink: 0` from the former button, keeping the footer two-column layout intact. The rating image renders at its intrinsic SVG dimensions (`width/height: auto`).

### Best Sellers heading (`BestSellerCarousel.vue`)
Default `heading` prop value corrected from `'BEST SELLER'` → **`'BEST SELLERS'`** (plural, matching the design copy).

### Asset refresh
- **New:** `src/img/rating.svg` — payment/store rating badge used in the checkout footer.
- **Updated:** `src/img/SKU Banners/Midnight Sun Strongbox.webp` — recompressed banner (~30% smaller).
- **Removed:** `src/img/SKU Images/4,000_CP_+_50_BONUS_STRONGBOXES.webp` — replaced by `midnight-sun-bundle-hero.webp` (committed in v0.6.0 patch).
