# Release Notes — v0.70.0

**Date:** August 2026
**Milestone:** FCM two-column split layout + glass SKU panel, fewer-payment-channels dev flag, equal-width payment cards

---

## Highlights

- **FCM homepage adopts Codashop's two-column split shell.** Reused the
  existing `config.page.layout === 'split'` mechanism (`App.vue`'s
  `.storefront`/`.storefront__col--lead`/`--main` grid) instead of building a
  new layout system — the story carousel moves into a sticky left rail
  (forced to a 1:1 crop, since the split's container-query breakpoint is keyed
  to the page container's width, not the narrower rail) while the sign-in
  card and SKU listings stay in the right column. Scoped to the **current
  production SKU card designs only** via a new `config.page.
  layoutRequiresProdCards` flag — previewing the new (unreleased) card
  designs via the `fcmSkuCardModel` flag falls back to the original
  single-column layout with no parent container, exactly as before this
  change.
- **SKU listings panel — frosted glass, not a flat card fill.** The whole
  category-nav + catalogue block now sits inside one visual container built
  from the repo's existing frosted-glass recipe (`--x-bg-sheet` translucent
  fill + `backdrop-filter: blur()` + `--x-border-sheet` hairline — the same
  recipe `BaseSheet`, the promo-code modal, and `CatalogNavStack`'s own
  `.nav-stack` already use), per a `material-fx` skill pass rather than the
  initial opaque `--x-bg-card-default` fill. `CatalogNavStack` bleeds full-
  width to the panel's own edges. Side margins collapse to match the split
  shell's own gutter at ≥801px, and match the player-profile card's inset at
  S and below; inner side padding is `--x-pad-surface-s` (8px) vs. the
  panel's `--x-pad-surface-l` (16px) top/bottom.
- **Story carousel — 1:1 in the split rail, and a double-render bug fixed.**
  Found and fixed a crossfade artifact where the CTA button's logo/heading/
  button block was one `<Transition>`-keyed unit — both the outgoing and
  incoming button briefly co-existed mid-crossfade, reading as a "sweeping"
  double-exposure. The button is now a non-keyed sibling that patches its
  label/handler in place instead of remounting; the logo/heading still
  crossfade as before.
- **New `fcmFewerPaymentChannels` dev flag.** Lets QA preview the case where
  the payment sheet has few enough channels that the body doesn't need to
  scroll — which, per `PaymentStepFooter`'s existing logic, hides the footer's
  "View Terms and Conditions" jump-link. Applied as a shallow config override
  in `usePurchaseFlow.js` (trims `checkout.channels` to 3) rather than in the
  static per-store config, so the scenario can flip live without touching
  FCM's real 14-channel list.
- **Payment-channel cards are now always equal width.** `PaymentStepBody`'s
  `.sheet__pc-list` used `flex-grow: 1`, so a trailing odd card alone in the
  last row stretched to fill it; changed to `flex-grow: 0` so every card
  stays a fixed ~50%-of-row width regardless of count.
- **Equal-height gift cards.** The click-interception wrapper `<div>` around
  each gift's `BundleSkuCard`/`SkuImageCard` was the actual grid item (and so
  the one CSS's default `align-items: stretch` resized), while the card
  inside stayed content-sized — cards with a longer subtitle read visibly
  taller. Tagged the four wrapper sites `.gift-tile` and added `display:flex`
  + `flex:1` on the child so it fills the wrapper's stretched height.

## Changes

### `src/App.vue`

- `isSplit` computed now also requires `isProdCards` when `config.page.
  layoutRequiresProdCards` is set; new `showLeadCarousel` computed gates the
  carousel's lead-column placement (and forced 1:1 ratio) on `isSplit`, not
  just the static `heroColumn` config key.
- New lead-column `<section>` rendering `StoryCarousel` with a literal
  `aspect-ratio="1 / 1"`; the two pre-existing carousel instances now also
  exclude on `!showLeadCarousel`.
- FCM's entire filter-mode content block wrapped in
  `<div :class="{ 'storefront__sku-listings': isProdCards }">` — the bordered/
  glass panel treatment only applies when that class is present.
- Four gift-tile wrapper `<div>`s tagged `class="gift-tile"`.
- New CSS: `.storefront__sku-listings` (frosted-glass panel, side margins,
  bottom margin), `.storefront__sku-listings :deep(.nav-stack)` (full-bleed
  negative margins), `.gift-tile` (equal-height fix).

### `src/stores/fcm/store.js`

- New `config.page = { layout: 'split', heroColumn: 'lead',
  layoutRequiresProdCards: true }`.

### `src/components/StoryCarousel.vue`

- Split `.story__content` into an always-present shell + a keyed
  `.story__content-text` (logo/heading only); the CTA button moved out of the
  `<Transition>` entirely (see Highlights).

### `src/components/CatalogNavStack.vue`

- `.nav-stack :deep(.cat-nav__list)` gap tightened to
  `--x-gap-content-narrow`, scoped to this nav surface only (not the shared
  `CategoryNav` component's other usages).

### `src/composables/useFeatureFlags.js`, `src/composables/usePurchaseFlow.js`

- New `fcmFewerPaymentChannels` flag + `effectiveConfig` computed applying it
  (see Highlights).

### `src/components/steps/PaymentStepBody.vue`

- `.sheet__pc-list > *` — `flex: 1 1 …` → `flex: 0 1 …`.

### `docs/README.md`

- Version footer bumped to v0.70.0.
