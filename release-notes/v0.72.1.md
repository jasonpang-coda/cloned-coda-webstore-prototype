# Release Notes — v0.72.1

**Date:** August 2026
**Milestone:** Fix — FCM Milestone Rewards / Events content pinned off-centre by the split layout's empty lead rail

---

## Highlights

- **FCM's Milestone Rewards and Events tabs now render centred at ≥801px**, matching the new
  (non-split) SKU card design's layout. FCM's two-column split shell
  (`config.page.layout: 'split'`) is store-wide, but its left rail only ever gets content while
  the Store intent is active (the story carousel). Switching to Milestone Rewards or Events left
  that rail empty while the grid still reserved its 4-of-12 columns, pinning the main content to
  columns `5 / 13` instead of collapsing to a centred single column.
- **New `hasLeadContent` / `isSplitActive` gate** (`src/App.vue`) — the split grid (and the
  `GRID_BARE_KEY` provide that tells nested `Grid`/`Span` instances to render bare) now only
  activates when the lead column actually has something to show (story carousel, Codashop's
  `CompactHero`, or its `TrustBar`). Otherwise the page falls back to the same centred
  single-column render every other non-split store already gets — the Store tab's split layout is
  unaffected.
- **Centred the "coming soon" stub block itself** (`CategoryCatalog.vue`) — `align-items: center` /
  `text-align: center` on `.cat-catalog__content--stub`, so the heading and note center within
  their own column regardless of the outer layout fix above.

## Changes

### `src/App.vue`

- Added `hasLeadContent` computed: true when the story carousel, Codashop identity hero, or trust
  bar would actually render in the lead rail.
- Added `isSplitActive` computed: `isSplit.value && hasLeadContent.value`.
- `storefront--split` class binding and the `GRID_BARE_KEY` provide now key off `isSplitActive`
  instead of `isSplit`.

### `src/components/CategoryCatalog.vue`

- `.cat-catalog__content--stub` gains `align-items: center` and `text-align: center`.

### `docs/grid-layout-system.md`

- Documented the `hasLeadContent`/`isSplitActive` fallback and updated the split-layout code
  samples to match.
