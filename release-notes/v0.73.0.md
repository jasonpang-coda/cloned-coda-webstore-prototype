# Release Notes — v0.73.0

**Date:** August 2026
**Milestone:** Codashop pure-dark reskin, embedded category nav, and a Codashop-only SKU card material-exploration pilot

---

## Highlights

- **Codashop is now a pure-dark store.** Dropped the repo's one light-card
  exception (white cards on a dark purple page) — Codashop inherits the
  standard dark `system.css` defaults directly like every other store now.
  New brand palette: electric violet primary, volt lime secondary
  (hyperlinks/on-brand text), orchid tertiary (final-price accent), and a
  quiet violet-black neutral ramp (hue ~305°) so shadows/ambient surfaces
  read as belonging to the same "room" as the brand colour. All 6 chromatic
  ramps + the neutral ramp were regenerated from the new seeds, and the old
  light-card semantic overrides (named surfaces, L1/L2/L3 elevation, ink
  ramp) were removed entirely rather than retuned.
- **New sibling material-fx skill doc, `codashop-mapping.md`.** COD:M's
  `material-fx/codm-mapping.md` is the repo's one whole-repo FX audit (FCM
  has no dedicated skill of its own); Codashop gets its own sibling doc for
  the same reason COD:M has one — a store-specific record of scene-light
  tuning and material classification, cross-linked from `SKILL.md`.
- **First store to use the per-store scene-light override.** `light.css`'s
  `[data-theme="codashop"]` block sets `--x-light-ambient-color` to a violet
  tint matching the new neutral ramp — the file's own header comment always
  invited this, but no store had exercised it before.
- **Category nav embedded in the SKU card, not the sticky bottom bar.**
  `App.vue`'s `config.page.topNav` capability (previously hardcoded to two
  section names, only used by ZZZ) was generalized to wrap whichever
  `config.page.sections` a store actually enables. Codashop opts in and
  additionally mounts the nav as a plain in-flow row at the top of its boxed
  `catalog-card` panel (its catalog shape differs from ZZZ's flat sections),
  suppressing the default sticky-bottom bar via `config.catalog.hideNav`.
- **New Codashop-only SKU card material-exploration pilot.** `skuCardMaterial`
  dev flag (glass / plastic / metal / carbon fibre), gated on
  `config.skuCard.materialExploration` so no other store is affected
  regardless of the flag's value. Deliberately restrained "suggested
  material" finishes, not literal physics simulations — a first pass
  followed `material-fx`'s recipes closely (a full chrome mirror for metal,
  a literal woven twill for carbon fibre) and read as too busy for a real
  product grid; reworked to one dominant cue each (fill + edge + one
  highlight), with only plastic keeping a travelling sweep since it's the
  one material with a real (if weak) one. Carbon fibre knowingly drops the
  physically-mandated weave pattern — documented as a UI-usability override
  in `codashop-mapping.md`, not a physics error.
- **Fixed the selected/hover SKU card glow.** Codashop never defined
  `--hdr-glow`, so the selected card's glow fell through to the repo's
  amber default — a yellow glow against a violet border. Aliased to the
  primary ramp, same pattern every other store already has; this also fixed
  the bestseller comet border/bloom, which shared the bug. Separately, hover
  now carries a faint version of the same glow (new `--fx-glow-hover`, all
  stores) so hover and selected read as one intensity continuum instead of
  two unrelated states.
- **Fixed a real transition bug (all stores).** `.sku-card--selected`'s
  transition list omitted `transform`, so a selected card's hover lift
  snapped back instantly on mouse-out instead of animating — read as lag.
  Now included; every store's cards ease consistently.
- **Fixed the grid row-gap token wiring (all stores).** `space.css` already
  defined `--gap-grid-row-default` (12px) for grid row spacing, but
  `Grid.vue`'s `.ce-grid` was never actually wired to it — `row-gap` reused
  the column-gutter token (8px at XS/S) instead, so wrapped grid rows read
  as cramped at small breakpoints. Fixed; row-gap is now 12px everywhere.

## Changes

### `src/tokens/ds/themes/codashop.css`

- New seeds + all 6 regenerated chromatic ramps + neutral ramp (dark-first,
  same direction as every other store now).
- Removed: named-surface overrides, L1/L2/L3 elevation overrides, ink-ramp
  inversion, SKU-card/input-disabled interactive-state overrides, tag-neutral
  polarity override — all inherited from `system.css`'s dark defaults now.
- Retained/retuned: navbar chrome (direct override, not via
  `--sys-colour-surface-inverse`), hyperlink family (sys-alias-role repoint,
  lime default / violet inverse), `--text-on-brand` (lime), radius profile,
  grid gutters, effect colours, homepage aggregator tokens (formulas
  unchanged, resolve to the new palette automatically).
- New: `--hdr-glow`/`-hot`/`-bloom` (violet, previously undefined here);
  `--x-fx-{metal,plastic,carbon}-*` (SKU card material pilot tokens).

### `src/tokens/light.css`

- New `[data-theme="codashop"]` block — `--x-light-ambient-color` only.

### `src/tokens/ds/extensions.css`

- New `--x-fx-glow-hover`; folded into `--x-shadow-card-hover` (all stores).

### `src/components/Grid.vue`

- `.ce-grid`'s `row-gap` now uses `--x-gap-grid-row-default` instead of
  `--x-gap-grid-gutter` (bug fix, all stores).

### `src/components/SkuCard.vue`

- `.sku-card--selected`'s transition now includes `transform` (bug fix, all
  stores).
- New `.sku-card--{metal,plastic,carbonFibre}` variants (Codashop-only,
  gated on `config.skuCard.materialExploration`), consuming the new
  `--x-fx-*` tokens; `skuCardMaterial` flag read via `useFeatureFlags`.

### `src/App.vue`

- `config.page.topNav` wrapper generalized from two hardcoded section names
  (`best-seller-img`/`cp-img`) to wrapping whichever `config.page.sections`
  render, mounted after Best Seller (matching FCM's `CatalogNavStack`
  placement) rather than at the very top of the catalog run.
- New in-card nav mount inside the `catalogBoxed` panel (`.catalog-card__nav`),
  mutually exclusive with the generic sticky wrapper via `!catalogBoxed`.

### `src/stores/codashop/store.js`

- `page.topNav: true`; `catalog.hideNav: true` (suppresses the default
  sticky-bottom bar); new `skuCard: { materialExploration: true }` capability.

### `src/composables/useFeatureFlags.js`

- New `skuCardMaterial` enum flag entry.

### `.claude/skills/material-fx/`

- New `codashop-mapping.md` (sibling to `codm-mapping.md`); `SKILL.md`
  cross-references it.

## New additions

- `.claude/skills/material-fx/codashop-mapping.md` — Codashop scene-light +
  material-classification audit, and the SKU-card-pilot simplification
  rationale.
