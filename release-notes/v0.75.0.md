# Release Notes — v0.75.0

**Date:** August 2026
**Milestone:** Tour Guide voice-over (mic) option, toggle-switch playback controls, and recording-safe player bar

---

## Highlights

- **Voice-over (mic) narration for manual-mode tours.** A demonstrator can
  now narrate live over a recorded walkthrough — the recorder mixes the
  microphone track into the captured `.webm` alongside the screen video.
  Only meaningful (and only ever enabled) when Autoplay is off and Record is
  on, since manual mode is the only mode with pauses to talk into and the
  narration needs a recording to land in; the engine enforces this gate
  itself, not just the UI. Denied/unsupported mic access falls back to a
  silent video-only recording instead of aborting the tour.
- **Autoplay / Record / Voice-over are now toggle switches, not checkboxes.**
  Replaced the native `<input type="checkbox">` controls in the Tour Guide
  modal with a small sliding-pill switch component local to the kit
  (`.tg-switch`), matching the kit's existing hard-coded colour vocabulary
  rather than the app's design tokens.
- **The bottom player control bar now hides itself while recording.** Its
  Back/Next/speed/stop controls used to show up inside the captured `.webm`;
  it's now suppressed for the duration of a recording so captures come out
  clean. Manual-mode step navigation stays available via the guide card's
  own Back/Next buttons, which were never part of the player bar.

## Changes

### `packages/tourguide-kit/src/core/recorder.js`

- `start(options)` gains `options.captureMic` — when set, requests
  `getUserMedia({ audio: true })` and adds the resulting audio track onto
  the existing display-capture `MediaStream` before starting
  `MediaRecorder`, so the mic is mixed directly into the recording.
- Mic request failures (denied permission, unsupported browser) are caught
  and logged, not thrown — recording continues video-only.
- `stop()` now also stops and clears the tracked `micStream`.

### `packages/tourguide-kit/src/core/engine.js`

- New `this.voiceOver` state, computed on `start()` as
  `!!options.voiceOver && this.record && !this.autoplay` — the gate is
  enforced in the engine so it can't be bypassed by a caller outside the
  modal.
- `voiceOver` included in the reactive snapshot; passed to the recorder as
  `captureMic`.

### `packages/tourguide-kit/src/vue/useTourGuide.js`

- New `voiceOver` ref, synced from the engine snapshot and exposed
  `readonly`, mirroring the existing `record`/`autoplay` pattern.

### `packages/tourguide-kit/src/vue/TourGuideModal.vue`

- Autoplay and Record checkboxes replaced with `role="switch"` buttons
  (`.tg-switch` / `.tg-switch--on` / `.tg-switch__knob`), keyboard-operable
  sliding pills styled with the kit's existing accent colour.
- New Voice-over (mic) row — rendered only when Autoplay is off; disabled
  with a "Turn on Record to enable" hint until Record is on. A `watch`
  forces the toggle back off whenever it becomes unavailable, so a stale
  `true` value can't leak into `startFlow()`.

### `packages/tourguide-kit/src/vue/TourGuideLayer.vue`

- `TourGuidePlayerBar` now renders behind `v-if="!isRecording"`.
