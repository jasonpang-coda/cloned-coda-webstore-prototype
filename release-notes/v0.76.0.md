# Release Notes — v0.76.0

**Date:** August 2026
**Milestone:** Zenless Zone Zero light-mode variant with a toolbar toggle, plus a checkout-CTA centering fix and a SEO-section layout fix

---

## Highlights

- **ZZZ now has a light-mode variant, switchable from the toolbar.** A new
  sun/moon toggle sits next to the store select — only shown for themes
  that actually ship a light variant. Flipping it writes
  `<html data-color-scheme>`, which drives an `html[data-theme="zzz"]
  [data-color-scheme="light"]` token block: every palette ramp's lightness
  mirrors around its 500 seed step (hue/chroma kept, only which step holds
  which L moves), flipping the brand's black-chrome surfaces to white and
  ink to black with no changes needed outside the theme file.
- **The light-mode primary colour is WCAG AA compliant.** `--x-sys-colour-
  primary-main` does double duty — it's the CTA fill *and* the direct text
  colour for hyperlinks, the final price, and the focused-input state — so
  it has to clear 4.5:1 contrast in both directions on a single token. The
  dark-mode neon seed (and an initial lighter swap) couldn't; the derived
  replacement (`oklch(0.555 0.132 119.8)`, `#6a7d00`) clears 4.62:1 against
  white as text and 4.62:1 under white on-brand text as a fill.
- **Guided checkout button now always centers.** Its centering was gated
  behind `@media (min-width: 801px)`, so at any width between the button's
  own 420px cap and that breakpoint it hugged the left edge instead of
  sitting in the middle of the row.
- **SEO benefits/FAQ section now matches the page's standard content
  width.** It previously used a full-bleed `fluid` span; now it shares the
  same 8-of-12/960px `content` span as every other section, for both ZZZ
  and Diablo Immortal (which share this template).

## Changes

### `src/tokens/ds/themes/zzz.css`

- New `html[data-theme="zzz"][data-color-scheme="light"]` block: mirrors
  every accent ramp (primary/secondary/tertiary/status-positive/-caution/
  -negative) and the neutral ramp around their 500/centre step. Higher
  specificity (0,2,1) than the `:root` structural tiers it overrides,
  regardless of import order — same escape hatch as the existing
  `html[data-theme]` HDR overrides.
- `--x-ref-primary` overridden to `oklch(0.555 0.132 119.8)` (`#6a7d00`)
  inside that block — solved by sweeping OKLCH at the brand hue (119.8°)
  for the highest chroma inside the ~0.175–0.183 relative-luminance band
  that clears 4.5:1 both as text-on-white and as a fill under on-brand
  text.
- `--x-text-on-brand` overridden to `--x-palette-neutral-1000` (white in
  this block) — a fill this dark reads better with light text than the
  ink-inverse alias it rode by default.

### `src/composables/useColorScheme.js` (new)

- Singleton `'dark' | 'light'` ref, same `globalThis`-symbol pattern as
  `useTheme.js` (guards against Vite evaluating the module twice under
  mixed import specifiers). Writes `<html data-color-scheme>`.
- Seeds from `prefers-color-scheme` on first load, but the toggle fully
  overrides it from then on — deliberately not media-query-driven, so the
  toggle is the single source of truth instead of racing the OS setting.
- Exports `SUPPORTED_THEMES` (currently `{'zzz'}`) so the toolbar can hide
  the toggle on themes with no light variant instead of showing a control
  that silently does nothing.

### `src/components/DeviceToolbar.vue`

- New light/dark toggle button next to the store select, gated by
  `useColorScheme`'s `SUPPORTED_THEMES`. Icon reflects the *current* mode
  (sun for light, moon for dark), not the target.

### `src/components/MaterialIcon.vue`

- Registered `light_mode`/`dark_mode` (both previously unimported, so an
  earlier pass at this icon rendered a blank square).

### `src/components/checkout/InlineCheckoutCta.vue`

- `display: flex; justify-content: center` moved onto `.checkout-cta`
  unconditionally, replacing the `@media (min-width: 801px)`-gated
  version. The button's own 420px `max-width` still caps it — only the
  centering was breakpoint-gated before, leaving a left-hugging button at
  any width between ~420px and 801px.

### `src/App.vue`

- SEO section's `<Span size="fluid">` → `<Span size="content">` (line
  ~2007) — now shares the same 8-of-12-column, 960px-capped span as the
  SKU grid, UID/details, and download-banner sections instead of reading
  as a wider outlier. Applies to every store that renders this shared
  section (ZZZ, Diablo Immortal).
