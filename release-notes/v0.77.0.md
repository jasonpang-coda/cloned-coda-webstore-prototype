# Release Notes — v0.77.0

**Date:** August 2026
**Milestone:** Codashop's new "Home Blob" acrylic organic-shapes homepage layout (now the store default), plus its own polish pass

---

## Highlights

- **Codashop's homepage gains a third layout: Home Blob.** `homepageLayout`
  (`useFeatureFlags.js`) picks up a new `'blob'` option — an acrylic /
  organic-shapes reinterpretation with full-bleed or confined SVG blob
  backgrounds behind Publisher Spotlight, a new "Picked for you" panel,
  Highlighted Titles, and a Genres/Category rail. It is now the store's
  default layout.
- **One shared card + nav-pill vocabulary across all four sections.**
  `HomeBlobCard.vue` (three size profiles) and `HomeBlobPillNav.vue` back
  every section instead of each authoring its own markup, and both get a
  matching playful "squash-and-stretch" hover/press bounce driven by a
  shared elastic easing token.
- **The whole shared chrome follows the Blob palette automatically.** An
  `html[data-theme="codashop"][data-home-layout="blob"]` attribute-scoped
  repoint aliases the navbar/story-carousel/footer's existing palette
  variables to a new `--x-palette-home-blob-*` ramp — no per-component
  edits needed, and it disappears the moment the layout flag switches away.
- **Real key art is scoped to exactly the two sections that asked for it.**
  Spotlight and Highlighted Titles get new key art via a name-keyed
  `home.highlightsArt` lookup, applied only inside `HomeBlob.vue` — every
  other section (Standard, Visual, Genres, Picked for you) keeps the
  original shared square ref tiles untouched.
- **Follow-up polish, same release:** Picked for you's heading is bigger,
  heavier, and recoloured to gold for contrast; its cards wrap long titles
  onto 2 lines instead of truncating, and all cards in the row stay the
  same height regardless of how many lines a given title needed; its blob
  background is now Publisher Spotlight's own silhouette, mirrored; and the
  nav chips' top/bottom padding grew from 8px to 16px (still token-driven).

## Changes

### `src/components/home/HomeBlob.vue` (new)

- Layout orchestrator, same content/props contract as `HomeStandard.vue`/
  `HomeVisual.vue`. Renders 4 `HomeBlobSection`-wrapped sections (Publisher
  Spotlight, Picked for you, Highlighted Titles, Genres/Category) and stops
  there — the trust/steps/reviews/payments/FAQ/newsletter sections other
  layouts show below "Shop by category" are intentionally not rendered.
- Every blob path (`SPOTLIGHT_PATH`/`HIGHLIGHTS_PATH`/`GENRES_PATH`/
  `PICKED_PATH`) is Figma-exported or hand-authored using cubic-bezier
  commands only — SVG arcs visibly kink under the non-uniform
  `preserveAspectRatio="none"` stretch `HomeBlobShape.vue` relies on, so
  arcs are never used.
- `PICKED_PATH` is Spotlight's own silhouette, manually mirrored
  horizontally (every x → 1038−x) — Picked for you had no Figma mock of its
  own, and this reads as a matched pair with the section above it.
- `highlightedTitles` computed maps `trendingTitles` through a new
  `highlightsArt` prop (name-keyed `{ [title.name]: tileUrl }` override),
  applied only to what's passed into `<HomeBlobHighlights>` — the shared
  `trendingTitles`/`categories` data itself is never mutated.

### `src/components/home/HomeBlobSection.vue`, `HomeBlobShape.vue` (new)

- `HomeBlobSection` wraps a section's content in a full-bleed or confined
  SVG blob background (`blobFull`/`full` props control blob vs. inner
  content width independently). Crossfades between category switches using
  a `position: absolute`-on-leave `<Transition>` (not `mode="out-in"`),
  avoiding a zero-height collapse that was visibly morphing the blob shape
  mid-transition.

### `src/components/home/HomeBlobSpotlight.vue`, `HomeBlobPicked.vue`, `HomeBlobHighlights.vue`, `HomeBlobGenreRail.vue` (new)

- Section-specific content shells, each just a heading/eyebrow + a row or
  rail of `HomeBlobCard` instances (plus `HomeBlobPillNav` for Highlighted
  Titles and Genres).
- `HomeBlobPicked.vue`: heading is `--x-sys-size-h2`/`--x-sys-weight-extra-
  bold` (24px/800 — the heaviest weight token this repo defines; there's no
  true 900/"black" step), recoloured from `--x-text-header-inverse` to
  `--x-sys-colour-tertiary-main` (gold) after the near-white default proved
  low-contrast against the green Picked blob fill. Its 3 `HomeBlobCard`
  instances now pass the new `wrap` prop (see below).

### `src/components/home/HomeBlobCard.vue` (new)

- Shared squircle "photo + caption" card, 3 size profiles (`featured`/
  `panel`/`rail`). Hover/press bounce warps the card's own `border-radius`
  (and, at half magnitude, the inner image's radius) in a diagonal-
  alternating pattern, plus a `transform` scale/lift — deliberately
  excludes `padding` from the animated properties.
- New `wrap` boolean prop: when set, the caption's `white-space` switches
  from `nowrap`/ellipsis to `normal`/wrap, with `min-height: calc(1.3em *
  2)` reserving 2 lines' height regardless of whether this card's own title
  needed 1 or 2 — keeps every card in a row the same height even though
  titles vary in length. Off by default (existing truncate behaviour is
  unchanged for Spotlight/Highlights/rail cards); wired on only for Picked
  for you.

### `src/components/home/HomeBlobPillNav.vue` (new)

- Floating filter/category pill, shared by Highlighted Titles and Genres.
  Chip padding is `--x-pad-surface-l --x-pad-surface-m` (16px/12px) — grew
  from `--x-pad-surface-s` (8px) on the vertical axis, still fully
  token-driven.

### `src/tokens/ds/themes/codashop.css`

- Full `--x-palette-home-blob-{primary,secondary,tertiary,neutral,status-
  positive,status-caution,status-negative}-*` ramps.
- `html[data-theme="codashop"][data-home-layout="blob"]` repoint block:
  aliases the main theme's `--x-palette-*`/`--x-ref-*` variables to the new
  ramps, so shared chrome (navbar, story carousel, footer) follows the Blob
  palette with no per-component edits; a second targeted override restores
  hyperlink-primary/text-on-primary-tertiary semantics this layout needs.
- New `--x-shadow-home-blob-{l1,l2}`, `--x-motion-home-blob-ease-elastic`,
  `--x-corner-shape-home-blob`, `--x-radius-home-blob-*`,
  `--x-home-blob-fill-{spotlight,highlights,genres,picked}`,
  `--x-home-blob-text-link` tokens.
- `@media (dynamic-range: high)` HDR boost for the 5 accent tokens seen
  directly in this layout.

### `src/tokens/ds/system.css`

- New placeholder tokens `--x-sys-surface-0` through `-4` (aliased to
  existing surface tokens pending a future remap).

### Global rename

- `--x-text-on-brand` → `--x-text-on-primary`, across every theme file —
  naming clarity, no behaviour change.

### `src/stores/codashop/store.js`

- New `home.highlightsArt` name-keyed lookup (see `HomeBlob.vue` above).
  Real key art imports added for Spotlight (`HoYoverse.svg`, `GI`/`HSR`/
  `ZZZ.webp`) and Highlighted Titles (`MLBB`/`FF`/`LoL`/`FCM.webp`).
  `'popular'` category's tiles stay on the original shared square ref art.
- `device.default` changed from `'samsung'` to `'none'` — Codashop now
  defaults to the Responsive device frame.

### `src/App.vue`

- Removed the dead "Back to Codashop" link and its CSS, and a stale
  `footer--home-inverse` class left over from before the home reskin (was
  causing dark-on-dark footer text).
