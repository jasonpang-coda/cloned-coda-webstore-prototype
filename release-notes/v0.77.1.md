# Release Notes — v0.77.1

**Date:** August 2026
**Milestone:** Codashop favicon switched to its logomark

---

## Highlights

- **Codashop's browser-tab favicon now uses its logomark, not the wordmark.**
  The favicon previously shared the same wide wordmark PNG as the navbar
  logo and sign-in icon — a banner-shaped logo that read poorly shrunk down
  to favicon size. It now points at the dedicated
  `codashop-logomark.svg` icon-mark instead.

## Changes

### `src/stores/codashop/store.js`

- New import: `codashopLogomark` from
  `./img/brand/codashop-logomark.svg`.
- `assets.brand.favicon` repointed from `codashopLogo` (the wordmark PNG) to
  `codashopLogomark`. `wordmark`/`logomark`/`navSignInIcon` are unchanged —
  this only affects the browser tab icon.
