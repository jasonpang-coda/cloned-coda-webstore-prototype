# Release Notes — v0.78.0

**Date:** August 2026
**Milestone:** Dev toolbar rebuilt as a collapsible side notch + drawer

---

## Highlights

- **The dev-chrome toolbar no longer eats a huge strip of the page.**
  `DeviceToolbar` used to render as a sticky, full-width bar pinned to the
  top of the site — even "collapsed" it left a full-width handle strip
  across the top. It's now a small notch tab fixed to the right edge of the
  viewport, collapsed by default on every device, that expands into a
  non-blocking side drawer (no scrim — the page stays interactive behind
  it) sliding in from the right.
- **The notch moves with the drawer, like a tab on a folder.** Instead of a
  separately fixed toggle button, the notch is a child of the drawer panel
  itself, offset to poke out past the panel's own left edge. When the panel
  slides open or closed, the notch rides along with it rather than sitting
  independently.
- **Build version moved to a pinned footer at the bottom of the drawer.**

## Changes

### `src/components/DeviceToolbar.vue`

- Replaced the sticky, full-width top bar with a fixed-position side panel.
  The panel is always mounted (not `v-if`/`<Transition>`-gated) and toggles
  via a `--collapsed` class driving `transform: translateX(...)`
  (`--x-motion-modal-enter`/`--x-motion-modal-exit`), mirroring
  `NavDrawer.vue`'s slide idiom but without a scrim.
- The notch tab (`.toolbar__notch`) is a child of the panel, positioned
  `left: -22px` so it protrudes past the panel's own edge whether the panel
  is on-screen or translated fully off-viewport — a tab attached to a
  folder, not an independent floating button.
- All controls (device-frame switcher, store/theme dropdown, feature-flag
  selects, inspector/library/handoff/screenshot buttons, comment mode,
  tracking viewer, color-scheme toggle) re-laid-out as a vertical stack
  instead of the old wrap-to-multiple-rows row layout. The mobile-only
  compact horizontal-scroll segment layout was removed as redundant.
- Version label moved from an absolutely-positioned corner label into a
  pinned footer (`flex-shrink: 0`, border-top) at the bottom of the drawer.
- Added outside-tap-to-close and `Escape`-to-close, mirroring
  `AccountPopover.vue`'s pattern: a `pointerdown` listener registered a
  tick after open (so the opening click doesn't immediately close it),
  skipping clicks on the notch itself.
- Content is wrapped in an `inert`-gated container while collapsed, so the
  off-viewport controls aren't reachable by keyboard/assistive tech.
- Removed the `ResizeObserver` that measured the bar's own height and
  published `--toolbar-h` — the toolbar no longer occupies top-of-page
  layout space, so this is no longer needed. Every existing consumer
  (`App.vue`, `useDeviceScale.js`, `useScreenshot.js`,
  `AccountPopover.vue`, `DeviceFrame.vue`, `CatalogNavStack.vue`,
  `CategoryNav.vue`) already read the variable via a
  `var(--toolbar-h, 0px)`/`parseFloat(...) || 0` fallback, so this now
  simply always resolves correctly with no other code changes required.

### `src/composables/useToolbarCollapse.js`

- Simplified the seed: `collapsed` now always starts `true` on every
  device, dropping the previous `matchMedia('(pointer: coarse)...')`
  touch-only default. Since the toolbar is a fixed overlay rather than
  in-flow chrome, there's no layout cost to defaulting closed everywhere.
