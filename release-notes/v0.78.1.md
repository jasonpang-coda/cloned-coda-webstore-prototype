# Release Notes — v0.78.1

**Date:** August 2026
**Milestone:** Token-discipline fix on the filled Sign In button

---

## Highlights

- **Codashop's filled Sign In CTA now stays on the semantic token tier.**
  `.navbar__signin--filled:hover` and its label's bold weight referenced
  system-tier tokens directly, bypassing the semantic layer that lets every
  store retarget colors without touching component code.

## Changes

### `src/components/NavBar.vue`

- Hover background: `var(--x-sys-colour-primary-strong)` → the semantic
  `var(--x-bg-action-primary-hover)`, which already existed and resolves to
  the same value.
- Label bold weight: dropped the raw `font-weight: var(--x-sys-weight-bold)`
  declaration in favor of conditionally binding the
  `.text-style-utility-default-bold` class in the template (matching the
  `.text-style-utility-default-regular` class used for the default variant).
