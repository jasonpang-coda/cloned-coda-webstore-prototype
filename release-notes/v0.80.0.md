# Release Notes — v0.80.0

**Date:** August 2026
**Milestone:** COD:M SEO/download block + a full PWA install feature across five surfaces

---

## Highlights

- **COD:M gets the SEO content block** — heading/body, a benefit grid, and an
  FAQ accordion, ported from the live `store.callofdutymobile.com` copy and
  reusing the shared `strings.page.seo` section every other store already
  renders through (ZZZ, Diablo Immortal). COD:M is the only store whose
  order is flipped (download banner leads, FAQ follows) via a new
  `config.content.downloadBannerFirst` capability flag — every other store's
  order is untouched.
- **A real, working PWA install flow** — not just a visual sign-post. A new
  build-time Vite plugin emits a per-store `manifest.webmanifest` + icons +
  `sw.js` (COD:M only, gated on the store having its own `pwa.config.js`),
  `main.js` registers the service worker in store-locked builds only, and a
  new `usePwaInstall` composable captures Android/Chromium's
  `beforeinstallprompt` for a native install trigger.
- **iOS gets its own instruction sheet**, since Safari has no
  `beforeinstallprompt`: `IosInstallSheet.vue` (media placeholder + numbered
  `Share → Add to Home Screen` steps + a "Got it" close CTA), gated on real
  iOS 16+ detection (`useIosPwaDetect.js`) OR'd with a new
  `forceIosInstallSheet` dev flag so the flow can be previewed from any
  device via the `/` command console.
- **Five install entry points**, all content-gated on `strings.page.pwaInstall`
  (so every other store is unaffected) and sharing the same install logic:
  the download banner (primary, shimmer CTA), the new Gifts-category banner
  (secondary/sign-in-styled CTA), the drawer footer (full-width sign-in-style
  button, above the region/language switcher), a hyperlink in the signed-in
  player card, and a new first story-carousel slide.
- **Experimental shimmer choreography** — `.fx-shimmer--metal-gloss` buttons
  now bloom, then sweep, then fade (a calm ~3s cycle), instead of a bare
  perpetual streak. Scoped to the metal-gloss variant only (bloom isn't
  physically valid for the unused glass/paper-coated variants per the
  material-fx skill), tinted from the scene light rather than the button's
  own fill so the glow actually reads against a bright surface. Flagged as
  disposable/reversible in the source comments.

## Changes

### `vite.config.js`

- New `pwa-manifest` plugin: `transformIndexHtml` injects
  `<link rel="manifest">` / `<meta name="theme-color">` /
  `<link rel="apple-touch-icon">` for a store-locked build with its own
  `pwa.config.js`; `generateBundle` emits `manifest.webmanifest`, copies the
  icon set into `dist/pwa/`, and copies `src/sw.js` to `dist/sw.js`.

### `src/stores/codm/store.js`

- `page.seo` (heading/body/benefits/FAQ), `page.download` (heading/body/app
  badges), `page.pwaInstall` (cta/bannerCta/drawerCta/storySlideCta/
  storySlideHeading/playerCardCta/iosSheetTitle/iosSteps/gotIt/
  giftsBannerDesc) — all new.
- `assets.content.giftsBanner`, `.downloadBannerBg` — new imagery.
- `assets.content.appStoreBadge` / `.googlePlayBadge` — real generic badge
  art (reused from ZZZ/Diablo Immortal) in place of the text-pill fallback.
- `config.content.downloadBannerFirst: true`.

### `src/App.vue`

- SEO section split into two independently-orderable sections (value-prop,
  FAQ) plus the download banner, all inside a `.seo-download-group` flex
  wrapper whose `order` is driven by the new config flag.
- Download-banner PWA row (shimmer primary CTA) and a new Gifts
  `CategoryBanner` instance with a secondary install CTA in its new
  `#action` slot.
- `stories` computed gains a content-gated first slide
  (`ctaAction: 'pwa-install'`) with its own icon+label CTA.
- `onStoryCta` branches on `ctaAction === 'pwa-install'` before its existing
  scroll-target logic.

### New files

- `src/composables/usePwaInstall.js`, `useIosPwaDetect.js`
- `src/components/IosInstallSheet.vue`
- `src/sw.js`, `src/stores/codm/pwa.config.js`
- `src/stores/codm/img/brand/pwa/icon-{192,512,512-maskable}.png`,
  `img/brand/{app-store,google-play}-badge.svg`,
  `img/content/{download-banner-bg.webp,gifts-banner-bg.jpg}`

### Shared components

- `CategoryBanner.vue` — new optional `#action` slot (no-op for every
  existing usage).
- `PlayerCard.vue` — new optional `#link` slot (no-op for `AccountPopover`).
- `StoryCarousel.vue` — slides may now carry an optional `ctaIcon`.
- `HomeFaq.vue` — `layout="grid"` now uses `min(3, item count)` columns
  (via a new `--home-faq-cols` CSS var) instead of a fixed `repeat(3, 1fr)`,
  so a short list (COD:M's 2-item FAQ) stretches to fill the row instead of
  leaving an empty trailing column; a 6-item list (ZZZ) is unaffected.
- `MaterialIcon.vue` — registered `install_mobile`.
- `NavDrawer.vue` — new PWA install row, pinned above the region/language
  switcher footer.

### `src/tokens/effects.css` / `keyframes.css`

- `.fx-shimmer--metal-gloss` gains the glow-then-shimmer-then-unglow
  choreography described above (`button-glow-choreo`,
  `shimmer-loop-metal-gloss` keyframes).

### `src/composables/useFeatureFlags.js`

- New `forceIosInstallSheet` boolean flag (COD:M-scoped).
