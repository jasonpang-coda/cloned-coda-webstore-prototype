# Release Notes — v0.81.0

**Date:** August 2026
**Milestone:** Device selector now auto-triggers the PWA iOS sheet, plus a guided tour for the whole install flow

---

## Highlights

- **The device-frame selector (iPhone/Android/Responsive) is now a shared
  singleton** (`useDeviceFrame.js`), not App.vue-local state — lifted so
  `usePwaInstall.js` and tour `setup()` hooks can read/set it directly,
  following the same `globalThis`-pinned pattern as `useTheme.js`.
- **Setting the device to iPhone now auto-previews the iOS install sheet** —
  `shouldOfferIos` folds in `device.value === 'iphone'` alongside the
  existing real-device check and the manual `forceIosInstallSheet` dev flag.
  Android and Responsive never trigger it this way, only a genuine iOS
  device or the flag still can — makes testing the iOS flow a one-click
  toolbar/console switch instead of hunting for the dev flag.
- **A new guided tour** (`pwa-install.tour.js`) walks all five install entry
  points in real page-position order — the drawer, story carousel, signed-in
  player card, Gifts banner, download banner — finishing on the iOS "Add to
  Home Screen" instructions. Every `data-poi` marker the tour targets was
  added to the actual components (not tour-only stubs), so the same anchors
  are available for any future automation.
- Iterated the tour to fix real playback bugs: the iOS sheet was leaking
  open across unrelated steps (fixed with a deterministic
  open/close-via-composable pattern instead of clicking DOM buttons between
  steps), tooltip cards were overlapping their own spotlighted CTA on three
  steps (fixed via `poiPlacement`), and the sheet was visibly opening a full
  step early (fixed by decoupling "spotlight the button" from "open the
  sheet" — only the tour's final step now controls opening it).
- Small copy/spacing fixes: a typo in the download banner's body copy, and
  the description text in both the download banner and the Gifts
  `CategoryBanner` sits closer to its heading (was inheriting the full flex
  gap; capped at a tight-but-not-overlapping 2px).

## Changes

### `src/composables/useDeviceFrame.js` (new)

- The device-frame ref (`'iphone' | 'samsung' | 'none'`), lifted out of
  `App.vue`'s local scope into a shared singleton.

### `src/composables/usePwaInstall.js`

- `shouldOfferIos` now also checks `device.value === 'iphone'`.

### `src/App.vue`

- `device` now sourced from `useDeviceFrame()` instead of a local `ref()`.
- Added `data-poi` markers to the download-banner and Gifts-banner install
  CTAs, and a `ctaPoi` field on the story-carousel's PWA slide.
- Tightened the download-banner description's spacing under its heading.

### `src/tourguide/flows/pwa-install.tour.js` (new)

- 7-step tour (`id: 'pwa-install'`, category "Growth"): drawer → story
  carousel → player card → Gifts banner → download banner → iOS
  instructions. Forces the device to iPhone and signs in a guest player in
  `setup()`; `teardown()` guarantees the sheet isn't left open if the tour
  is stopped mid-flow.

### Shared components

- `NavBar.vue`, `NavDrawer.vue`, `PlayerAccount.vue`, `StoryCarousel.vue` —
  `data-poi` markers added to the hamburger button, drawer close button,
  drawer install row, player-card install link, and (conditionally) the
  story-carousel CTA.
- `CategoryBanner.vue` — description spacing tightened under its title,
  same recipe as the download banner.

### `src/stores/codm/store.js`

- Fixed a typo in `page.download.body` ("...Store on to be the first..." →
  "...Store to be the first...").
