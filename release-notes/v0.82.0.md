# Release Notes — v0.82.0

**Date:** September 2026
**Milestone:** New COD:M Purchase Success page (Order Complete) — hero, PWA install signpost, order summary, and after-sale help

---

## Highlights

- **New `OrderCompletePage.vue`** — the full page shown after a successful
  purchase (Figma node 335:61272), COD:M only for now. It's a view, not an
  overlay: swapped into `App.vue`'s `DeviceFrame` slot in place of the
  storefront while `useOrderComplete().orderCompleteOpen` is true, exactly
  the same pattern `TransactionHistoryPage.vue` already established. NavBar
  stays mounted above it; the bottom `CategoryNav` hides while it's open.
- **Reached two ways:** the real checkout-complete step
  (`PurchaseSheet.vue`'s `onCheckoutConfirm()`), and a dev/demo entry in
  `DeviceToolbar.vue` for previewing the page without running a full
  checkout.
- **The SKU persists from the actual purchase.** The Order Summary's SKU
  banner reads `useCheckout().selectedItem` — the same item the user tapped
  through checkout — merged field-by-field over a Figma-matched default, so
  the page never renders a blank field even when opened cold (e.g. from the
  dev toolbar with no prior selection).
- **Hero is full-bleed at every breakpoint**, not just phone width — a
  deliberate departure from this codebase's usual `Span size="carousel"`
  convention (which reverts to a 960px-capped column at M/L). Only the hero's
  text/CTA column caps at that width; the background always spans edge to
  edge.
- **Found and fixed a real rendering bug while building this:**
  `--x-border-sku-card-default` is a `linear-gradient()`, which a plain
  `border: ... solid var(...)` silently can't render (a gradient isn't a
  valid CSS `<color>`) — the SKU banner and Need Help rows both had
  invisible borders until switched to the `::before` mask-composite ring
  technique `SkuCard.vue` already uses for the same token.
- **Two new design tokens:** `--x-bg-tag-promo`/`--x-text-tag-promo` (a new
  `promo` variant on `SkuTag.vue`, for the purple "NEW USER" badge) and
  `--x-bg-action-neutral` (+`-hover`/`-pressed`), a solid white CTA fill for
  the "Back to Game" button — distinct from `--x-bg-action-secondary`'s
  pale-yellow tint.

## Changes

### `src/components/OrderCompletePage.vue` (new)

- Hero (full-bleed at every breakpoint, background art + scrim + title/
  subtitle + primary CTA capped at 420px) → PWA install bar (reuses
  `usePwaInstall()`/the shared `IosInstallSheet`, no new sheet instance) →
  Order Summary card (SKU banner, secondary CTA, 50/50 label:value detail
  grid) → Need Help card (4 external link-out rows, not an accordion).

### `src/composables/useOrderComplete.js` (new)

- Singleton `orderCompleteOpen` ref + `order` (computed) that merges
  `useCheckout().selectedItem`'s SKU fields over a Figma-matched
  `DEFAULT_ORDER`, field-by-field (so a partial or missing selection still
  resolves every field).

### `src/App.vue`

- New `OrderCompletePage` view branch alongside `TransactionHistoryPage`;
  `CategoryNav`/subcategory nav additionally guard on `!orderCompleteOpen`.
- `watch(strings, ...)` now also closes the Order Complete view if the
  active store doesn't ship `page.orderComplete` copy (store-switch safety,
  mirrors the existing Transaction History guard).

### `src/components/PurchaseSheet.vue`

- `onCheckoutConfirm()` now closes the sheet and opens Order Complete when
  `strings.page.orderComplete` exists (COD:M-style checkout-step stores
  only; `usesPaymentView` stores are untouched for now).

### `src/components/DeviceToolbar.vue`

- New `check_circle` button: "Preview Order Complete page" — opens the page
  directly for demos, with no checkout required.

### `src/components/SkuTag.vue`

- New `promo` variant (`--x-bg-tag-promo`/`--x-text-tag-promo`) for the
  Order Complete SKU banner's "NEW USER" badge.

### `src/tokens/ds/semantics.css`

- `--x-text-tag-promo`, `--x-bg-tag-promo` (tertiary role ramp — nearest
  existing hue family to Figma's flat purple).
- `--x-bg-action-neutral` (+`-hover`/`-pressed`) — solid near-white CTA fill,
  aliasing `--x-sys-colour-surface-inverse`.

### `src/stores/codm/store.js`

- New `page.orderComplete` copy block (hero heading/subtitle, CTAs, summary
  field labels, `needHelp[]` link rows) and `pwaInstall.postPurchaseCta`.
  Both gated on the key's presence, so other stores no-op until they add
  copy — zero component forks.
- New `orderCompleteHero` asset import (CP-coin-stack key art).

### New asset

- `src/stores/codm/img/content/order-complete-hero.webp` — the Order
  Complete hero's background image.
