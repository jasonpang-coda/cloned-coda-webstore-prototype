# Release Notes — v0.83.0

**Date:** September 2026
**Milestone:** Page-switching infrastructure (universal home button, close-all-overlays), a restructured dev toolbar, and Order Complete polish

---

## Highlights

- **The navbar wordmark is now a real "go home" button in every store**, not
  just Codashop. Tapping it closes Order Complete/Transaction History (COD:M)
  or returns from a title's product page to the aggregator homepage
  (Codashop) — and now also dismisses every open sheet/popup/modal so you
  never land on the default page with something stale still floating over it.
- **New `closeAllOverlays()`** — a single call that dismisses every overlay
  the app can have open (checkout sheet, Buy Now bar, sign-in sheet, account
  popover, claim-gift sheet, item-summary sheet, region/language selectors,
  iOS install sheet, nav drawer). Wired into every page-switching action
  (navbar logo, `DeviceToolbar`'s "Pages" dropdown), so switching pages is
  now guaranteed to leave a clean slate.
- **`DeviceToolbar` restructured**: analytics moved into the main Tools row;
  the old single "Preview Order Complete" button is now a "Pages" dropdown
  that jumps between whichever pages the active store actually has
  (Codashop: Homepage/Product Page; COD:M: Product Page/Order Complete);
  every per-store enum flag folded into one "Variants" section instead of
  scattered bare selects; every dropdown now stacks an eyebrow label above a
  full-width control; final section order is Tools → Stores → Light/Dark →
  Pages → Variants.
- **Order Complete polish**: the hero is now genuinely full-bleed at every
  breakpoint (not just phone width); three separate places where a border
  was silently rendering as invisible (an unset CSS custom property, and two
  gradient values used as a plain `border-color`) now render correctly;
  Player ID and Payment Method persist from the actual checkout flow instead
  of always showing demo placeholders; the "NEW USER" badge now reuses the
  same styling as SKU Card's "Free Gift"/"Best Value" tag instead of a
  bespoke variant; "Need Help" gained a "?".

## Changes

### `src/composables/useCloseAllOverlays.js` (new)

- `closeAllOverlays()` — closes visibility only (never clears a selection):
  `useCheckout().closeCheckout()` + `buyNowVisible=false` (deliberately not
  `dismissBuyNow()`, which also clears `selectedChannel` — needed intact for
  Order Complete's Payment Method persistence), plus every sign-in/gift/
  item-summary/region/language/iOS-sheet/nav-drawer close function.

### `src/composables/useCodashopHome.js` / `useNavDrawer.js` (new)

- Codashop's home/product-page toggle and the nav-drawer open state, lifted
  out of `App.vue`'s local scope into singletons (same pattern as
  `useDeviceFrame.js`) so `DeviceToolbar`/`useCloseAllOverlays` can read/set
  them directly. `useCodashopHome`'s `goHome()`/`openTitle()` both call
  `closeAllOverlays()`.

### `src/composables/useOrderComplete.js` / `useTransactionHistory.js`

- `openOrderComplete()`/`closeOrderComplete()`/`openHistory()`/
  `closeHistory()` all call `closeAllOverlays()`.
- `order.player.playerId` now reads `useCheckout().guestPlayerName` (the
  typed "Your COD:M Player ID" value), falling back to the Figma default.
- `order.player.paymentMethod` now reads `useCheckout().selectedChannel`
  through a new `PAYMENT_CHANNEL_LABELS` list mirroring `sheetContent.js`'s
  hardcoded 4-channel grid, falling back to the Figma default.
- `DEFAULT_ORDER.player.nickname`/`email` changed to `codayw`/
  `codayw@coda.com` (was `codaot`/`codaot@coda.com`).

### `src/components/NavBar.vue`

- The wordmark button is no longer gated on `config.home` — it's a real tap
  target in every store now, always emitting `home`.

### `src/App.vue`

- `goHome()` now calls `useCodashopHome()`'s `goHome()` plus
  `closeOrderComplete()`/`closeHistory()`, so the logo always returns to the
  default page and clears every other full-page view.
- `.section--seo` gained `--x-home-surface-border: var(--x-border-card-default)`
  — `HomeFaq`'s card border falls back to `transparent` unless a consumer
  overrides it (only `HomeVisual`'s cinematic hero did), so the storefront's
  SEO FAQ cards were rendering with no visible border at all.

### `src/components/DeviceToolbar.vue`

- Analytics (Session tracker) moved from its own segment into the main Tools
  row.
- The old "Preview Order Complete" button replaced by a "Pages" dropdown,
  computed per store capability (`config.home` / `strings.page.orderComplete`).
- Every enum feature flag folded into one "Variants" section with per-field
  sub-labels, instead of one bare `<select>` per segment.
- Every dropdown segment now stacks an eyebrow label ("Tools"/"Stores"/
  "Pages"/"Variants") above a full-width control.
- Section order: Tools → Stores → Light/Dark → Pages → Variants.
- COD:M's Pages option label reads "Product Page" (was "Storefront") for
  terminology parity with Codashop's own Homepage/Product Page pair.

### `src/components/OrderCompletePage.vue`

- Hero restructured to a plain full-width block outside any `Grid`/`Span`,
  so it stays full-bleed at every breakpoint instead of reverting to the
  960px-capped column at M/L like `Span size="carousel"` does elsewhere.
- SKU banner and Need Help row borders (`--x-border-sku-card-default` is a
  `linear-gradient()`, invalid as a plain `border-color`) now render via the
  `::before` mask-composite ring technique, same as `SkuCard.vue`'s own
  gradient border.
- Detail rows restructured to a 50/50 label:value grid; dropped a redundant
  separate `:` span now that labels carry their own trailing colon.
- Need Help's chevron icon recoloured to `--x-text-hyperlink-default` (was
  inheriting white from the row).
- `needHelpTitle` copy changed to "Need Help?" (was "Need Help").

### `src/components/SkuTag.vue` / `src/tokens/ds/semantics.css`

- Removed the bespoke `promo` variant (+ its two tokens,
  `--x-bg-tag-promo`/`--x-text-tag-promo`) added in v0.82.0 — the "NEW USER"
  badge now reuses the existing `value` variant instead, the same styling
  `SkuCard`/`GiftSkuCard` use for BEST VALUE/FREE GIFT.

### `src/components/PlayerAccount.vue` / `ClaimGiftSheet.vue`

- New `showPwaLink` prop (default `true`) on `PlayerAccount.vue` — the
  found-state PlayerCard's PWA install link now only shows on the main
  storefront's own instance; `ClaimGiftSheet.vue`'s reused instance passes
  `:show-pwa-link="false"` so a claim-gift sheet doesn't also pitch the
  install flow.
