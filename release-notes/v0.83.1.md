# Release Notes — v0.83.1

**Date:** September 2026
**Milestone:** Fixed device-frame notches rendering washed out behind the status bar's backdrop blur

---

## Highlights

- **The iPhone notch/Samsung punch-hole tied the status bar for stacking order, and lost.**
  Both `.device__island`/`.device__punch` (the notch hardware) and
  `.device__statusbar` (the translucent time/signal/battery bar) sat at
  `z-index: 45`. With equal z-index, paint order falls back to DOM order —
  and the status bar markup comes after the hardware markup — so the status
  bar's semi-transparent tint and `backdrop-filter: blur()` painted directly
  over the notch, dimming and blurring it instead of leaving it a crisp
  cutout.

## Changes

### `src/components/DeviceFrame.vue`

- `.device__statusbar` z-index dropped from `45` to `44`, putting it below
  the camera-cutout hardware layer while staying above `.device__overlay`
  (`40`). The notch/punch-hole now renders on top, unblurred.
