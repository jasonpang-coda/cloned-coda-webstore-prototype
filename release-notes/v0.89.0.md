# Release Notes — v0.89.0

**Date:** September 2026
**Milestone:** Design harness grade-A pass — every confirmed audit defect fixed across L1–L5, backed by a real `npm test` regression suite so the fixes can't quietly reappear

---

## Highlights

- **A full audit found the harness's own "fixed" regressions had reappeared.**
  Two of the four entries in `audits/regressions-log.json` — REG-RETRO02
  (duplicate token-scanning regex) and REG-RETRO04 (silent zero-match
  exit) — had resurfaced, relocated to `token-cli.mjs` and `preflight.mjs`,
  files nobody re-checked once the original fix landed. The ledger recorded
  the lesson; nothing enforced it. New `tests/` (`npm run test`, Node's
  built-in test runner) locks every fix from this release with a real
  assertion, so a recurrence fails a test instead of waiting for the next
  full audit to catch it.
- **The render/crash gate now sweeps all 3 widths, not just iPhone.**
  `harness-cli.mjs`'s static sweep advertised "12 themes × 3 widths" but the
  width dimension was dead code — token resolution doesn't vary by width
  anyway. `harness-render.mjs` now renders every variant at iPhone/Samsung/
  responsive via real SSR, which is where a container-query layout break
  actually shows up. The static sweep's own header now says what it
  actually does: a 12-theme token sweep, nothing more.
- **The orchestrator pipeline now actually halts on failure.**
  `tools/orchestrator.mjs`'s `runStage()` returned a pass/fail boolean that
  was never checked — a broken `intake`/`sweep`/`render`/`preflight` stage
  didn't stop `handoff` from running anyway, so a component known to crash
  could still get a handoff spec exported for a downstream engineer to
  trust. Verified live against a deliberately broken component: `render`,
  `preflight`, and `handoff` now correctly show `SKIPPED`.
- **`export-handoff.mjs --verify` used to check nothing in flow mode.**
  `isStoryMode = args.includes('--story') || isVerifyMode` forced bare
  `--verify` into story mode unconditionally, so flow-mode output
  (`docs/Handoff/<slug>/{spec.md,spec.json}` — the exact shape
  `pwa-web-push` and `locale-selector-sheets` are) had zero drift coverage
  and could never report anything but silence. `--verify` now respects
  `--story` the same way a plain export does, and diffs real content
  (including the `--target=codashop-client` bundle) — confirmed by
  hand-corrupting a real spec and watching it fail, then restoring it and
  watching it pass.
- **A working Figma token-drift audit, not a stub.** `figma-harness.mjs`'s
  `diff-tokens` threw a `ReferenceError` on every invocation (`getAllTokens`
  was never imported) and its "match variables" logic was an empty comment.
  It now does a real diff against a Figma variables export file, including
  a from-scratch OKLCH→sRGB conversion (standard CSS Color 4 / Ottosson
  OKLab matrices — every prototype color token resolves to `oklch(...)`,
  never hex) validated against known pure-RGB↔OKLCH reference points.
  `figma-sync.mjs`'s duplicate `audit` command (which only printed
  instructions and always exited 0) now redirects here instead of existing
  as a second, weaker copy. A detached script still can't call the Figma
  MCP itself — the design-harness skill documents the achievable
  Claude-driven capture step that produces the file this diffs against.
- **Two ledgers had a real lost-write race.** `compound.mjs` and
  `retro.mjs` both did a plain read → push → `writeFileSync` — under
  concurrent writers (the exact scenario both ledgers exist for: multiple
  worktrees/agents compounding a lesson at once) the second write silently
  clobbers the first's entry. New `tools/lib/ledger.mjs` (mkdir-based lock +
  write-temp-then-rename) fixes both; verified with 10 real concurrent OS
  processes appending to each ledger — 10/10 survive.

## Changes

### `tools/lib/ledger.mjs` (new)

- `readLedger(path)` / `appendToLedger(path, record)` — safe read/append for
  a committed JSON-array ledger, shared by `compound.mjs` and `retro.mjs`
  instead of each hand-rolling its own (non-atomic) version.

### `tools/lib/naming.mjs` (new)

- `toKebabCase` / `toCamelCase` extracted out of `scaffold.mjs` (which has
  no import-guard around its CLI dispatch) so they're unit-testable.
  `toKebabCase` also gained an acronym-boundary pass — `SKUCard` used to
  collapse to `skucard` (no lower→upper transition for the old regex to
  find); it's now `sku-card`.

### `tools/lib/component-tokens.mjs`

- New `scanVarUsages(content)` — a line-aware `var(--token, fallback)`
  scanner, single-sourcing what `token-cli.mjs`'s `handleAudit` and
  `preflight.mjs` used to reimplement independently (the exact REG-RETRO02
  mistake, recurring in different files).

### `tools/token-cli.mjs`

- `audit` now calls the shared `scanVarUsages` instead of its own
  duplicated regex.

### `tools/preflight.mjs`

- Token-validity check now uses `scanVarUsages` too.
- `checkOverlayParity` traces each `SURFACES` ref back to the composable
  that actually owns it (via `App.vue`'s own `const { x } = useY()`
  destructuring) and checks that composable is invoked in
  `useCloseAllOverlays.js` — replacing an order-sensitive concatenated
  substring match that reported `claim-gift` and `signin-loader` as
  unregistered even though both are genuinely wired (`closeGiftClaim()`,
  `cancelSignIn()`). Confirmed live: both false positives are gone, no new
  ones introduced.

### `tools/scaffold.mjs`

- `handleScaffoldOverlay` now guards `readFileSync` on
  `useCloseAllOverlays.js`/`App.vue` with `existsSync`, matching the clean
  `Error:`-prefixed messages the rest of the file already uses.

### `tools/harness-cli.mjs`

- Dropped the dead `WIDTHS` constant and every "3 widths" claim — see
  Highlights.
- A story testing zero tokens now fails (`NO_TOKENS_TESTED`) instead of
  silently reporting a clean pass.
- `@media` exemption check now evaluates each occurrence individually
  (`prefers-reduced-motion`/`print`) instead of a whole-file substring
  check that exempted every `@media` in a file as soon as any of them,
  anywhere, mentioned the phrase.
- Variant-name extraction now scoped to the `variants: [...]` block itself
  (bracket-depth tracked) instead of scanning `name:` across the whole
  file, which could also pick up an unrelated `name:` prop inside a
  variant's own `props` factory.

### `tools/harness-render.mjs`

- Renders every variant at all 3 `StoryStage` widths (iphone/samsung/
  responsive), not hardcoded `'iphone'`.
- The store-module-load fallback no longer swallows its error silently —
  now warns loudly (the same swallow-and-mask pattern REG-RETRO01 exists to
  catch elsewhere).
- `--json` output gained `renderedCount`/`skippedCount`; the human-readable
  summary always states the skip count (not just when nonzero), so
  `skipRender` coverage erosion stays visible.
- (Considered, not built: cross-rendering `variants × states`. `states`
  like hover/pressed are post-mount DOM simulations —
  `packages/inspect-kit`'s `buildHoverOverride`/`applyPressedState` clone
  live `document.styleSheets` rules — which SSR's `renderToString` has
  nothing to simulate against. Faking it would test nothing real.)

### `tools/orchestrator.mjs`

- `runStage`'s return value is now checked; a hard-gate stage
  (`intake`/`scaffold`/`sweep`/`render`/`preflight`) failing now halts the
  pipeline and marks every remaining stage `SKIPPED` instead of running
  them regardless.

### `scripts/export-handoff.mjs`

- `--verify` decoupled from forcing story mode — see Highlights.
- Flow mode's `--verify` now diffs `spec.md`, `spec.json`, and (when
  `--target=codashop-client` is requested and the prod root exists) every
  bundle file (`AGENTS.md`, `tokens.md`, `file-map.md`, `house-rules.md`,
  the bundle's own `spec.md`) — previously zero coverage.

### `scripts/check-version.mjs`

- Strips a leading `v`/`V` from `--version` before comparing — `--version
  v0.87.0` and `--version 0.87.0` are now both correctly detected as the
  same (already-claimed) version.
- Notes every run that signal 2 (`git log --all`) only sees locally-known
  refs; a release made on another worktree's branch and never fetched here
  is still invisible to it.

### `tools/figma-harness.mjs`

- Fixed the `getAllTokens` `ReferenceError` (missing import).
- `diff-tokens --figma-file <path>` now does a real diff — see Highlights.
  Fails loud (not the old exit-0 aspirational text) when `--figma-file` is
  omitted. `--json` output is now a single clean JSON blob with no
  interleaved prose, matching `harness-cli.mjs`'s convention.
- Header rewritten: no longer claims to be a "bidirectional MCP loop" (a
  detached `node` process cannot call an MCP tool) — it's a file-based diff
  engine; the Claude-driven MCP capture step that produces its input file
  is documented in the `design-harness` skill instead.

### `tools/figma-sync.mjs`

- `audit` command removed in favor of `figma-harness.mjs diff-tokens` (was
  a second, weaker copy of the same idea — REG-RETRO02's duplication
  pattern again, just for a whole command this time). Header corrected to
  describe what it actually does: a one-way Code Connect mapping generator.

### `.claude/skills/design-harness/SKILL.md`

- New §5 documenting the Claude-driven Figma MCP capture → file-based
  `diff-tokens` workflow.
- Corrected the opening claim (12 themes × 3 widths in one sweep) to match
  reality: 12-theme static sweep, 3-width render gate.
- New Gotchas: a ledger entry without a locking test can quietly reappear
  (this release's own root cause); two ledger writers, one lock
  (`tools/lib/ledger.mjs`); prototype colors are OKLCH-only, a Figma export
  is hex/rgb.
- `npm run retro -- --list` / `npm test` rows added to Quick Reference.

### `tests/` (new)

- 28 tests across 10 files (`node --test`, no new dependency) locking every
  fix above — unit tests for the pure helpers (`naming.mjs`,
  `component-tokens.mjs`, `ledger.mjs`'s concurrency guarantee) and CLI
  integration tests (spawning the real tools, asserting on real exit codes
  and output) for the rest. `npm run test` wired into `package.json`.

### `package.json`

- New `test` script (`node --test`).
