# Release Notes — v0.89.1

**Date:** September 2026
**Milestone:** `design-harness` skill trigger broadened to cover tooling work, not just component/story/theme work

---

## Highlights

- **The skill wasn't auto-loading for the exact work it documents.** v0.89.0's
  entire grade-A pass (editing `tools/*.mjs`/`scripts/*.mjs`, adding the
  `npm test` suite, checking `compound.mjs`/`retro.mjs` lessons) never
  triggered `design-harness`, because its description only covered
  component/story/theme-testing phrasing. The skill's own Gotchas and
  Quick Reference already covered this work — it just never got loaded for
  it.

## Changes

### `.claude/skills/design-harness/SKILL.md`

- Description now also triggers on: editing any `tools/*.mjs` or
  `scripts/*.mjs` harness/CLI script; running or adding to the `npm test`
  suite (`tests/`); checking accumulated lessons in
  `audits/regressions-log.json` or `audits/retro-ledger.json`
  (`compound.mjs`/`retro.mjs`) before starting work.
