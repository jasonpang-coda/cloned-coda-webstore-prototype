# Release Notes — v0.9.0

**Date:** June 2026  
**Milestone:** Sign-in flow rework, shared PlayerCard component, token system corrections

---

## Highlights

- **Reworked sign-in flow** — SIGN IN now opens a bottom sheet; the signed-in state shows the player's in-game avatar and a dedicated account popover.
- **Shared `PlayerCard` component** — single source of truth for the player identity card, used in both the account popover and the guest lookup result.
- **`--text-hyperlink-*` remap** — yellow is now the semantic default hyperlink colour across all components; the cascade specificity bug that caused components to render cyan is fixed.

---

## New components

### `SignInSheet.vue`
Bottom sheet opened from the navbar SIGN IN button (Figma 4863:14324). No dimming scrim — the page behind stays interactive.

- **"Sign in with COD:M"** — dark-fill button that runs the existing full-screen loader flow
- **"Check out as a guest"** — underline link that closes the sheet and scrolls to the `PlayerAccount` section
- Dismisses on Esc, tap-outside (document `pointerdown` listener), or clicking the × close button
- Same L3 frosted surface + slide-up motion as `CheckoutSheet`; shares z-index 4 (mutually exclusive with checkout)

### `AccountPopover.vue`
Scrim-less popover opened by tapping the in-game avatar (Figma 5199:12187). Anchored 8px below the navbar bottom, right-aligned with the avatar.

- Shows `PlayerCard` (with avatar) + a "Sign out" underline link
- Dismisses on Esc, tap-outside, or scroll (navbar hides on scroll-down; popover closes to stay anchored)
- Sign out row: top divider, 14px sentence-case label, 20px logout icon
- z-index 5 (above all other overlays)

### `PlayerCard.vue`
Reusable player identity card. Props: `name` (required), `idMasked`, `level`, `rank`, `avatarSrc` (optional — omits the avatar when absent).

- 48×48 circular avatar (`--size-img-l`, `--radius-badge-full`) when `avatarSrc` is provided
- Ghost surface + hairline border (`--surface-ghost`, `--border-soft`)
- Used by `AccountPopover` (avatar supplied) and `PlayerAccount` found state (avatar supplied)
- **Do not duplicate this markup inline.** Use `<PlayerCard>` wherever a player identity card appears.

## Sign-in flow changes

### `NavBar.vue`
- SIGN IN button now calls `openSignInSheet()` instead of `startSignIn()` directly
- Signed-in avatar is now the player's in-game image (`assets.content.avatar`, `Avatar.webp`) instead of the generic Material `account_circle` icon
- Avatar tap calls `openAccountMenu()` instead of `signOut()`

### `NavDrawer.vue`
- Removed the sign-in / sign-out footer entirely — the drawer is now a navigation menu only
- Removed `useAuth` and `useStoreAssets` imports (no longer needed)

### `useAuth.js`
New state and functions added to the singleton:

| Addition | Type | Description |
|---|---|---|
| `signInSheetOpen` | ref(Boolean) | Controls SignInSheet visibility |
| `accountMenuOpen` | ref(Boolean) | Controls AccountPopover visibility |
| `openSignInSheet()` | fn | No-op if already signed in |
| `closeSignInSheet()` | fn | Closes the sign-in sheet |
| `openAccountMenu()` | fn | Opens the account popover |
| `closeAccountMenu()` | fn | Closes the account popover |

`signOut()` now also calls `closeAccountMenu()`.

### `useStoreAssets.js`
- Registered `Avatar.webp` (already in `src/stores/codm/img/content/`) as `content.avatar`

## `PlayerAccount.vue` changes

- Instruction panel is now **hidden by default** — the chip tabs (Find UID / Find Player ID / Find Nickname) are always visible, but the panel expands only when a chip is clicked (and collapses if the same chip is clicked again)

- Found state now uses the shared `<PlayerCard>` component with the player's avatar

### `--text-hyperlink-*` remap

The hyperlink family is now remapped in `themes/codm.css` via an `html[data-theme="codm"]` selector (specificity 0,1,1 — beats `semantics.css` `:root` at 0,1,0):

| Token | Before | After |
|---|---|---|
| `--text-hyperlink-default` | cyan (`secondary-main`) | **yellow** (`primary-main`) |
| `--text-hyperlink-hover` | lighter cyan | lighter yellow (`primary-strong`) |
| `--text-hyperlink-focused` | lighter cyan | lighter yellow (`primary-strong`) |
| `--text-hyperlink-pressed` | even lighter cyan | even lighter yellow (`primary-heavy`) |
| `--text-hyperlink-inverse` | yellow | **near-white** (`neutral-inverse`) |

All 17 component usages of `--text-hyperlink-inverse` updated to `--text-hyperlink-default` across 10 files.

**Specificity note:** the theme file is imported before `semantics.css`. For overrides targeting a property that `semantics.css` also defines at `:root`, use `html[data-theme="codm"]` (not `[data-theme="codm"]`) to ensure the theme wins regardless of import order.
