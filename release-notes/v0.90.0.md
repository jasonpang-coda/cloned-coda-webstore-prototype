# Release Notes — v0.90.0

**Date:** September 2026
**Milestone:** Component library completed — full story/spec coverage across every reusable UI component, plus the cross-store token and container-query defects that surfaced along the way

---

## Highlights

- **The component library goes from 8 stories to 57.** Every reusable UI
  component (cards, overlays, navigation, layout, carousels, controls,
  atoms, content blocks) now has a real, full-depth library story — real
  props read from source, meaningful variants, notes, and usage rules. The
  library viewer, harness render/token gates, and `docs/Handoff` specs now
  cover the whole component set, not just a sample.
- **A real containment bug in `@coda/harness-kit`'s `StoryStage`.** The
  package's own CSS was never imported into the app, so the story stage had
  no `container-type`/positioning/clipping at all — any overlay component
  using `position: fixed` (Snackbar's responsive mode, sheets, drawers)
  rendered outside the stage, in the middle of the real page. Fixed by
  importing the stylesheet and adding `contain: paint` (which
  `container-type` alone does not provide — only layout containment, not a
  fixed-position containing block).
- **Six pre-existing component defects, found and fixed.** Writing stories
  against components that had never been exercised by the harness surfaced
  real bugs: `@media` used instead of `@container` (BaseSheet, BuyNowBar),
  and missing `var()` fallbacks for tokens that only a few store themes
  define (`--x-fx-metal/plastic/carbon-*` on SkuCard's material variants,
  `--x-bg-action-signin`, `--x-bg-loyalty-banner`). `npm run harness test
  all` is fully green for the first time.
- **A harness-cli parsing bug fixed.** `title`/`id`/`componentFile`
  extraction was a first-match regex over the whole `.stories.js` file, not
  scoped to the `defineStory({...})` call — a story with local demo data or
  a helper import above `defineStory()` could have the wrong component
  attributed to it, silently sweeping the wrong file's tokens.

## Changes

### `src/library/stories/`

- 49 new story files across Cards, Overlays, Navigation, Layout, Carousels,
  Controls, Atoms, and Content — each read from the real component's props/
  slots, with 2–4 meaningful variants and real usage notes/rules.
- `src/library/story.js` / `tools/harness-cli.mjs`: added a `tokenFree: true`
  story field so a genuinely token-free component (MaterialIcon, Media, Span)
  can acknowledge that explicitly instead of failing `NO_TOKENS_TESTED` with
  no opt-out.

### `packages/harness-kit`

- `src/vue/components/StoryStage.vue`: `.stage-host__screen` now sets
  `contain: paint` alongside `container-type: inline-size` — the former
  actually establishes the containing block for `position: fixed`
  descendants; the latter only does so for `position: absolute`.
- `tools/harness-cli.mjs`: `title`/`id`/`componentFile` extraction now
  scoped to the `defineStory({...})` argument block via a new
  `extractBalancedCallBlock()` helper, mirroring the existing
  `extractBalancedArrayBlock()` used for `variants:`.

### `src/library/StoryStage.vue`, `vite.config.js`

- Import `@coda/harness-kit/vue/style.css` (with a matching Vite alias for
  the subpath) so the harness-kit package's own scoped CSS actually loads.

### Component fixes surfaced by the new story coverage

- `SkuCard.vue`: metal/plastic/carbon-fibre material variants fall back to
  the card's own default fill/border tokens outside Codashop (the only
  store with those tokens defined).
- `BaseSheet.vue`, `BuyNowBar.vue`: desktop (≥801px) breakpoints converted
  from `@media` to `@container`.
- `BuyNowBar.vue`, `ClaimGiftSheet.vue`, `PageSignInSection.vue`,
  `SignInSheet.vue`, `InfoStepFooter.vue`: added a fallback for
  `--x-bg-action-signin`.
- `PurchaseSheet.vue`: added a fallback for `--x-bg-loyalty-banner`.
- `DeviceFrame.vue`: the responsive device overlay now sets
  `container-type: inline-size` so the new `@container` desktop breakpoints
  above have an ancestor to resolve against.

## New additions

- `docs/Handoff/components/<id>/spec.md` generated for all 49 new stories
  (`node scripts/export-handoff.mjs --story`), verified in sync via
  `--verify`.
