# Release Notes — v0.94.0

**Date:** September 2026
**Milestone:** Four new component primitives (Card, SkuBanner, LinkRow, GiftTaskBanner) extracted from Order Complete, replacing its inline markup

---

## Highlights

- **`Card.vue`** — the plain bordered L2 "sheet" content pane (border/background matching `BaseSheet`'s own container tier, but static — no scrim, no transition). Extracted from the two identical `.order-complete__card` wrappers (Order Summary, Need Help).
- **`SkuBanner.vue`** — a read-only L1 pane summarizing one SKU (art + amount + bonus breakdown + optional corner tag), using the same mask-composite gradient-border ring as `SkuCard`/`BundleItem`. Deliberately not built on `SkuCard`/`SkuImageCard` — both are full interactive product cards (click-to-checkout, hover/press states); this is purely presentational, same contract as `TransactionCard` (amount/bonus arrive pre-formatted from the caller).
- **`LinkRow.vue`** — a full-row tappable external link-out (label + trailing chevron), same gradient-border technique as `SkuBanner`. Deliberately not built on `ListItem` — `ListItem` has no gradient-border hook and renders on a flat `--li-bg`.
- **`GiftTaskBanner.vue`** — `CategoryBanner` wrapped with the task-gated gift's step-driven action (a `ToggleSwitch` for the push step, a `Button` tertiary CTA pill otherwise). Presentational only — the caller owns which step is active. `App.vue`'s own Gifts-category banner uses a near-identical pattern but adds a glow animation this component doesn't have yet, so it stays a one-off consumer, not migrated.
- **`Button.vue`'s tertiary variant** gained three new override hooks — `--btn-border`, `--btn-bg-hover`, `--btn-hover-filter` — so `GiftTaskBanner`'s CTA pill (a non-default border color + flat hover fill instead of a brightness filter) didn't need a bespoke button.
- **`OrderCompletePage.vue`** now composes all four primitives instead of inline markup: its primary/secondary CTAs use `Button`, the gift banner uses `GiftTaskBanner`, the Order Summary/Need Help panes use `Card`, the SKU summary uses `SkuBanner`, and the Need Help rows use `LinkRow`. Scoped CSS dropped from ~280 lines to ~115.

## Changes

### `src/components/Button.vue`

- `.btn--tertiary`'s border now reads `var(--btn-border, var(--x-border-action-default))` instead of the token directly.
- `.btn--tertiary:hover` now applies `background: var(--btn-bg-hover, var(--btn-bg, transparent))` and `filter: var(--btn-hover-filter, brightness(1.2))`, both backward-compatible no-ops for every existing tertiary consumer.

### `src/components/OrderCompletePage.vue`

- Primary/secondary hero and summary CTAs replaced with `Button` (`variant="primary"`, `size="large"`, override hooks for the secondary's neutral fill).
- Gift banner block replaced with `GiftTaskBanner` (`tone="success"`, `mode` driven by `giftTaskStep`).
- Order Summary and Need Help panes replaced with `Card`.
- SKU summary block replaced with `SkuBanner`.
- Need Help link rows replaced with `LinkRow`.
