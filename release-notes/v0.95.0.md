# Release Notes — v0.95.0

**Date:** September 2026
**Milestone:** Component library store selector is now a scalable dropdown; the whole icon system migrated off the frozen classic Material Icons package onto the actively-maintained Material Symbols set

---

## Highlights

- **Component library store selector** (`LibraryViewer.vue`) — the "Theme" control switched from a horizontal row of segmented buttons (one per store, ~12 and growing) to a native `<select>` dropdown. The old row didn't scale as more stores were added; the dropdown does, at no cost to keyboard/native-select accessibility.
- **Icon system migrated to `@material-symbols/svg-400`**, replacing `@material-design-icons/svg` (a "classic" Material Icons set frozen years ago, missing newer icons like `contextual_token`). `MaterialIcon.vue`'s public API is unchanged — `name`/`variant`/`size` props and every existing `name="..."` call site are untouched; only the underlying `?url` imports moved packages.
  - 2 icons renamed with an identical glyph: `expand_less`→`keyboard_arrow_up`, `expand_more`→`keyboard_arrow_down`.
  - 3 icons discontinued in Material Symbols, replaced with the closest semantic match: `install_mobile`→`system_update_alt` (PWA install CTA), `question_answer`→`forum` (Footer support pill), `highlight_alt`→`frame_inspect` (Inspect-elements tool).
  - Dropped an unused `discount` entry found dead in the `ICONS` map (no call site referenced it).
  - `contextual_token` (added last release as a hand-fetched local SVG stopgap) now resolves from the real package like every other icon.
  - 4 components that imported icons directly (bypassing `MaterialIcon.vue`) — `CategoryCatalog.vue`, `MilestoneRewards.vue`, `BestSellerCard.vue`, `MilestoneRewardCard.vue` — repointed to the new package.
  - `@material-design-icons/svg` fully removed from `package.json`/lockfile.

## Changes

### `src/library/LibraryViewer.vue`

- Theme `<div class="lib__seg">` button row replaced with a `<select class="lib__select">`.
- New `.lib__select` style — matches the existing segmented-control chrome (rounded dark fill, custom chevron) rather than a browser-default select.

### `src/components/MaterialIcon.vue`

- All ~57 icon imports repointed from `@material-design-icons/svg/<round|outlined>/<name>.svg` to `@material-symbols/svg-400/<rounded|outlined>/<name>.svg`. `variant="round"` is kept as the public prop value (maps internally to the package's `rounded` folder) so no call site changed.

### Docs

- `docs/component-breakdown.md`, the 5 `docs/Handoff/*/component-breakdown.md` files, `docs/Handoff/components/material-icon/spec.md` (regenerated via `node scripts/export-handoff.mjs --story material-icon`), and `.claude/skills/web-store-fe/SKILL.md` updated to reference `@material-symbols/svg-400` instead of the retired package.
