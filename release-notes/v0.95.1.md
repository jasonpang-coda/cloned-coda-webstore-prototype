# Release Notes — v0.95.1

**Date:** September 2026
**Milestone:** PWA install icon swapped to `download_for_offline`; fixed a blank-icon regression from v0.95.0's Material Symbols migration

---

## Highlights

- **PWA install icon** (`install_mobile` in `MaterialIcon.vue`'s `ICONS` map) now uses `download_for_offline` instead of `system_update_alt` — a closer match for the "add to home screen" action across all 4 call sites (App.vue ×2, NavDrawer.vue, PlayerAccount.vue).
- **Fixed a real regression from v0.95.0**: the `discount` icon was dropped as dead code during the Material Symbols migration, on the assumption no call site referenced `name="discount"` in any template. It's actually consumed as data — `icon: 'discount'` in 3 stores' (`codm`, `diabloimmortal`, `zzz`) trust-bar features config — so it was rendering as a blank glyph in production since that release. Restored under the same `round/discount` key, now backed by Material Symbols' `sell` (closest available price-tag glyph, since Material Symbols has no direct `discount` icon).

## Changes

### `src/components/MaterialIcon.vue`

- `installMobile` import repointed from `system_update_alt.svg` to `download_for_offline.svg`.
- Re-added `discount` import (now from `@material-symbols/svg-400/rounded/sell.svg`) and its `'round/discount'` `ICONS` entry.

## Verification

- `npm test` — 29/29 passing.
- Visual check: PWA install CTA banner shows the new download-into-tray glyph; "Exciting Promotions" trust-bar item (COD:M store) shows the price-tag glyph instead of a blank circle.
