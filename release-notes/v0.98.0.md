# Release Notes — v0.98.0

**Date:** September 2026
**Milestone:** Bidirectional oklch ↔ hex colour conversion tool, plus a first Codashop Figma-tokens export

---

## Highlights

- **`oklchToHex` added to `generators/color.mjs`.** The module previously only converted `hex → oklch` (for ingesting style-guide seed colours). It now converts the other direction too — same zero-dependency OKLab/OKLCH matrix math, plus sRGB gamut-mapping: an out-of-gamut oklch value has its chroma binary-searched down at fixed L/H (rather than naive per-channel clipping, which would shift hue/lightness) — matching the gamut-mapping method the Python `web-store-figma-tokens` skill already used via `coloraide`.
- **`tools/color-cli.mjs`** — a thin CLI wrapper (`to-oklch <#hex>` / `to-hex "oklch(l c h)"`) so either conversion is a one-line terminal lookup, no skill invocation or Python dependency needed.
- **First Codashop Figma-tokens export.** `docs/style-guides/codashop/codashop-figma-tokens.json`, generated by the `web-store-figma-tokens` skill's script against `src/tokens/ds/themes/codashop.css` — verified against the bundled reference template (10/10 collections, matching token counts, zero leaked `oklch()`/`color-mix()`/`var()` values).

## Fixes

- Found and fixed, outside this repo: the `web-store-figma-tokens` skill's `build_figma_tokens.py` regexes were written against a pre-`--x-`-prefix theme CSS and silently failed (`KeyError: 'neutral-1000'`) against every current store theme, all of which now use the `--x-` prefix (`--x-ref-`, `--x-palette-`, `--x-sys-`, `--x-border-`, `--x-radius-`). Patched to accept the prefix optionally, so it works for every store again, not just Codashop. (Lives at `~/.claude/skills/web-store-figma-tokens/`, untracked by this repo's git.)
