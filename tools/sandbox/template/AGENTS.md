You are composing a new page idea for the **{{STORE_LABEL}}** web store, using

## What's here

- `vendor/` — **read-only.** Real components (`vendor/components/`), real
  composables, the real token cascade (`vendor/tokens/`), and each vendored
  store's real data (`vendor/stores/<key>/` — `{{STORE}}` is the primary
  one). Never edit these — if you need a behavior they don't have, work
  around it in your own page, don't patch the vendored file.
- `catalog.json` — every curated component's props/variants/states/rules and
  its full resolved token contract for **{{STORE_LABEL}}**. Read this first —
  it's your reference for what each component accepts and which tokens it
  already uses.
- `src/page.example.vue` — a working starting example. Edit it directly, or
  add `src/page.<your-idea>.vue` and update the `import Page from …` line in
  `src/main.js` to point at it.
- `guardrail/` — a linter (`npm run lint`) that checks **only your `src/`
  pages**, not the vendored components. Run it before you consider anything
  done.

## Workflow

1. Read `catalog.json` to see what's available and how each component is
   used.
2. Compose your page in `src/*.vue`, importing real components via the `@/`
   alias, e.g. `import SkuCard from '@/components/SkuCard.vue'`.
3. `npm run lint` — fix everything it reports. It will not pass silently;
   self-correct and re-run until it's clean.
4. `npm run dev` to view it.

## Hard rules (read `ruleset/` for the full versions)

Two rules specific to this sandbox, not in the real repo's own checklist
(the real repo doesn't have a static-scanner guardrail or a per-store bundle
choice the same way):

- **Never build a token name by string interpolation**
  (`` `--x-bg-${thing}` ``) — the guardrail's scanner cannot see through it,
  so a broken token would pass silently. Use a literal lookup object instead.
- **Prefer composition over invention.** If a curated component almost does
  what you want, compose it with layout (Grid/Span/flex) rather than copying
  its internals into a new component.
